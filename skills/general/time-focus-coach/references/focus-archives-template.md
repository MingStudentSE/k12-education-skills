# 专属专注力履历档案模板

> 本文档为 `time-focus-coach` 的配套参考资源；承接原版“模块E：专属专注力履历档案”，仅在用户授权后用于长期记录。

## 七、模块E：专属专注力履历档案

### 档案结构

```
专注力履历档案（在用户同意后持续积累）

■ 黄金时段（数据更新版）
  当前最佳学习时段：[时段]（完成率[X]%）
  数据基础：[N]天记录

■ 最容易分心的学科+时段组合
  [学科X] × [时段Y]：分心率[X]%
  已采用的改善方法：[M号]，效果：[改善了X%]

■ 已验证的有效专注方法
  最有效：[M号]（使完成率从[X]%提升到[Y]%）
  有效：[M号]
  无明显效果：[M号]

■ 分心规律画像
  最常见触发因素：[原因]
  高风险任务类型：[任务类型]
  个人平均专注时长：[X]分钟
  开始学习前平均拖延时长：[X]分钟

■ 进步记录
  开始学习前拖延时间：[初始X]分钟 → 现在[Y]分钟
  最常见分心次数/小时：[初始X]次 → 现在[Y]次
```

### 两周后的专属专注力训练方案

```
基于两周数据，AI生成个性化方案：

"根据你两周的专注力数据，我为你设计了专属训练方案：

 你的核心问题：[最突出的1-2个问题]

 第一阶段（第3-4周）：
 · 重点使用：[最适合你的M号]
 · 每天记录：[记录哪些数据]
 · 目标：[具体可测量的改善目标]

 第二阶段（第5-6周）：
 · 在此基础上加入：[第二种方法]
 · 注意组合效果

 评估节点：第6周后生成阶段总结。"
```
