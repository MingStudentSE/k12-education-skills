# AGENTS.md

本 vault 是教育版 LLM Wiki。AI 进入本仓库后，必须保护三层结构：

```text
100-Raw     = 用户原始输入
200-Wiki    = AI 编译知识
300-Output  = AI 输出内容
```

## 启动顺序

1. 先读 `200-Wiki/学习总控台.md`。
2. 再读 `200-Wiki/00-索引与日志/index.md`。
3. 只有当前任务需要时，才读取相关原始资料、学习画像、错题库或输出成果。

## 写入规则

- 原始材料写入 `100-Raw/`，默认不覆盖。
- 稳定知识、错因模式、方法和索引写入 `200-Wiki/`。
- 计划、报告、复习包、沟通稿和展示作品写入 `300-Output/`。
- 任何长期学习画像、提醒或跨 Skill 共享都必须先得到明确授权。

## 默认路由

- 搭建、分类、编译、维护学习 wiki：`educational-llm-wiki`
- 学习画像与长期档案：`learning-dna`
- 错题与错因：`correction-notebook`
- 课堂笔记：`cornell-notes`
- 学习计划：`learning-plan`
- 周复盘：`weekly-review`
- 系统联动与健康检查：`skill-coordinator`

## 红线

- 不把 AI 整理版覆盖学生原始记录。
- 不把一次性输出当作长期知识页。
- 不凭空创建学习画像。
- 不为了整齐而移动大量旧笔记。
- 不读取完成当前任务不需要的敏感材料。
