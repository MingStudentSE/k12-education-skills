# 真实成熟仓库适配模式

> 当目标仓库不是空仓库、而是一个已在深度使用的成熟教育/应试仓库时，`educational-llm-wiki` 的模式 B（适配）和模式 E（健康检查）需要一套更强的判据和纪律。本文基于一个真实高考仓库（20000+ 文件、Game 化路由、语义命名）的双盲测试校验总结，作为 `assets/vault-template/`（空仓库模板）之外的**第二个范例：成熟定制仓库的语义目录**。

---

## 一、成熟仓库识别判据

满足以下**任一**，即按"成熟定制仓库"处理，**禁止套用空仓库的数字前缀模板**（否则会造成目录翻倍、命名冲突）：

1. 根目录存在 `AGENTS.md` 且 > 50 行（有仓库宪法/路径规则）
2. 存在本地顶层路由 Skill（如 `gaokao-life`、`game-wiki` 等非 K12 标准 Skill）
3. 单层目录文件数 > 1000（如 `100-Raw/某转写目录` 上万文件）
4. 子目录用**语义命名**（如 `学科`、`索引`、`复盘`），部分仓库加 emoji 前缀——遇到 emoji 前缀即判为已定制（注：emoji 是定制风格，**非通用推荐**，通用结构见 `recommended-directory-structure.md`）

**判据命中后，模式 B 的第一步必须是"输出语义目录 ↔ skill 三层语义映射表"，而非"补建数字前缀目录"。**

---

## 二、成熟仓库目录结构范例（脱敏）

```text

├── AGENTS.md                    # 仓库宪法：路径规则 + 顶层路由 + 最小记忆启动包
├── 100-Raw/                     # 原始证据层（顶层用数字前缀，子层语义命名）
│   ├── Journal/                 # 每日学习记录 YYYY-MM-DD.md
│   ├── 学校考试/ 作业/ 原始资料/   # 按来源分类的原始证据

│   ├── index.md  log.md         # 索引日志放本层根，不强制塞进 00-子目录
│   ├── 索引/                     # = 模板的 00-索引与日志（含知识点总索引 + 资料处理台）
```

## 三、五条通用目录模式（可复用）

1. **数字前缀（100/200/300）只用于顶层，子层用语义命名**——兼顾"AI 路由靠数字识别顶层"和"人类靠语义导航子层"。emoji 前缀是部分仓库的定制风格，**非通用推荐**。
2. **`index.md` / `log.md` 放 200-Wiki 根，不强制塞进 `00-索引与日志/` 子目录**——减少一层路径，降低断链。
3. **OCR/转写素材（mineru-md 类）单独成目录 + 配独立索引页**：体量可达万级（实测 10000+ 文件、300MB+），若无可索引的汇总页，AI 无法定位"某知识点的同类题在哪个转写文件"。索引页放 `200-Wiki/资料/`，记录 `题源 → 转写文件路径 → 知识点标签`。
4. **加 `999-Assets/` 层**放已稳定资产（题库快照、固化模板），区别于 `100-Raw/` 的原始证据——空仓库模板缺这一层，成熟仓库建议采纳。
5. **成熟仓库必须有"顶层路由 Skill + 最小记忆启动包"**：路由 Skill（如 `gaokao-life`）决定每轮主控权；启动包（如 `玩家状态 + 学习画像` 两文件）是每次对话第一入口。`educational-llm-wiki` 应**识别并服从**本地路由，不另起路由、不抢主控。

## 四、语义命名 ↔ 数字前缀映射原则

当 skill 的默认模板（数字前缀）遇到成熟仓库（语义命名）时，**输出映射表，不并列创建两套目录**：

| 成熟仓库语义目录                         | 对应 skill 模板目录                      | 入口文件              | 处理       |
| -------------------------------- | ---------------------------------- | ----------------- | -------- |
| `200-Wiki/索引/`                   | `200-Wiki/00-索引与日志/`               | index.md / 知识点总索引 | 复用现有，不新建 |
| `200-Wiki/学科/<📐-数学>/🧠-知识点/`    | `200-Wiki/20-学科知识/`                | 学科知识总图            | 复用现有     |
| `200-Wiki/复盘/🧭-阶段分析/👤-学习画像.md` | `200-Wiki/10-学习画像/`                | 学习画像              | 复用现有     |
| `200-Wiki/系统/`                   | `200-Wiki/70-模板与规则/`               | 多 Skill 协作规则      | 复用现有     |
| `300-Output/每日/`                 | `300-Output/10-学习计划/` + `90-临时生成/` | 作战卡 / today-plan  | 复用现有     |

**原则**：遇到 emoji + 语义命名（如 `📐-数学`、`🧠-知识点`）视为已定制，**原样保留**，只在 `AGENTS.md` 追加一列 skill 语义映射。

---

## 五、服从本地顶层路由

当仓库已有本地顶层路由 Skill（如 `gaokao-life` → `game-wiki / learning-system / goal-management / perspective-roundtable`）时：

- `educational-llm-wiki` **不接管主控权**，只负责：结构判断、索引/日志维护、健康检查、Obsidian skills 安装。
- 不生成学习计划、不改玩家状态、不做错题训练——这些交给本地路由选定的主控 Skill。
- 在 `AGENTS.md` 追加规则片段时，声明"本 skill 从属于本地路由，只做结构/编译/维护纪律"。

## 六、健康检查增强：旧路径体检（模式 E 补充）

成熟仓库常见的隐性事故是**目录重命名后未批量更新引用**。模式 E 增加可执行的"旧路径前缀体检"：

```bash
# 统计已不存在的旧目录前缀引用（物理目录若是 100/200/300，则 01/02/03 前缀的引用全是断链）
V="<vault 路径>"
for p in "01-Raw" "02-Wiki" "03-Output"; do
  echo "$p: $(grep -rc "$p" "$V" --include='*.md' 2>/dev/null | awk -F: '{s+=$2} END{print s}') 次"
done

# 物理目录确认
ls -d "$V"/[0-9]*-*

# index.md 自身的旧路径引用
grep -c "01-Raw\|02-Wiki\|03-Output" "$V/200-Wiki/index.md"
```

**判定**：若旧前缀引用 > 100 且物理目录已改名，判定为"路径别名损坏"，列为必修健康问题。区分三类引用：普通文本、wikilink `[[01-Raw/...]]`、frontmatter `source:` 字段——批量替换策略不同。

## 七、反面案例：路径重命名纪律（必修）

**真实事故**（来自被测仓库）：曾把物理目录 `01-Raw/02-Wiki/03-Output` 重命名为 `100-Raw/200-Wiki/300-Output`，但**未批量更新 wiki 内引用**，导致 `index.md`、`log.md`、学科页 wikilink、转写素材 frontmatter `source:` 字段出现**数万处断链**（实测 `02-Wiki` 残留引用 58000+ 次）。

**纪律（写入编译流程）**：

1. 重命名任何已有引用的目录前，**必须先 `grep -rc` 全库扫描引用数量**。
2. 若引用 > 0，必须**同步批量更新引用**（普通文本用 sed，wikilink/frontmatter 单独处理），否则视为**破坏性操作**，禁止执行。
3. 索引文件（`index.md` / `log.md` / 知识点总索引）内的 wikilink**必须用当前物理路径**，禁止用别名前缀。
4. 若已发生损坏，修复优先级：先修 `index.md` / `log.md` / 知识点总索引（AI 入口），再修 frontmatter `source:`，最后修学科页正文。

## 八、对 SKILL.md 本身的改进指向

基于本次真实仓库测试，`SKILL.md` 与其他 reference 可考虑增强（供后续迭代）：

- 模式 B：加入"成熟仓库判据"（见本文第一节），命中后走映射表而非套模板。
- 模式 E：加入"旧路径前缀体检"可执行命令（见本文第六节）。
- `compile-workflow.md`：加入"路径重命名纪律"（见本文第七节）+ "若已有总索引/日志，更新既有文件，不创建平行 index/log/source-map"。
- 默认目录模板说明：标注"数字前缀目录名仅用于空仓库；成熟仓库必须先输出映射表"。
