# 推荐目录结构（通用版）

> educational-llm-wiki 推荐的**通用** K12 教育 LLM Wiki 目录结构。任何新建或适配的仓库都可参考此结构。顶层用数字前缀（AI 路由识别），子层用语义命名（人类导航），不使用 emoji 前缀，不含特定仓库的个性化目录。

---

## 结构总览

```text
Root/
├── AGENTS.md                    # 仓库宪法：路径规则 + 顶层路由 + 最小记忆启动包
│
├── 100-Raw/                     # 原始证据层（学生/家长/老师的原始输入，默认不改写）
│   ├── Journal/                 # 每日学习记录（YYYY-MM-DD.md）
│   ├── 学校考试/                # 考试原卷、答题卡
│   ├── 作业/                    # 作业原文
│   └── 原始资料/                # 外部教辅、讲义、文章原文
│
├── 200-Wiki/                    # 编译知识层（AI 维护的稳定知识）
│   ├── index.md                 # 知识库总索引（放本层根）
│   ├── log.md                   # 维护日志（放本层根）
│   ├── 索引/                    # 知识点总索引、资料处理台、source-map
│   ├── 学科/                    # 学科编译知识
│   │   └── <学科>/              # 数学 / 语文 / 英语 / 物理 / 历史 / 地理 / 政治
│   │       ├── 知识点/          # 概念定义、原理、例题
│   │       ├── 解题方法/        # 题型方法、思路模板
│   │       ├── 错题/            # 错因模式、顽固弱项
│   │       ├── 错题资料缺口/    # 待补资料的错题登记
│   │       ├── 练习题/          # 分知识点练习
│   │       └── 试卷/            # 历次试卷分析
│   ├── 复盘/                    # 阶段分析、学习画像、仪表盘、每次考试复盘
│   ├── 系统/                    # 规则、路由、多 Skill 协作
│   ├── 资料/                    # 题源地图（指向原始资料）
│   └── 模板/                    # 笔记、页面模板
│
├── 300-Output/                  # 输出成果层（面向具体任务的交付物）
│   ├── 每日/                    # 每日作战卡、today-plan（高频）
│   ├── 每周/                    # 周报
│   ├── 每月/                    # 月报
│   ├── 每学期/                  # 学期计划与总结
│   ├── 每学年/                  # 学年规划
│   ├── 报告/                    # 阶段报告
│   ├── 视图/                    # 可视化看板
│   ├── 系统体检/                # 知识库健康检查报告
│   ├── 系统评估/                # 学习系统评估
│   ├── 归档/                    # 已完成归档
│   ├── 导出/                    # 对外交付导出
│   └── 倒计时/                  # 考试倒计时等时间视图
```

## 关键设计决策（通用）

| 决策                                      | 理由                                                       |
| --------------------------------------- | -------------------------------------------------------- |
| **顶层用数字前缀**（100/200/300）                | AI 路由靠数字识别三层；数字排序稳定，不依赖具体语义                              |
| **子层用语义命名**（学科/复盘/索引，不用 emoji 前缀）       | 人类靠语义导航；纯语义命名通用、可移植，不绑定视觉风格                              |
| **index.md / log.md 放 200-Wiki 根**      | 减少一层路径，降低断链风险；不强求塞进 `00-索引与日志/` 子目录                      |
| **学科下统一六子类**（知识点/解题方法/错题/错题资料缺口/练习题/试卷） | 覆盖学科编译知识的稳定维度，可链接互通；通用适用于各学科                             |
| **AGENTS.md 作为宪法**                      | 声明路径规则 + 顶层路由 + 最小记忆启动包，是 AI 进入仓库的第一入口                   |
| **三层职责严格分离**                            | 100-Raw 只放原始证据（不改写）、200-Wiki 只放编译知识、300-Output 只放交付物；不混层 |

---

## 三层职责边界

| 层             | 职责   | 放什么                      | 不放什么                       |
| ------------- | ---- | ------------------------ | -------------------------- |
| `100-Raw/`    | 原始证据 | 学生原答、原卷、作业原文、外部资料原文      | AI 编译的知识、交付物               |
| `200-Wiki/`   | 编译知识 | 知识点、解题方法、错因模式、学习画像、索引、规则 | 原始证据、一次性交付物                |
| `300-Output/` | 输出成果 | 作战卡、计划、报告、复习包            | 原始证据、稳定知识（稳定知识回填 200-Wiki） |

---

## 适配已有仓库时的映射原则

当目标仓库已有自己的命名时，**输出映射表，不并列创建两套目录**：

| 已有仓库常见命名                              | 对应本结构                       | 处理     |
| ------------------------------------- | --------------------------- | ------ |
| `200-Wiki/索引/` 或 `200-Wiki/00-索引与日志/` | `200-Wiki/索引/` + 根 index.md | 复用，不新建 |
| `200-Wiki/学科/<某学科>/`                  | `200-Wiki/学科/<学科>/`         | 复用     |
| `200-Wiki/复盘/学习画像.md`                 | `200-Wiki/复盘/` 下学习画像        | 复用     |
| `300-Output/每日/作战卡`                   | `300-Output/每日/`            | 复用     |

**铁律**：遇到已存在的语义命名目录视为已定制，**原样保留**，只在 `AGENTS.md` 追加 skill 三层语义映射列，不重命名、不并列创建。

---

## 服从本地路由（若仓库已有）

若仓库已有本地顶层路由 Skill（非 K12 标准 Skill），educational-llm-wiki **不抢主控**，只负责：结构判断、索引/日志维护、健康检查、Obsidian skills 安装。学习计划、错题训练等交给本地路由选定的主控 Skill。

---

## 可选定制（非通用，按需）

以下为部分仓库的定制实践，**不作为通用推荐**，仅在确有需要时采纳：

- **`999-Assets/`**：放已稳定资源资产（题库快照、固化模板），区别于 100-Raw 原始证据。
- **转写素材目录**：OCR/PDF 转写中间产物体量大时，单独成目录并配索引页（题源→文件→知识点）。

这些定制遇到时按"映射原则"处理，不强加到通用结构。
