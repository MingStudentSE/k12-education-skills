# 学习区原则

> 本文件随 `science-solving-four-steps` 单个 skill 安装，用于单题训练时控制变式难度。

## 单题训练的学习区

```text
熟悉区：原题或同套路题太熟，只是在重复步骤
学习区：大部分结构熟悉，但有一个关键意外点
挫败区：条件、概念、方法都陌生，只能等答案
```

单题掌握训练的目标不是“越难越好”，而是让学生在可承受挑战中长出迁移能力。

## 85%规则

变式题和复测题建议保持：

```text
85%：题目结构、旧知识或解题入口是熟悉的
15%：改变一个条件、问法、图形、情境或方法要求
```

## 变式调参

- 太容易：改条件、改问法、要求换方法解释
- 刚刚好：保留一个意外点，要求学生解释第一入口
- 太困难：退回原题结构，只改数值或先补前置知识

## 掌握验证

```text
当天：遮住答案独立重做
1-3 天后：做一道同类变式
7 天后：只看题型信号，口述解题入口
```
