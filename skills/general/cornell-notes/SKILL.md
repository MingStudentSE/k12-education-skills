# 📝 康奈尔笔记 SKILL

> 把课堂笔记整理成可复习、可自测、可在错题/费曼/复习场景中被按需唤醒的康奈尔三栏笔记。

## 什么时候使用我

- 学生发来课堂原始笔记、教材页、板书截图、手写照片或课后回忆，请求“整理这页笔记/提炼今天学的内容”。
- 用户问“康奈尔笔记怎么做”“帮我从笔记出题”“把这节课变成复习卡/线索问题/底部总结”。
- 复习、错题分析或费曼测试需要调取已授权的笔记锚点，帮助学生主动回忆而不是直接看答案。
- 需要把笔记按学科、课题、日期建立索引，或在用户允许时生成笔记健康报告、跨学科关联。

## 什么时候不要使用我

- 任务不是课堂笔记整理、知识沉淀或复习卡生成；先建议更合适的技能或普通回答。
- 只有零散主题、没有任何笔记材料或学生回忆；先给最小补充模板，不臆造课堂内容。
- 用户只要当前题目答案且不想整理笔记；可快速回答当前问题，不强行进入完整笔记流程。
- 未获授权时，不写入笔记DNA、不创建提醒、不跨技能共享笔记摘要。

## 核心流程

1. **确认输入**：识别学科、课题、日期、来源与材料质量；缺材料时请学生补充“右栏原始记录/教材页/老师强调/自己不懂处”。
2. **先保留原意**：不要把学生原笔记改成新教材；先提取知识点、例题、定义、公式、易错点和疑问。
3. **生成固定版式**：输出课题/日期/学科、左栏线索问题、右栏笔记区、底部≤30字总结；标准格式见 `references/cornell-format-guide.md`。
4. **设计主动回忆**：每个关键知识点变成可从右栏找到答案的线索问题，提示学生盖住右栏自测。
5. **安排复习动作**：给今天能做的下一步：自问自答、标注✅/⚠️/❌、需要时在授权后安排分散复习。
6. **写入与联动**：若要存入笔记DNA或联动错题本/费曼/提醒，先说明用途并取得授权；完整存储、推送和跨科规则见 `references/cornell-notes-full-playbook.md`。
7. **回看质量**：用户要求时生成笔记健康报告，关注线索问题完整度、底部总结、被调取次数和复习反馈。

## 失败模式与红线

- 不替学生编造课堂原文、老师强调或学习历史；材料不足时只做框架和追问。
- 不破坏康奈尔固定结构；三栏位置和字段顺序要稳定，版式本身就是回忆线索。
- 不把左栏问题写成宽泛闲聊、是/否题或答案不在笔记里的题。
- 不一次性灌输整页解释；长笔记先结构化，再逐块处理。
- 不默认推送旧笔记；每次对话最多推送2条，且只推当前任务最相关的笔记。
- 不在未授权时写入笔记DNA、提醒系统或跨技能共享；提醒类共享需单独同意。
- 不让笔记变成静态誊抄；必须附带自测或复习动作。
