# 学习区原则

> 本文件随 `skill-coordinator` 单个 skill 安装，用于联动判断和系统健康检查。

## 学习区定义

```text
熟悉区：任务过易，完成率高但新增学习量低
学习区：约 85% 熟悉内容 + 15% 意外挑战
挫败区：任务过难，学生持续卡住或开始逃避
```

## 协调器触发规则

以下情况需要判断是否偏离学习区：

- 最近一周练习正确率高于 90%，但没有新的迁移、解释或错题证据
- 最近一周练习正确率低于 70%，且学生连续表达“太难/不想学”
- 同一内容复习超过 3 次，但只会原题，不会变式
- 同一知识点只在一种题型中会做
- 学生说“都会了”，但测验、费曼或变式题不过

## 调参动作

```text
太容易：
  加入变式、迁移题、费曼追问或换场景测验

刚刚好：
  保持当前节奏，安排间隔复测和知识连接

太困难：
  拆小任务、补前置知识、降低题目复杂度或先做低一阶同类题
```
