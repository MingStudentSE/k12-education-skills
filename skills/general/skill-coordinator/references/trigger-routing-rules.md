# 触发、转交与并行规则

> 本文件依据原版 `SKILL.md` 的“核心联动流程”“扩展联动判断规则”“联动前置条件”“与IM智能提醒的轻联动”等段落整理，不新增规则；原版未写清的冲突优先级见本文末“待拍板疑问”。

## 1. 先判定是否由协调器启动

协调器只在当前任务明确需要多 skill 联动、系统健康检查或全景月报时启动。若只是单一错题、笔记、复习提醒或普通答疑，先交给对应技能；协调器不默认读取全部活跃 skill 数据。

## 2. 单题/错题链路的顺序

原版顺序为：

```text
错题本 → 理科题目掌握 → 康奈尔笔记 → 费曼测试 → 学习计划/时间专注 → IM提醒
```

执行含义：
1. 错题本先接手：记录错误、定位根因、判断是否为固定模式。
2. 若是理科题，再进入理科题目掌握：拆解题目结构、解题入口、关键步骤和变式迁移。
3. 检索康奈尔笔记：查看该知识点是否已有笔记或线索。
4. 若概念模糊、方法边界不清、同类错误>=3次，或学生“看答案后觉得懂了”，触发费曼测试。
5. 若问题不是不会，而是“总是做不到”，检查是否需要学习计划或时间专注支持。
6. 只有在用户明确同意提醒时，才同步 IM 提醒安排复测、复习或行动回访。

## 3. 何时转交给计划/专注

- 学生知道方法，但连续拖延没执行 → 调取学习计划制定师。
- 计划写了，但总是无法按时完成 → 调取时间与专注力教练。
- 错题长期不回看、费曼测试总约不上 → 同时检查计划安排和专注阻力。

## 4. 何时并行或补链

- 全景月报和系统健康检查可并行汇总五维摘要：错题、理解、知识沉淀、计划执行、时间专注；但只拉取当前报告所需且已授权的数据摘要。
- 学习区校准贯穿流程：过易时加入变式、迁移或费曼追问；过难时调取学习计划降难度；只会一种题型时调取理科题目掌握、康奈尔笔记或学科专项做多场景学习。
- IM提醒只是轻联动：计划任务定时提醒、探索任务提醒、时间销行账每日确认提醒都需要用户明确同意。

## 5. 可不转交的情况

可不联动费曼测试：明显计算失误；明显读题失误且概念没问题；学生明确要求“今天只记录，不做深挖”。

## 6. 强 Schema 与降级

底层数据交接与回写均校验 `schemas/handover-protocol.schema.json`。若 Schema 解析异常或校验失败，自动阻断写入，降级为单会话纯文本诊断，并投递 `[SCHEMA_VALIDATION_ERROR]` 警告日志。
