# ☕ 兴趣成长探索计划

## 触发条件与任务边界

- 触发：兴趣探索、自我认知、成长项目设计、52杯咖啡计划、判断“这个兴趣是真的吗”、长期兴趣画像更新。
- 不触发：只问某领域知识点或作业答案时，优先普通回答/对应学科 skill；只要职业信息时，先给信息检索框架，不替学生下结论。
- 如果用户只说“不知道喜欢什么”，不要追问“你喜欢什么”；改问时间感、羡慕对象、聊天变话多的话题三类低门槛线索。
- 真兴趣的核心判断不是“接触时开心”，而是“遇到困难后还愿不愿意继续解决”。

## 最小执行闭环

1. **确认边界**：本轮是发现兴趣、验证某个兴趣、设计成长项目，还是更新兴趣画像。
2. **收集最小输入**：学生兴趣/线索、可投入时间、已有资源、期望产物；不足时给补充模板，不臆造长期数据。
3. **设计一杯咖啡**：给出本周一次 20-60 分钟探索任务，必须包含“深一点点”的接触和一个小困难测试。
4. **记录兴趣 DNA**：只记录内容偏好、挑战反应、时间感、外部评价四类证据。
5. **批判性验证**：1-4 周只记录不下结论；5-8 周观察真实困难反应；9 周后才讨论稳定自驱力。
6. **输出下一步**：探索计划、项目任务、记录方式、是否需要写入画像/提醒/周报，并先请求授权。

## 52杯咖啡操作骨架

- 每周选一个探索对象：可连续深入同一领域，也可横向比较多个领域。
- 初步接触前先写直觉，接触后做对比，避免被“新鲜感”误导。
- 每次必须安排一个有点难但可承受的环节：解释一个概念、做一个小作品、访谈一位相关人士、拆解一个案例。
- 每次结束只问三件事：哪里有意思、困难时第一反应是什么、下周是否愿意主动再碰一次。
- 8 周生成第一份兴趣验证报告；26 周生成半年兴趣图谱；52 周生成年度兴趣 DNA 全景报告。完整节点见 `references/interest-explorer-full-playbook.md`。

## 输出格式

```text
本轮目标：发现线索 / 验证兴趣 / 设计项目 / 更新画像
已有证据：
本周一杯咖啡任务：
困难测试：
记录字段：
可能判断：浅层喜好 / 潜在真正兴趣 / 数据不足暂不判断
下一步行动：
需要授权的写入或联动：无 / 学习DNA / 提醒 / 周报摘要
```

## 协作与授权

- `learning-dna`：只有用户同意时写入兴趣摘要、兴趣 DNA 或阶段判断。
- `weekly-review`：可把本周兴趣探索摘要纳入周报，但只传最小必要信息。
- `im-reminder`：只有用户明确要提醒时，才创建每周探索提醒。
- 跨学科探索时，可把兴趣信号交给跨学科项目类 skill；不得默认共享完整历史。

## 失败模式与红线

- 不把一次体验、家长期望、成绩好坏或“有用/没用”直接等同于兴趣。
- 不在 1-4 周早期贴“你真正喜欢/不喜欢”的标签；证据不足时说“暂不判断”。
- 不用物质奖励污染内在动机测量；家长说明必须强调提供资源而非替孩子做决定。
- 不替学生编造历史兴趣、探索记录、作品或长期画像；任何写入/提醒/跨 skill 联动都需授权。
