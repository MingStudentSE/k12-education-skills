# 生命过程机制链指南

## 1. 机制链基本格式

```text
条件/刺激 → 结构或场所 → 阶段变化 → 物质/能量/信息转化 → 结果 → 反馈/调节
```

每个箭头都要能说出关系词，如“促进、抑制、转化、运输、释放、调节、反馈”。

## 2. 起点终点定位

| 过程 | 起点 | 终点 |
|------|------|------|
| 光合作用 | 光照、CO2、水进入叶绿体 | 有机物和氧气形成 |
| 呼吸作用 | 有机物和氧气参与分解 | 能量释放，CO2 和水产生 |
| 消化吸收 | 食物进入消化道 | 小分子营养进入血液/淋巴 |
| 血液循环 | 心脏泵血 | 物质运输到组织并返回 |
| 免疫应答 | 抗原进入 | 清除抗原并形成记忆 |
| 遗传信息表达 | DNA 信息 | 蛋白质合成并影响性状 |
| 生态能量流动 | 生产者固定太阳能 | 沿食物链传递并逐级散失 |

## 3. 断链类型

| 断链 | 表现 | 修复 |
|------|------|------|
| 起点错 | 不知道过程从哪里开始 | 先写输入或刺激 |
| 阶段漏 | 中间步骤跳过 | 拆成 2-4 个阶段 |
| 方向反 | 把因果或物质流反过来 | 标箭头和条件 |
| 调节点漏 | 不能解释条件变化 | 找反馈或限制因素 |
| 层级混 | 分子、细胞、器官、生态混讲 | 回到生命层级 |

## 4. 条件变化预测

```text
改变条件 → 影响哪个阶段 → 该阶段增强/减弱 → 下游结果怎样变化 → 是否有反馈限制
```

示例：光照减弱 → 光合作用光反应受限 → 有机物合成减少 → 植物生长可能变慢。

## 5. 解释句式

```text
当 [条件] 改变时，会先影响 [阶段/结构]，
使 [物质/能量/信息流] 发生 [方向变化]，
因此 [结果] 发生变化。
如果存在 [调节/限制因素]，变化不会无限扩大。
```
