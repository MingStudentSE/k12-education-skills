# 生命结构层级指南

## 1. 基本层级

```text
细胞 → 组织 → 器官 → 系统 → 个体 → 种群 → 群落 → 生态系统 → 生物圈
```

不是每道题都需要全部层级。先定位题目所处层级，再选择解释深度。

## 2. 层级判断表

| 层级 | 关键词 | 示例 |
|------|--------|------|
| 细胞 | 细胞膜、细胞核、线粒体、叶绿体 | 神经元、红细胞、保卫细胞 |
| 组织 | 同类细胞群，执行相同功能 | 上皮组织、肌肉组织、输导组织 |
| 器官 | 多种组织构成，完成特定功能 | 心脏、肺、叶、根 |
| 系统 | 多个器官协同 | 消化系统、循环系统、神经系统 |
| 个体 | 一个完整生物体 | 一株玉米、一个人 |
| 种群 | 同一区域同种生物 | 一个池塘里的鲫鱼 |
| 群落 | 同一区域全部生物 | 池塘中的所有生物 |
| 生态系统 | 生物群落 + 非生物环境 | 池塘生态系统 |

## 3. 层级定位追问

```text
题目问的是一个细胞结构，还是一个器官功能？
这个对象能不能独立完成完整生命活动？
它由同类细胞组成，还是多种组织组成？
题目是否已经从个体扩展到种群、群落或生态系统？
```

## 4. 常见错法

| 错法 | 示例 | 修复 |
|------|------|------|
| 器官和系统混 | 把“心脏”写成循环系统 | 系统由多个器官构成 |
| 种群和群落混 | 把池塘全部鱼当群落 | 群落包含所有生物类群 |
| 细胞器和器官混 | 把叶绿体叫器官 | 叶绿体是细胞器 |
| 生态系统漏非生物 | 只写生物部分 | 加入阳光、水、温度、土壤等 |

## 5. 学段边界

初中重点掌握细胞到系统、种群到生态系统的基本区分；高中可加入分子层、稳态调节层和生态系统能量流动/物质循环。
