# 生物图表与数据错因检查

## 1. 图表读取顺序

```text
标题 → 横轴 → 纵轴 → 单位 → 图例 → 趋势 → 关键点 → 机制解释
```

任何 B5 图表错误都先检查是否跳过这个顺序。

## 2. 趋势句式

| 趋势 | 规范表达 |
|------|----------|
| 持续上升 | 随着 X 增大，Y 持续增加 |
| 持续下降 | 随着 X 增大，Y 持续降低 |
| 先升后降 | Y 随 X 增大先增加，达到峰值后降低 |
| 先升后稳 | Y 先增加，随后趋于稳定 |
| 最适点 | 当 X 为……时，Y 达到最大/最适 |
| 异常点 | 该点偏离总体趋势，可能与……有关 |

## 3. 证据化结论

```text
从图中可以看出，在 [范围] 内，
随着 [自变量] 的变化，[因变量] 出现 [趋势]。
这说明 [限定结论]，
可能原因是 [机制解释]。
```

## 4. 常见错因

| 错因 | 表现 | 修复 |
|------|------|------|
| 坐标错 | 把横纵轴读反 | 先读轴和单位 |
| 趋势泛化 | 只写“有影响” | 写变化方向和范围 |
| 结论越界 | 推广到所有生物或所有条件 | 加限定范围 |
| 因果过度 | 相关数据直接判因果 | 回到实验设计和变量控制 |
| 术语口语化 | “长得更好”“反应更强” | 改为生长量、萌发率、酶活性等指标 |

## 5. 复测建议

B5 修复后至少换一张不同图表复测：折线图、柱状图、表格或坐标曲线。学生必须说出标题、变量、单位、趋势和限定结论。
