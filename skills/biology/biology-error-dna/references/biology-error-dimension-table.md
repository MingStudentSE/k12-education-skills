# 生物错误维度表

## B1 层级定位错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| B1.1 细胞/组织/器官/系统混 | 把叶绿体叫器官，把心脏叫系统 | 生命层级树 |
| B1.2 个体/种群/群落/生态系统混 | 忽略同种/全部生物/非生物环境 | 生态层级判断表 |
| B1.3 分子/细胞/个体层级跳跃 | 用分子概念回答器官题或相反 | 题目层级标注 |
| B1.4 图示层级误读 | 不知道图是细胞图、器官图还是生态图 | 先读标题和图例 |

## B2 结构功能断裂

| 子类型 | 表现 | 修复 |
|--------|------|------|
| B2.1 只背功能 | 说不清结构特征 | 结构-功能表 |
| B2.2 特征漏关键项 | 肺泡漏毛细血管，小肠漏绒毛 | 结构标注 |
| B2.3 功能跳步 | 结构直接连结论，中间过程缺失 | 因为-所以机制句 |
| B2.4 适应性表达错 | 用“为了”替代证据化解释 | 改成“有利于” |

## B3 过程机制断链

| 子类型 | 表现 | 修复 |
|--------|------|------|
| B3.1 起点终点错 | 不知道过程从哪里开始到哪里结束 | 起点终点表 |
| B3.2 阶段漏 | 光合、呼吸、消化、免疫步骤跳过 | 拆阶段 |
| B3.3 方向反 | 物质流、能量流或因果方向反 | 箭头和关系词 |
| B3.4 调节点漏 | 血糖、体温、生态反馈解释不完整 | 反馈链 |
| B3.5 条件预测错 | 改光照/温度/激素后不会推结果 | 条件影响哪个阶段 |

## B4 实验探究错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| B4.1 变量不清 | 自变量、因变量、控制变量混 | 变量表 |
| B4.2 对照缺失 | 无法比较处理效果 | 对照组设计 |
| B4.3 重复不足 | 样本太少，结论不稳 | 增加重复和样本 |
| B4.4 数据证据不足 | 不引用数据或趋势 | 数据句式 |
| B4.5 结论越界 | 超出实验范围推广 | 限定结论 |

## B5 图表信息与术语表达错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| B5.1 坐标单位漏读 | 横纵轴、单位、图例看错 | 图表阅读顺序 |
| B5.2 趋势表达不清 | 只写“有影响” | 趋势句式 |
| B5.3 异常点忽略 | 不解释拐点、峰值、异常 | 标关键点 |
| B5.4 术语混用 | 消化/吸收、种群/群落混用 | 易混概念表 |
| B5.5 答案口语化 | 不能用学科语言表达证据 | 规范句式改写 |

## 主次维度记录

复杂题可记录次错因，但训练只抓主错因。

示例：把生态系统误判为群落后能量流动解释也错，可记为 `主 B1.2 + 次 B3.4`。
