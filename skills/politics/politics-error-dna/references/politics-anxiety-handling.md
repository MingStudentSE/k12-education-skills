# 政治焦虑处理指南

> 本文档为 `politics-error-dna` 的焦虑处理参考，定义政治学习焦虑信号词、数据替代情绪流程和三题递进训练。所有价值相关表达只训练论证链，不评判学生个人立场。

---

## 一、政治焦虑信号词

```text
模块定位焦虑：
  - "我不知道这题考哪个模块"
  - "哲学题我永远不知道用哪个原理"
  - "政治选择题每个选项都像对的"

理论应用焦虑：
  - "背了原理不会用"
  - "政治大题我永远不知道答什么"
  - "材料题我只会抄材料"
  - "我写的理论和材料总是两张皮"

价值论证焦虑：
  - "政治是不是只要写正确立场"
  - "开放题我怕观点不对"
  - "评价题我只会写应该支持"

表达焦虑：
  - "我知道意思但写不出来"
  - "答案总是口语化"
  - "老师说我没有政治术语"
```

---

## 二、处理原则

| 原则 | 做法 | 禁止 |
|------|------|------|
| 先接住情绪 | 用1-2句确认挫败 | 长篇安慰替代分析 |
| 数据替代情绪 | 调取 Po1-Po5 分布和具体记录 | 说"你就是政治不行" |
| 任务具体化 | 把焦虑变成一个子类型训练 | 一次性安排整本书复习 |
| 授权可控 | 写入档案和提醒前请求同意 | 默认长期记录 |
| 立场中立 | Po5 只说论证链缺口 | 评价个人政治立场 |

---

## 三、标准处理流程

```text
Step 1：确认感受
  "你现在很挫败，我听到了。政治大题最容易让人觉得无从下手。"

Step 2：调取数据
  "先看档案，不凭感觉判断。你最近的政治错题里，
   Po1理论模块定位出现了4次，Po3理论联系实际出现了3次。
   这说明问题不是'政治不行'，而是入口定位和材料映射需要专项训练。"

Step 3：具体任务化
  "今天只处理 Po1：30秒说出模块→单元→原理。
   做3道极简题，不写完整答案。"

Step 4：递进训练
  第1题：纯净版审题，只有设问和一句材料
  第2题：加入一段材料，要求圈主体和行为
  第3题：换设问限定，检查是否仍能定位

Step 5：复测安排
  经学生同意，安排次日和3天后各一道短题复测。
```

## 四、焦虑类型到训练映射

| 学生说法 | 初判维度 | 立即训练 |
|----------|----------|----------|
| "不知道考哪个模块" | Po1 | 30秒纯净版审题测试 |
| "背了原理不会用" | Po3 | 材料句→原理→分析句映射 |
| "选择题每个都对" | Po1/Po2 | 设问限定 + 选项四类排除 |
| "哲学原理总用错" | Po1/Po2 | 哲学板块关键词树 |
| "材料题只会抄材料" | Po3/Po4 | 材料提取 + 理论连接句 |
| "开放题怕立场不对" | Po5 | 明确只练论证不评立场，做三行论证 |
| "知道但写不出来" | Po4 | 主体+术语+逻辑词+结论表达 |

## 五、三题递进模板

### Po1 模块定位焦虑

```text
第1题：极简定位
  材料：某企业增加研发投入，提高产品质量。
  任务：只说模块和原理。
  目标：经济生活→企业经营→创新发展。

第2题：加入设问干扰
  设问：运用经济生活知识分析该企业做法。
  任务：圈设问限定和材料主体。

第3题：换模块
  材料：某地政府公开执法依据，接受群众监督。
  目标：政治生活→政府→依法行政/接受监督。
```

### Po3 理论联系实际焦虑

```text
第1题：给材料句，选原理
  "居民通过议事会参与社区治理" → 基层民主/公共参与

第2题：给原理，找材料句
  原理：政府接受监督 → 材料中"公开整改清单、群众反馈"

第3题：写分析句
  "居民通过议事会参与社区治理，体现基层民主，有利于提升社区治理效能。"
```

### Po5 价值论证焦虑

```text
先声明：
  "这里只练论证链，不评你的个人立场。"

第1题：事实一句
  材料中谁做了什么？

第2题：标准一句
  这涉及人民利益、法治、公共参与还是社会责任？

第3题：选择一句
  基于事实和标准，应怎样做？
```

## 六、禁用话术与替代表达

| 禁用话术 | 问题 | 替代表达 |
|----------|------|----------|
| "你政治就是不行" | 固化焦虑 | "档案显示卡点集中在 Po1/Po3" |
| "你立场不对" | 违反价值红线 | "这段价值论证缺少学科依据" |
| "多背就好了" | 不解决应用问题 | "先练模块定位和材料映射" |
| "这题就这么写" | 替代学生思考 | "你先说模块，我再帮你修正" |
| "开放题要写正确态度" | 混淆立场和论证 | "开放题要写完整论证链" |
