# 政治题型手册

> 本文档为 `politics-application-coach` 的题型参考，覆盖选择题、材料分析题、论述题、开放性评价题和错题复盘。

---

## 一、题型总览

| 题型 | 识别信号 | 核心动作 | 常见错因 |
|------|----------|----------|----------|
| 选择题 | 四个选项，正确/不正确/最符合 | 限定词→模块→排除→回代 | 选项正确但材料无关 |
| 材料分析题 | 根据材料，说明/分析/为什么/如何 | 模块→原理→映射→表达 | 理论和材料两张皮 |
| 措施建议题 | 如何做、提出建议、应采取措施 | 问题→主体→措施→效果 | 主体错、措施空泛 |
| 论述题 | 评析、谈看法、自拟观点 | 观点→理论→材料→结论 | 观点无依据 |
| 开放性评价题 | 应不应该、如何评价、价值选择 | 事实→价值→选择 | 只有态度无论证 |
| 错题复盘 | 做错、不会、答案不一致 | 回溯四步断裂点 | 把模块错当粗心 |

---

## 二、选择题

### 解题流程

```text
Step 1 看设问限定
  正确/不正确/最符合/根本原因/直接体现

Step 2 定模块和主体
  经济/政治/文化/哲学；主体是企业、政府、公民还是文化机构

Step 3 排除四类陷阱
  错误表述 / 模块不符 / 材料无关 / 绝对化

Step 4 回代验证
  最佳选项必须同时符合设问、材料和教材表述
```

### 选择题陷阱表

| 陷阱 | 示例 | 处理 |
|------|------|------|
| 错误表述 | "市场能解决所有资源配置问题" | 教材表述不成立，直接排除 |
| 模块不符 | 哲学设问选文化传承 | 回到设问限定 |
| 材料无关 | 材料讲政府公开，选项讲企业创新 | 正确但不选 |
| 绝对化 | "必然消除、唯一途径、完全解决" | 检查条件和程度 |
| 主体错位 | 把公民权利写成政府权力 | 先看行为主体 |

## 三、材料分析题

### 设问动词表

| 设问词 | 答题方向 | 骨架 |
|--------|----------|------|
| 体现 | 材料对应原理 | 材料句 + 体现 + 原理 |
| 说明 | 解释材料现象 | 现象 + 原理 + 结论 |
| 分析原因 | 为什么会这样 | 背景/条件 + 机制 + 结果 |
| 分析意义 | 有什么作用 | 做法 + 有利于 + 目标 |
| 如何做 | 主体应采取措施 | 主体 + 措施 + 理论依据 + 效果 |

### 材料标注法

```text
圈四类词：
  主体词：政府、企业、公民、文化机构、国家
  行为词：公开、创新、监督、传承、调控、参与
  结果词：提升、促进、保障、推动、规范
  价值词：公平、法治、人民利益、共同富裕、文化自信
```

### 答案点生成表

| 材料标注 | 原理调动 | 答案点 |
|----------|----------|--------|
| 政府公开权力清单 | 依法行政、监督权力 | 规范权力运行，建设法治政府 |
| 企业研发绿色技术 | 创新发展、绿色发展 | 提升竞争力，促进可持续发展 |
| 居民参与社区协商 | 基层民主、公共参与 | 保障人民当家作主，提升治理效能 |
| 传统技艺进入校园 | 文化传承、文化育人 | 传承优秀传统文化，增强文化认同 |

## 四、措施建议题

### 主体先行原则

```text
措施题先问"谁来做"：
  政府：依法履职、完善政策、公共服务、监管
  企业：依法经营、创新、诚信、社会责任
  公民：依法参与、履行义务、理性表达、监督
  学校/社会组织：教育引导、服务支持、协同治理
```

### 措施题矩阵

| 问题类型 | 主体 | 措施 | 避免 |
|----------|------|------|------|
| 市场乱象 | 政府 | 加强监管、完善规则、依法处罚 | 只写"提高意识" |
| 企业转型 | 企业 | 技术创新、质量提升、绿色生产 | 只写"政府加大支持" |
| 社区治理 | 公民/基层组织 | 协商议事、有序参与、公开监督 | 空喊"积极参与" |
| 文化保护 | 政府/文化机构/公众 | 保护传承、创新传播、公众参与 | 把所有责任推给个人 |

## 五、论述题与开放性评价题

### 普通论述题结构

```text
观点：一句清楚判断
理论依据：来自对应模块的原理
材料分析：至少两条材料证据
结论：回扣设问
```

### 开放性评价题结构

```text
事实判断：材料/现象是什么
价值判断：依据教材中的学科标准作评价
价值选择：在事实和价值判断基础上提出建议或选择
```

### 价值红线

```text
开放性题可以训练：
  论证是否完整
  依据是否来自学科标准
  事实和价值判断是否分开
  选择建议是否由前文推出

开放性题不能训练：
  学生必须持有某种个人立场
  用立场正确/错误评价学生
```

## 六、错题复盘

### 四步回溯模板

```text
模块定位：我一开始判的模块是什么？正确模块是什么？
知识调动：我调错/漏掉了哪条原理？
对应映射：我的哪一点没有材料支撑？
规范表达：我是否分点、使用术语、写出逻辑？
价值论证：若有评价题，我是否只有结论没有依据？
```

### 错因初判表

| 断裂步骤 | 初判维度 |
|----------|----------|
| 模块定位错 | Po1 理论模块定位错误 |
| 概念原理错 | Po2 概念/原理混淆 |
| 材料对应错 | Po3 理论联系实际错误 |
| 表达结构乱 | Po4 逻辑与表达错误 |
| 只有态度无依据 | Po5 价值论证缺失 |

## 七、学段边界

| 学段 | 题型重点 | 不强制内容 |
|------|----------|------------|
| 初中 | 生活情境题、权利义务、法律规则、责任建议 | 不强制高中四模块术语和哲学原理体系 |
| 高中 | 选择题、材料题、措施题、论述题、时政综合 | 不展开大学学术争议或脱离课本的政策评论 |
