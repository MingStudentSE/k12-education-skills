# 政治苏格拉底追问指南

> 本文档为 `politics-application-coach` 的追问参考，围绕定位层、原理层、应用层三层展开，并提供学段适配与卡点回退路径。

---

## 一、三层次追问总览

```text
定位层：这题考哪个模块？
  ↓
原理层：这个模块下哪条原理适用？
  ↓
应用层：材料哪一句对应这条原理，答案怎样分层？
```

### 三层追问表

| 层次 | 目标 | 典型追问 | 通过标准 |
|------|------|----------|----------|
| 定位层 | 防止调错模块 | "设问限定了哪个模块？材料主体是谁？" | 能说出模块、单元和可能概念 |
| 原理层 | 找到适用原理 | "这条原理的关键词和适用条件是什么？" | 能筛出2-4条贴合设问的原理 |
| 应用层 | 理论联系实际 | "材料中哪一句能支撑这条原理？" | 能写出材料-理论-结论链 |

## 二、定位层追问

### 基础追问

```text
1. 设问有没有写"运用经济生活/政治生活/文化生活/哲学知识"？
2. 如果没有限定，材料的核心主体是谁？
3. 材料主要讨论资源配置、公共权力、文化发展，还是哲学方法？
4. 这个问题是初中生活主题，还是高中四大模块？
```

### 模块定位快问

| 材料主体/现象 | 追问 | 可能模块 |
|---------------|------|----------|
| 企业、市场、价格、收入 | "这是不是在讲资源配置或经济发展？" | 经济生活 |
| 政府、公民、人大、党 | "这是不是在讲公共权力或政治参与？" | 政治生活 |
| 传统文化、传播、创新 | "这是不是在讲文化传承和文化作用？" | 文化生活 |
| 实践、矛盾、实际、发展 | "这是不是在讲方法论或哲理？" | 生活与哲学 |

### 定位层错误纠偏

```text
学生：我觉得这题可以写政府宏观调控。
AI：先停一下。设问要求"运用政治生活知识"，这里的政府不是经济调控主体，
而是依法履职、接受监督或服务人民的主体。我们先把模块改回政治生活。
```

## 三、原理层追问

### 基础追问

```text
1. 这个模块的主干链条是什么？
2. 当前材料落在哪个单元？
3. 这条原理的关键词是什么？
4. 原理适用条件满足吗？
5. 有没有相邻概念容易混？
```

### 原理筛选表

| 模块 | 从宽到窄追问 | 常见筛选结果 |
|------|--------------|--------------|
| 经济生活 | "主体是企业、国家还是消费者？" | 企业经营、市场配置、宏观调控、分配公平 |
| 政治生活 | "主体是公民、政府、党还是国际关系？" | 公民参与、政府履职、依法行政、国家利益 |
| 文化生活 | "材料讲作用、传承、交流还是创新？" | 文化作用、文化继承、文化交流、文化创新 |
| 哲学 | "设问词是实际、实践、联系、发展、矛盾还是群众？" | 唯物论、认识论、辩证法、历史唯物主义 |

### 原理层错误纠偏

| 学生表现 | 追问 | 回退 |
|----------|------|------|
| 原理太多全想写 | "哪两条最能解释材料核心行为？" | 缩到2-4条 |
| 原理选错 | "材料中哪个词支撑这条原理？" | 回到定位层 |
| 概念混淆 | "权利和权力的主体分别是谁？" | 转 concept |
| 只写口号 | "这条话是原理、目标还是态度？" | 重筛原理 |

## 四、应用层追问

### 基础追问

```text
1. 材料中哪个主体做了什么？
2. 这个行为对应哪条理论？
3. 这个理论如何解释材料中的结果？
4. 答案是否包含材料词、学科术语和逻辑连接词？
5. 如果是价值评价，事实、标准和选择是否分开？
```

### 材料映射追问模板

```text
材料句："某地政府公开权力清单，接受群众监督。"
追问：
  主体是谁？——政府
  行为是什么？——公开权力清单、接受监督
  对应原理是什么？——依法行政、权力需要监督
  结论是什么？——规范权力运行，提升治理效能
```

### 应用层表达句式

| 题型 | 句式 |
|------|------|
| 体现类 | 材料中"..."体现了...，说明... |
| 原因类 | 因为...原理，所以材料中的...有利于... |
| 措施类 | 针对...问题，...主体应...，以... |
| 意义类 | 这一做法有利于...，体现/贯彻了... |
| 评析类 | 从事实看...；从学科标准看...；因此应... |

## 五、学段适配

| 学段 | 追问重点 | 追问语言 |
|------|----------|----------|
| 初中 | 生活情境、规则、权利义务、责任、行动建议 | "这件事涉及哪条规则？谁有什么权利和责任？你会怎么做？" |
| 高中 | 模块、单元、概念、原理、材料映射 | "模块是什么？原理是哪条？材料哪一句对应？" |

### 初中降级示例

```text
高中问法：
  "这体现了公民有序政治参与的什么要求？"

初中问法：
  "这件事里，公民是在依法表达意见，还是在破坏规则？
   他的权利和责任分别是什么？"
```

### 高中升级示例

```text
基础问法：
  "政府这样做有什么意义？"

高中升级：
  "请从政治生活角度，把政府主体、依法行政、接受监督和治理效能连成两点答案。"
```

## 六、追问质量自检

| 低效追问 | 有效追问 |
|----------|----------|
| "你知道答案吗？" | "设问限定了哪个模块？" |
| "还有什么原理？" | "哪条原理最贴合材料主体和行为？" |
| "写具体一点" | "材料哪一句可以放进这一点？" |
| "你的观点对吗？" | "你的事实依据、学科标准和推理链完整吗？" |

---

## 七、价值红线追问

```text
可以追问：
  你的事实判断是什么？
  你使用的学科评价标准是什么？
  你的结论和依据之间有没有跳步？

不能追问：
  你为什么不持某种立场？
  你的价值观是不是正确？
  你应该赞成还是反对某个个人立场。
```
