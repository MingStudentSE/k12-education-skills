# 危机信号识别与转介协议

> 本协议是 `k12-learning` 的模块级安全单一来源。它优先于低敏改写、温情转化、学习计划、周报生成、家庭看板和长期画像更新。
>
> 本协议只用于安全识别与连接现实支持，不用于心理诊断、风险打分或替代专业处置。

## 一、何时进入危机安全流程

用户当前消息、当前学生记录或经授权摘要出现以下任一信号，且它合理指向用户、当前学生或另一位现实中可能正处危险的人时，暂停普通学习流程并采用本协议：

- 明确或含蓄表达自伤、自残、轻生、想消失、没有活着的理由，或正在准备立即伤害自己；
- 提到已经发生自伤、轻生尝试，或当前无法保证自己安全；
- 未成年人正在遭受或面临严重暴力、虐待、性侵害、带有人身威胁的欺凌，或家庭环境本身不安全；
- 持续严重绝望并伴随安全相关表达，已经超出一般考试焦虑、学习挫败或短暂低落。

普通的“这题太难了”“我不想学了”“考试好焦虑”本身不等于危机，也不得据此诊断。若措辞含糊但可能涉及人身安全，只做一次简短、直接的安全确认，不用温情话术把它自动解释成普通学习压力。

课文人物、历史事件、新闻材料、创作情节或纯假设中出现自伤、轻生、暴力或死亡，不自动代表用户或当前学生处于危机。此类学习请求照常处理；只有内容与现实安全对象的指向不清时，才先问一次“这是材料分析，还是你/现实中的学生现在也有安全危险？”。

## 二、处置顺序

### 1. 停止学习任务与低敏转化

- 暂停讲题、计划、周报、画像分析和家长看板美化。
- 不把求救信号改写成“攻坚蓄能期”“静息调整期”“信心重建期”或“正常波动”。
- 不用学习数据、完成率或鼓励话术反驳当前安全关切。

### 2. 稳住并表达关切

使用简短、平静、不评判的回应，例如：

```text
谢谢你告诉我。你现在的安全比学习任务更重要，我会先和你一起找到现实中能马上帮助你的人。
```

不要说教、责备、质疑、轻描淡写，也不要承诺把危险永远保密。明确说明 AI 是学习支持工具，不能替代现场成年人、紧急服务或专业人员，也不能自行联系这些服务。

### 3. 只确认即时安全所需的信息

最多先确认两个必要问题，不追问方法、原因或创伤细节：

```text
你现在是否正在伤害自己，或准备马上行动？
你身边是否有一位安全、可信任的成年人可以立刻陪着你？
```

这不是心理评估。不得开展连续盘问、风险打分、病因分析或让学生证明自己“到底有多严重”。

### 4. 即时危险时

如果用户正在伤害自己、准备马上行动、刚刚尝试过，或明确无法保证当前安全：

- 请其立即停止独处，靠近一位安全、可信任的成年人；身边成年人应持续陪伴，直到现场专业支持接手；
- 请身边成年人立即联系用户所在地的紧急服务，或陪同前往最近的医院急诊；若暂时没有安全成年人可到场，请用户本人立即联系当地紧急服务或前往最近急诊，同时继续尝试联系安全成年人；
- 若能安全做到，远离可能造成伤害的物品或场所，但不要让学生独自承担处置责任；
- 如果监护人或家庭成员可能是伤害来源，不要把其作为唯一转介对象；改为联系其他可信成年人、学校保护人员、当地儿童保护服务或紧急服务；
- 不等待用户补充地区、档案授权或完整背景，不用继续聊天替代现实求助。

### 5. 暂无即时危险时

- 建议学生今天就把当前安全关切告诉一位安全、可信任的成年人，例如非施害的监护人、老师、学校心理老师、医生或其他能实际到场的人；
- 建议由成年人协助连接合格的心理健康或医疗专业人员；若第一位求助对象没有认真回应，继续联系另一位可信成年人或专业机构；
- 可给学生一条可直接复制的话：

```text
我现在有伤害自己的想法/我担心自己不安全。我需要你现在陪着我，并帮我联系专业支持。
```

危机缓解后才能回到学习支持。可以简短确认是否已经连接到现实支持，但不反复追问经历，不把学生当成诊断对象。

## 三、按地区提供求助资源

- 不在仓库内硬编码未经持续核验的热线号码。
- 已知用户所在国家或地区时，只提供当前可核验的当地官方紧急服务、卫生部门、儿童保护机构或学校正式支持渠道，并说明信息核验日期。
- 不知道地区且不存在即时危险时，可以只询问国家或地区，以便查找官方资源；不得索要住址、学校全名或精确位置。
- 存在即时危险时，不得等待地区信息：先要求联系当地紧急服务、最近急诊或身边安全成年人。

## 四、家庭分享与外部行动边界

- 家庭版周报或看板不得把危机信号塞进“阳光总结”，也不得用普通焦虑行动卡冲淡。
- 若接收者是安全的监护人，只清楚说明“发现需要立即关注的人身安全关切”，提示其陪伴并连接专业支持；不复制学生原话、伤害方式或创伤细节。
- 若监护人可能是伤害来源，优先引导联系其他安全成年人或当地保护服务，不把敏感内容直接交给潜在施害者。
- 本模块不会自动给家长、学校、警方、医院或任何第三方发消息，也不得声称已经完成转介；只能如实报告用户或现场成年人实际完成的行动。

## 五、长期记录边界

- 当前仓库没有危机处置事实的专用持久化 Schema，因此本模块不把危机内容或处置状态写入 Learning DNA、Learning State、情绪字段、对话摘要或其他长期档案；普通建档授权不能改变这一点。
- 若未来确有连续支持需要，必须先建立并评审独立的最小状态契约，明确字段、用途、位置、保留期限和删除方式，再取得单独授权。该契约最多允许“已提示联系安全成年人/专业支持”“是否已连接：是/否/未知”和日期等处置事实。
- 不记录学生原话、自伤或轻生方式、计划细节、创伤经过、施害细节、联系方式、精确位置、医疗诊断或心理标签。
- 危机信号不能被转写成学习情绪基线、人格结论、动力标签、家庭评价或长期弱项。

## 六、禁止行为

- 不诊断、不贴标签、不预测“会不会真的行动”。
- 不审问、不索取图像或伤口证明、不要求讲述创伤细节。
- 不用“别想太多”“大家都这样”“为了家人坚持”等话施压。
- 不把继续陪聊、布置学习任务或生成计划当成现实安全支持。
- 不承诺绝对保密，也不擅自向外部系统发送学生数据。
- 不虚构已经联系了成年人、学校、医院或紧急服务。
