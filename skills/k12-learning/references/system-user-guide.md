## 这个系统是什么

日常学习只有一个入口。AI 会根据当前目标选择讲题、概念理解、错因分析、写作辅导、计划或复盘等内部方法。你可以问“刚才用了哪些内部方法，为什么”，但日常不必先选功能。

| 模块 | 你用它做什么 | 什么时候需要 |
|---|---|---|
| 学习 | 讲题、概念、错题、写作、实验、计划、专注、笔记与复盘 | 日常默认使用 |
| Wiki | 建立、接入、查询和维护 Markdown/Obsidian 知识库 | 需要把已确认的结果长期沉淀时 |
| 自动化 | 真实提醒、OCR、夜间错题分析和看板 | 需要宿主真正执行时 |
| 系统维护 | 创建和评测内部方法 | 仅维护者需要 |

一次对话可以组合多种方法。例如“把这道物理错题学透”可以同时包含当前步骤诊断、分级提示和变式验证，但你仍只需说一个目标。

## 第一次怎么说

### 1. 先让 AI 安装日常模块

直接发送下面整段：

```text
请帮我安装以下两个模块：
k12-learning：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/k12-learning
llm-wiki：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/llm-wiki
```

让 AI 根据当前宿主处理安装。安装后按宿主提示刷新或重启。

### 2. 从手头选一份真实材料

第一次先建立一份有证据的初版学习 DNA。请从手头任选一份最近的材料：

- 一页课本或课堂笔记；
- 一页作业或一道错题，最好带自己的草稿；
- 一张试卷或其中有代表性的几道题；
- 一段作文、阅读答案或实验记录。

不用一次交齐，更不用准备全科资料。材料上有姓名、学校或考号时可以先打码。

### 3. 发起 3–5 分钟快速测评

复制下面这段，并把材料一起发来：

```text
我是第一次使用，这是我最近的学习材料和自己的过程。
请先基于材料做一次 3–5 分钟的快速测评，不做全面测评，也不要让我填长问卷。
形成一份有证据、带置信度的初版学习 DNA，然后马上用这份材料带我完成一个真实学习动作。
如果要跨会话保存画像，请在完成第一个动作后再单独问我。
```

AI 最多只补材料无法判断的年级和当前目标，再围绕这份材料做 1–3 个短动作。一旦能说清一个当前优势、一个首要卡点和一个下一步，就应停止测评并开始学习。

### 4. 没有现成材料也能快速开始

```text
我是初一学生，第一次使用，手边暂时没有材料。
我最近在学一元一次方程。请只用一道微型题快速建立初版学习 DNA，然后马上带我完成下一步；不要做综合测试。
```

### 5. 初版 DNA 与保存

首次测评会先生成“仅本次会话”的初版学习 DNA，包括当前目标、已查看证据、一个优势、一个首要卡点、待验证项和下一步。一次材料不会被写成固定能力或性格标签。

如果希望以后继续积累，再回答“保存这份初版学习 DNA”。AI 应先列出拟保存字段、用途、位置和删除方式；没有明确同意时，不跨会话保存。

### 6. 想先看全部用法

```text
请按学习目标介绍你能帮我做什么，重点讲第一次和平时该怎么说。
不要让我选内部功能名，每类给一句可复制的例子。
```

如果这也是你的首次使用，能力介绍应保持简短，随后仍回到“拿一份材料—快速测评—初版 DNA—真实任务”的启动路径。

## 平时怎么说

自然语言就可以。若想得到更准确的帮助，尽量包含五件事：

```text
我的情况 + 当前材料 + 我已经做到哪里 + 这次目标 + 希望的帮助方式
```

例如：

```text
这是初三物理电学题。我已经画了电路图，但不知道两个电表分别测什么。
先检查我的图，再用问题引导我判断；如果还不会，再逐级增加提示。
```

你还可以直接指定交互方式：

- “只给提示，不公布答案。”
- “我今天赶时间，先完整示范，再给我一题自己做。”
- “每次只问一个问题，等我回答后再继续。”
- “用初一能懂的话讲，但不要牺牲准确性。”
- “结尾用一道变式题检验，不要只问我听懂了吗。”

## 学科学习与讲题

### 当前单题

```text
这是题目和我的过程。请先找第一个出问题的步骤，告诉我该检查什么；
先给提示，我还不会时再给完整过程。
```

### 概念理解

```text
我不理解“负负得正”为什么成立。
请从一个直觉例子开始，再连到严格表达，说清类比在哪里会失效，最后用一个反例检验我。
```

### 各学科都可以怎么问

| 学科 | 可以做什么 | 示例话术 |
|---|---|---|
| 语文 | 现代文证据、文言翻译、古诗情感、语病、作文构思与素材 | “这道标题含义题为什么失分？请带我回到原文找证据。” |
| 英语 | 语法、词汇、听力、口语角色扮演、书面表达 | “和我模拟餐厅点餐，我说完后再纠错，先改影响理解的问题。” |
| 数学 | 概念、单题思路、应用题建模、难度梯度、反复错因 | “这道行程题我读懂了，但不知道设什么为 x，先带我说清量和关系。” |
| 物理 | 概念直觉、图景、受力/电路、模型选择、实验 | “我的受力图在这里，先检查对象和漏力，再决定用哪个模型。” |
| 化学 | 概念边界、微粒视角、反应方程式、实验探究 | “盐溶于水后微粒怎么变？请连起宏观现象、微观模型和符号表达。” |
| 生物 | 生命过程、结构与功能、概念网络、实验与数据 | “光照变强后光合速率为什么不一定继续上升？请用因果链讲。” |
| 地理 | 读图、地理过程、区域分析、综合题组织 | “这张等高线图我看不出方向和坡度，请让我一步步标出证据。” |
| 历史 | 时间轴、因果链、史料证据、材料题 | “这段日记能不能证明当时所有人的态度？请检查史料边界。” |
| 道德与法治/思想政治 | 概念、知识框架、材料应用、开放题论证 | “我有一个开放题观点，请检查事实、标准和结论的连接，不要评价我的立场。” |

## 错题、写作与实验

### 一道错题

最有用的材料是：题目、你的答案/过程、正确答案或解析（如果有）、你自己觉得卡住的地方。

```text
这是我做错的题、我的过程和正确解析。
先指出第一个错误发生在哪一步，再追到可训练的根因，不要只说“粗心”。
最后出一道变式题验证；这次只在会话中使用，不保存。
```

### 同类错误反复发生

长期弱项需要证据。最好提供多道题、发生时间和复测结果：

```text
这是我近两周三道等值线错题和每次的过程。
请比较共同错误模式，区分是读图、原理还是答题表达的问题。
证据不足的结论请标成“待验证”。
```

### 写作与批改

AI 可以帮你审题、找材料、检查提纲、批改初稿、比较改写和设计小练习，但不应替你代写整篇作业。

```text
这是作文题目、我的提纲和初稿。
请先按审题、结构、证据、语言四项评价，每项只找一个最值得修的问题。
用我原文中的一段示范怎么改，不要重写全文。
```

英语写作可再加一句：“优先修正影响理解的问题，保留我能掌握的词汇和语气。”

### 物理、化学和生物实验

```text
这是实验题、装置图和数据。
请按研究问题、假设、自变量、因变量、控制变量、证据和误差带我检查。
先指出我的设计中无法支持结论的一点，不要直接给标准答案。
```

对现实实验，说清年级、可用器材和是否有老师/家长在场。涉及火源、高压电、腐蚀性试剂、有毒物质或生物安全时，只在合格监督和课程规范内操作。

## 计划、专注与深度理解

### 还没有计划

```text
三周后模考，我平日每晚有 90 分钟，周末每天有 3 小时。
数学函数和英语听力是当前重点。
请排成每天可执行的任务，预留补缺时间，并给每周的验收标准。
```

### 已有计划，但总是拖延或分心

```text
计划已经有了，但我每次坐下五分钟就刷手机。
不要重新排一份大计划；先帮我找今天的启动阻力，把第一步缩到 5 分钟，
再给一张 25 分钟专注卡和结束后的简短复盘。
```

学习模块可以生成计划和专注卡，但没有真实调度能力时不会假装闹钟已开始。需要真实提醒时使用自动化。

### 用自己的话检验是否真懂

```text
我来给你讲牛顿第二定律。
请先听我完整讲，不要中途替我补答案；
然后按概念边界、为什么、自己举例、换情境迁移来追问，最后告诉我哪一层还没过。
```

“请解释”和“我来讲”是两种不同目标。想先学会就请 AI 解释；想检验自己就由你先讲。

## 笔记、复盘与兴趣

### 整理课堂笔记并自测

```text
这是今天的课堂笔记。请保留老师原意，整理成线索问题、主体笔记和底部总结，
再出 5 个盖住笔记就能做的自测题。这次先不写入 Wiki。
```

“整理笔记内容”属于学习；“放进哪个目录、怎么建索引”属于 Wiki 维护。只整理笔记不等于同意写入文件。

### 本周复盘

```text
这是我这周完成的任务、三道错题和两次复测结果。
请区分事实、我的感受和你的推断，总结一个进步、一个阻塞和下周唯一重点。
不要因一周状态就给我下长期能力结论。
```

多周或阶段体检应提供更长时间的记录，并要求 AI 给每个判断标注证据强度。

### 兴趣探索

```text
我还不知道自己真正喜欢什么，最近对机器人和生物都有点好奇。
请不要一次自评就给我贴兴趣标签，而是设计两个一周小实验，用我是否愿意持续投入来验证。
```

### 跨学科项目

```text
我想用“城市热岛”做一个一周项目，连接地理、物理和生物。
请帮我缩小核心问题，设计每天的证据任务，最终产出一张可展示的关系图。
```

## Wiki 怎么用

Wiki 用来长期保存**已确认**的知识、方法、资料和学习产物；它不应默认收集所有对话。你不需要先理解“Raw、索引或 Schema”这些词，只要告诉 AI 你是新建、接入、入库、查找还是整理即可。

### 1. 第一次：新建，还是接入已有库

如果还没有知识库：

```text
我想新建一个学习 Wiki，用来长期整理学习资料、错因和复习方法。
请先用通俗语言告诉我会建立什么结构、每一层放什么；列出计划后等我确认，再创建文件。
```

如果已经在用 Obsidian 或 Markdown 文件夹：

```text
我有一个正在使用的 Obsidian/Markdown 知识库，想接入 llm-wiki。
请先读取现有结构和本地规则，给我一份增量适配计划；不要批量改名、搬空或覆盖已有笔记，首次写入前等我确认。
```

如果任务需要 Obsidian 的原生能力（例如 Bases、CLI、附件嵌入），AI 会先检查 `kepano/obsidian-skills`；缺失时自动尝试安装官方版本。网络失败不会中断你的 Wiki 工作，只会回退到普通 Markdown/Wikilink 流程。

### 2. 把课本、文章、PDF 或笔记入库

```text
把这份资料入我的 Wiki。请保留原始材料，提炼可复习的知识点、概念关系和待验证问题；
先告诉我会新增或更新哪些页面，再执行。
```

原始资料保留为证据，AI 编译出的知识页可以随着理解更新；不要因为有新结论就悄悄覆盖原文。

### 3. 把已完成的学习沉淀进去

```text
把刚才已经确认的错因、订正方法和复测题写入我的 Wiki。
只传这次任务所需的最小内容，写入前展示目标文件、将新增或修改的字段和撤销方式。
```

这一步适合在讲题、错题分析、作文修改或阶段复盘已经完成之后做；“整理当前内容”本身不等于同意写入 Wiki。

### 4. 查询、复用和体检

```text
在我的 Wiki 里找与“函数单调性”相关的笔记和错因。
只返回与本次复习直接相关的文件摘要，不扫描无关私人目录。
```

```text
检查我的 Wiki：找出断链、孤儿页、缺少来源或已过期的结论。
按严重程度列出问题和修复计划；不要为了消除报错而创建空页面，也不要直接批量修改。
```

### 什么时候需要确认

首次创建、接入已有库、写入学习结果、批量迁移、删除、覆盖和大量重命名都要单独确认。普通查询只回答当前问题，不应强制新建文件或读取完整学习档案。

## 提醒、OCR 和夜间分析怎么用

### 安装按需模块

```text
请帮我安装 k12-automation：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/k12-automation
```

### 创建真实提醒

```text
每天 20:30 提醒我复习 15 分钟英语单词。
创建前先展示提醒内容、渠道、时区、频率和下一次触发时间，等我确认。
创建后返回真实任务 ID；如果没有可用的调度器，只给可复制计划并明确说“未创建”。
```

常用控制话术：“查看提醒”“暂停这个提醒”“恢复提醒”“取消提醒”。

### OCR

```text
请识别这张题目图片，先标出模糊或不确定的区域，不要自行补全数字和公式。
如果需要把图片发给外部模型，先告诉我会发送什么、用于什么、是否保留，等我同意。
```

### 夜间错题分析

```text
请帮我启用夜间错题分析。
先用 mock 模式验证运行时，再列出真实运行将读取的数据、可能发送到的服务、输出位置、
运行时间、日志保留和停用/删除方式。真实模型、OCR、长期档案和提醒分别等我授权。
```

夜间分析成功不等于默认允许建档或提醒。每种真实副作用都有独立开关。

## 隐私与授权

### 默认规则

- 默认只使用当前会话中的材料。
- 普通讲题、解释、批改和会话内复盘不需要长期授权。
- 安装模块不等于同意建档、写 Wiki、创建提醒或外传材料。

### 什么动作必须先确认

跨会话档案、Wiki 写入、真实提醒/夜间任务、向外部服务发送图片或学习摘要，都应先说明：

1. 要处理哪些字段或文件；
2. 用于什么学习目的；
3. 保存或发送到哪里；
4. 保留多久；
5. 如何查看、更正、导出或删除。

你可以直接说：

- “这次只在当前会话使用，不要保存。”
- “使用我本次提供的题目，但不要读取历史档案。”
- “先给我看准备记录的字段，我确认后再建档。”
- “查看我的学习档案。”
- “把档案里的这一条更正为……”
- “删除我的英语学习偏好记录，执行前先显示匹配项。”
- “不要写入 Wiki，不要共享给其他模块。”
- “撤回之后停止后续使用；是否删除已有数据由我再选择。”

系统不应记录身份证件、真实住址、电话、账户、医疗诊断、家庭纠纷或财务细节。一次情绪或一道错题不应被固化为性格、智力或长期能力标签。

## 家长怎么用

家长可以用系统帮助孩子分析材料、设计支持方式和进行家庭复盘，但应让孩子知情，并避免把系统变成默默监控工具。

```text
这是孩子知情并同意提供的本周作业、错题和自评。
请只基于这些证据，区分“知识不会”“方法不稳”和“执行阻力”，
给我一个可支持的家长动作和一个应该交还给孩子的自主决定，不要贴标签。
```

要做阶段复盘时，可以说：

```text
请生成一份适合亲子共读的复盘：先写事实和进步，再写一个待验证问题，
最后让孩子自己选下周重点。不使用“懒”“粗心”“不自律”等人格判断。
```

## 常用话术速查

| 我想做的事 | 直接这样说 |
|---|---|
| 第一次使用 | “这是我最近的材料。用 3–5 分钟快速测评建立初版学习 DNA，然后马上带我完成一个真实动作；不要全面测评。” |
