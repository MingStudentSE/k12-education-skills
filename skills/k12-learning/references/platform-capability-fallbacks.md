# 平台能力与诚实降级矩阵

本文件是 `k12-learning` 对宿主能力的统一判断规则。先确认本轮实际可用的能力和返回证据，再决定执行路径；用户的历史授权、平台名称或任务描述都不能代替能力检查。

| 能力 | 只有满足以下条件才可声称已执行 | 能力缺失时的降级 | 禁止声称 |
|---|---|---|---|
| TTS / 音频播放 | 宿主实际生成或播放音频并返回可核验结果；若把文本发送给远端 TTS，还必须具备本批次有效的外传授权 | 生成朗读稿，请教师、家长或本地设备朗读；学生直接看文本时，只算阅读或听前准备 | 不把纯文本生成说成“已经播放/完成听力训练”，不因有远端能力就跳过外传授权 |
| 录音 / 音频分析 / 音素评估 | 本轮确实收到可分析音频，宿主提供相应分析能力；若发送给远端服务，还必须具备本批次有效的外传授权 | 使用学生转写或文字作答，只反馈用词、语法和结构 | 不评价发音、重音、语调、连读、语速或音素准确度，不把录音静默发送到远端 |
| 视觉理解 / OCR | 本轮实际获得图片识别结果；OCR 外传还须遵守 `k12-automation` 的逐批授权 | 请用户手动转录题面、笔记或词表；图形题补充对象、标注、已知条件和关系 | 不在图片不可读或未识别时补猜题目、笔记或单词 |
| 定时调度 / 主动提醒 | `k12-automation` 的真实 adapter 已创建任务并返回任务 ID、下一次触发时间和控制入口 | 只给可复制计划、日历文本或“下次回来先做什么”的队列，并明确“未创建提醒” | 不把计划、意向或授权说成“提醒已设置” |

## 执行顺序

1. 识别任务依赖的能力，不因用户说“播放、识别、提醒”就假定能力存在。
2. 先判断能力在本地还是远端执行。远端 TTS、音频分析或 OCR 都会外传未成年人内容，必须按 `SECURITY_BASELINE.md` 单独记录提供方 origin、固定数据范围和授权日期；提供方或范围变化后旧授权失效。长期建档、OCR 或其他历史授权不能相互替代。
3. 能力与授权都满足时，只报告宿主真实返回的结果；失败或返回不完整时进入对应降级。
4. 降级后重新命名任务，例如“听力训练”降为“朗读稿＋听前准备”，“纠音”降为“口语文本表达反馈”。
5. 需要外传文本、录音或图片，长期写入或创建真实提醒时，能力检查不能替代对应授权。
