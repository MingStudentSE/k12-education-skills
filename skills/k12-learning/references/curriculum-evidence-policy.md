# 课标证据镜头

本规则把课程标准转成学生任务中的证据链。它是 `k12-learning` 的跨切执行规则，不是新的 capability、playbook、评分体系或 Learning State。

## 何时加载

先按正常路由选择主 playbook，再判断是否需要课标证据镜头：

- 用户明确提到“2022 新课标、核心素养、学业质量、教—学—评一致、学习目标或评价标准”时加载。
- 义务教育阶段的首次快速测评、阶段计划或证据复盘，需要把材料观察转成下一项任务时加载。
- 普通单题只在它能改善当前反馈时轻量使用；不要为了展示术语而打断解题。

选择路径只有一条：

1. 读 `curriculum/2022/index.json`，使用其中的 `resolver`；不要由 caller 自己拼接 policy、standards 和 profile。
2. 先用年级和学科取得 scope 与当前学科候选；根据学生材料中的可观察行为选一个 competency/model，再用同一 resolver 取得完整模型。
3. resolver 只加载当前学科的一份 `curriculum/2022/evidence/*.json`。候选阶段返回学科章节起始页；选定模型后只通过 `sourceEvidence` 返回该 competency 的精确 `sourcePage`，并与学科级 PDF URL、章节和内容指纹组合；不要让 caller 复用章节起始页或一次加载九科。
4. `needs-context`、`out-of-scope` 或 `unsupported-route` 不得降级成假对齐；按返回的 `scopeNote` 说明边界。

## 学段与版本边界

- `cn-compulsory-2022` 仅适用于九年义务教育，2022 年秋季起执行。
- 高中请求不得标成“2022 新课标”。高中应另行核对《普通高中课程方案和课程标准（2017 年版 2020 年修订）》及学科版本；当前模型未建立高中事实库时，只使用通用证据链，不冒充课标对齐。
- 年级不明且用户没有要求课标对齐时，不为此阻塞当前学习任务；使用通用可观察行为。用户明确要求 2022 对齐且学段会改变结论时，只问一个年级/学段问题。
- `politics` 是内部路由别名。义务教育正式科目是“道德与法治”；高中“思想政治”属于另一套标准，不共用 2022 事实。
- 当前仓库没有小学“科学”专用学科能力。`science-solving-four-steps` 是理科解题方法，不得宣称等同于 2022 科学课程覆盖。

## 执行链

每次只选择一个最能解释当前材料的主素养及一个证据模型：

1. **核心素养**：使用 resolver 返回的正式名称与 `sourceLocator`；不把旧“三维目标”重新包装成并列目标。
2. **可观测证据**：描述学生在题面、步骤、表达、实验、作品或复测中实际做了什么。不得用“素养高/低”“能力差”替代证据。
3. **学习任务**：选择能直接暴露该行为的最小任务，给出成功标准；首次使用不得额外扩成长测评。
4. **反馈调整**：根据缺失、初现、稳定表现三种结果改变支架、难度或迁移距离，并给下一次复测。

若材料不足，输出“尚无足够证据”和最小取证动作，不判定掌握。一次观察只能形成会话内局部观察；至少需要独立复现和迁移证据，才可讨论稳定表现。

学习任务必须由学生执行。用户尚未给出自己的尝试时，首轮只提供一个线索以及空白问题、表格或句架，随后停止输出并等待作答；不得先列完候选知识点、处理程序、案例分析或答案骨架。拿到表现后再选择 `whenMissing / whenEmerging / whenDemonstrated`，不能在观察发生前假装已经反馈调整。

## 首次使用

- 仍遵守 3–5 分钟、最多 3 个短动作的上限。
- 一份材料最多选一个局部证据指标，不做全科核心素养测评。
- 初版学习 DNA 只写“观察到的行为 + 材料来源 + 待验证项 + 置信度”，不写“已具备/缺失某核心素养”。
- 形成下一步判断后，立即回到学生带来的真实任务。

## 状态与表达

- 默认只在当前会话使用证据模型。跨会话保存仍按 `privacy-and-state.md` 单独确认。
- 即使获得授权，也只保存可更正的观察摘要和复测结果，不保存由单次材料推断的素养总分。
- 面向学生优先说“这次我们观察什么、做到什么算成功、下一步怎么调”；只有用户需要时再展示课标术语和模型 ID。
- `standards.json` 的正式名称属于课标事实摘要；学科级只保存官方 PDF、章节起始页和 SHA-256，每项 competency 只保存去重后的精确 `sourcePage`，由 resolver 组合成可复核引用。`evidence/*.json` 的观察、任务和反馈均为本项目操作化，不得称为教育部原文。
