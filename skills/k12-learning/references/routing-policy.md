# K12 Learning 内部路由规则

## 原则

1. 当前明确目标优先于首次定位；强材料信号优先于宽泛自评。
2. 一个主 playbook 对当前结果负责；辅助 playbook 最多两个，且必须直接改善同一结果。
3. 路由只用当前消息。历史证据在选择完成并通过授权门后按需读取。
4. 学科是稳定 seam，方法是 module 内部 mode。不要把方法重新暴露为 Skill。

## 高频冲突

| 冲突 | 选择 |
|---|---|
| 当前题 vs intake | 有具体材料直接处理；无明确任务才 intake |
| 当前解法 vs 反复错因 | 当前步骤走单题；有多次证据才走 error-dna |
| 错题首次处理 vs error-dna | 首次走 correction；长期模式走学科 error-dna |
| 概念解释 vs 费曼 | “请解释”走概念；“我来讲”走费曼 |
| 普通单题 vs 四步法 | 普通卡点走学科单题；“学透/遮住不会/变式”叠加四步法 |
| 计划 vs 专注 | 未形成安排走计划；计划已有但执行失败走专注 |
| 周复盘 vs 360 | 单周轻复盘走 weekly；多周证据评级走 360 |
| 跨学科项目 vs 学习编排 | 主题研究走侦探；同一学习结果需要多方法时内部组合 |
| 笔记内容 vs Wiki 结构 | 内容组织走康奈尔；目录、索引、入库走 llm-wiki |
| 文本提醒计划 vs 真实提醒 | 文本计划留在本 module；真实调度走 automation |

## 最小澄清

只有两个候选会产生不同下一步时，问一个问题：

- “你现在想解决这道题，还是分析为什么同类题反复错？”
- “你想让我解释，还是由你讲一遍、我来检验？”
- “你需要安排任务，还是已有计划但执行不下去？”
- “你想整理这页内容，还是维护整个 Wiki 仓库？”

不会改变主 playbook 时直接执行，不追问年级、教材、画像和授权全套信息。

## 组合规则

- 学科单题 + 四步法 + 费曼：用于“学透并验证”。
- 错题处理 + 学科 error-dna：仅在用户提供反复证据时。
- 学科概念 + 康奈尔：用户明确要形成自测笔记时。
- 计划 + 专注：先产出可执行计划，再解决执行阻力；不要并行给两套任务。
- 任何组合涉及历史、写入、提醒或跨 module 时，先走授权门。
