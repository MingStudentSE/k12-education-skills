# 地理地图类型库

> 本文档为 `geography-map-coach` 的地图类型判读资源，按分布图、统计图、示意图、景观图、区域图、剖面图组织。

---

## 一、地图类型总览

| 类型 | 核心问题 | 必读要素 | 常见题目 |
|------|----------|----------|----------|
| 分布图 | 地理事物在哪里、多不多、怎么排布 | 范围、密度、走向、集聚、空白区 | 人口、城市、农业、资源、灾害分布 |
| 统计图 | 数值如何变化、结构如何组成 | 轴名、单位、时间、峰谷、转折 | 人口增长、产业结构、气候资料 |
| 示意图 | 过程如何发生、关系如何连接 | 箭头、环节、输入输出、反馈 | 水循环、热力环流、洋流、城市功能 |
| 景观图 | 看到哪些地表特征 | 地貌、植被、聚落、生产活动 | 地貌识别、农业地域类型、城市景观 |
| 区域图 | 该区域有什么综合特征 | 位置、自然要素、人文要素 | 区域发展、流域治理、工业区位 |
| 剖面图 | 垂直方向如何变化 | 高程、坡向、垂直带、地下结构 | 地形剖面、地质剖面、垂直自然带 |

---

## 二、分布图

### 判读要点

```text
1. 看分布范围：集中在哪些区域，缺失在哪些区域
2. 看密度差异：哪里密，哪里疏
3. 看走向：沿海、沿河、沿山麓、沿交通线、沿纬线
4. 看边界：过渡带在哪里，界线是否清晰
5. 看异常：有没有离群点或反常空白区
```

### 高频分布图

| 图型 | 典型规律 | 解释入口 | 易错点 |
|------|----------|----------|--------|
| 人口分布图 | 平原、沿海、河谷、城市群密集 | 地形、气候、水源、经济、交通 | 只写"经济发达"，漏掉自然基础 |
| 城市分布图 | 沿河、沿海、交通干线、资源地集中 | 交通、资源、地形、历史基础 | 把所有城市都解释成资源型 |
| 农业分布图 | 受热量、水分、地形、市场影响 | 气候、地形、土壤、水源、市场 | 忽视作物生长条件 |
| 工业分布图 | 资源型、市场型、交通型、技术型 | 原料、能源、市场、劳动力、技术 | 不区分传统工业和高新技术产业 |
| 灾害分布图 | 沿板块边界、季风区、河谷低地集中 | 地质、气候、地形、人类活动 | 把灾害只归因于自然，不看暴露度 |

## 三、统计图

### 图型速查

| 图型 | 读图顺序 | 规范表达 | 易错点 |
|------|----------|----------|--------|
| 折线图 | 轴名→起终点→峰谷→转折→斜率 | "先升后降，某年达到峰值" | 只说升降，不说阶段 |
| 柱状图 | 类别→数值→高低→差值 | "A高于B约X，差异明显" | 忽略单位和数量级 |
| 饼图 | 总体→最大项→最小项→结构 | "以X为主，Y占比较低" | 把占比当绝对数量 |
| 堆积图 | 总量变化→结构变化→主导项变化 | "总量增长，同时结构由X转向Y" | 只看总量，不看结构 |
| 气候资料图 | 气温曲线→降水柱→雨热组合 | "夏季高温多雨/全年温和湿润" | 南半球季节读反 |

### 气候资料图专项

| 判断项 | 操作 | 例子 |
|--------|------|------|
| 半球 | 最高温出现在7月左右为北半球，1月左右为南半球 | 7月高温：北半球夏季 |
| 热量 | 看最冷月和最热月 | 最冷月>15度：热带 |
| 降水 | 看年总量和季节分配 | 夏雨型、冬雨型、全年湿润、全年少雨 |
| 类型 | 组合热量与降水 | 高温多雨：热带雨林气候 |

## 四、示意图

### 判读状态机

```text
S1 识别对象：图中有哪些地理对象或环节？
S2 识别箭头：箭头表示流向、风向、能量、水分、人口还是货物流？
S3 判断输入输出：系统从哪里获得物质/能量，向哪里输出？
S4 判断循环反馈：是否存在循环、增强或削弱关系？
S5 进入机制解释：若需要解释原因，转 geography-process-explainer
```

### 高频示意图

| 图型 | 关键箭头 | 机制入口 | 易错点 |
|------|----------|----------|--------|
| 水循环 | 蒸发、水汽输送、降水、径流、下渗 | 水分收支与环节联系 | 把径流和水汽输送方向混淆 |
| 热力环流 | 近地面风、高空风、上升/下沉气流 | 冷热不均→气压差→空气运动 | 把冷热与气压高低关系读反 |
| 洋流 | 洋流方向、寒暖性质 | 盛行风、地转偏向力、海陆轮廓 | 只背名称，不看方向和性质 |
| 城市功能区 | 中心、边缘、交通轴、地价 | 地租、交通、环境、功能分化 | 把示意图当真实比例地图 |

## 五、景观图

### 景观图四问

```text
1. 看自然：地貌、坡度、水体、植被、土壤裸露程度
2. 看人文：聚落、道路、农田、工厂、旅游设施
3. 看尺度：这是局部照片、遥感影像还是剖面景观？
4. 看证据：每个判断必须对应可见特征
```

| 景观特征 | 可能判断 | 证据要求 |
|----------|----------|----------|
| 梯田 | 山地农业、坡地改造 | 阶梯状田块、坡地、水源条件 |
| 沙丘 | 干旱区风力沉积 | 新月形/波状沙丘、植被稀少 |
| 喀斯特峰林 | 石灰岩溶蚀地貌 | 峰丛、洼地、地下河或溶洞线索 |
| 河曲/牛轭湖 | 河流侧蚀和裁弯取直 | 弯曲河道、废弃弯道 |
| 高架道路和密集楼群 | 城市化和交通立体化 | 建筑密度、道路层级 |

## 六、区域图

### 区域图要素表

| 要素 | 图上证据 | 分析方向 |
|------|----------|----------|
| 位置 | 经纬度、海陆、邻国、交通通道 | 决定热量、水分、交通联系 |
| 地形 | 等高线、山脉、平原、河谷 | 影响气候、水文、农业和交通 |
| 气候 | 等温线、降水量、气候图 | 影响植被、农业、水资源 |
| 水文 | 河流、湖泊、流向、流域 | 影响供水、航运、洪涝、农业 |
| 资源 | 矿产、能源、土地、水能 | 影响工业和区域开发 |
| 人文 | 城市、人口、产业、交通 | 影响经济联系和人地关系 |

### 区域图禁止清单式罗列

```text
低效：
  该地有山、有河、有城市、有铁路。

有效：
  该地位于河流中下游平原，地形平坦、水源充足，
  城市和交通线沿河谷集中，说明自然通道和水源共同影响聚落分布。
```

## 七、剖面图

| 图型 | 判读要点 | 易错点 |
|------|----------|--------|
| 地形剖面图 | 高程、坡度、起伏、相对高度 | 横纵比例不同，不能直接按视觉坡度判断 |
| 地质剖面图 | 岩层新老、断层、褶皱、侵入体 | 不把地表高低直接等同岩层新老 |
| 垂直自然带图 | 基带、雪线、坡向差异 | 迎风坡/背风坡与阳坡/阴坡要分开 |
| 河流剖面图 | 上中下游坡降和侵蚀沉积 | 上游流速快不等于流量一定大 |

## 八、图型选择与联动规则

```text
读图后如果问题是：
  "在哪里、有什么特征" → 继续 map-coach
  "为什么形成这个过程" → 转 geography-process-explainer
  "这个区域如何综合评价" → 转 geography-region-analyzer
  "这道题怎么答" → 转 geography-problem-coach
  "总在这种图上错" → 经同意转 geography-error-dna
```
