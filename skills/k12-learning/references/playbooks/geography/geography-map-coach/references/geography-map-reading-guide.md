# 地理读图四步法手册

> 本文档为 `geography-map-coach` 的核心参考资源，定义读图四步法、空间定位、等值线判读、图图转换和学段降级规则。

---

## 一、读图四步法

```text
Step 1 看三要素：图名、图例、比例尺/方向
Step 2 定位置：经纬网、海陆轮廓、相对位置
Step 3 提信息：数值、分布、趋势、结构、过程
Step 4 判规律与异常：总体规律、局部异常、可能因素、下一步解释
```

### Step 1：看图名、图例、比例尺

| 信息 | 必问问题 | 输出句式 | 常见错误 |
|------|----------|----------|----------|
| 图名 | 这张图研究什么主题、什么区域、什么时间？ | "这是一张[区域/主题/时间]图" | 不看图名，把区域或年份猜错 |
| 图例 | 颜色、符号、线型分别表示什么？ | "深色代表[含义]，虚线代表[含义]" | 把颜色深浅当作审美差异 |
| 比例尺 | 这张图是大尺度还是小尺度？ | "这是[全球/国家/省域/城市/局部]尺度" | 用国家尺度结论解释街区图 |
| 方向 | 北在哪里？河流/风/洋流箭头指向哪？ | "箭头显示[方向]，说明[流向/运动方向]" | 默认上北下南，忽略图上方向标 |

### Step 2：定位置

```text
定位顺序：
  1. 先判纬度：低纬/中纬/高纬，南北半球
  2. 再判经度：东西半球，大致经度范围
  3. 再判海陆：临海/内陆/岛屿/半岛/海峡
  4. 最后判相对位置：位于山脉、河流、城市、国家的哪一侧
```

### Step 3：提取信息

| 图上信息 | 提取动作 | 标准输出 |
|----------|----------|----------|
| 数值 | 找最大、最小、等值距、单位 | "最大值在A，最小值在B，差值约为X" |
| 分布 | 找密集区、稀疏区、空白区 | "主要集中在沿海/河谷/平原/交通线附近" |
| 趋势 | 找起点、终点、峰谷、转折 | "总体上升，但在某年后增速放缓" |
| 结构 | 看占比、主导项、次要项 | "第一产业占比下降，第三产业占比上升" |
| 过程 | 看箭头、环节、输入输出 | "A环节输入水汽，B环节形成降水" |

### Step 4：判断规律与异常

```text
规律句模板：
  [地理事物]在[区域]呈现[方向/密度/数值/结构]特征，
  主要与[纬度/地形/海陆/洋流/交通/资源/政策/人类活动]有关。

异常句模板：
  [地点]不符合总体规律，可能因为[局部地形/城市热岛/河流补给/资源点/交通节点/人为调控]。
```

## 二、空间定位三法

### 1. 经纬网定位法

```text
三问：
  1. 纬度向哪边增大？北增为北纬，南增为南纬
  2. 经度向哪边增大？东增为东经，西增为西经
  3. 点在格网的哪一格？先读纬度，再读经度
```

| 场景 | 读法 | 易错提醒 |
|------|------|----------|
| 单点定位 | 读交点或估读范围 | 不把纬度经度顺序写反 |
| 区域定位 | 读边界范围 | 区域题不能只写中心点 |
| 半球判断 | 先南北，后东西 | 东西半球分界不是0度经线，而是20W和160E |

### 2. 海陆轮廓定位法

| 轮廓线索 | 典型使用 | 注意 |
|----------|----------|------|
| 大洲大洋轮廓 | 世界区域定位 | 先大后小，不用细碎海岸线硬猜 |
| 半岛/岛屿 | 亚洲、欧洲、东南亚、地中海区域 | 要结合纬度和邻近海域 |
| 海峡/运河 | 交通区位题 | 说明连接的海域或大洲 |
| 河口/三角洲 | 农业、城市、港口题 | 结合河流流向和沉积环境 |

### 3. 相对位置定位法

```text
标准句：
  A位于B的[方向]，靠近[河流/山脉/海域/城市/交通线]，属于[上游/下游/迎风坡/背风坡/沿海/内陆]位置。
```

相对位置必须包含参照物。不能只说"在东部"，要说"在某山脉以东、某河流下游、某城市群北侧"。

## 三、等值线判读规范

### 五原则操作表

| 步骤 | 操作 | 输出 |
|------|------|------|
| 1 同线等值 | 找任意一条等值线，确认线上的值 | "该线为X，线上各点相同" |
| 2 等值距 | 看相邻线差值 | "等值距为X，便于估算闭合区" |
| 3 数值增减 | 标出高值区和低值区 | "数值由东南向西北递减" |
| 4 疏密 | 找最密和最疏位置 | "A处变化快，B处变化慢" |
| 5 弯曲闭合 | 先判高低，再解释成因 | "闭合区内部高于/低于周围" |

### 等高线专项

| 图形特征 | 地形判断 | 判读理由 |
|----------|----------|----------|
| 等高线闭合，中间高 | 山峰/丘陵 | 内高外低 |
| 等高线闭合，中间低 | 盆地/洼地 | 内低外高 |
| 等高线向高处凸 | 山谷 | 谷线海拔较低，常有河流 |
| 等高线向低处凸 | 山脊 | 脊线海拔较高 |
| 两山顶之间低处 | 鞍部 | 连接两个高地的低洼部位 |
| 等高线重合 | 陡崖 | 坡度极陡 |

### 等温线、等压线、等降水量线

| 类型 | 先看 | 常用解释因素 | 易错点 |
|------|------|--------------|--------|
| 等温线 | 纬度走向、海陆弯曲、地形高低 | 纬度、海陆热力差异、地形、洋流 | 不同半球季节相反 |
| 等压线 | 高低压中心、疏密、风向 | 气压梯度力、地转偏向力、摩擦力 | 风从高压吹向低压但不垂直等压线 |
| 等降水量线 | 迎风坡/背风坡、距海远近 | 海陆位置、地形抬升、季风、洋流 | 不能只用纬度解释所有降水 |

## 四、统计图判读规范

```text
统计图四读：
  读轴：横轴、纵轴、单位、时间范围
  读点：最大值、最小值、起点、终点
  读线：上升、下降、波动、转折、增速变化
  读义：趋势对应的地理含义
```

| 图型 | 判读要点 | 输出句式 |
|------|----------|----------|
| 折线图 | 趋势、斜率、峰谷、转折 | "总体上升，某年后增速放缓" |
| 柱状图 | 高低比较、组间差异 | "A明显高于B，差异约为X" |
| 饼图 | 结构占比、主导部门 | "以X为主，占比超过一半" |
| 雷达图 | 多指标强弱 | "X、Y优势明显，Z是短板" |
| 散点图 | 相关方向、离群点 | "总体正相关，但A点偏离明显" |

## 五、图图转换

### 文字转图

| 文字线索 | 转换方式 |
|----------|----------|
| 自东南向西北递减 | 画方向箭头和高低区 |
| 沿河流/铁路分布 | 画线状分布 |
| 山地垂直变化 | 画剖面或垂直带谱 |
| 城市圈扩展 | 画中心-外围圈层 |

### 图转表

```text
区域图 → 要素表：
  位置：经纬度/海陆/相对位置
  自然：地形/气候/水文/资源
  人文：人口/城市/产业/交通
  证据：每个要素必须对应图上一个线索
```

### 图转答题句

```text
图上证据：
  东部沿海城市密集，西部内陆城市稀疏。

规范表达：
  该区域城市分布呈东密西疏、沿海沿交通线集中的特点，
  可能与地形平坦、交通便利、经济基础较好有关。
```

## 六、学段降级与升级

```text
初中降级：
  读图目标 = 图名图例 + 位置 + 一条主要信息
  等值线目标 = 高低、疏密、基本地形
  统计图目标 = 增减趋势和最大最小

高中升级：
  读图目标 = 多图互证 + 异常解释 + 尺度转换
  等值线目标 = 弯曲闭合、成因推断、条件变化预测
  统计图目标 = 阶段划分、相关关系、结构转型
```
