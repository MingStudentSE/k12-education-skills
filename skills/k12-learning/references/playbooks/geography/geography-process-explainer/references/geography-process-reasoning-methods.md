# 地理过程推理方法手册

> 本文档为 `geography-process-explainer` 的核心参考资源，定义过程推理四步法、六大过程因子-机制表、反事实验证和学段边界。

---

## 一、过程推理四步法

```text
Step 1 过程识别：判断是哪类地理过程
Step 2 因子分解：拆出驱动因子、限制因子、调节因子
Step 3 机制推理：说明因子如何作用并叠加
Step 4 结论验证：换区域/条件/时间检验机制
```

### 状态执行表

| 状态 | AI 动作 | 学生动作 | 退出条件 |
|------|---------|----------|----------|
| S1 识别过程 | 追问图上箭头、环节、对象和尺度 | 先说出过程名称和证据 | 能说"这是X过程，因为图上有Y" |
| S2 分解因子 | 引导列驱动、限制、调节因子 | 先列已有因子 | 因子不只是标签，能分类 |
| S3 推理机制 | 要求写"因子→作用→结果" | 用箭头连成链条 | 机制链不跳步，方向正确 |
| S4 验证结论 | 提出换条件问题 | 预测变化并解释 | 能指出哪一步改变 |

## 二、水循环过程

### 因子-机制表

| 因子 | 作用方式 | 影响环节 | 常见题型 |
|------|----------|----------|----------|
| 太阳辐射 | 提供蒸发和蒸腾能量 | 蒸发、蒸腾 | 水循环环节识别 |
| 大气环流/风 | 输送水汽 | 水汽输送、降水 | 季风降水、迎风坡 |
| 地形 | 抬升气流或阻挡水汽 | 降水、径流 | 地形雨、背风坡干旱 |
| 植被 | 截留降水、促进下渗和蒸腾 | 下渗、径流、蒸腾 | 水土保持 |
| 城市化 | 地面硬化，减少下渗 | 地表径流、地下径流 | 城市内涝 |
| 水利工程 | 调节径流时空分配 | 径流、蒸发、补给 | 水库影响 |

### 机制链模板

```text
自然状态：
  热量充足 → 蒸发/蒸腾增强 → 水汽输送 → 地形或锋面抬升 → 降水 → 径流/下渗

城市化影响：
  地面硬化增加 → 下渗减少 → 地表径流增加 → 汇流时间缩短 → 内涝风险上升

植被破坏影响：
  植被截留减少 → 坡面径流增强 → 土壤侵蚀加剧 → 河流含沙量上升
```

## 三、热力环流过程

### 基本机制

```text
地表冷热不均
  → 受热多处空气膨胀上升
  → 近地面形成低压，高空形成高压
  → 受热少处空气冷却下沉
  → 近地面形成高压，高空形成低压
  → 近地面风由高压吹向低压，高空相反
```

### 常见场景

| 场景 | 白天/夏季机制 | 夜晚/冬季机制 | 易错点 |
|------|---------------|---------------|--------|
| 海陆风 | 陆地升温快，近地面低压，风由海吹向陆 | 陆地降温快，近地面高压，风由陆吹向海 | 把风向和冷热关系说反 |
| 山谷风 | 山坡升温快，气流沿坡上升形成谷风 | 山坡降温快，冷空气沿坡下沉形成山风 | 不区分坡面和谷地 |
| 城市热岛 | 城市较热，气流上升，近地面风向城市汇聚 | 夜间仍可能维持热岛 | 只说污染，不说热力差异 |

### 判断口诀

```text
先判冷热，再判升沉；
上升近地低压，下沉近地高压；
近地面风从高压吹向低压。
```

## 四、大气环流过程

### 核心因子

| 因子 | 作用 | 结果 |
|------|------|------|
| 纬度热量差 | 赤道热、极地冷 | 形成大尺度气压差 |
| 地转偏向力 | 北半球右偏，南半球左偏 | 风向偏转，形成信风、西风等 |
| 太阳直射点移动 | 气压带风带随季节移动 | 季节性降水和风向变化 |
| 海陆热力差异 | 陆地升降温快，海洋慢 | 季风环流 |

### 气压带风带影响

| 控制系统 | 气流运动 | 降水特征 | 典型气候 |
|----------|----------|----------|----------|
| 赤道低压带 | 上升 | 多雨 | 热带雨林气候 |
| 副热带高压带 | 下沉 | 少雨 | 热带沙漠气候、地中海夏季 |
| 西风带 | 中纬西风 | 较湿润 | 温带海洋性气候、地中海冬季 |
| 极地高压带 | 下沉 | 少雨寒冷 | 极地气候 |

### 季风机制

```text
夏季：
  陆地升温快 → 陆地低压，海洋高压 → 风由海洋吹向陆地 → 带来水汽

冬季：
  陆地降温快 → 陆地高压，海洋低压 → 风由陆地吹向海洋 → 干冷为主
```

## 五、洋流过程

### 因子-机制表

| 因子 | 作用方式 | 结果 |
|------|----------|------|
| 盛行风 | 持续推动表层海水运动 | 洋流初始方向 |
| 地转偏向力 | 北半球右偏，南半球左偏 | 洋流方向偏转 |
| 海陆轮廓 | 陆地阻挡和海盆形状 | 洋流转向和闭合环流 |
| 密度差异 | 温度、盐度导致海水密度差异 | 深层环流或局部补偿流 |

### 影响机制

| 影响对象 | 暖流 | 寒流 |
|----------|------|------|
| 气候 | 增温增湿 | 降温减湿 |
| 海雾 | 暖湿空气遇冷流可形成海雾 | 寒流降低近海温度 |
| 渔场 | 暖寒流交汇或上升流带来营养盐 | 秘鲁寒流上升补偿流典型 |
| 航运 | 顺流加速，逆流减速 | 寒暖流交汇处多雾需注意 |

### 易错纠正

```text
错误："洋流都由风形成。"
修正：表层洋流主要受盛行风驱动，但地转偏向力、海陆轮廓和密度差异共同塑造方向和性质。

错误："暖流一定让沿岸降水多。"
修正：暖流增温增湿，但降水还取决于大气环流、地形抬升和水汽输送条件。
```

## 六、人口迁移过程

### 推拉阻力模型

| 类型 | 因子 | 机制 |
|------|------|------|
| 推力 | 就业不足、收入低、生态恶化、灾害、冲突 | 增加迁出意愿 |
| 拉力 | 就业机会、收入高、教育医疗、城市服务 | 增加迁入吸引 |
| 阻力 | 距离、成本、户籍/政策、语言文化、信息不足 | 降低迁移可能 |

### 机制链模板

```text
区域经济差异扩大
  → 迁出地就业机会不足、收入较低
  → 迁入地产业集聚、就业机会多
  → 青壮年劳动力迁入城市
  → 迁出地老龄化和留守问题，迁入地住房交通压力增加
```

### 判断边界

人口迁移解释不评价学生对迁移的个人态度，只评价推拉因子是否完整、证据是否充分、影响是否双向。

## 七、城市化过程

### 过程链

```text
工业化/服务业发展
  → 就业岗位增加
  → 农村人口向城市迁移
  → 城市人口比重上升
  → 建成区扩展和功能区分化
  → 交通拥堵、住房压力、热岛、内涝等问题
  → 城市更新、公共交通、海绵城市、产业升级等治理
```

### 阶段判断

| 阶段 | 特征 | 常见问题 |
|------|------|----------|
| 初期 | 城市化水平低，速度较慢 | 基础设施不足 |
| 加速期 | 人口快速集聚，建成区扩张 | 交通、住房、环境压力 |
| 成熟期 | 水平高，速度放缓 | 郊区化、老龄化、城市更新 |

### 人地协调追问

| 城市问题 | 过程机制 | 对应治理 |
|----------|----------|----------|
| 内涝 | 地面硬化→下渗减少→径流增加 | 海绵城市、透水铺装、湿地保留 |
| 热岛 | 人工热排放+下垫面改变→城市温度高 | 增加绿地、水体、通风廊道 |
| 通勤拥堵 | 居住与就业空间分离→通勤距离增加 | 公共交通、职住平衡 |
| 生态破碎 | 建成区扩张占用生态空间 | 生态红线、紧凑开发 |

## 八、反事实验证模板

```text
模板一：换区域
  如果这个过程发生在[高纬/低纬/沿海/内陆/山地/平原]，哪一步会变化？

模板二：换季节
  如果从夏季换到冬季，太阳直射点、海陆热力差异或风向如何改变？

模板三：换坡向/地形
  如果从迎风坡换到背风坡，气流抬升和降水会怎样变？

模板四：换人类活动
  如果植被减少、城市硬化或水库建设加强，水循环哪一环节会变？

模板五：换尺度
  全球尺度的气压带风带解释，是否能直接用于城市微气候？不能时需换到热力环流或下垫面机制。
```

## 九、学段边界

```text
初中：
  目标：识别过程、说出基本环节、用一个主要因子解释现象。
  例：海陆位置影响降水，地形影响河流流向，城市化带来交通压力。

高中：
  目标：多因子叠加、机制链、反事实验证、区域条件约束。
  例：洋流由盛行风、地转偏向力、海陆轮廓共同影响；
      气候受纬度、大气环流、海陆、地形、洋流综合影响。

不对初中硬讲：
  三圈环流完整推导、洋流环流系统成因、太阳高度角计算、大气受热过程细节。
```
