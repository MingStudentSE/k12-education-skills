# 🧬 地理错误 DNA

> **一句话定位：** 普通错题本告诉你"哪道地理题错了"——
> 地理错误DNA告诉你"你为什么总在同一类读图、过程或区域综合上出错"，
> 然后用数据消灭那个模糊的"我地理图看不懂/自然地理太难"的感觉。

---

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于地理错因模式、读图定位错、地理概念混淆、过程推理断裂、区域综合偏差、计算表达错误或地理焦虑分析；如果不是，先指出更合适的方法，或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：地理错题、题图/图例/设问、学生答案、正确答案、解题过程和同类错误摘要。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续八节推进，优先用 G1-G5 分类表、纯净版读图测试、追问和小步验证帮助学生找到根因；不要把可训练的修正过程直接替学生做完。
4. **产出结果**：给出 G1-G5 错因分类、子类型ID、跨维度关联、深度根因、专项修复任务和复测计划，并明确"现在能做的下一步"。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不调用 `k12-automation` 创建提醒、不跨 module 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、题图数据、历史记录或学习画像。
- **任务不匹配**：说明当前方法不适合的原因，并建议更合适的方法或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示"快速答案"和"真正掌握"是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 module 共享摘要。
- **内部组合边界**：只传递当前错因修复需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加换图型、换区域或换条件验证；太困难时先做纯净版读图测试或单因子解释。

---

## 学习科学约束

- **单目标**：本轮只定位一个主要地理错因，不同时处理完整复习、月报和多个专项训练。
- **主动回忆**：先让学生复述自己的读图、定位、原理调用或推理过程，再进行深度分类。
- **错误反馈**：每个错误必须形成"根因→修正→再犯预警→变式验证"闭环。
- **结构化表达**：错因必须落入 G1-G5、子类型ID和跨维度关联，不只写"粗心"。
- **交错迁移**：顽固弱项修复后要换图型、换区域或换设问验证。
- **分散复习**：顽固弱项必须给出次日和 3 天后的复测内容。写入长期记录由 `k12-learning` 按 Learning State 授权门处理；需要真实提醒时切换到 `k12-automation`，由 Automation 另行取得调度授权。

## 一、核心使命与架构定位声明

**地理错题的双重特征：**

```text
特征一：读图和空间定位是地理独有地基错因
  数学错题常见根源是概念或计算
  地理错题常常是——图没有读清，位置没有定准
  经纬网判错、图例漏看、等值线读反、区域尺度错配
  → 这不是"粗心"，是地理读图方法缺失

特征二：自然地理焦虑会遮蔽真实根因
  学生常说"自然地理太难""地理图我从来读不懂"
  但档案可能显示：真正高频的是 G1 读图定位或 G3 过程推理
  → 用数据把模糊焦虑变成具体训练任务
```

**这个方法解决的问题：**

```text
出错 → 诊断是读图、概念、过程、区域还是计算表达问题
     → 分类存档 → 发现规律 → 顽固弱项专项突破
                    ↑
        从"这道题错了"上升到"这类地理能力总卡住"
        从孤立错题变成可分析的数据
```

⚠️ **【架构定位——通用记录与地理深度诊断】**

`correction-notebook` 和本方法都是 `k12-learning` 的内部实现。前者提供通用错题记录视图，后者提供地理深度诊断视图；它们不彼此调用或传递中间消息。`k12-learning` 只在同一份当前结果中按需组合两种视图。

| 职责 | 归属 | 说明 |
|------|------|------|
| 当前地理错题与学生尝试 | `k12-learning` 主流程 | 唯一入口，原题证据只收集一次 |
| 基础四维分类与表面字段 | 通用错题记录视图 | 作为同一结果的通用维度 |
| **G1-G5 子类型与跨维度分析** | **地理深度诊断视图** | 结合通用维度、题图和原题证据完成诊断 |
| **顽固弱项识别与专项突破** | **地理深度诊断视图** | 只在多次独立证据或复测支持时升级为模式 |
| **地理焦虑处理** | **当前主 playbook** | 用题目证据和最小任务替代模糊贴标 |
| 月度与学期摘要 | `k12-learning` | 仅读取用户当前提供或已授权的 Learning State |
| 复测建议·地理部分 | `k12-learning` | 只生成内容与建议时间；真实调度由 `k12-automation` 通过自己的 interface 授权后执行 |

**核心原则：通用层记表面，地理层记根因；不产生重复记录，不重复触发预警。**

## 二、五维错误分类体系

这是整个档案系统的核心——每一道地理错题都必须判定一个主维度；跨维度错题可同时记录次要维度子标签：

| 错误类型 | 定义 | 典型特征 | 根治方法 |
|---------|-----|---------|---------|
| G1 读图与空间定位错误 | 读不懂图、定位错，是地理独有地基错误 | 经纬网判错、等值线误读、空间关系乱、地图三要素漏 | 读图四步法专项，联动 map-coach |
| G2 地理概念/原理错误 | 概念混、原理用错 | 天气/气候混、水资源/水能资源混、人口流动/迁移混 | 概念混淆对照表 |
| G3 地理过程推理错误 | 因子遗漏、机制反向、叠加错 | 洋流成因漏因子、热力环流方向反、城市化机制断裂 | 过程推理四步法，联动 process-explainer |
| G4 区域综合分析错误 | 要素关联遗漏、特征概括偏、比较维度缺 | 只罗列要素不说关联、跨尺度硬比 | 区域五步框架，联动 region-analyzer |
| G5 地理计算与表达错误 | 计算错、术语不规范、答题结构乱 | 时区算错、太阳高度错、术语口语化、措施空泛 | 计算手册 + 术语规范 |

### 跨维度错因归属规则

```text
判主维度看本题得分断裂点：哪一步最先导致失分，哪一维就是主维度。
允许并列记录次要维度子标签，不把复杂错题强行压成单一归类。
格式示例：G2+G3概念误用致推理错。
```

| 跨维度示例 | 主维度判断 | 次要维度子标签 |
|------------|------------|----------------|
| 把"水能资源"误当"水资源"，再错误推断水电开发条件 | G2 概念原理先断裂 | G3 概念误用致推理错 |
| 漏看图例，把等温线当等高线，随后区域农业条件分析全错 | G1 读图定位先断裂 | G4 图例误读致综合错 |

### 维度优先级

```text
G1 读图定位 > G3 过程推理 > G4 区域综合 > G2 概念原理 > G5 计算表达

理由：
  读图定位是地理分析起点；
  过程推理决定自然地理高阶解释；
  区域综合决定人地关系和区域认知；
  概念原理贯穿理解；
  计算表达在地理题中常作为最后执行层，但错误仍需精确记录。
```

### 五维诊断苏格拉底追问

```text
G1 读图与空间定位：
  "图名、图例、比例尺告诉你什么？这是哪里？经纬度和相对位置是什么？"
  "如果先做30秒读图，你的答案会不会改变？"

G2 地理概念/原理：
  "你这里用的概念和相邻概念边界在哪里？"
  "这个原理的适用条件满足吗？"

G3 地理过程推理：
  "哪些因子推动这个过程？每个因子怎样起作用？"
  "换一个区域或季节，机制哪一步会变？"

G4 区域综合分析：
  "你列出的要素之间有什么关系？自然要素怎样影响人文活动？"
  "比较对象是否同一尺度，比较维度是否一致？"

G5 地理计算与表达：
  "公式、单位、日期/等值距检查了吗？"
  "你的答案是否有地理术语、分点和问题-措施对应关系？"
```

### 各学段适配

| 学段 | 诊断重点 | 降级/升级策略 |
|------|----------|----------------|
| 初中 | G1 读图定位、G2 基础概念、G4 基础区域差异、G5 基础比例尺/人口密度 | 不把三圈环流、洋流成因、太阳高度角计算作为硬性诊断；过程题降级为现象识别 + 单因子解释 |
| 高中 | G3 多因子机制、G4 区域综合与可持续发展、G5 太阳高度/等值线综合计算 | 要求机制链、要素关联矩阵、反事实验证和规范综合题表达 |

## 四、顽固弱项追踪机制

### 触发标准

**同类错误（相同错误类型+相同知识点标签）出现3次时，可提示进入专项跟踪：**

```text
🧬 档案提醒：
"我发现了一个规律——
 你在[知识点X]上的[错误类型]已经出现了3次：

 第1次：[日期] [题目概述]
 第2次：[日期] [题目概述]
 第3次：今天  [题目概述]

 这可能是一个'顽固弱项'。
 如果你愿意，我可以把它加入持续跟踪档案，后面专门帮你验证和突破。
 现在有10分钟吗？我们来处理它。"
```

### 顽固弱项专项突破流程（地理版）

```text
Step 1：纯净版读图测试
给一个简化版地理任务（只含该知识点，排除长材料和选项干扰）：
"先读一下这张极简图，只需要30秒：
 图名是什么？图例表示什么？这是哪里？图上最关键的信息是什么？"

读图读对了 → 问题在原理应用、区域关联或表达
→ 出3道"加入材料/选项/综合设问"的递进题

读图读错了 → 根源在读图定位或概念
→ 判断是 G1 类还是 G2 类，联动 map-coach 或概念混淆对照训练

Step 2：规则重建
G1 → 读图四步法 + 经纬网/等值线/统计图专项
G2 → 概念混淆对照表 + 概念边界追问
G3 → 过程推理四步法 + 因子-机制链
G4 → 区域五步框架 + 要素关联矩阵
G5 → 自然计算手册 + 术语和答题结构训练

Step 3：验证锁定
"你刚才做对了——但我还不完全放心。
 明天我会再出一道同类型但换图型/换区域的题给你，
 连续两次做对，这个弱项才算真正攻克。"

Step 4：写入档案
在学生同意持续跟踪时，更新该条目状态为"突破中"
若学生同意真实调度，向 `k12-automation` 提交次日和 3 天后的验证题提醒请求
```

## 六、地理弱项月报

## 七、地理焦虑专项处理

### 识别地理焦虑的信号词

```text
触发信号：
- "地理图我从来读不懂"
- "自然地理太难"
- "大题不知道答什么"
- "地理全靠背"
- "我看到等值线就慌"
- "区域题我只会乱写"
- "时区和太阳高度我永远算不对"
```

### 标准处理流程：数据替代情绪 + 具体任务化

```text
Step 1：确认感受（1-2句，不展开）
"你现在很挫败，我听到了。
 先别急，我来看一下你的档案说了什么。"

Step 2：调取精准数据（关键步骤）
不说"你肯定行"，而是说：
"你的档案告诉我：
 [具体知识点]最近两周你出错了[N]次，
 主要集中在[G1读图定位/G3过程推理]。

 [另一个知识点]上次你出错了，
 但后来做了3道同类题，
 第2道和第3道都对了。"

Step 3：把模糊焦虑变成具体任务
"所以'地理不行'这个说法太宽了——
 你现在真正需要的是：
 搞定[精确子类型]这一个点。

 如果是读图问题，我们用3张极简图就能看到进步；
 如果是过程问题，我们把因子和机制画成3条箭头链。
 地理不是全靠背——图读出来，链条连起来，就会清楚很多。"

Step 4：执行（出3道递进题，地理版强调读图和机制）
第1道：简化版读图题（建立信心——"原来先读图就清楚了"）
第2道：精确弱项点（直面问题）
第3道：弱项点的变形（换图型/换区域确认掌握）
```

## 考前梳理

```text
考前地理错因档案自查：

一、先看五维分布
  □ G1是否超过25%？超过则考前先复读图四步法、经纬网、等值线
  □ G3是否超过25%？超过则考前先练过程推理四步法
  □ G4是否集中在区域题？超过则复区域五步框架和要素关联矩阵
  □ G2是否集中在概念混淆？超过则复高频概念对照表
  □ G5是否集中在计算表达？超过则复时区、比例尺、太阳高度和术语模板

二、再看顽固弱项
  □ 只看"顽固/突破中"两类，不翻所有错题
  □ 每个弱项只做1道纯净图题 + 1道变形题
 □ 做错立即回到对应专项方法，不继续刷同类题

三、最后看考场预警句
  □ "无图不题，先读图定位"
  □ "自然题先理机制"
  □ "人文题先析结构"
  □ "措施必须对应问题"
  □ "只评价论证链，不空喊态度"
```

## 八、当前结果的内部组合

### 8.0 单一责任主体

`k12-learning` 对当前结果负责。通用错题记录、地理深度诊断、读图定位、过程解释和区域分析是内部视图，不定义彼此发送消息的 interface。当 G1、G3 或 G4 错因需要专项修复时，当前主 playbook 在同一结果内加入对应训练，只产出一组任务和掌握判据。

### 8.1 最小输入与输出

- 输入只包含当前题目与题图、学生原答或步骤、通用四维的初步判断，以及用户当前提供或已授权读取的最多 3 份相关错题摘要。
- 输出只保留题目证据引用、通用维度、G1-G5 主次维度、判断线索、置信度、修复任务和复测标准。
- 证据不足时写“本次记录，不足以判断长期趋势”，不猜测历史次数。

### 8.2 Product Module seams

- 写入 Learning State 前展示字段、目的、位置和删除方式，并获得用户明确同意。
- `k12-learning` 只生成复测内容、建议时间和掌握判据。用户确认需要真实提醒后，才切换到 `k12-automation`；Automation 通过自己的 interface 获取和保存调度授权。
- 周复盘或阶段报告只读取用户当前提供或已授权的最小摘要，不默认展开完整错题历史。

### 8.3 V3 当前结果内的组合摘要

`k12-learning` 直接组合通用错题记录与地理深度诊断，不创建中间协议对象。若同一结果需要两种视角，只保留题目证据引用、通用维度、地理深度维度、判断线索、修复任务、复测标准与置信度。首次出现保持会话内，只有用户提供多次证据时才判断反复模式。

地理深度维度使用以下值：

```text
读图与空间定位错误(G1)
概念原理错误(G2)
地理过程推理错误(G3)
区域综合分析错误(G4)
地理计算与表达错误(G5)
```

### 8.4 授权后的记录更新

- 当前结果可补充地理子类型、主次维度、深度根因、修复任务和复测结果，但不重复建立题目记录。
- 弱项状态只有在多次独立证据支持时更新为“观察 / 顽固 / 突破中 / 已攻克”。
- 月度摘要可包含五维占比、读图缺口和攻克进展；写入 Learning State 前必须展示字段并获得授权。

### 8.5 V3 去重保障

- 用户首次提交地理错题时，通用记录与地理深度诊断在同一结果内完成。
- 递进练习只生成一组，由当前主 playbook 对结果负责。
- 真实提醒只能在用户单独确认后切换到 `k12-automation`；学习方法不提交或调度提醒。
- 阶段报告只读取用户当前提供或已授权的最小摘要，不推送完整记录。

边界：
- 不在未授权情况下建立长期错因档案。
- 不把"第3次出现"直接写死为长期标签，需结合验证或学生确认。
- 不默认向提醒、学习DNA或周复盘外发完整记录。
- 不为同一道地理错题建立第二条记录。

## 禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 用 G1-G5 和子类型ID定位错因 | 用"粗心""不认真"替代可训练根因 |
