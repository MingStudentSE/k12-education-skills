# 地理自然与基础计算手册

> 本文档为 `geography-problem-coach` 的计算参考资源，覆盖时区、比例尺、太阳高度、人口密度和等高线相对高度。

---

## 一、计算总原则

```text
1. 先判断计算类型
2. 写公式，不心算跳步
3. 统一单位
4. 代入数据
5. 检查数量级、日期或地理意义
```

| 类型 | 公式 | 单位检查 | 高频错误 |
|------|------|----------|----------|
| 时区 | 目标时间=已知时间+目标时区-已知时区 | 小时、日期 | 东西方向和日期变更 |
| 比例尺 | 比例尺=图上距离/实地距离 | cm、m、km统一 | 分子分母单位不同 |
| 太阳高度 | H=90°-|当地纬度-太阳直射纬度| | 度 | 直射点纬度南北号取错 |
| 人口密度 | 人口密度=人口/面积 | 人/km² | 万人和平方千米换算 |
| 相对高度 | 两点海拔差或等高线范围 | m | 等高距、闭合区判断错 |

## 二、时区计算

### 基本规则

```text
目标时间 = 已知时间 + (目标时区 - 已知时区)

东时区为正，西时区为负。
结果超过24点，日期加一天；
结果小于0点，日期减一天。
```

### 例题

```text
已知北京时间（东八区）6月1日20:00，
求伦敦（零时区）时间。

目标时间 = 20:00 + (0 - 8) = 12:00
所以伦敦为6月1日12:00。
```

### 地方时

```text
经度每差15°，地方时差1小时；
经度每差1°，地方时差4分钟；
东边地点时间早，西边地点时间晚。
```

### 易错表

| 错误 | 修正 |
|------|------|
| 目标在东边却减时间 | 东早西晚，东边加，西边减 |
| 把经度差直接当时区差 | 时区差以时区编号为准；地方时才按经度差 |
| 忘记跨日期 | 超过24点加一天，小于0点减一天 |

## 三、比例尺计算

### 公式

```text
比例尺 = 图上距离 / 实地距离
图上距离 = 实地距离 × 比例尺
实地距离 = 图上距离 / 比例尺
```

### 单位换算

```text
1 km = 1000 m = 100000 cm
1 m = 100 cm
比例尺通常写成 1 : N，必须保证图上和实地距离单位一致。
```

### 例题

```text
图上距离为3 cm，实地距离为6 km。
6 km = 600000 cm
比例尺 = 3 / 600000 = 1 / 200000
所以比例尺为 1:200000。
```

### 比例尺大小判断

| 比例尺 | 表示范围 | 内容详略 |
|--------|----------|----------|
| 大比例尺 | 范围小 | 内容详细 |
| 小比例尺 | 范围大 | 内容简略 |

## 四、太阳高度角计算（高中）

### 正午太阳高度公式

```text
H = 90° - |当地纬度 - 太阳直射纬度|
```

纬度带符号：北纬为正，南纬为负；太阳直射北回归线为 +23.5°，南回归线为 -23.5°，赤道为 0°。

### 例题

```text
夏至日，北纬40°某地正午太阳高度：
H = 90° - |40° - 23.5°|
  = 90° - 16.5°
  = 73.5°
```

### 学段边界

```text
初中：不要求太阳高度角计算，只需知道太阳高度与纬度、季节有关。
高中：可计算二分二至日或给定直射纬度下的正午太阳高度。
```

### 易错表

| 错误 | 修正 |
|------|------|
| 南北纬不带符号 | 北正南负，代入后取绝对值 |
| 把太阳高度和昼长混为一谈 | 太阳高度是角度，昼长是时间 |
| 忘记二分日直射赤道 | 春分、秋分直射纬度为0° |

## 五、人口密度计算

### 公式

```text
人口密度 = 人口数量 / 面积
常用单位：人/km²
```

### 例题

```text
某地人口500万人，面积2万km²。
人口密度 = 500万 / 2万 = 250 人/km²
```

### 易错表

| 错误 | 修正 |
|------|------|
| 万人和人混用 | 如果人口用万人、面积用万km²，结果仍可化为人/km² |
| 面积单位不同 | 平方米、平方千米要统一 |
| 把人口密度当人口总量 | 密度高不一定总人口最多 |

## 六、等高线相对高度

### 两点相对高度

```text
相对高度 = 两点海拔差
```

如果两点都在等高线上，直接相减。若点位于两条等高线之间，则用范围表示。

### 闭合等高线范围

```text
闭合区域内部数值：
  若内部比周围高：高于相邻高值线，低于再高一条线
  若内部比周围低：低于相邻低值线，高于再低一条线
```

### 陡崖相对高度估算

```text
若陡崖处重合等高线条数为 n，等高距为 d：
  (n - 1)d ≤ 陡崖相对高度 < (n + 1)d
```

### 易错表

| 错误 | 修正 |
|------|------|
| 闭合线内部高低不判 | 先看相邻等高线数值增减方向 |
| 把等高距当海拔 | 等高距是相邻等高线差值 |
| 陡崖高度只用最大减最小 | 用重合线条数范围估算 |
