# 理科解题四步法掌握检查表

> 本文件随 `science-solving-four-steps` 单个 skill 安装，用于判断学生是否真正掌握一道理科题。

## 掌握等级

| 等级 | 状态 | 判断标准 |
|------|------|----------|
| A | 真正掌握 | 能独立重做、讲清思路、完成变式、隔天复测仍能找到入口 |
| B | 基本掌握 | 能独立重做原题，也能说明关键步骤，但变式还不稳定 |
| C | 表面理解 | 看答案懂，遮住答案后入口不清楚 |
| D | 尚未进入题目 | 目标、条件、未知量还没有读清楚 |

## 四个验证动作

### 1. 独立重做

要求学生不看答案重新完成一次。  
如果只能照着答案复述，不能判定为掌握。

### 2. 口头解释

要求学生用自己的话讲清：

- 这道题在考什么
- 第一入口为什么这样选
- 最关键的一步是什么
- 哪一步最容易错

### 3. 变式迁移

至少选择一种轻量变式：

- 改一个数值
- 改一个条件
- 改问法
- 换一个图形或物理情境
- 要求用另一种方法解释

变式难度应优先保持在学习区：大部分结构熟悉，只加入一个新的意外点。

### 4. 间隔复测

建议复测节奏：

```text
当天：遮住答案重做
1-3 天后：做一道同类变式
7 天后：只看题型信号，口述解题入口
```

## 常见误判

- 学生说“懂了”，但不能说出第一步从哪里来
- 原题能做，条件一变就不会
- 能算出答案，但不知道结果是否合理
- 会套公式，但说不出公式适用条件
- 能讲答案步骤，但无法指出自己的卡点
