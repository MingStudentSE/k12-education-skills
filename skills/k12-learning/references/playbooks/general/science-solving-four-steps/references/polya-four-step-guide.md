# 波利亚四步解题法提炼

> 本文件随 `science-solving-four-steps` 单个 skill 安装。内容只提取可用于学生端 skill 的少量方法框架，不复刻原书内容。

## 核心四阶段

### 1. 理解题目

解题前先确认：

- 要求什么，未知量是什么
- 已知数据是什么
- 条件是什么
- 条件是否足够、是否矛盾、是否多余
- 能否用图形、符号、表格或模型重述题目

学生常见问题：还没弄清目标和条件，就开始套公式。

### 2. 拟定方案

找方案时优先问：

- 是否见过相似题
- 是否见过有相同未知量或相似结论的题
- 能否调用相关定理、公式、模型或解题方法
- 能否先做一个更简单的辅助问题
- 能否考虑特殊情况、类比问题或反向推理
- 是否已经使用了全部条件

学生常见问题：记住了答案的第一步，却不知道第一步从哪里来。

### 3. 执行方案

执行时不只是“算下去”，还要检查每一步：

- 这一步做了什么
- 依据是什么
- 是否满足公式、定理、模型的使用条件
- 是否存在计算、单位、符号、定义域等风险

学生常见问题：会抄步骤，但中间的依据链断了。

### 4. 回顾

完成后必须回头看：

- 结果是否合理
- 论证是否完整
- 是否有另一种方法
- 这道题的关键转折是什么
- 方法能否推广到同类题
- 如果改变条件，原方法是否仍然可用

学生常见问题：答案对了就停止，没有把题目转化成可复用经验。

## 教练原则

- 先理解学生当前想到哪一步
- 给出学生本来可能想到的一小步提示
- 优先问问题，而不是直接展示完整答案
- 让学生补全关键桥梁
- 最后用变式题检查是否真的掌握

## 问题库

```text
理解题目：
这道题要求什么？
未知量、已知量、条件分别是什么？
能不能用图、式子或模型重述？

拟定方案：
它像以前哪道题？
有没有相关公式、定理或模型？
能不能先做一个更简单的子问题？
能不能从结论倒推？
还有哪些条件没用上？

执行方案：
这一步为什么成立？
这里调用的旧知识是什么？
哪一步最容易出错？

回顾迁移：
答案是否合理？
关键转折是什么？
换一个条件还能做吗？
以后看到什么信号要想到这个方法？
```
