# 🔭 跨学科侦探周方法

> **一句话定位：** 用真实主题把多门学科串成一张连接网；轻量响应用本文件，项目周/沉淀/联动必须读取完整手册。

## 最小执行闭环

1. **判断触发**：仅在跨学科主题探索、项目周、知识连接发现、项目学习或“某主题能串哪些学科”场景激活；不匹配时切换到普通回答或更合适方法。
2. **收集最小输入**：主题线索、候选学科、已有材料、学生兴趣点、时间投入与最终产物；不足时给补充模板，不编造长期画像。
3. **定边界再展开**：先缩小核心问题、至少连接2门学科、确定产物；时间不足可降级为3天侦探任务或单次连接卡。
4. **执行侦探流程**：按“选题→学科视角→逐科深潜→建立连接→项目DNA”推进；优先追问与证据，不把可训练思考直接做完。
5. **输出与复盘**：产出问题链、连接图、项目卡、展示成果和下一步；写入长期系统、在内部组合中共享或向 `k12-automation` 提交提醒请求前必须说明路径并获授权。

## 通用边界与降级策略

- **信息不足**：只追问完成当前任务必需的信息；可先给3个候选主题/学科视角帮助选择。
- **范围过大**：把“世界历史/科学发展”等大题缩成一个可研究问题；不无限添加新学科。
- **学生只要答案**：给必要快速帮助，但提示“快速答案”和“跨学科训练”目标不同；学生坚持时不强行完整项目。
- **长期记录**：未获明确同意时，只输出本轮结果，不更新兴趣、学习画像、知识树或项目DNA。
- **内部组合**：只传递当前任务所需最小摘要；不默认读取或共享完整历史。
- **难度失配**：太容易时增加“为什么有关/能否迁移”追问；太难时先减学科、补材料、拆成单日小任务。

## 快速触发判断

| 用户意图 | 处理方式 |
|---|---|
| “丝绸之路能串哪些学科？” | 启动单次跨科视角清单，必要时升级侦探周。 |
| “帮我做一个主题研究/项目学习” | 先确认主题边界、最终产物和时间，再选择完整或简化流程。 |
| “历史和地理有什么关系？” | 用双学科连接卡：证据→关系→反例/边界→迁移主题。 |
| “我想跨学科侦探周” | 读取完整手册，按五步流程组织项目。 |

## 协作边界

- `learning-dna`：仅在获授权后写入知识积累树新增节点/跨科关联。
- `cornell-notes`：把探索内容沉淀为跨科标签笔记；不替代侦探周的“连接发现”。
- 每周复盘/兴趣探索：只传本项目必要摘要，先说明用途和范围。

> 先帮学生制造“原来这两件事有关”的瞬间，再决定是否沉淀为长期项目DNA。
