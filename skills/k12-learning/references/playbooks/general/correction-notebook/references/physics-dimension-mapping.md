# 通用四维到物理五维映射表

本文件只提供 `k12-learning` 当前结果内的分类映射。通用错题记录和物理深度诊断由 module 直接组合，不创建发送方/接收方封装或中间协议状态。

## 映射原则

| 通用错因 | 物理深度维度 | 判断线索 |
|---|---|---|
| 概念理解 | 图景建立 P 或概念混淆 C | 没有把文字转成对象/过程/图景时偏 P；已有图景但概念关系错误时偏 C |
| 计算/操作 | 数学工具 T | 单位、比例、图像坐标、代数或数量级操作失效 |
| 审题习惯 | 图景建立 P 或概念混淆 C | 漏条件导致对象/过程建错时偏 P；不理解条件物理含义时偏 C |
| 策略选择 | 公式误用 F 或过程分析 R | 适用条件不满足仍套式时偏 F；多阶段、方向或状态变化遗漏时偏 R |

### 图景建立 P

- 没有画受力图、电路图、光路图或运动过程就直接列式。
- 漏掉对象、阶段、相互作用或题图中的隐含条件。
- 判断线索必须写清“缺了哪一幅图景、因此哪一步无法建立”。

### 概念混淆 C

- 速度与加速度、压力与压强、功率与功等关系混淆。
- 看见“静止/匀速”等条件，却不知道它约束了什么物理量。
- 判断线索必须包含被混淆的两个概念和可区分它们的条件。

### 公式误用 F

- 公式适用条件不成立，或把矢量、方向、参考系忽略后套式。
- 判断线索必须指出原公式需要的条件和题目哪里不满足。

### 过程分析 R

- 多阶段运动只分析一段，状态转折、能量转化或电路变化遗漏。
- 判断线索必须指出遗漏的阶段或状态边界。

### 数学工具 T

- 单位换算、比例、图像斜率/截距、代数或数量级错误。
- 判断线索必须区分物理关系已经建立但数学操作失败，还是前面的物理模型本身错误。

## 当前结果内的最小组合摘要

若同一结果需要通用记录与物理深度诊断，只保留以下字段，避免重复建题：

```yaml
subject: physics
evidence_ref: 当前题面与学生步骤的会话内引用
general_dimension: 概念 | 计算 | 审题 | 策略
physics_dimension: P | C | F | R | T
judgment_clue: 为什么从通用维度映射到该物理维度
repair_task: 一个针对同一根因的修复动作
retest: 一道同结构变式及验收标准
confidence: insufficient_sample | preliminary_trend | data_sufficient
```

- 首次出现只形成会话内诊断，不写“顽固弱项”。
- 只有用户提供多次独立证据时，才比较是否为反复模式。
- 需要写入 Learning State 时先按 module 授权门展示字段、用途、位置和删除方式。
- 真实提醒或夜间任务不在该摘要中创建；它们只能经 `k12-automation` seam 单独授权。
