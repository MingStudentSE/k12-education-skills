# 智能错题本操作手册

> 从原 `playbook.md` 外移的执行细则，覆盖最小闭环、边界、学习科学约束、核心流程、档案、预警、专项突破、全景报告与使用边界。

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于错题记录、错因分析、复测安排或错题模式归纳；如果不是，先指出更合适的方法，或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：题面、学生答案、正确答案/解析、学生自述卡点。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续章节推进，优先用追问、验证、例子和小步反馈帮助学生自己完成关键思考；不要把可训练的步骤直接替学生做完。
4. **产出结果**：给出错题卡、错因标签、订正步骤和复测任务，并明确“现在能做的下一步”。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不调用 `k12-automation` 创建提醒、不跨 module 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、历史记录或学习数据。
- **任务不匹配**：说明当前方法不适合的原因，并建议更合适的方法或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示“快速答案”和“真正掌握”是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 module 共享摘要。
- **跨 module 联动**：只传递当前任务需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加解释、变式或迁移；太困难时拆成子问题、补前置知识或降一级练习。
- **无视觉/OCR**：请学生手动转录题干、选项、图形关系、自己的步骤和答案；不得补猜未识别图片，也不得在题面不全时进入错因诊断。

---

## 学习科学约束

- **错误促进学习**：错题不能停在“哪里错了”，必须形成“错误-修正-再犯预警-变式验证”。
- **主动回忆优先**：学生看过答案时，也要先让学生复述自己认为的错因，再给 AI 判断。
- **情境记录**：记录做错时状态，如赶时间、紧张、以为做对、已经看答案，避免把状态问题误判成知识问题。
- **交错迁移**：同类题通过后，至少加入一道相似易混或换表述的变式题，防止只会识别原题型。
- **分散复测**：高频错因要进入后续复测或提醒，不把订正当天视为攻克完成。

## ⚠️ 技术实现边界声明

> **关于“拍照解析”机制：** 本模块对错题图片的提取与结构化分析，强依赖于本轮真实可用的多模态视觉能力或本地 OCR。只有宿主返回可核验识别结果时才能使用；否则必须转为手动录入题面和学生步骤。

## 一、方法的核心使命

传统错题本常见的问题：
- 抄了一本题，但不复用
- 知道错了，却不知道为什么总在同类地方出错
- 同类题换一种样子，又重新犯错

这个方法要解决的是更根本的问题：
**找到错误的根因、识别固定模式、触发后续突破，而不只是保存题目。**

⚠️ **【学科组合声明】**：`correction-notebook` 是 `k12-learning` 的通用错题视图，不是独立接收器。主流程只读取一次当前错题与学生尝试，并在同一结果中组合通用四维字段和学科深层字段。数学错题可补充概念混淆、读题训练、数学焦虑和数学子类型；物理错题可补充 P/C/F/R/T 子类型、跨维度关联和顽固弱项突破。内部 playbook 之间没有中间消息，也不重复建立记录或触发预警。

## 三、核心流程

### 3.1 拍题三信息法

学生发来错题图片时，不要立刻追问做法，先确认三件事：

```text
信息一：题目来源
"这道题是作业、测验，还是你自己练习时做的？"

信息二：做错时的状态
"你做这道题时有没有感觉哪里不对，
还是你以为自己做对了，对完答案才发现错？"

信息三：是否已看正确答案
"你现在已经看过正确答案了吗？"
  - 如果看过：继续问“你看完后觉得自己错在哪里？”
  - 如果没看过：先保持未看答案状态，继续追问思路
```

这一步的目的：
- 判断紧迫程度
- 区分理解问题和执行问题
- 决定后续该追问“原始思路”还是“错后反思”

### 3.2 先说过程，后做分析

绝对不能一上来给答案。顺序必须是：

```text
① 收三信息
② 让学生说解题过程 / 错在哪一步
③ 帮助定位错误根因
④ 引导学生自己找到正确路径
⑤ 出同类、变形或易混题验证
⑥ 写入错题档案
```

### 3.3 四维错因分析

每道错题必须至少归入以下四类中的一类：

```text
维度① 概念理解错误
  对概念、定理、规则本身有偏差

维度② 计算 / 操作失误
  思路对，但运算、书写、变形出错

维度③ 审题习惯问题
  漏条件、跳读、误读关键词

维度④ 策略选择错误
  知道相关知识点，但不会选择合适方法
```

给学生的反馈必须是：

```text
"你这道题的问题不是简单算错，
而是属于[错误类型]。
更根本的原因是：[一句话根因]。
我先帮你把这个点讲清，再给你一道变形题验证。"
```

## 五、弱项预警系统

v1.1新增四种预警触发条件。只要命中，就不能把它当普通错题处理。

### 5.1 触发条件

```text
触发一：同一知识点 + 同一错误类型连续出现3次
  预警级别：中度
  结论置信度：⚠️初步判断（需注意3次错误的时间跨度，若跨度>1个月则可能只是遗忘，若在3天内则规律可信）
  ⚠️ 【数学深化】：数学科目的 3 次触发由 `k12-learning` 在同一结果中补充数学子类型、证据强度、顽固弱项判断和专项突破任务，不再建立第二条待处理记录。

  ⚠️ 【物理深化】：物理科目的 3 次触发由 `k12-learning` 在同一结果中补充 P/C/F/R/T 子类型、证据强度和物理版突破任务（纯净版图景测试→规则重建→验证锁定）；只有用户同意长期记录后才更新 Learning State。

触发二：单次考试中，同一章节失分超过总失分50%
  预警级别：高度

触发三：同一知识点费曼测试后仍“未掌握”超过2次
  预警级别：高度

触发四：高频失分点超过14天未复习
  预警级别：中度
```

### 5.2 预警响应

命中预警后必须：
1. 明确告诉学生“这不是一次偶然错误”
2. 写入DNA中的弱项状态
3. 给出专项复习内容与建议时间；需要真实调度时切换到 `k12-automation` 并由 Automation 取得授权
4. 必要时在同一结果加入费曼解释验证
5. 在周报或月报中高亮并附带【结论置信度】标签

推荐话术：

```text
"我发现了一个规律——你在[知识点X]上已经第3次出现
[错误类型]类错误。
这不是粗心，而是一个固定模式，我们要专项突破它。"
```

## 六、专项突破与错题集

### 6.1 固定错误模式触发后的处理

同类错误出现第3次时：
- 明确告知学生进入“固定错误模式”
- 生成3-5题递进练习
- 在同一结果加入费曼解释验证
- 用户明确要求真实提醒时切换到 `k12-automation`，由 Automation 展示并确认后续复测任务

### 6.2 按需生成错题集

可生成以下类型：
- 本章错题集
- 学期薄弱点错题集
- 考前专项突破卷
- 某个固定错误模式的专题训练包

输出应包含：

```text
覆盖知识点
错误类型分布
优先复习顺序
预计完成时间
本次错题集要解决的核心问题
```

## 八、使用边界

错题本不是神谕，以下四种情况要及时提示学生纠偏：

```text
1. 跨题型的隐性规律
   两道题表面不同，可能根因一样，需要学生主动提示合并分析

2. 情绪性失误
   焦虑、赶时间、状态差导致的错误，不一定是知识问题

3. 信息不完整
   只有题目和答案，没有过程，根因判断会不够准

4. “我以为我懂了”
   学生口头说懂，不等于真正掌握，必须用变形题验证
```
