# ❌ 智能错题本方法

> **一句话定位：** 从“收集错误”到“消灭错误基因”。先收最小信息，再定位根因、安排验证与复测。

## 什么时候用我

- 学生发来错题图片或题面，并说明“我做错了”“帮我看看哪里错了”。
- 学生提供自己的答案、正确答案/解析或卡点，要求做错因分析、订正、同类题、变式题。
- 学生请求查看错题记录、整理本章/考前错题集、生成学期错题全景报告。
- 已出现同一知识点/同一错误类型反复出错，需要判断弱项预警、复测或内部组合。

## 什么时候不用我

- 只是普通讲题、查概念、写作文、制定计划，且没有“做错/错因/复测/错题本”任务。
- 用户只要快速答案且明确拒绝错因训练时，只回答当前问题，不强行进入完整错题闭环。
- 只有情绪倾诉、学习规划或真实提醒请求，不包含错题材料时，切换到普通回答、对应方法或 `k12-automation`。
- 需要深度数学/物理错误 DNA 分析时，本方法只做基础记录和通用四维分类，再与对应专项方法组合。

## 核心流程骨架

1. **判断触发**：确认任务属于错题记录、错因分析、复测安排或错题模式归纳；否则说明更合适路径。
2. **收集最小输入**：至少要题面、学生答案、正确答案/解析、学生自述卡点；拍题先用“三信息法”。
3. **先说过程**：让学生复述解题过程或错在哪一步，再做分析，不一上来给答案。
4. **四维归因**：在概念理解、计算/操作、审题习惯、策略选择中标注至少一类；各科细分见 `references/error-analysis-framework.md`。
5. **订正与验证**：讲清一句话根因，安排同类、易混或跨场景变式题验证，形成再犯预警。
6. **档案与预警**：只有用户明确同意长期记录后才按错题档案结构写入；未授权时只给会话内字段建议。同类错误 3 次、章节失分集中、费曼未掌握或 14 天未复习等结论必须有当前证据或已授权摘要。
7. **飞轮闭环出口（强制）**：错因分析后，本轮按四要素产出飞轮推进链（掌握验证/沉淀建议/复测安排/复盘入口）。需要其他方法时由 `k12-learning` 在当前会话直接组合，不建立额外中转状态。

## 飞轮闭环出口（本轮错因必须推进）

- ① 掌握验证：概念类错因时，在同一结果中加入费曼复述与画图验证；方法、过程或计算类错因时，加入 1 道变式并要求学生独立做到第一步。给出明确通过判定，例如“学生能说出或画出哪些关键关系才算掌握”。
- ② 沉淀入口：`k12-learning` 把当前错题证据一次整理为通用表面字段和对应学科深层字段，同一事件只形成一条候选记录；概念或模型混淆时，在这条记录中补充康奈尔线索字段。只有用户同意长期记录后才写入 Learning State，未授权时只展示建议字段。
- ③ 复测安排：T+1→T+3→T+7→T+14 间隔序列，复测用变式题（非原题）；需要实际提醒时，经授权后向 `k12-automation` 提交最小提醒请求。
- ④ 复盘入口：在同一结果中给出周复盘视图和触发信号（同类累计≥3 或复测未过）；涉及历史趋势时，只读取当前证据或已授权的 Learning State。

## 失败模式与红线

- **不得臆造数据**：信息不足时给补充模板；不要编造学生水平、历史记录或学习档案。
- **不得跳过学生思考**：不要把可训练的步骤直接替学生做完；先追问过程，再提示。
- **不得把错题当失败标签**：反馈必须聚焦“待攻克模式”，避免羞辱或贴标签。
- **不得只说“粗心/算错”**：必须追到根因、再犯信号和验证任务。
- **不得未授权写入或产生副作用**：长期档案和画像写入必须获得用户同意；真实提醒必须通过 `k12-automation` 的独立 interface 再取得相应授权。当前会话内组合 playbook 只处理本次材料，不等于长期共享。
- **不得制造内部接力**：数学或物理错题仍由 `k12-learning` 主流程一次读取当前证据，并在同一结果中组合通用字段与相应学科的深层诊断字段；内部 playbook 不彼此收发、重复记录或重复触发预警。
- **不得伪造指针**：只读取本 playbook 明确列出的当前任务资源，不跨目录寻找其他方法实现。
- **不得分析完就结束**：错因分析后必须产出飞轮闭环出口四要素；只归档/预警而无掌握验证、复测时间点和复盘入口，视为未完成。

## 物理映射与 schema 要点

- 通用四维到物理五维不是 1:1：概念理解可落到 P 图景建立或 C 概念混淆，审题习惯可落到 P 或 C，计算/操作落到 T 数学工具，策略选择落到 F 公式误用或 R 过程分析。
- 物理内部组合必须附判断线索，字段和示例见 `references/physics-dimension-mapping.md`。
- 物理错因需要辅助视角时，由 `k12-learning` 在当前会话直接组合所需字段；长期记录仍走统一授权门。
