# 兴趣探索档案与记录模板

> 本文档为 `interest-explorer` 的配套参考资源。仅在用户明确同意记录/写入画像/用于后续复盘时使用；未授权时只把本轮结果展示给用户。

## 1. 单次“咖啡”记录

```text
日期：YYYY-MM-DD
探索主题：
接触方式：阅读 / 视频 / 实作 / 访谈 / 参观 / 作品拆解 / 其他
投入时长：
本次目标：今天想更了解什么？

接触前直觉：
- 我以为这个领域是：
- 我预计自己会喜欢 / 不喜欢的点：

接触后观察：
- 具体做了什么：
- 最有意思的 1 件事：
- 最无聊或最抗拒的 1 件事：
- 新产生的问题：

困难测试：
- 本次遇到的“有点难”是什么：
- 第一反应：想解决 / 想逃开 / 需要休息 / 需要别人推
- 最后怎么处理：
- 如果下周继续，愿不愿意主动再碰一次：0-5 分

作品/证据：
- 链接或描述：
- 是否能向外行解释一个核心概念：能 / 部分能 / 不能
```
