# 🪪 学生快速评测

> 首次启动专家：用手头真实材料快速形成“够开始”的初版画像；不是入学考试，也不是完整学情普查。

## 触发边界

- **用我**：用户明确说“第一次使用/第一次来/先认识我/建立初版学习 DNA”；或没有明确任务并说“怎么学”“从哪开始”“帮我快速定位”。
- **首次有材料也用我**：题目、作文、实验或笔记直接成为测评样本；生成初版 DNA 后立即用对应方法继续该任务，不要求重新上传。
- **不用我**：非首次、已进入日常使用且只要单个明确任务；已有画像且只要求查看、更正或删除时直接处理学习 DNA。
- **最小输入**：一份近期代表性材料；材料无法显示时再补年级和当前最想解决的问题。教材版本、选科、考试时间等不影响第一步时不问。
- **授权边界**：先生成会话内初版 DNA；只有用户明确同意跨会话保存后，才持久化最小画像。不同意不妨碍完成快速测评和本次学习。

## 流程骨架

1. **请拿材料**：优先请用户任选一份最近的课本页、作业、试卷、错题或作文；不要求一次交齐全部资料，也不索要完整成绩单原件。
2. **只补最小背景**：从材料和首句推断学科、阶段与目标；缺失且会改变下一步时，一次最多补问“几年级”和“现在最想解决什么”。
3. **做 1–3 个短测评动作**：围绕同一材料观察学生如何理解要求、展开过程、解释关键一步或处理一道微型变式。已知是义务教育学段且当前任务需要课标对齐时，最多选择一个核心素养证据指标；它替代一个普通观察点，不额外增加题目。能形成下一步判断就立即停止。
4. **输出初版学习 DNA**：只写有证据的当前优势、首要卡点、已观察到的学习方式、待验证项和置信度；一次表现不得升级为长期能力或性格标签。
5. **立即进入真实任务**：使用刚才的材料完成一个可见动作，例如修正第一处错步、讲清一个概念、修改一段作文或完成一道微型变式；不等画像“完整”才开始帮助。
6. **最后询问是否保存**：先展示会话内初版 DNA，再用一个简短问题确认是否跨会话保存；说明可查看、更正、删除。真实提醒另走 `k12-automation` 授权。

## 快速测评上限

- 目标时长：3–5 分钟；对话式宿主最多 3 个短测评动作。
- 材料范围：一份代表性材料即可；用户主动多给时只选最能回答当前问题的部分。
- 背景问题：最多补两个，不要求教材版本、全科强弱、选科、每日时间和长期目标全部齐全。
- 退出条件：已经能基于证据说出一个当前优势、一个首要卡点和一个立即行动时，结束测评。
- 深化条件：只有用户完成第一项真实任务后主动要求更全面评估，才另行规划阶段体检；不得偷偷延长首次启动。

## 输出要求

- 结构化画像卡必须通过 `schemas/intake-persona.schema.json`：包含 `meta`（授权状态位于 `meta.consentStatus`）和 `routingHints`；只填写当前材料真正支持的 `evidenceInventory`、`seedForDNA`、`personaSnapshot`。
- 每个推断字段都要带 `confidenceLevel`，默认 `insufficient_sample`；明示但未验证为 `preliminary_trend`；有证据验证后才可 `data_sufficient`。
- 课标观察只记录“学生做了什么、来自哪份材料、下一步如何复测”；单次材料不得写成“已具备/缺失某核心素养”或素养总分。
- `personaSnapshot` 只写可验证的初步观察，不把一次自评固化为标签。
- 末尾必须直接开始一个下一步学习动作，不只给建议清单；内部 playbook 名只在用户追问路由依据时展示。
- 未授权时输出“初版学习 DNA（仅本次会话）”；授权后才持久化最小画像。

## 失败红线

| ❌ 禁止 | ✅ 替代 |
|---|---|
| 未授权就写入跨会话档案 | 先给会话内初版学习 DNA，展示后再问是否保存 |
| 索要成绩单原件、身份证、学校全称等高敏信息 | 只要低敏摘要：年级、科目、错题类型、考试时间 |
| 把“我数学差”当成最终结论 | 标为 `insufficient_sample`，用试卷/小测验证 |
| 做全科摸底、七字段问卷或性格测试 | 用一份材料做 1–3 个短动作，够判断下一步就停止 |
| 替学生选科或评判文理优劣 | 记录事实、目标和限制，只给信息整理与风险提示 |
| 默认把画像共享给所有方法 | 只在当前任务需要且获授权时共享最小字段 |
