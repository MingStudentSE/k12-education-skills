# 首次使用快速测评题库

本文件只支持材料驱动的快速启动。目标是尽快形成“够开始”的初版学习 DNA，并进入真实学习任务；不得把它扩展成全科摸底、七字段问卷或性格测试。

## 1. 先请用户拿出材料

优先话术：

```text
先从你手头任选一份最近的材料发来：一页课本、一页作业、试卷局部、一道错题、作文片段或实验记录都可以。带上你自己的答案、草稿或卡住位置会更有用；不用一次交齐，也可以打码。
```

材料选择优先级：

1. 有学生本人过程的近期作业、试卷或错题。
2. 与当前目标直接相关的课本页、课堂笔记或作文片段。
3. 没有现成材料时，由学生说一个最近学过但拿不准的知识点，现场生成一个微型任务。

不得索要学校全称、身份证、联系方式、住址或完整成绩单原件。

## 2. 只补最小背景

先从材料和首句推断，不重复询问。只有缺失信息会改变难度或下一步时，才在一轮内最多补两个问题：

```text
1. 你现在是几年级？
2. 这次最想先解决什么：看懂、改错、提速，还是找出反复卡住的原因？
```

教材版本、选科组合、全科强弱、考试时间、每日学习时长和长期目标不是首次启动必填项。第一项真实任务不需要它们时不要问。

## 3. 按材料选择 1–3 个短动作

只选能辨别下一步的动作；已经足够时不要做满三个。

| 材料 | 短测评动作 |
|---|---|
| 课本/笔记 | 让学生用自己的话解释一个核心概念；指出一个例子为什么符合；做一道最小迁移题 |
| 作业/错题 | 找到学生过程的第一处分叉；请学生解释当时依据；改一道同结构的小变式 |
| 试卷 | 选一个最有代表性的失分点；区分不会、会但断链、表达或时间问题；修复其中一道题 |
| 作文/阅读 | 让学生指出中心或证据；检查一处“观点—材料”连接；只改一小段并比较前后 |
| 实验记录 | 说清变量与证据；预测改变一个条件后的结果；检查结论是否超出数据 |
| 无材料 | 围绕一个最近知识点做 1 道微题或 60 秒复述，不生成综合试卷 |

观察维度只限当前任务：

- 是否读懂要求和材料；
- 第一个失效步骤在哪里；
- 能否说明关键依据；
- 接受一级提示后能否继续；
- 能否完成一个最小迁移。

## 4. 初版学习 DNA 字段

只写材料能够支持的内容：

```text
【初版学习 DNA｜仅本次会话】
- 当前阶段与学科：
- 本次目标：
- 已查看证据：
- 当前优势：
- 首要卡点：
- 已观察到的学习方式：
- 待验证项：
- 下一步：
```

每条结论标注来源与置信度：

- `data_sufficient`：当前材料直接验证；
- `preliminary_trend`：只有一次或局部证据；
- `insufficient_sample`：尚不能判断，不补写结论。

一次作业或试卷只能支持当前任务画像，不能证明“长期数学差”“注意力差”“不努力”或固定学习风格。

## 5. 退出规则

满足以下条件就结束测评并立即学习：

- 已能指出一个当前优势；
- 已能指出一个首要卡点；
- 已能选择一个 5–10 分钟内可完成的真实动作。

硬上限：3–5 分钟、最多 3 个短测评动作。用户说“不想继续测”“先做题”时立即退出，不劝说补齐信息。

## 6. 保存授权

初版 DNA 先在当前会话展示。完成第一个真实动作后再问：

```text
要不要把刚才这份初版学习 DNA 保存下来，供以后继续修正？如果要保存，我会先列出字段、用途、位置和删除方式；不保存也不影响这次学习。
```

明确同意前不得跨会话写入。真实提醒、Wiki 写入和向外部服务发送材料分别走各自授权门。
