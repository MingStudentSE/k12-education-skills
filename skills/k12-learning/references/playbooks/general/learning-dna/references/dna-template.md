# 学习 DNA 初版模板

本模板用于首次使用后的会话内画像。先用一份真实材料完成快速测评，再生成初版；不要先发空白表格让学生填写，也不要用全科自评代替证据。

## 会话内初版

```text
【初版学习 DNA｜仅本次会话】

- 当前阶段与学科：{{材料或用户明示；不确定则留空}}
- 本次目标：{{当前最想解决的一件事}}
- 已查看证据：{{课本页/作业/试卷局部/错题/作文/实验记录}}
- 当前优势：{{当前材料直接支持的一点}}
- 首要卡点：{{第一个失效步骤或待训练机制}}
- 已观察到的学习方式：{{仅写本轮真实表现或明确偏好}}
- 待验证项：{{不能由一次材料下结论的部分}}
- 下一步：{{马上完成的一个真实学习动作}}
```

每项附证据来源和 `data_sufficient`、`preliminary_trend` 或 `insufficient_sample`。一次表现不得写成长期能力、人格、动机或固定学习风格。

## 首次启动话术

```text
第一次先不做全面测评。请从手头任选一份最近的材料发来：一页课本、一页作业、试卷局部、一道错题或一段作文都可以，最好带上你自己的过程。我们用 3–5 分钟做一次快速测评，形成初版学习 DNA，然后马上处理其中一个真实问题。
```

若没有材料：

```text
没关系。告诉我年级和最近一个“学过但拿不准”的知识点，我只用一道微题或一次简短复述来建立初版，不做综合测试。
```

## 从初版到持久画像

先完成第一个真实学习动作，再展示拟保存字段并询问：

```text
这是根据本次材料形成的初版学习 DNA。要不要跨会话保存，供以后继续验证和修正？如果同意，我会只保存刚才列出的低敏学习摘要，并告诉你存放位置以及如何查看、更正、暂停或删除。
```

只有明确同意后才持久化。未同意时，初版只在当前会话使用。

## 后续更新规则

- “我懂了”只能作为自述；用复述、例题或迁移验证后再更新掌握状态。
- 新错题先记录当前证据；达到多次重复证据后再标记稳定错误模式。
- 年级、目标或偏好由用户明确更正时更新，并保留更正依据。
- 进步与攻克时刻也记录为证据，不让画像只剩弱点。
- 提醒、Wiki 写入、夜间分析均需各自授权，不因 DNA 已开启而自动执行。

## 成长阶段

| 阶段 | 判断依据 |
|---|---|
| 初版 | 一份材料 + 一次快速测评，只能形成局部假设 |
| 初步稳定 | 多次学习记录出现可复现模式，能给有证据的个性化建议 |
| 持续校准 | 通过复测、复盘和用户更正持续更新，不把旧结论永久固化 |
