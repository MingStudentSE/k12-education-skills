# 阶段学习体检评分参考

本文件用于 `learning-360-review`。评分必须基于证据，不基于感觉或鼓励话术。

## 证据门槛

满足以下任意 3 类证据，才建议评级：

- 学习记录：日志、周报、计划执行记录、课堂/自学记录
- 错题证据：错题卡、错因分类、复错次数、同类题迁移
- 掌握证据：费曼解释、独立重做、变式题、测验
- 执行证据：计划完成、专注记录、提醒响应、复盘记录
- 目标证据：阶段目标、考试目标、主攻学科或主攻题型

不足 3 类时，默认输出“暂不评级”。

## 维度评分锚点

### 1. 目标贡献 30%

- 90-100：学习行动高度服务当前最重要目标，有明确主攻学科/题型和结果证据。
- 70-89：大部分行动服务目标，但仍有部分时间花在低收益任务。
- 50-69：目标存在，但行动和目标连接弱，容易被临时任务带偏。
- 0-49：看不出当前学习在服务哪个关键目标。

### 2. 掌握证据 25%

- 90-100：有独立重做、费曼解释、变式迁移或测验通过的硬证据。
- 70-89：有解释或练习证据，但复测和迁移不足。
- 50-69：主要停留在看懂、听懂、整理过。
- 0-49：没有能证明掌握的证据。

### 3. 错题修复 20%

- 90-100：错因定位清楚，顽固弱项有修复动作，同类复错下降。
- 70-89：错题有记录和分析，但复测、迁移或追踪还不足。
- 50-69：错题被保存，但主要停留在订正答案。
- 0-49：错题没有形成系统处理。

### 4. 执行稳定 15%

- 90-100：计划、专注、提醒、复盘形成稳定节奏，能应对波动。
- 70-89：大体稳定，但遇到压力或任务变难时容易断。
- 50-69：执行靠临时状态，计划和真实行动经常脱节。
- 0-49：缺少持续执行证据。

### 5. 反思迁移 10%

- 90-100：阶段复盘沉淀出可复用方法、规则、题型信号或避坑清单。
- 70-89：有反思，但还没有稳定迁移到下一次行动。
- 50-69：主要是情绪总结或流水账。
- 0-49：没有反思或复盘证据。

## 评级映射

| 等级 | 总分 | 使用条件 |
| --- | ---: | --- |
| A：突破明显 | >= 85 | 必须有硬证据支持，不能只靠完成率 |
| B：稳定推进 | 70-84 | 默认健康状态，有推进但仍需 sharpen |
| C：需要修复 | < 70 | 下周期必须明确修复一个系统问题 |
| 暂不评级 | N/A | 证据不足或证据冲突严重 |

## 输出约束

- 评级后必须解释“为什么不是更高一档”。
- C 级必须给出修复动作，不做道德批评。
- 暂不评级时，不输出假分数。
- 所有结论都要能回到具体证据或明确的证据缺口。
