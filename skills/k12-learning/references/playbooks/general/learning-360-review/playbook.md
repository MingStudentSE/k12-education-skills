# 🧭 阶段学习体检

> **一句话定位：** 用阶段证据判断学习系统是否真的在变好，而不是凭感觉打分或把周报升级成焦虑审判。

## 触发条件与不触发边界

**使用本 SKILL：**
- 用户明确说“阶段学习体检 / 360 复盘 / A-B-C 评级 / 系统审计 / 最近两周学习系统运转得好吗 / 这段时间到底有没有进步 / 考前准备状态评级”。
- 复盘窗口通常超过一周，或虽然是一周但用户要多维证据审计、评级、目标对齐、系统修复动作。
- 已有或愿意补充至少 3 类证据：周报/日志、错题、费曼或测验、计划/专注/提醒执行、阶段目标或考试目标。

**不要使用本 SKILL：**
- 用户只是要“生成本周周报 / 总结这周 / 下周重点是什么”：交给 `weekly-review`，本 SKILL 不替代普通周报。
- 只处理单题、错题订正、费曼讲解、制定计划或专注力问题：转对应专项 skill。
- 只有主观感受却要求直接打分：必须输出“证据不足，暂不评级”，并给最小补证据清单。

**与 `weekly-review` 的互相边界：** weekly-review 负责“周报/轻量周复盘/下周重点”，不输出 A/B/C 评级；learning-360-review 负责“阶段体检/多维证据审计/评级/系统修复”。同时命中时，若用户只要本周周报，交给 weekly-review；若出现“评级、360、体检、系统审计、阶段判断”等意图，本 SKILL 优先，并可把 weekly-review 生成的周报摘要作为证据之一。

## 核心流程骨架

1. **确认窗口和意图**：明确日期范围、是否要评级、是否只是普通周报；模糊的“最近”必须先落到具体范围。
2. **收集证据启动包**：按最小必要原则请求周报/学习记录、错题摘要、掌握证据、执行证据、目标证据；未授权不读取长期档案。
3. **先过证据门槛**：证据少于 3 类或冲突严重时输出“暂不评级”，列出缺口和下一步补证据动作。
4. **五维体检评分**：证据足够时按目标贡献、掌握证据、错题修复、执行稳定、反思迁移五维判断；评分锚点见 rubric。
5. **输出 A/B/C 或暂不评级**：评级只用于决定修复动作，必须解释证据、置信度和“为什么不是更高一档”。
6. **做多视角轻检查**：用费曼、成甲、芒格、张一鸣、塔勒布视角各回答一个问题；没有外部 perspective skill 时不要假装调用。
7. **给唯一修复动作**：最后只给一个下周期关键动作、频率、验收标准和下次复查时间。
8. **授权后沉淀**：用户明确同意后，才把阶段结论写入学习画像、vault 或转给计划/提醒系统。

## 失败模式与红线

- 不凭感觉、完成率或鼓励话术给 A/B/C；证据不足时“暂不评级”是正确结果。
- 不评价学生人格，不说“懒/笨/不自律”；只评价学习系统与可观察行为证据。
- 不制造焦虑；C 级必须配修复动作，不能变成道德批评。
- 不把普通周报膨胀成 360 体检；没有评级/审计意图时转回 `weekly-review`。
- 不默认读取完整长期档案或跨 skill 全量同步；只取当前窗口最小摘要并先获授权。
- 不输出没有证据来源的分数、趋势、错题复发或目标偏差；每个结论都要能回到证据或证据缺口。
- 不一次给多个修复方向；阶段体检的价值是锁定下一周期最关键的一处系统修复。
