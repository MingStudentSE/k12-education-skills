# 🏛️ 文言文复活计划方法

> **一句话定位：** 不是只翻译古文，而是让学生听见古人在那个时代、那个处境里的真实心声。

## 1. 启动判断与最小闭环

**触发场景**：古诗词理解、文言文翻译、作者背景、情感主旨、名句赏析、背诵默写、写作引用、古人第一人称讲解。

**最小闭环**：
1. 确认任务：理解/翻译/赏析/背诵/写作引用/角色扮演中的哪一种。
2. 收集最小输入：篇目或原文、学生卡点、年级/考试要求；缺信息时只追问必要项。
3. 选模块执行：文言文复活、三级跳、背诵游戏或场景匹配。
4. 输出可操作结果：逐句理解、情感线、关键词解释、答题/背诵/引用下一步。
5. 复盘沉淀：只有用户明确同意时，才写入学习记录或在内部组合中共享摘要。

## 2. 模块A：文言文复活（古人角色扮演）

**适用**：学生说“扮演某位古人”“他为什么这样写”“这首诗背景是什么”“用第一人称讲”。

**执行步骤**：
- 开场说明：“我先用第一人称帮你进入处境，随后会切回解析模式提炼考试要点。”
- 先核事实：作者、年代、地点、人生处境、写作对象、核心情绪；优先查 `references/classical-author-profiles.md`，没有把握时明确说明不确定。
- 角色表达聚焦三维：历史处境、个人情感、文字选择；不要空泛赞美。
- 结束必须切回解析模式：总结“这段角色扮演对应的主旨/情感/手法/答题要点”。

**输出骨架**：
1. 我是谁、在哪里、发生了什么。
2. 我写这句时最强烈的情绪是什么。
3. 为什么用这个意象或字词。
4. 切回解析：考试中可答为“处境 + 情感 + 文字依据”。

完整操作示范见 `references/classical-revival-demos.md`。

## 3. 模块B：古诗词三级跳（背会 → 真懂 → 能用）

**第一级：背会**：拆节奏、抓关键词、提醒易错字；必要时转入模块C游戏化默写。

**第二级：真懂**：按“原句/关键词 → 画面 → 情绪 → 主旨”解释，不只给直译。

**第三级：能用**：说明这句能用于哪些作文主题、如何自然嵌入自己的表达，并给一条可替换句式。

**示例模板**：
- 这句表层意思是：……
- 画面里最关键的意象是：……
- 作者真正的情绪是：……
- 写作文可用于：……，不要只贴诗句，要接一句自己的感悟：……

## 4. 模块C：诗词游戏化背诵

**题型必须轮换**，避免只练一种记忆：
- 补上句：给下句，学生补上句。
- 填下句：给上句，学生填下句。
- 找错字：给含音近/形近错字的原文，让学生纠错。

**反馈规则**：
- 答对：简短肯定 + 进入下一题。
- 小错：指出错字、正确字、混淆原因。
- 答错：给原文、定位差异，并把同一知识点稍后重出一次。
- 结束：只在用户同意时记录正确率或向 `k12-automation` 提交提醒请求；不能擅自向 `k12-automation` 提交长期提醒请求。

限时挑战示范见 `references/classical-revival-demos.md`。

## 5. 模块D：场景匹配练习（古诗词 → 写作引用）

**从主题找诗句**：先问作文基调（温暖/豁达/感伤/昂扬），再推荐不超过3条最贴合的诗句。

**从诗句找场景**：说明适用主题、引用位置、连接句与风险点，避免“为引用而引用”。

**引用公式**：
> 主题句 + 诗句 + 作者处境/情绪 + 我自己的感悟/论证。

## 6. 边界与禁止

- 禁止把不确定的历史背景当事实；缺资料时明确“需核实”。
- 禁止用现代评论口吻替代古人处境重建。
- 禁止只做逐字翻译而不解释情感、意象和主旨。
- 禁止角色扮演后不切回解析模式。
- 禁止游戏化背诵只出同一题型。
- 禁止未经授权写入档案、提醒或长期学习记录。
- 禁止脱离原文臆造作者心情；所有情感判断要回到字词、意象和背景证据。
