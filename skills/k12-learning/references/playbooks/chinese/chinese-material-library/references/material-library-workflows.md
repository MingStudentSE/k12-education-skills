# 语文素材库2.0执行细则

## 1. 核心定位

本方法解决的不是“把好句放进仓库”，而是“写作时能被主动找到”。所有执行都围绕三件事：存入时自动打标签，写作前按主题主动推荐，用后追踪哪类素材真正有用。

## 2. 存储系统

### 2.1 触发词

- “这句话先存着”“记到素材库”“以后写作文能用”“帮我整理这段材料”。
- “这是我读到的好句/看到的典故/想到的比喻”。
- 阅读、文言文、古诗词任务中，学生对某句表达表示喜欢或要求积累。

### 2.2 单条存入模板

1. 复述素材原文，核对是否完整。
2. 记录来源：作者、篇名、书名、朝代、课堂材料；不确定则写“来源待确认”。
3. 自动生成标签：
   - 主题：坚持、成长、家国、自然、亲情、选择、挫折、创新等。
   - 类型：名言、古诗词、典故、事实论据、人物事例、环境描写、自创句。
   - 情感色彩：昂扬、沉静、温暖、悲壮、理性、幽默等。
4. 给出适用场景：开头引用、论据支撑、结尾升华、过渡语、描写润色。
5. 请求确认：“标签对吗？要不要改成更贴近你的作文主题？”

示例输出：

```text
已存入素材库：
原文：积土成山，风雨兴焉；积水成渊，蛟龙生焉。
来源：荀子《劝学》
标签：坚持·积累·学习 / 古诗文 / 励志
适用：写积累、坚持、学习方法的议论文开头或论据。
提醒：引用时要连接“微小行动长期累积”的观点，避免只抄句子。
```

### 2.3 批量存入

- 先说明边界：“一条一条发，我一条一条建卡；说‘存完了’就停止。”
- 每条都要拆出原文、来源、标签、适用场景；不能把多条混成一张卡。
- 对来源、主题或边界不清的条目，单独标“待确认”，不要补编。

## 3. 主动推送

### 3.1 触发识别

- “我要写关于某主题的作文”“有没有某主题的好句子”。
- “帮我找可以引用的素材”“素材库里有什么适合这篇文章”。
- 写作教练进入审题立意或列提纲前，且学生授权调用素材库。

### 3.2 推送格式

```text
你这篇文章的主题是【主题】，基调偏【基调】。
我从素材库里先挑 3-5 条：

① 素材（来源）
   为什么适合：连接主题/论点的理由
   建议位置：开头引用 / 论据支撑 / 结尾升华 / 过渡语
   引用示范：一句自然嵌入当前作文语境的话

② ...

哪一条最适合你的文章？选一条，我帮你写进段落里。
```

### 3.3 素材库为空或不足

- 明确说明：“你的素材库里关于该主题的积累暂时不多。”
- 允许推荐通用高质量素材，但必须标明不是学生个人历史积累。
- 邀请学生保存：“喜欢哪条可以说‘存这条’，我再帮你建卡。”

## 4. 阅读积累联动

- 精读、阅读理解、文言文复活、古诗词赏析中遇到精彩表达时，只轻量提示：
  “这里的表达很适合积累，是否要存入素材库？我建议标签为……”。
- 学生未同意时继续原任务，不强行切换。
- 学生自创好句也可以存，需标记为“原创句/待打磨”，并说明适用题材。

## 5. 使用追踪与月度报告

### 5.1 使用追踪

经学生同意后，每次素材被写进文章时记录：素材标题或摘要、使用文章/题目、位置、教师或自评分、是否值得复用。没有授权时只在当前对话内建议，不进入长期档案。

### 5.2 月度报告

报告字段：

- 本月新增素材数量与主题分布。
- 最常用的 3 类素材和最常空缺的主题。
- 被实际用于作文的素材清单和效果反馈。
- 下月建议重点积累方向：例如“人物事例不足”“自然描写偏少”“家国主题可增加古诗文”。

## 6. 推荐质量标准

- 优先选择与中心论点有清晰关系的素材，而非“看起来高级”的句子。
- 同一篇作文不要堆叠同质名言；事实论据、诗文、个人观察要搭配。
- 低年级优先通俗表达，高年级可增加典故和抽象论证。
- 来源不可靠、语义不确定或时代背景复杂的素材，必须提示核对。
- 每条素材都要附“怎么用”，否则不算完成推送。

## 7. 与其他方法的协作边界

- 阅读理解拆解师：发现好句时可建议保存，但不自动中断阅读任务。
- 文言文复活计划：理解古诗文后可提取可引用句，需学生确认后入库。
- 写作任务：`k12-learning` 可在同一结果加入按主题筛选的 3–5 条素材，不读取或复制完整历史。
- learning-dna：仅在授权后写入素材积累摘要、标签偏好或使用反馈。
- 每周/每月复盘：只提供授权范围内的统计摘要，不输出完整私人素材库。
