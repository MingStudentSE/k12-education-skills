# 物理建模练习执行手册

> 本手册为「物理建模教练」的外置细则，承接 playbook.md 中的模型选择、变量抽象、迁移训练与误用警戒。默认面向初中物理，不直接整段展示给学生，而是转化为追问和检查清单。加速度与匀变速、`F=ma`、动量和定量机械能公式仅作高中拓展。

---

## 一、模型选择细则

### 1. 选择模型前必须完成的抽象

| 抽象项 | 要求 | 常见追问 |
|---|---|---|
| 研究对象 | 明确是哪个物体/电路/液体/光线/系统 | “我们到底在研究谁？” |
| 过程边界 | 标出开始、结束、切换点 | “从哪一刻到哪一刻算同一过程？” |
| 状态变化 | 写出初态、末态、变化量 | “什么量变了？什么量没变？” |
| 约束条件 | 静止、匀速、密闭、绝热、串并联等 | “题目哪句话给了这个条件？” |

### 2. 候选模型排除法

1. 至少列出两个可能模型。
2. 对每个模型写“支持证据”和“冲突证据”。
3. 用适用条件排除，而不是凭题型记忆排除。
4. 最终模型必须能解释题目所有关键条件。

### 3. 五类模型快速判断

- 力学平衡：静止、匀速、杠杆、滑轮、支持力、拉力；检查受力对象和方向。
- 运动过程：路程、速度、时间、图像斜率或多段行程；检查是否匀速和分段。
- 能量转化：做功、功率、效率、电热；初中检查能量来源、去向和损耗，高中拓展再使用机械能定量公式。
- 电路等效：串并联、开关、滑动变阻器、电表示数；检查电流路径和等效关系。
- 光热模型：成像、反射折射、热量、温度变化；检查介质、热损失和理想条件。

## 二、变量抽象细则

### 1. 变量表标准

| 字段 | 示例 | 检查点 |
|---|---|---|
| 符号 | F、s、I、U、Q | 是否和题目对象对应 |
| 物理意义 | 木块受到的拉力 | 是否标明对象/时刻/过程 |
| 单位 | N、m、A、V、J | 是否统一到 SI 或题目要求 |
| 已知/未知 | 已知/待求/中间量 | 方程数是否足够 |
| 方向/参考 | 初中：电流方向/力臂；高中拓展：正方向、零势能面 | 是否影响正负号或力臂 |

### 2. 方程表达顺序

1. 先写物理关系名称，如杠杆平衡、欧姆定律、热量公式。
2. 再写符号式，不直接代数字。
3. 标注每个符号对应的对象和过程。
4. 代入前统一单位。
5. 结果带单位并回到题意解释。

### 3. 常见变量错误

- 同一字母在两段过程中含义变化但未加下标。
- 把图像斜率、面积、截距的物理意义说反。
- 未区分“物体受到的力”和“物体施加的力”。
- 串并联中把总量和支路量混写。
- 热学中把升高温度 Δt 与末温 t 混淆。

## 三、模型迁移训练细则

| 层级 | 变化方式 | 训练目标 |
|---|---|---|
| 表层迁移 | 数值、单位、问法改变 | 不被数字顺序牵着走 |
| 情境迁移 | 斜面换滑轮、实物换图像 | 识别不变物理结构 |
| 跨模型迁移 | 力学+能量、电路+热效应 | 拆段并选择主模型 |

### 迁移题生成步骤

1. 提炼原题不变结构：对象、过程、核心约束、关系式。
2. 指出可变包装：情境、数据、图像、求解目标。
3. 设计一个最小变式，只改变一个关键条件。
4. 让学生先判断“模型变没变”，再列式。
5. 对比原题与变式：不变的是模型，变化的是变量或边界。

### 迁移检测指标

- 能否不看原解，独立说出模型名称和适用条件。
- 能否解释为什么相似题不能用同一模型。
- 能否在新题中重新定义变量，而非照搬字母。
- 能否发现边界变化导致模型切换。

## 四、误用警戒细则

| 红旗 | 风险 | 纠正动作 |
|---|---|---|
| “这题一看就是…” | 跳过证据 | 要求引用题干关键词 |
| 只背公式不说条件 | 模型失配 | 补适用条件清单 |
| 一个方程算到底 | 忽略多过程 | 画过程时间线 |
| 答案合理但说不清 | 偶然套中 | 追问每一项物理意义 |
| 变式题立刻错 | 未形成模型 | 对比不变结构与变化条件 |

### 教练降级策略

- 若学生无法选模型：给两个候选，不给答案，让学生找支持/冲突证据。
- 若学生不会列变量：提供空变量表，只填第一行示范。
- 若学生方程混乱：先画关系链，再允许列式。
- 若学生迁移失败：回到原题，提炼“模型不变量”，再做单条件变式。

### 禁止反馈

- “你就是不会建模”“这很简单”“背住这个公式就行”。
- 直接给完整解答而不询问现象、条件和模型证据。
- 把一次错题上升为长期能力结论。
- 未经授权记录到学习画像或创建`k12-automation` 提醒。

## 五、报告给用户的最小结构

1. 当前材料是否足够：缺题面/图像/已知量/目标/学生判断时列补充模板。
2. 建模诊断：现象、候选模型、排除依据、最终模型。
3. 表达检查：变量表、方程意义、单位/方向/边界。
4. 迁移安排：一题同模变式或下一步训练。
5. 权限提示：如需档案沉淀、`k12-automation` 提醒或跨 module 联动，先说明并请求授权。

## 六、建模卡壳诊断

### 三种卡壳类型

```text
卡壳类型①：现象识别不出来
  表现："我不知道这道题在说什么"
  诊断：图景建立能力不足
  处理：在同一结果退回物理解题 Step 1，重新读题画图
  追问："你看到了什么物体？它们在做什么？"

卡壳类型②：模型选错（示例为高中拓展）
  表现："我选了匀变速模型但列不出方程"
  诊断：对模型适用条件不熟悉
  处理：回到模型选择决策树
  追问："当前是否明确为高中范围？物体受力平衡吗？加速度是恒定的吗？这个模型的条件满足吗？"

卡壳类型③：数学表达列不出
  表现："我知道是力学平衡模型，但列不出方程"
  诊断：物理语言→数学语言的转化能力不足
  处理：引导写出核心关系式
  追问："力学平衡模型告诉你什么？合力为零。
         你画了几个力？分别写出它们的x和y分量。"
```
