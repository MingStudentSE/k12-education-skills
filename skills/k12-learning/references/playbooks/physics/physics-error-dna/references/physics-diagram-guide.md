# Physics Diagram Guide for Error DNA

用途：为 `physics-error-dna` 的“图景建立错误”提供可执行判据。它不是通用绘图教程，而是把受力图、电路图、过程图、图像读数中的可观察错误转成 P 维度错因证据。

## 1. 先判定是不是图景问题

满足任一条，优先进入 P 维度排查：

- 学生不画图直接套公式，且追问“对象、相互作用、状态变化”时回答不稳定。
- 图画了，但漏对象、漏力、方向错、状态节点错、串并联关系错。
- 公式记得，代数也能做，但一换情境就不知道选哪个模型。
- 图像题能读数，却说不出斜率、面积、截距对应的物理量。

排除项：若学生图景完整，只是在单位换算、比例、方程求解出错，归入 T 数学工具错误；若图景与计算都对但概念定义混用，转 C 概念混淆。

## 2. 受力图规范（力学）

四步检查：

1. **对象隔离**：每张受力图只画一个研究对象；多个物体分别画。
2. **接触与场**：先列接触力（支持、压力、摩擦、拉力、弹力），再列场力（重力、电场力、磁场力）。
3. **方向与作用点**：重力竖直向下；支持力垂直接触面；摩擦力沿接触面且阻碍相对运动或趋势；绳拉力沿绳。
4. **坐标与状态**：标出正方向、是否平衡、是否加速、是否临界。

常见错因编码：

| 现象 | 证据问法 | 记录建议 |
|---|---|---|
| 漏重力/支持力/摩擦力 | “这个物体和谁接触？有没有相对运动趋势？” | P01 漏对象或漏力 |
| 把速度方向当成合力方向 | “若速度向右但减速，合力应指向哪里？” | P02 方向误判 |
| 多物体只画一张混合图 | “现在研究的是哪一个物体？” | P03 对象未隔离 |
| 临界状态不标注 | “刚要滑动/刚离开/刚断开时哪个量取边界值？” | P04 状态节点缺失 |

## 3. 运动过程图规范

用于直线运动、抛体、碰撞、能量转化、多阶段过程。

> 学段边界：初中默认画状态轴、过程分段和 s-t 图，并定性描述运动状态变化；加速度、抛体、动量以及 v-t 图斜率/面积属于高中拓展。

- 画时间轴或状态轴：初态、过渡态、末态至少三点。
- 每一段标：已知量、未知量、恒定量、变化量、适用规律。
- 多阶段题必须写清分段边界：如“加速到 v 后匀速”“接触弹簧前/压缩中/离开后”。
- 能量题要画能量流向：重力势能、弹性势能、动能、内能/损失。

错因信号：只列一个全程公式、忽略初末态限制，归 P/R 联合；高中拓展中把不同阶段加速度混用也归 P/R 联合。若阶段能分但公式条件错，归 F。

## 4. 电路图规范（电学）

1. **等效前先拓扑**：先标节点，再判断串并联，不凭元件位置“看起来像”。
2. **电表处理**：理想电流表近似导线，理想电压表近似断路；先重画等效电路。
3. **开关状态**：每个开关闭合/断开对应一张等效图；动态电路至少画变化前后两张。
4. **量的归属**：电压、电流、电阻要标在具体支路或元件上，不写漂浮变量。

常见错因编码：

| 现象 | 证据问法 | 记录建议 |
|---|---|---|
| 串并联判断错误 | “这两个元件是否共享同一对节点？” | P11 电路拓扑错误 |
| 电压表当导线/电流表当断路 | “理想表内阻该怎样处理？” | P12 电表等效错误 |
| 开关变化前后用同一张图 | “开关闭合后哪条支路被短接/接入？” | P13 动态电路状态图缺失 |
| 把总量当支路量 | “这个 U/I 属于电源、总电路还是某个电阻？” | P14 变量归属不清 |

## 5. 图像题规范

- 先写坐标轴物理量、单位和量纲；缺单位时不进入计算。
- 斜率、面积、截距、交点必须翻译成物理含义；例如 I-U 图斜率对应电阻的倒数。v-t 图斜率和面积的含义仅作高中拓展。
- 读取数据要标明点、区间或趋势，不只抄数值。
- 非线性图像禁止默认“斜率恒定”；必要时用切线或平均变化率说明。

错因边界：读数/比例尺错误多属 T；不知道斜率面积含义属 P+C；知道含义但选错公式属 F。

## 6. 记录到错误DNA的最小字段

当判定为图景问题，错题记录至少写：

```text
图景类型：受力分析 / 运动过程 / 电路 / 光路 / 图像
缺失点：漏对象 / 漏力 / 方向错 / 阶段错 / 拓扑错 / 量义错
证据：学生原图或口述中的一句关键表现
边界：为何不是纯数学工具错误或通用错题本表面分类
修复任务：下一次先画哪一种图、用哪条检查清单自检
```

## 7. 与通用错题本的边界

- `general/correction-notebook` 记录题目、答案、日期、来源、通用四维分类和复习状态。
- 本文件只服务物理根因：把“为什么同类物理图景反复错”编码到 P 维度及其跨维度关联。
- 未经授权，不把图景诊断写入长期画像；需要联动时只同步最小摘要，并使用规范命名空间，如“physics:P11 电路拓扑错误（当前证据）”。
