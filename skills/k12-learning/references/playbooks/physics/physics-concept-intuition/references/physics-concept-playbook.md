# 物理概念直觉器操作手册

> 本文件承接 `playbook.md` 外移出的长流程、模板、示例和理论细则。回答时优先按主文件路由，再来本手册取操作细节。

## 1. 核心判断：公式是直觉的数学缩写

典型症状：学生能背 `F=ma`、`I=U/R`、`W=Fs`，但换题就不知道乘除关系。根源不是记忆差，而是跳过了“量与量如何互相影响”的直觉建模。

处理原则：

1. 先问学生已有经验，不直接抛定义。
2. 让学生预测变量变化方向。
3. 再把预测压缩成公式或规律。
4. 最后用新情境迁移验证。

## 2. 模型A：生活类比法

适用：力、压强、浮力、电流、电压、电阻、热量、比热容等能在生活中找到相似体验的概念。

### 标准步骤

1. 选择类比：优先身体经验，其次日常观察，再其次可想象场景。
2. 讲述场景：“你有没有这样的经历……”
3. 建立映射：日常量分别对应物理量。
4. 追问变量：让学生判断“变大/变小/极端情况”。
5. 引出公式：把直觉写成数学。
6. 标出边界：说明类比哪里不再成立。

### 典型示例

**压强 = 力分摊到面积上的拥挤程度**

- 生活类比：同样一个人站在雪地，穿普通鞋会陷下去，穿滑雪板不容易陷。
- 映射：人的重力→压力；鞋底/滑雪板面积→受力面积；陷得深→压强大。
- 追问：力不变、面积变大，压强怎样？面积不变、力变大呢？
- 公式：`p=F/S`，力越大压强越大，面积越大压强越小。
- 边界：雪地类比只表达宏观效果，不等于所有接触面都会发生明显形变。

**电流/电压/电阻 = 水流/水泵/水管**

- 电压U：推动电荷流动的“水压差”。
- 电阻R：通路难走程度，“水管粗细与阻碍”。
- 电流I：实际流过多少电荷，“水流量”。
- 直觉：U越大I越大；R越大I越小；压缩为 `I=U/R`。
- 边界：水流有惯性，简单电路中断开后电流立即消失，不能无限延伸。

## 3. 模型B：实验想象法

适用：惯性、磁场、内能、光路、变量控制等缺少直接触感的概念。

### 标准步骤

1. 搭建可想象实验场景。
2. 固定无关变量，只改一个关键变量。
3. 要学生先预测结果。
4. 对比预测与现象。
5. 抽象出概念语言。

### 典型示例

**惯性：公交车刹车实验**

- 场景：你站在匀速公交车上，车突然刹车。
- 预测：身体会向前倾，因为身体倾向保持原来的运动状态。
- 变量：换成空书包、满书包、小车、大车，越重越难改变运动状态。
- 结论：惯性是物体保持原有运动状态的性质，大小与质量有关；惯性不是力。

**磁场：指南针探路实验**

- 场景：把小磁针放在磁体周围不同位置。
- 观察：小磁针方向变化，说明周围空间存在看不见但能产生作用的“场”。
- 边界：磁感线是人为画出的模型，不是空气里真实存在的线。

## 4. 模型C：公式拆解法

适用：学生已见过公式，但不知道每个符号为什么这样组合。

### 拆解顺序

1. 每个字母：名称、单位、可测量含义。
2. 运算结构：为什么相乘、相除或平方。
3. 极端验证：某个量为0、无穷大或翻倍时是否符合直觉。
4. 适用条件：公式在哪些前提下成立。

### 典型示例

**功 `W=Fs`**

- `W`：做功多少，单位J。
- `F`：沿运动方向的力，单位N。
- `s`：在力方向上通过的距离，单位m。
- 为什么相乘：既要“使劲”，又要“移动”；任一为0都没有机械功。
- 易错：推墙很累但墙没动，物理上对墙不做功。

**速度 `v=s/t`**

- `s`：路程；`t`：时间；`v`：单位时间走多远。
- 为什么相除：把总路程平均分到每一秒。
- 极端：同样路程用时越短速度越大；同样时间路程越长速度越大。

## 5. 概念直觉四层验证

1. **举新例子**：学生能找一个未讲过的生活现象。
2. **判断变化方向**：能回答“这个量变大，另一个量怎样”。
3. **解释反例/边界**：知道类比哪里失效，避免过度延伸。
4. **迁移到题目**：看到题目能先说物理图景，再列公式。

若只会复述定义，不算通过。

## 6. 常见失败与修正

- 学生说“我没经历过”：立即换更贴近日常的类比，不强迫想象。
- 学生过度延伸：先肯定方向，再说“类比到这里为止”。
- 类比引起误解：换用实验想象或公式拆解，不在错误类比上补丁。
- 公式先行：退回变量方向追问。
- 超纲内容：标注“这是更高年级解释，本阶段只需掌握……”。

## 7. 自定义类比模板

```text
【概念名称】
生活类比：2-3句话描述学生可感知现象
类比映射：日常概念A → 物理概念X；日常概念B → 物理概念Y
追问序列：基础关联 → 变量控制 → 极端/边界
公式引入：公式 + 每个字母的直觉含义与单位
迁移验证：一个新情境问题
边界提醒：这个类比哪里不成立
```

## 8. 素材库使用规则

`physics-analogy-bank.md` 覆盖力学、电学、光学、热学常见概念。使用时不要逐字照搬，应根据学生年级、生活经验和误解点裁剪；如果素材库没有命中概念，就按本手册的自定义模板现场生成。
