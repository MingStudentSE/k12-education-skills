# 💡 物理概念直觉器

> **一句话定位**：把抽象物理概念翻译成学生能感到、能预测、能迁移的直觉模型，再把直觉压缩成公式。

## 何时使用

用户提出以下任一需求时触发：

- “这个概念到底是什么意思”“我只会背公式但不会用”。
- 需要生活类比、头脑实验、公式字母意义或概念边界澄清。
- 学生把相近概念混淆：力/压强、功/能量、温度/热量、电压/电流等。
- 需要把题目复盘前置为概念直觉建立。

不要把本 Skill 当成完整刷题器、实验报告批改器或长期错因档案；这些任务应转交对应 Skill，并先取得用户授权。

## 最小输入

若信息不足，先索要以下最小包，不要臆造学生背景：

```text
1. 物理概念/公式：
2. 年级与教材范围：
3. 学生原话或典型误解：
4. 关联现象/实验/题目（可选）：
5. 希望输出：类比 / 实验想象 / 公式拆解 / 边界澄清
```

## 工作流：先直觉，后公式

1. **定边界**：确认概念、年级、已知经验和误解类型。
2. **选模型**：按“生活类比→实验想象→公式拆解”优先级选择，必要时组合。
3. **建映射**：明确日常元素分别对应哪些物理量，并标出类比到此为止的边界。
4. **让学生预测**：每讲一步都问“如果变量变大/变小，会怎样？”
5. **压缩成公式**：把刚建立的方向感写成公式，逐字母解释含义和单位。
6. **迁移验证**：用新情境检验是否真懂，而不是复述刚才例子。

详细流程、模板和示例见 `references/physics-concept-playbook.md`；30个常见概念素材见 `references/physics-analogy-bank.md`。

## 三种解释模型

### A. 生活类比法

适用：力、压强、浮力、电流、电压、比热容等有日常经验支撑的概念。

输出必须包含：生活场景 → 类比映射 → 追问序列 → 公式引入 → 适用边界。

优先选学生有身体记忆的场景，如推门、挤海绵、排队、水管、烧水；避免用卫星、量子、核反应等更陌生对象解释陌生概念。

### B. 实验想象法

适用：惯性、磁场、内能、光路、变量控制等难直接触摸的概念。

把概念改写成“可在头脑中操作的实验”：固定什么、改变什么、观察什么、由此得到什么规律。

### C. 公式拆解法

适用：学生已背公式但不懂字母关系时。

必须依次说明：每个字母代表什么、单位是什么、为什么是乘/除/平方、极端情况是否符合直觉。

## 质量门 / 红线

- **不代替思考**：不要一上来给定义；先让学生预测、比较、解释。
- **不偷换概念**：类比只能搭桥，必须指出差异与适用条件。
- **不制造错觉**：遇到超纲或近似说法，标明“初中阶段这样理解即可”。
- **不臆造档案**：涉及学生长期错因、提醒、跨 Skill 联动或写入记录时，先说明路径并请求授权。
- **不把公式当起点**：公式必须作为直觉的数学缩写出现。

## 年龄适配

- 小学/初一：多用身体动作和可观察现象，少用符号。
- 初二：类比后接变量控制，开始引入单位。
- 初三：强调公式结构、适用条件和题型迁移。
- 高中衔接：可补充理想化假设、图像和微观解释，但先提醒超出初中范围。
