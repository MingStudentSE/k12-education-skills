# 化学错误维度表

## Ch1 宏微符断裂

| 子类型 | 表现 | 修复 |
|--------|------|------|
| Ch1.1 宏观到微观断裂 | 只描述现象，不知道粒子变化 | 三列表 + 粒子清单 |
| Ch1.2 微观到符号断裂 | 会说粒子但写不出式子 | 下标/系数/电荷拆解 |
| Ch1.3 符号到宏观断裂 | 会配平但解释不了现象 | 用符号反推现象 |
| Ch1.4 守恒图像断裂 | 微粒图前后原子不守恒 | 原子逐个配对 |

## Ch2 概念分类混淆

| 子类型 | 表现 | 修复 |
|--------|------|------|
| Ch2.1 物质分类错 | 纯净物/混合物、单质/化合物混 | 必要条件表 |
| Ch2.2 溶液概念错 | 饱和/浓、溶质/溶剂混 | 溶液三要素图 |
| Ch2.3 酸碱盐错 | 酸性/酸、碱性/碱、盐概念混 | H+、OH-、离子组成解释 |
| Ch2.4 氧化还原错 | 氧化剂/还原剂、化合价判断错 | 标化合价 + 电子转移 |
| Ch2.5 有机基础错 | 有机物、烃、官能团边界不清 | 结构和官能团对比 |

## Ch3 反应与守恒错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| Ch3.1 反应事实错 | 产物不符合事实 | 反应类型和证据回查 |
| Ch3.2 配平错误 | 改下标、漏配、未化简 | 配平检查表 |
| Ch3.3 质量守恒错 | 忽略气体、沉淀或反应前后总量 | 反应前后质量表 |
| Ch3.4 电荷守恒错 | 离子方程式电荷不平 | 电荷总数检查 |
| Ch3.5 电子守恒错 | 氧化还原得失电子不等 | 化合价升降法 |

## Ch4 实验证据错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| Ch4.1 变量不清 | 自变量、因变量、控制变量混 | 变量表 |
| Ch4.2 对照缺失 | 无法判断变化来源 | 对照组设计 |
| Ch4.3 证据不足 | 只写结论不写现象或数据 | 证据表 |
| Ch4.4 干扰未排除 | 漏气、温度、剂量、时间不一致 | 误差表 |
| Ch4.5 安全意识缺失 | 忽略危险操作 | 安全降级方案 |

## Ch5 计算与化学用语错误

| 子类型 | 表现 | 修复 |
|--------|------|------|
| Ch5.1 单位错误 | g/mol/L/mL/% 混用 | 单位栏 |
| Ch5.2 比例关系错 | 未按方程式系数或溶液关系 | 已知未知表 |
| Ch5.3 溶液量关系错 | 溶质、溶剂、溶液混 | 三者关系图 |
| Ch5.4 符号表达错 | 化学式、离子、电荷、状态不规范 | 符号检查 |
| Ch5.5 答题术语错 | 用口语替代化学术语 | 规范表达改写 |

## 主次维度记录

复杂错题允许记录次错因，但修复时只抓一个主错因。

示例：把酸性当酸导致方程式写错，可记为 `主 Ch2.3 + 次 Ch3.1`。
