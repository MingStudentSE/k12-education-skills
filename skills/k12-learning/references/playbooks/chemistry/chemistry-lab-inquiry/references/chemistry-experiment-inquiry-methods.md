# 化学实验探究方法

## 1. 探究问题格式

好的探究问题要包含变量关系：

```text
探究 [自变量] 对 [因变量] 的影响。
比较 [条件A] 与 [条件B] 下 [现象/数据] 的差异。
验证 [某性质/某反应] 是否成立。
```

## 2. 变量表

| 类型 | 问题 | 示例 |
|------|------|------|
| 自变量 | 主动改变什么？ | 酸的种类、温度、浓度、金属种类 |
| 因变量 | 观察或测量什么？ | 气泡速率、沉淀质量、颜色变化、pH |
| 控制变量 | 必须保持什么一致？ | 体积、质量、反应时间、颗粒大小 |
| 对照组 | 用来比较什么？ | 不加催化剂、室温条件、蒸馏水 |

## 3. 步骤设计检查

1. 每一步是否服务于探究问题。
2. 是否一次只改变一个自变量。
3. 是否有对照组。
4. 观察指标是否可记录。
5. 是否有重复实验或多组数据。
6. 是否包含安全处理。

## 4. 结论限定

实验结论必须只覆盖证据支持的范围。

| 证据 | 合格结论 | 越界结论 |
|------|----------|----------|
| 某温度下溶解更快 | 升高温度可加快本实验中该物质溶解速率 | 温度越高所有物质都无限快溶解 |
| 某金属与酸产生气泡 | 该金属能与这种酸反应产生气体 | 所有金属都能与所有酸剧烈反应 |

## 5. 干扰因素

常见干扰：

- 药品浓度、体积或质量不一致。
- 固体颗粒大小不同。
- 温度变化。
- 反应时间不一致。
- 装置漏气。
- 观察指标主观，缺少量化记录。

## 6. 追问模板

```text
你真正要探究的是哪个变量关系？
如果只改一个条件，其他条件需要保持什么一致？
没有对照组时，你怎么知道变化来自这个变量？
你的结论有没有超过数据范围？
```
