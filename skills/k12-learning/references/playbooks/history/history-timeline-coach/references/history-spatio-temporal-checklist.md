# 历史时空定位自检清单

> 本文档为 `history-timeline-coach` 的配套检查工具，用于课堂答题、错题复盘和考前快速自检。

---

## 一、四步法检查表

| 步骤 | 必答问题 | 学生输出 | 未通过信号 |
|------|----------|----------|------------|
| 定时代 | 这是古代、近代还是现代？具体朝代/世纪/阶段是什么？ | 朝代/世纪/阶段 | 只说事件，不说时间 |
| 定空间 | 发生在哪里？中国/世界？具体区域是什么？ | 地域/国家/区域 | 把世界史背景和中国史空间混在一起 |
| 定序列 | 之前是什么？之后是什么？夹在哪两个节点之间？ | 前后节点 | 原因晚于结果，改革战争顺序混乱 |
| 定同期 | 同期中国/世界还有什么？是否有关联？ | 同期参照 | 中外对照空白或硬凑因果 |

### 快速口头模板

```text
我先定位：
  这件事发生在[时代/朝代/世纪]，
  空间上是在[区域/国家/城市/边疆]，
  它之前是[前一节点]，之后是[后一节点]，
  同期[中国/世界]还有[同期节点]。

所以我再分析[原因/影响/比较/评价]。
```

## 二、三种时空错乱识别信号

### H1-1 时代错位

| 信号词/表现 | 典型例子 | 追问 |
|-------------|----------|------|
| "好像都是古代的" | 把科举创立、三省六部成熟、八股取士混为同一时期 | "这三个制度分别对应哪个朝代？" |
| "明清和宋元差不多" | 用宋代商品经济特征解释明清闭关政策 | "你说的特征在明清是否仍然成立？有什么变化？" |
| "近代探索顺序不清" | 洋务、戊戌、辛亥、新文化顺序颠倒 | "器物、制度、思想的探索顺序是什么？" |

### H1-2 中外错位

| 信号词/表现 | 典型例子 | 追问 |
|-------------|----------|------|
| "中国这时世界在干什么不知道" | 鸦片战争背景只写清政府腐败，不写工业革命 | "英国此时为什么需要海外市场？" |
| "把世界史阶段套错" | 把启蒙运动放到第一次工业革命之后作为直接背景 | "启蒙运动与资产阶级革命、工业革命的先后关系是什么？" |
| "同期就等于因果" | 看到同期事件就说互相导致 | "它们之间有材料或机制证明联系吗？" |

### H1-3 序列倒置

| 信号词/表现 | 典型例子 | 追问 |
|-------------|----------|------|
| 原因晚于结果 | 用《辛丑条约》的影响解释甲午战争爆发 | "这个原因发生在结果之前吗？" |
| 把改革和战争顺序颠倒 | 先写戊戌变法再写洋务运动 | "这些探索从器物到制度再到思想，顺序是什么？" |
| 把阶段结果当背景 | 用新中国工业化成果解释新中国成立 | "这是成立前的条件，还是成立后的结果？" |

## 三、题型自检清单

### 排序题

```text
□ 我是否先写出了所有事件的绝对时间或朝代？
□ 没有年份的事件是否找到了锚点？
□ 是否检查过"熟悉的事件不一定更早"？
□ 是否把同一时期并列事件和先后事件区分开？
```

### 因果题

```text
□ 原因是否都早于结果？
□ 是否区分长期条件、直接原因、导火索？
□ 是否先定位再使用因果框架？
□ 是否避免用后来的影响反推前面的原因？
```

### 比较题

```text
□ 比较对象是否处在可比的时间范围？
□ 是否先并置两条时间线？
□ 比较维度是否一致：政治对政治，经济对经济？
□ 是否说明差异来自不同的时代条件或空间环境？
```

### 材料题

```text
□ 材料中有没有年份、朝代、人物、制度、地名？
□ 没有明示时间时，是否用关键词反推阶段？
□ 是否先提取材料线索，再调用课本知识？
□ 是否避免脱离材料直接背时间轴？
```

## 四、考前时空观自查表

| 自查项目 | 通过标准 | 不通过时的补救 |
|----------|----------|----------------|
| 中国古代朝代轴 | 2分钟内写出主朝代顺序和3个阶段特征 | 重画朝代分期表，先抓大阶段 |
| 中国近现代轴 | 能说出1840、1919、1949、1978四个关键节点意义 | 用四节点搭框架，再补事件 |
| 世界近现代轴 | 能定位新航路、工业革命、两次世界大战、冷战 | 画世界近现代五阶段轴 |

| 错题回看 | 能指出近期H1错题属于哪一类 | 联动 history-error-dna 做H1追踪 |

## 五、30秒纯净版时空测试

用于判断学生是"知识记忆缺口"还是"时空定位能力缺口"。

```text
测试流程：
  1. 给一个极简事件：如"辛亥革命"
  2. 学生30秒内回答四项：
     时代/阶段：？
     空间：？
     前一个重要节点：？
     后一个重要节点：？
  3. 只看时空坐标，不考细节背诵

判定：
  四项都能答 → 基础时空坐标可用，问题可能在材料应用或因果解释
  时代/空间错 → H1时空定位弱项
  前后错 → H13序列倒置风险
  同期空白 → H12中外错位风险
```

### 纯净测试题样例

| 事件 | 期待定位 |
|------|----------|
| 商鞅变法 | 战国时期，秦国；前有诸侯争霸，后助推秦统一 |
| 科举制创立 | 隋朝；中国古代选官制度变化，唐代完善 |
| 鸦片战争 | 1840-1842，清朝晚期，中国东南沿海与英国 |
| 五四运动 | 1919，中国北京等地；一战后巴黎和会背景 |
| 第一次工业革命 | 18世纪中后期起，英国为中心；机器生产和工厂制度扩展 |
