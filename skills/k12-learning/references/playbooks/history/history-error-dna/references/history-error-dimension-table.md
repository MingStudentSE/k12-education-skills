# 历史错因维度表

> 本文档为 `history-error-dna` 的核心参考资源，定义历史学科包的五维错因维度体系、子类型分类、跨维度关联规则与追踪标准。

---

## 一、维度总览

```text
历史错因维度体系（H1-H5×多子类型）

H1 时空定位错误 ── 历史独有的地基错误
  事件没有放进正确的时代、空间、前后序列和同期坐标

H2 史料实证错误 ── 材料题核心错误
  不会判断史料性质、混淆史实与观点、不能论从史出

H3 历史解释错误 ── 机制层错误
  因果层级、阶段特征、多元解释和历史评价逻辑偏差

H4 概念术语错误 ── 表达与理解层错误
  历史概念、制度术语、专有名词、时代语义混淆

H5 价值评价失当 ── 论证能力错误
  价值评价链条不完整；只评价论证质量，不评价个人立场

每道错题必须归入且只归入一个主维度。
如存在跨维度因素，记录为"主维度+次要维度"。
```

---

## 二、H1：时空定位错误

**定义：** 不会将事件、制度、人物或材料放进正确的时间、空间、前后序列和同期背景。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| H11 | 时代错位 | 唐宋制度、明清政策、近代探索顺序混用 | 选择题/排序题 | 朝代分期轴 |
| H12 | 中外错位 | 不知道同一时期世界/中国发生什么 | 材料题/比较题 | 中外双轨时间线 |
| H13 | 序列倒置 | 把结果当原因，事件先后颠倒 | 因果题 | 前后节点轴 |
| H14 | 空间误置 | 把区域、国家、边疆位置混淆 | 地图题/材料题 | 空间标注训练 |
| H15 | 阶段特征错配 | 用不属于该阶段的特征解释题目 | 论述题/选择题 | 阶段色块法 |

### 根治方法映射

```text
H11 → 中国/世界主轴默写 + 阶段关键词
H12 → 中外双轨轴，上轨中国下轨世界
H13 → 原因必须早于结果的因果前后轴
H14 → 地图/区域标注，尤其边疆治理和世界区域史
H15 → 阶段特征表：政治、经济、思想、国际关系分列
```

---

## 三、H2：史料实证错误

**定义：** 不会把材料当证据处理，不能正确判断史料性质、可信度、证据范围和结论限度。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| H21 | 史论不分 | 把作者观点当事实，或把事实当评价 | 材料题 | 史实/观点切割 |
| H22 | 史料性质误判 | 一手/二手、有意/无意、文献/实物判断错 | 材料题 | 史料分类状态机 |
| H23 | 曲解史料 | 抓错关键词，材料主旨读反 | 材料题/选择题 | 关键词证据链 |
| H24 | 作者立场忽略 | 不看作者身份、时间、目的 | 材料题 | 作者-时间-目的三问 |
| H25 | 内证外证缺失 | 只读材料不联系所学，或只背所学不读材料 | 材料题 | 材料+所学双证 |
| H26 | 孤证立论 | 用单条材料推出过大结论 | 论述题/探究题 | 互证训练 |

### 根治方法映射

```text
H21 → 逐句标注：史实/观点/推论/混合
H22 → 一手/二手、有意/无意、载体类型四象限
H23 → 材料句→有限结论，不允许跳到宏大结论
H24 → 作者是谁、写给谁、为什么写
H25 → 内证外证表：材料证据 + 课本史实
H26 → 至少提出一类互证材料
```

## 四、H3：历史解释错误

**定义：** 历史解释链条不完整或错误，包括因果层级、阶段特征、多元解释和时代条件判断。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| H31 | 因果层级混乱 | 根本原因、直接原因、导火索混淆 | 因果题 | 因果链绘制 |
| H32 | 影响与原因倒写 | 用后果解释原因，或影响分层错误 | 材料题 | 原因/影响双向表 |
| H33 | 阶段特征解释错误 | 不能用阶段特征解释材料 | 选择题/材料题 | 阶段特征表 |
| H34 | 以今律古 | 用现代标准脱离历史条件评价 | 论述题 | 历史条件追问 |
| H35 | 多元解释单一化 | 只从一个角度解释复杂事件 | 论述题 | 经济/政治/思想/国际多角度 |

### 根治方法映射

```text
H31 → 根本原因/主要原因/直接原因/导火索四栏表
H32 → 先画时间轴，确保原因早于结果
H33 → 阶段特征与材料关键词配对
H34 → "放回当时"：制度、技术、社会条件、国际环境
H35 → 至少比较两种解释，判断解释力
```

## 五、H4：概念术语错误

**定义：** 历史概念、制度术语、专有名词、时代语义混淆，导致理解和表达失准。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| H41 | 时代语义混淆 | "封建"古今义混用 | 选择题/论述题 | 概念古今义对照 |
| H42 | 改革/改良/革命混淆 | 把制度内调整和根本变革混为一谈 | 比较题 | 概念边界表 |
| H43 | 民族/民主革命混淆 | 民族独立与民主政治任务混乱 | 近现代史 | 双任务对照 |
| H44 | 矛盾概念混淆 | 主要矛盾/基本矛盾、社会性质混用 | 高中材料题 | 概念层级训练 |
| H45 | 专有名词错配 | 人物、制度、会议、条约名称错 | 选择题 | 名词卡片 |

## 六、H5：价值评价失当

**定义：** 历史价值评价论证链不完整，属于学科能力描述；不判断学生个人政治立场或价值取向。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| H51 | 只有结论无依据 | 只写"伟大/进步/落后" | 论述题 | 观点+史实+解释 |
| H52 | 评价标准错位 | 用不属于该时代的标准评价 | 评价题 | 历史条件表 |
| H53 | 作用局限失衡 | 只写积极或只写消极 | 评价题 | 作用+局限双栏 |
| H54 | 家国情怀表达空泛 | 只有情绪性表述，无史实支撑 | 开放题 | 史实依据链 |
| H55 | 论证对象跑偏 | 评价人物却写成评价事件 | 论述题 | 对象-标准-依据三问 |

### H5处理红线

```text
只训练：
  评价标准是否清楚
  史实依据是否充分
  是否放在历史条件中
  作用和局限是否平衡

绝不训练：
  学生应该持什么个人立场
  用立场正确/错误给学生贴标签
```

## 七、跨维度关联规则

```text
H11(时代错位) + H31(因果层级混乱)
  → 判断：画出时间轴后能否区分原因和影响？
    能 → H1为主
    不能 → H3为主

H21(史论不分) + H31(因果层级混乱)
  → 判断：材料证据标清后，因果链能否建立？
    能 → H2为主
    不能 → H3为主

H41(概念语义混淆) + H34(以今律古)
  → 判断：概念边界讲清后，评价是否仍脱离历史条件？
    能修正 → H4为主
    仍不能 → H3/H5为主

H51(只有结论无依据) + H25(内证外证缺失)
  → 判断：给材料证据后能否组织价值论证？
    能 → H2为主
    不能 → H5为主

跨维度记录格式：
  主维度：[H类+子类型ID]
  次要维度：[H类+子类型ID]（如有）
  交叉判断依据：[时空测试/史料标注/因果链/概念对照结果]
```

## 八、顽固弱项追踪标准

```text
同一子类型（相同维度+子类型ID+相同知识点标签）出现次数追踪：

出现1次 → 标记"偶发"，低优先级
出现2次 → 标记"初步弱项"，进入观察期
出现≥3次 → 标记"顽固弱项"，启动专项突破流程

顽固弱项突破流程（历史版）：
  Step 1：纯净版时空测试
    给一个简化版历史定位任务，只看时代、空间、序列、同期
    → 定位对了 → 问题在材料、因果或表达
    → 定位错了 → H1或H4优先处理

  Step 2：专项训练
    H1 → 时间轴/双轨轴/空间标注
    H2 → 史料状态机/史实观点切割
    H3 → 因果四框架/多元解释
    H4 → 概念混淆对照/术语卡片
    H5 → 价值论证链/作用局限平衡

  Step 3：验证锁定（次日+3天后各验证一次）
    → 连续2次做对 → 标记"攻克（待巩固）"
    → 连续3次做对 → 标记"已攻克"

  Step 4：写入档案
    更新该条目状态；获授权后向 `k12-automation` 提交验证提醒请求
```

## 九、与通用错题本的协作边界

```text
通用错题本职责（表面层）：
  → 接收所有科目错题（统一入口）
  → 拍题三信息法收集信息
  → 基础四维分类（概念/计算/审题/策略）
  → 记录错题表面信息
  → 跨科目统一管理与学期报告汇总
  → `k12-automation` 提醒统一调度

历史错误DNA职责（深度层，本维度表）：
  → 历史专属H1-H5深度分类
  → 子类型精确定位（H11/H23/H34等）
  → 跨维度关联分析
  → 顽固弱项专项突破（纯净版时空测试→规则重建→验证锁定→写入档案）
  → 历史焦虑处理
  → 历史弱项月报生成
```

### 通用四维到历史五维映射

| 通用错题本四维 | 可能映射 | 判断依据 |
|----------------|----------|----------|
| 概念模糊 | H1/H3/H4 | 是时空坐标不清、解释机制不清，还是术语混淆？ |
| 计算失误 | H1/H2 | 多为时序推算、图表数据读取或材料数字误读 |
| 读题失误 | H1/H2 | 是漏看时间地点，还是曲解材料/设问？ |
| 方法用错 | H3/H5 | 是因果/比较方法错，还是评价论证结构错？ |

组合摘要时使用 `historyBasicDimension` 字段，枚举值必须与 schema 一致。
