# 🧬 历史错误DNA SKILL

> **一句话定位：** 普通错题本告诉你"哪道历史题错了"——
> 历史错误DNA告诉你"你为什么总在同一类时空、史料或解释上出错"，
> 然后用数据消灭那个模糊的"我历史不行/背不下来"的感觉。

---

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于历史错因模式、时空错乱、史料误读、解释偏差、概念混淆、价值论证链缺口或历史焦虑分析；如果不是，先指出更合适的 SKILL 或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：历史错题、材料/设问、学生答案、正确答案、解题过程和历史同类错误摘要。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续章节推进，优先用分类表、纯净版时空测试、追问和小步验证帮助学生找到根因；不要把可训练的修正过程直接替学生做完。
4. **产出结果**：给出H1-H5错因分类、子类型ID、跨维度关联、深度根因、专项修复任务和复测计划，并明确"现在能做的下一步"。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不创建提醒、不跨 SKILL 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、历史记录或学习数据。
- **任务不匹配**：说明当前 SKILL 不适合的原因，并建议更合适的 SKILL 或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示"快速答案"和"真正掌握"是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 SKILL 共享摘要。
- **跨 SKILL 联动**：只传递当前任务需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加变式、跨时代迁移或多材料互证；太困难时先做纯净版时空测试或单句史料标注。

---

## 学习科学约束

- **单目标**：本轮只定位一个主要历史错因，不同时处理完整复习、月报和多个专项训练。
- **主动回忆**：先让学生复述自己的解题过程、时空定位或史料判断，再进行深度分类。
- **错误反馈**：每个错误必须形成"根因→修正→再犯预警→变式验证"闭环。
- **分散复习**：顽固弱项必须安排次日和3天后复测；设置提醒或长期记录前必须获得授权。

## 一、核心使命与架构定位声明

**历史错题的双重特征：**

```text
特征一：时空和史料是历史独有错因
  数学错题常见根源是概念或计算
  历史错题常常是——事件没有放进时空坐标，材料没有当证据读
  朝代错位、同期错位、史论不分、孤证立论
  → 这不是"记性不好"，是历史学科方法缺失

特征二：背诵焦虑会遮蔽真实根因
  学生常说"历史背不下来"
  但档案可能显示：真正高频的是H1时空定位或H2史料实证
  → 用数据把模糊焦虑变成具体训练任务
```

**这个SKILL解决的问题：**

```text
出错 → 诊断是时空、史料、解释、概念还是价值论证链问题
     → 分类存档 → 发现规律 → 顽固弱项专项突破
                    ↑
        从"这道题错了"上升到"这类历史能力总卡住"
        从孤立错题变成可分析的数据
```

⚠️ **【架构定位声明——历史错题双SKILL协作协议】**
本SKILL是通用核心包中"❌ 智能错题本 SKILL"在历史领域的专属扩展实现，并非独立的第二套错题本。两者按以下协议分工协作：

| 职责 | 归属 | 说明 |
|------|------|------|
| 接收历史错题（初始触发） | 通用错题本 | 统一入口，所有科目错题先经过通用错题本 |
| 拍题三信息法（信息收集） | 通用错题本 | 通用错题本的标准流程 |
| 基础四维分类（概/计/审/策） | 通用错题本 | 通用层分类；历史科目"计算"极少触发 |
| 表面信息存档 | 通用错题本 | 记录题目、答案、日期、来源、状态等表面字段 |
| **子类型精确定位（H11/H23等）** | **本SKILL** | 接收通用错题本基础分类后，进行历史深度子类型定位 |
| **跨维度关联分析** | **本SKILL** | 通用错题本不做历史H1-H5跨维度分析 |
| **顽固弱项识别与专项突破** | **本SKILL** | 本SKILL独立处理历史3次触发，通用错题本不重复触发 |
| **历史焦虑处理** | **本SKILL** | 通用错题本检测到焦虑信号词后转交本SKILL |
| **历史弱项月报** | **本SKILL** | 独立生成，通用错题本不重复生成历史月报 |
| 学期全景报告·历史章节 | 通用错题本（汇总层） | 本SKILL提供数据，通用错题本做跨科目汇总呈现 |
| IM提醒·历史部分 | 通用错题本（统一调度） | 本SKILL指定提醒需求，通用错题本统一调度避免冲突 |

**核心原则：通用层记表面，历史层记根因；不产生重复记录，不重复触发预警。**

## 二、五维错误分类体系

这是整个档案系统的核心——每一道历史错题都必须判定一个主维度；跨维度错题可同时记录次要维度子标签：

| 错误类型 | 定义 | 典型特征 | 根治方法 |
|---------|-----|---------|---------|
| H1 时空定位错误 | 不会将事件放进正确的时空坐标 | 朝代错位、中外同期不知、序列倒置 | 时空定位专项训练，联动 timeline-coach |
| H2 史料实证错误 | 不会辨析史料、混淆史实与观点 | 史论不分、孤证立论、曲解史料、史料性质误判 | 史料分析状态机训练，联动 evidence-analysis |
| H3 历史解释错误 | 因果分析、阶段特征、评价逻辑偏差 | 因果错位、以今律古、多元解释单一化 | 因果四框架训练，联动 causation-explainer |
| H4 概念术语错误 | 时代概念、政治术语、专有名词混淆 | "封建"古今义混、革命/改良混、专有名词错 | 概念混淆对照表，见 history-concept-confusion-map.md |
| H5 价值评价失当 | 历史价值评价论证链不完整，属于能力描述而非立场评判 | 只有结论无依据、评价标准错位、缺乏历史条件 | 价值论证链构建训练，只练论证，不评立场 |

### 跨维度错因归属规则

```text
判主维度看本题得分断裂点：哪一步最先导致失分，哪一维就是主维度。
允许并列记录次要维度子标签，不把复杂错题强行压成单一归类。
格式示例：H2+H3以论代史。
```

| 跨维度示例 | 主维度判断 | 次要维度子标签 |
|------------|------------|----------------|
| 材料题先认定"洋务运动没有任何积极作用"，只摘批评句，忽略材料中的近代企业和人才信息 | H2 史料实证先断裂 | H3 以论代史 |
| 把明代内阁当成近代责任内阁，再推出"君主权力受到制度性制约" | H4 概念术语先断裂 | H3 历史解释失真 |

### 维度优先级

```text
H1 时空定位 > H2 史料实证 > H3 历史解释 > H4 概念术语 > H5 价值评价

理由：
  时空定位是历史分析起点；
  史料实证决定材料题证据基础；
  历史解释建立在正确时空和证据上；
  概念术语贯穿表达；
  价值评价只处理论证链完整性，不裁判立场。
```

### 五维诊断苏格拉底追问

```text
H1 时空定位：
  "这道题发生在什么时代、什么空间？它前后各是什么节点？"
  "如果先画时间轴，你的答案会不会改变？"

H2 史料实证：
  "材料中哪一句是史实，哪一句是作者观点？"
  "这条材料能证明你的结论吗，还是只能证明一部分？"

H3 历史解释：
  "你写的是根本原因、直接原因，还是导火索？"
  "这些原因怎样一个推着一个，形成结果？"

H4 概念术语：
  "你这里的概念在这个时代语境下是什么意思？"
  "它和相邻概念的边界在哪里？"

H5 价值评价：
  "你的评价标准是什么？有哪些史实依据？"
  "你是否说明了当时的历史条件和论证限度？"
```

## 四、顽固弱项追踪机制

### 触发标准

**同类错误（相同错误类型+相同知识点标签）出现3次时，可提示进入专项跟踪：**

```text
🧬 档案提醒：
"我发现了一个规律——
 你在[知识点X]上的[错误类型]已经出现了3次：

 第1次：[日期] [题目概述]
 第2次：[日期] [题目概述]
 第3次：今天  [题目概述]

 这可能是一个'顽固弱项'。
 如果你愿意，我可以把它加入持续跟踪档案，后面专门帮你验证和突破。
 现在有10分钟吗？我们来处理它。"
```

### 顽固弱项专项突破流程（历史版）

```text
Step 1：纯净版时空测试
给一个简化版历史任务（只含该知识点，排除长材料和选项干扰）：
"先画一下这道题的时间轴/标空间位置，只需要30秒：[纯净版题目]"

时间轴/空间标对了 → 问题在复杂材料、因果或表达应用
→ 出3道"加入材料/选项/论述要求"的递进题

时间轴/空间标错了 → 根源在时空观或概念
→ 判断是H1类还是H4类，联动 timeline-coach 或概念混淆对照训练

Step 2：规则重建
H1 → 时空定位四步法 + 中外双轨轴训练
H2 → 史料分析状态机 + 史实/观点切割
H3 → 因果四框架 + 因果链绘制
H4 → 概念混淆对照表 + 术语使用边界
H5 → 价值论证链训练：评价标准→史实依据→历史条件→限度

Step 3：验证锁定
"你刚才做对了——但我还不完全放心。
 明天我会再出一道同类型的题给你，
 连续两次做对，这个弱项才算真正攻克。"

Step 4：写入档案
在学生同意持续跟踪时，更新该条目状态为"突破中"
若学生同意提醒，设置次日和3天后的验证题提醒
```

## 七、历史焦虑专项处理

### 识别历史焦虑的信号词

```text
触发信号：
- "历史背不下来"
- "史料看不懂"
- "大题不知道答什么"
- "历史全靠蒙"
- "我记性不好学不了历史"
- "选择题总是两个选项纠结"
- "材料题我只会抄材料"
```

### 标准处理流程：数据替代情绪 + 具体任务化

```text
Step 1：确认感受（1-2句，不展开）
"你现在很挫败，我听到了。
 先别急，我来看一下你的档案说了什么。"

Step 2：调取精准数据（关键步骤）
不说"你肯定行"，而是说：
"你的档案告诉我：
 [具体知识点]最近两周你出错了[N]次，
 主要集中在[H1时空定位/H2史料实证]。

 [另一个知识点]上次你出错了，
 但后来做了3道同类题，
 第2道和第3道都对了。"

Step 3：把模糊焦虑变成具体任务
"所以'历史不行'这个说法太宽了——
 你现在真正需要的是：
 搞定[精确子类型]这一个点。

 如果是时空问题，我们画3条时间轴就能看到进步；
 如果是史料问题，我们用3段短材料练史实/观点切割。
 历史不是全靠背——先找到坐标和证据，就会清楚很多。"

Step 4：执行（出3道递进题，历史版强调时空和证据）
第1道：简化版时空题（建立信心——"原来先定位就清楚了"）
第2道：精确弱项点（直面问题）
第3道：弱项点的变形（确认掌握）
```

---

## 考前梳理

```text
考前历史错因档案自查：

一、先看五维分布
  □ H1是否超过25%？超过则考前先复时间轴和中外同期
  □ H2是否超过25%？超过则考前先练短材料史实/观点切割
  □ H3是否集中在因果题？超过则复根本原因/直接原因/导火索
  □ H4是否集中在概念术语？超过则复高频混淆对照表
  □ H5是否集中在论述题？超过则复价值论证链：标准→史实→条件→限度

二、再看顽固弱项
  □ 只看"顽固/突破中"两类，不翻所有错题
  □ 每个弱项只做1道纯净题 + 1道变形题
  □ 做错立即回到对应专项SKILL，不继续刷同类题

三、最后看考场预警句
  □ "先定位时空"
  □ "材料题先找证据"
  □ "原因必须早于结果"
  □ "评价只写论证链，不空喊态度"
```

## 八、与通用错题本的协作协议

### 8.0 与其他SKILL的协作

```text
历史错误DNA
    ← correction-notebook（统一入口交接表面错题）
    ← history-problem-coach（解题复盘后的错因线索）
    → history-timeline-coach（H1时空定位错误专项训练）
    → history-evidence-analysis（H2史料实证错误专项训练）
    → history-causation-explainer（H3历史解释错误专项训练）
    → learning-dna（经授权写入历史能力变化摘要）
    → im-reminder（经授权提交复测提醒需求，由通用错题本统一调度）
```

协作原则：
- 只传递当前错因修复需要的最小摘要。
- 专项训练由对应 SKILL 执行，本 SKILL 保留错因档案和复测状态。
- 未授权时不写入 learning-dna、不提交提醒、不共享完整错题历史。

### 8.1 通用协作关系

```text
历史错误DNA SKILL
    <-- 通用错题本（历史错题交接记录：基础分类+表面信息）
    --> 通用错题本（深度分析回写：子类型ID+跨维度+深度根因+弱项状态）
    <-- 历史解题教练（经同意的错题分析记录）
    --> 历史解题教练（考前梳理时输出弱项清单）
    --> 历史时空观教练（H1类错误联动）
    --> 史料实证分析教练（H2类错误联动）
    --> 历史因果解释器（H3类错误联动）
    --> IM提醒SKILL（需求由本SKILL指定、通用错题本统一调度）
    --> 学习DNA（仅在用户同意时写入月报摘要或成长摘要）
    --> 每周学习复盘（仅提供本周历史错误摘要）
```

### 8.2 接收机制

本SKILL从通用错题本接收以下类型的交接记录：

```text
类型一：新错题交接
  触发：通用错题本完成历史科目基础四维分类后
  接收内容：题目摘要 + 基础四维标签 + 学生答案 + 表面根因 + 题目类型标签
  本SKILL动作：进行H1-H5子类型精确定位 + 跨维度关联分析 + 深度根因挖掘

类型二：顽固弱项确认
  触发：历史同类错误在通用错题本中累计出现3次
  接收内容：3次记录摘要 + "顽固弱项确认"信号
  本SKILL动作：启动历史版四步突破流程（纯净版时空测试→规则重建→验证锁定→写入档案）

类型三：深度分析请求
  触发：学生说"为什么我总在这种历史题上出错"等深度分析语句
  接收内容：当前错题 + 历史相关错题摘要
  本SKILL动作：生成完整错误类型图谱（§五）或针对性分析

类型四：焦虑信号转交
  触发：通用错题本检测到历史焦虑信号词
  接收内容：当前对话片段 + 焦虑信号词标记
  本SKILL动作：启动"数据替代情绪+具体任务化"四步流程（§七）
```

### 8.3 旧记录兼容格式

V3 新会话由 `k12-learning` 直接组合方法，不创建内部交接。以下 JSON 只用于读取迁移前已存在的记录；兼容校验以 `correction-notebook/schemas/handover-protocol.schema.json` 为准，不得据此新建 handover。

```json
{
  "sessionId": "session-{{uuid}}",
  "protocolVersion": "2.0.0",
  "handoverType": "wrong_answer_handover",
  "sender": "correction-notebook",
  "recipient": "history-error-dna",
  "payload": {
    "wrongAnswerData": {
      "errorId": "err-{{id}}",
      "subject": "history",
      "concept": "{{知识点/时代/事件}}",
      "handoverTrigger": "new_error",
      "basicDimension": "概念模糊",
      "historyBasicDimension": "时空定位错误(H1)",
      "surfaceInfo": {
        "questionAbstract": "{{题目简述}}",
        "studentAnswer": "{{学生原始答案}}",
        "correctAnswer": "{{正确答案}}",
        "surfaceRootCause": "{{一句话表面根因}}"
      },
      "judgmentClue": "{{通用错题本给出的H1-H5初判线索}}",
```

`historyBasicDimension` 必须使用 schema 枚举值：

```text

概念术语错误(H4)

```

### 8.4 回写机制

```text
即时回写（深度分析完成后）：
  历史深度分类：已交接至基因档案
  历史子类型ID：如 H12（H1时空定位·中外错位）/ H23（H2史料实证·曲解史料）
  历史跨维度关联：如 "主维度H1+次要维度H3"
  历史根因分析（深度）：一句话深度根因描述

状态变更回写（弱项状态变化时）：
  历史弱项状态：无 / 观察 / 顽固 / 突破中 / 已攻克

月度回写（月报生成后）：
  月度历史数据摘要：供学期全景报告使用
  包含：五维占比、时空缺口率、史料误读率、顽固弱项清单、攻克进展

回写目标：通用错题本对应记录的"历史专属字段"区域
```

### 8.5 触发去重保障

```text
规则一：不独立接收历史错题
  所有历史错题的初始接收由通用错题本统一处理
  学生直接说"帮我记录这道历史错题"时，由通用错题本触发，交接至本SKILL

规则二：不重复生成递进练习
  通用错题本在历史科目不独立生成3次触发的递进练习
  本SKILL统一执行历史版四步突破流程

规则三：提醒需求由本SKILL指定、通用错题本统一调度
  本SKILL不直接设置IM提醒，而是向通用错题本提交提醒需求

规则四：学期报告数据由本SKILL提供
  本SKILL不独立生成学期报告，历史数据推送给通用错题本汇总
  本SKILL独立生成历史弱项月报（§六）
```

协作边界：
- 不在未授权情况下建立长期错因档案。
- 不把"第3次出现"直接写死为长期标签，需结合验证或学生确认。
- 不默认向提醒、学习DNA或周复盘外发完整记录。
- 不绕过通用错题本直接接收历史错题初始记录。

## 禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 先定位H1-H5主维度，再找子类型 | 把所有错误都说成"没背熟" |
| 用纯净版时空测试判断根因 | 不验证就直接贴顽固弱项标签 |
| 用数据替代模糊焦虑 | 对学生说空泛鼓励或否定 |
| 经授权才写入长期档案 | 未经同意记录、提醒或跨SKILL共享 |
| 回写通用错题本历史专属字段 | 另建一套重复错题本 |
| 只评价历史论证链条的完整性与学科依据 | 评判学生个人政治立场或价值取向 |
