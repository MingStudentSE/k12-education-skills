# 历史因果分析四框架

> 本文档为 `history-causation-explainer` 的核心参考资源，定义历史因果解释的四个框架、因果链绘制方法、必然/偶然辨析和典型案例。

---

## 一、框架A：唯物史观视角

### 基本链条

```text
生产力变化 → 生产关系调整 → 经济基础变化 → 上层建筑变化

解释原则：
  1. 不把历史变化只归因于个人好坏或道德评价
  2. 先看经济结构、社会矛盾、制度安排和群体利益
  3. 再看人物、政策、思想如何在具体条件中发挥作用
```

### 操作四问

| 问题 | 作用 | 示例 |
|------|------|------|
| 当时生产力有什么新变化？ | 找深层动力 | 工业革命中的机器生产、蒸汽动力 |
| 原有生产关系是否阻碍发展？ | 找矛盾 | 封建制度束缚资本主义发展 |
| 经济基础变化需要什么制度回应？ | 找制度变革原因 | 资产阶级要求政治权利和市场规则 |
| 思想文化如何表达这些变化？ | 找观念层机制 | 启蒙思想为政治变革提供理论武器 |

### 常见误区

| 误区 | 错在哪里 | 修正 |
|------|----------|------|
| 只说"先进战胜落后" | 价值标签不能替代机制 | 说明生产方式、制度效率、社会动员能力 |
| 把人物当唯一原因 | 忽略历史条件 | 人物作用必须放进时代结构 |
| 只写经济原因 | 忽略制度和思想反作用 | 经济基础与上层建筑双向作用 |

## 二、框架B：长时段与短时段

### 变量分类

| 类型 | 定义 | 常见内容 | 答题位置 |
|------|------|----------|----------|
| 长时段慢变量 | 长期积累、短期不易改变的条件 | 地理环境、经济结构、制度传统、社会矛盾 | 根本原因/背景 |
| 中时段条件 | 几十年内形成的发展态势 | 工业化、阶级力量变化、思想传播、国际格局 | 主要原因 |
| 短时段快变量 | 临近事件、政策、人物决策 | 危机、战争、起义、会议、导火索 | 直接原因/触发 |

### 判断流程

```text
一个因素出现后，先问：
  它存在了多久？
  它是否长期积累？
  它是否直接触发事件？
  它能解释"为什么发生"还是只解释"为什么此时发生"？
```

### 示例：法国大革命

```text
长时段：
  封建等级制度、财政结构问题、社会矛盾积累

中时段：
  资本主义发展、启蒙思想传播、资产阶级力量上升

短时段：
  财政危机、三级会议召开、巴黎人民起义

解释句：
  封建制度与资本主义发展之间的矛盾长期积累，
  启蒙思想和资产阶级壮大提供思想与社会力量，
  财政危机和三级会议则使矛盾集中爆发。
```

## 三、框架C：必然性与偶然性

### 区分标准

| 类别 | 判断问题 | 典型内容 | 表述方式 |
|------|----------|----------|----------|
| 必然趋势 | 没有某个个人/事件，长期方向是否仍存在？ | 生产力发展、社会矛盾、民族危机、制度转型需求 | "反映了……的历史趋势" |
| 偶然路径 | 换一个人物/时间/地点，具体过程是否会变化？ | 刺杀事件、临时决策、具体战役、个人选择 | "加速/触发/改变了具体路径" |

### 反事实检验法

```text
检验一：去掉某个人
  趋势是否仍会存在？
  如果存在，个人不是根本原因，但可能改变速度、方式和结果。

检验二：去掉某个导火索
  事件是否完全不会发生？
  如果社会矛盾仍高度紧张，则导火索只是触发，不是根本。

检验三：换一个区域
  条件是否仍然具备？
  如果不具备，说明空间条件是关键变量。
```

### 表述模板

```text
[事件]的发生具有必然性，因为[长期结构条件]已经形成；
但其具体爆发时间/形式具有偶然性，[具体事件/人物/决策]起到触发或加速作用。
```

## 四、框架D：内因与外因

### 分析表

| 因素 | 看什么 | 常见表达 | 例子 |
|------|--------|----------|------|
| 内因 | 国内政治、经济、社会、思想、阶级/群体关系 | 内部矛盾、制度危机、社会力量 | 清朝政治腐败、自然经济占主导 |
| 外因 | 国际格局、战争、殖民、技术传播、思想输入 | 外部压力、国际环境、外来冲击 | 英国工业革命后海外扩张 |
| 交互 | 外因如何通过内因起作用 | 外部压力激化内部矛盾 | 鸦片战争暴露清朝制度和军事落后 |

### 使用原则

```text
不能只写外因：
  外因要通过内部条件起作用。

不能只写内因：
  近现代史中外部环境常常改变事件节奏和方向。

必须写交互：
  "外部冲击 + 内部危机"比单列两个原因更有解释力。
```

## 五、因果链绘制法

### 标准符号

```text
→  表示直接推动
⇒  表示长期趋势导致
┬  表示多因素共同作用
?  表示需要史料或事实验证的可能联系
×  表示不能成立的因果，通常因为时间倒置或机制缺失
```

### 因果链模板

```text
长期结构条件A
长期结构条件B ─┬→ 主要矛盾加深 → 直接原因 → 导火索 → 事件
外部环境C     ─┘

事件 → 直接影响 → 深远影响
```

### 检查清单

| 检查项 | 通过标准 |
--------|----------|
| 时间顺序 | 所有原因都早于结果 |
| 机制完整 | 每个箭头都能说出"怎样推动" |
| 主次明确 | 根本、主要、直接、导火索有区分 |
| 证据支撑 | 需要材料证明的联系不空口断言 |
| 影响分层 | 影响不倒写成原因 |

## 六、经典案例一：工业革命原因

### 原因清单

| 因素 | 层级 | 作用机制 |
|------|------|----------|
| 资产阶级统治确立 | 制度条件 | 提供相对稳定的政治环境和产权保护 |
| 海外市场扩大 | 市场条件 | 传统手工生产无法满足需求，推动技术革新 |
| 圈地运动 | 劳动力/资本条件 | 提供自由劳动力和资本积累 |
| 科学技术积累 | 技术条件 | 为机器发明和改进提供知识基础 |
| 煤铁资源与交通 | 资源/空间条件 | 支撑蒸汽动力和机器生产扩展 |

### 因果链

```text
资产阶级统治确立 + 海外市场扩大 + 圈地运动
        ┬              ┬              ┬
        └────→ 资本、市场、劳动力条件成熟
科学技术积累 + 煤铁资源 ─→ 技术和能源条件成熟
        └────────────────→ 机器发明与工厂制度 → 工业革命
```

### 反事实追问

```text
如果没有海外市场扩大：
  手工生产压力是否仍足够大？

如果没有资产阶级统治确立：
  资本和技术创新是否能稳定扩展？

如果换到农业经济占主导且闭关限制更强的地区：
  市场、制度、技术和劳动力条件是否同时具备？
```

## 七、经典案例二：鸦片战争原因

### 分层分析

| 层级 | 内容 | 机制 |
------|------|------|
| 根本背景 | 英国工业革命后需要市场和原料 | 工业资本主义扩张要求打开海外市场 |
| 内部条件 | 清朝政治腐败、自然经济占主导、闭关限制 | 国家应对外部冲击能力不足 |
| 直接原因 | 禁烟运动打击鸦片贸易 | 英国以保护贸易为借口发动战争 |
| 导火索 | 虎门销烟后的外交和军事冲突升级 | 矛盾集中爆发 |

### 正确表述

```text
鸦片战争不是"因为虎门销烟所以发生"这么简单。
虎门销烟是直接原因和导火索，
更深层的是工业革命后英国对市场和原料的需求，
与清朝封闭落后的统治状态发生冲突。
```

### 常见错误

| 错误说法 | 问题 | 修正 |
|----------|------|------|
| 林则徐禁烟导致鸦片战争 | 把导火索当根本原因 | 禁烟是直接触发，根本背景是工业资本主义扩张 |
| 清朝腐败是唯一原因 | 忽略外部扩张压力 | 写内外因共同作用 |
| 英国想侵略所以战争必然发生 | 机制不足 | 说明工业革命、市场需求和贸易冲突 |

## 八、经典案例三：辛亥革命成败

### 为什么会成功推翻清王朝

```text
民族危机加深 → 清政府统治合法性下降
民族资本主义发展 → 资产阶级政治要求增强
革命思想传播和组织发展 → 革命力量形成
清末新政和预备立宪失败 → 体制内改革失信
武昌起义和各省响应 → 清王朝统治瓦解
```

### 为什么没有完成反帝反封建任务

```text
资产阶级力量相对弱小
旧官僚和立宪派影响仍大
帝国主义和封建势力仍然存在
革命派缺乏彻底的群众动员和政权建设能力
→ 革命果实被袁世凯窃取，社会性质未根本改变
```

### 多元解释比较

| 解释角度 | 能解释什么 | 局限 |
|----------|------------|------|
| 阶级力量 | 为什么革命目标有限 | 不能单独解释武昌起义迅速扩展 |
| 制度危机 | 为什么清王朝崩溃 | 不能完全解释革命后政权走向 |
| 国际环境 | 为什么民族危机加深 | 需要结合国内社会力量 |

## 九、输出模板

```text
历史因果解释输出：

1. 时空定位：
   [事件]发生在[时代/空间]，前后节点是[前]→[后]。

2. 因果分层：
   根本原因：[长期结构条件]
   主要原因：[贡献最大的因素]
   直接原因：[临近推动因素]
   导火索：[触发事件，如有]

3. 因果链：
   [A] → [B] → [C] → [事件]

4. 多元解释：
   角度一：[解释]
   角度二：[解释]
   判断：[哪种解释更能覆盖问题]

5. 易错预警：
   [最容易把什么当成什么]

6. 迁移题：
   换一个事件/时代，让学生重新画链。
```
