# 历史题型手册

> 本文档为 `history-problem-coach` 的题型参考资源，覆盖选择题、材料解析题、论述题的判别、陷阱和模板。

---

## 一、选择题

### 解题流程

```text
Step 1：读设问
  正确/不正确/最符合/主要原因/直接原因/根本原因

Step 2：定时空
  题干中的年份、朝代、阶段、地域

Step 3：抓关键词
  人物、制度、经济现象、思想主张、国际背景

Step 4：排除选项
  绝对化表述、时空不符、史实错误、概念偷换

Step 5：回代验证
  把最佳选项放回题干，看是否回答设问
```

### 三类高频陷阱

| 陷阱 | 信号 | 示例 | 处理 |
|------|------|------|------|
| 绝对化 | 完全、彻底、唯一、全部、根本消除 | "彻底改变了社会性质" | 查是否过度 |
| 时空不符 | 选项事件与题干时代不同 | 用明清政策解释宋代现象 | 画时间轴 |
| 史实错误 | 人物、制度、事件错 | 把科举制创立说成唐朝 | 回到基础史实 |

### 最佳选项判断

```text
如果两个选项都正确：
  选更符合题干主旨、设问程度和材料中心的一项。

如果选项都像对：
  先看时空，再看设问词，最后看材料关键词。
```

## 二、材料解析题

### 读-提-调-答模板

```text
读：
  读设问 → 看出处 → 读材料

提：
  时间、地点、人物、制度、关键词、数据变化、作者观点

调：
  对应课本知识、阶段特征、概念术语、因果框架

答：
  按设问动词组织答案
```

### 设问动词处理

| 设问词 | 要求 | 答法 |
|--------|------|------|
| 概括/指出 | 从材料提取信息 | 少解释，多归纳关键词 |
| 说明/反映 | 材料信息 + 所学判断 | 说明材料背后的历史现象 |
| 分析原因 | 因果分层 | 根本/主要/直接，写机制 |
| 比较 | 同维度并列 | 相同点/不同点，维度一致 |
| 评价 | 作用+局限+历史条件 | 史实依据，不裁判立场 |

### 答案语言模板

```text
材料型：
  "根据材料中[关键词/句子]，可知……"

材料+所学型：
  "材料反映了……；结合所学可知，这与[阶段背景/制度/事件]有关。"

原因型：
  "从根本上看……；从直接因素看……；材料中的……体现了……"

影响型：
  "直接影响是……；深远影响是……；对[国家/世界/社会群体]产生了……"
```

## 三、论述题

### 观点-史实-结构模板

```text
第一步：提观点
  观点必须可论证，不能只是主题词。

第二步：选史实
  每个史实必须有时间、空间和事件名。

第三步：写论证
  史实后必须解释它如何支持观点。

第四步：回扣总结
  总结观点，说明历史条件、趋势或限度。
```

### 常用结构

| 结构 | 适用题 | 段落顺序 |
|------|--------|----------|
| 是什么-为什么-怎么样 | 概念/观点论述 | 定义→原因→影响 |
| 背景-过程-影响 | 事件论述 | 背景→关键过程→历史影响 |
| 观点-史实1-史实2-总结 | 开放论述 | 判断→论据→论据→回扣 |
| 正反/作用局限 | 评价题 | 积极作用→历史局限→条件说明 |

### 常见失分与修正

| 失分 | 表现 | 修正 |
|------|------|------|
| 观点空泛 | "历史发展很重要" | 写成具体判断 |
| 史实不准 | 时间、人物、事件错 | 先做时空定位 |
| 史论脱节 | 史实罗列后没有解释 | 每个史实后加"这说明" |
| 结构混乱 | 一段到底 | 分点或分段 |
| 价值空喊 | 只说"伟大/正确" | 用史实和历史条件论证 |

## 四、CLAW式历史专项模板

### 模板一：选择题纠结

```text
C（情况）：
  "我在做一道[时代/主题]选择题，题干关键词是[关键词]。"
L（逻辑）：
  "我知道要先定位时空和看设问词。"
A（尝试）：
  "我排除了[选项]，但在[两个选项]之间纠结。"
W（需求）：
  "帮我用时空、设问和史实一步步排除，不要直接告诉我答案。"
```

### 模板二：材料题看不懂

```text
C：
  "我有一段关于[主题]的材料，出处是[出处]。"
L：
  "我知道要先圈关键词和区分史实/观点。"
A：
  "我圈了[关键词]，但不知道对应哪个知识点。"
W：
  "帮我从材料信息接到课本知识。"
```

### 模板三：论述题不会展开

```text
C：
  "题目要求围绕[主题]论述。"
L：
  "我知道要有观点、史实和论证。"
A：
  "我想到的观点是[观点草稿]，史实有[史实]。"
W：
  "帮我检查观点是否可论证，并引导我组织结构。"
```

## 五、题型与错误DNA映射

| 题型 | 高频错误 | 对应维度 |
|------|----------|----------|
| 选择题 | 时空不符、概念混淆、绝对化误判 | H1/H4/H3 |
| 材料题 | 史论不分、曲解材料、脱离材料 | H2 |
| 因果题 | 根本/直接/导火索混淆 | H3 |
| 比较题 | 维度不一致、时代条件错位 | H1/H3 |
| 论述题 | 观点无依据、史实不准、评价空 | H3/H5 |
