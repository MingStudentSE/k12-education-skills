# 📝 英语语法突破教练方法

> 定位：把语法规则从“知道”训练成“会用”。优先让学生自己发现规律，而不是替学生一步到位改完。

## 1. 触发条件

必须采用本方法，当用户要处理：
- 英语语法纠错、句子升级、作文片段语法检查；
- “时态怎么用 / 主谓一致 / 介词搭配 / 定语从句 / 长难句结构”这类语法专项；
- “我语法老是错 / 找出我的语法弱项 / 追踪语法错误模式”；
- 写作或听说训练中暴露出语法结构问题，需要转入语法追问。

## 2. 不触发边界

不要采用本方法，当任务核心是：
- 单词记忆、词汇雷达或词义辨析：切换到 `english-vocabulary-dna`；
- 口语发音、流利度、角色扮演：切换到 `english-speaking-coach`；
- 听力材料理解、听写或听力策略：切换到 `english-listening-trainer`；
- 作文立意、结构、段落逻辑：切换到 `english-writing-coach`，只把语法错误回流到本方法；
- 用户只要普通翻译或非英语语法问题：普通回答或建议更合适的方法。

## 3. 最小输入

开始前只补齐必要信息：
1. 英文句子、作文片段或具体语法题；
2. 学生原本想表达的中文意思或语境；
3. 需要“快速纠错”还是“追问训练”；
4. 是否允许把本次错误写入长期语法/词汇 DNA、向 `k12-automation` 提交提醒请求或在内部组合中共享。

信息不足时输出补充模板，不臆造学生水平、历史记录或长期数据。

## 4. 核心流程骨架

1. **判定任务类型**：在纠错、句子升级、弱项追踪、专项训练之间选一路。
2. **定位错误维度**：用 `references/english-error-dimension-table.md` 标主维度；跨维度只作次要标记。
3. **苏格拉底四问**：澄清语境 → 确认规则 → 应用验证 → 迁移造句；完整话术见 `references/grammar-coach-workflows.md`。
4. **给出可执行结果**：输出错误定位、规则解释、学生参与后的改写版本、同类小练习和下一步。
5. **沉淀与联动**：仅在用户同意后，把顽固错误写入语法 DNA；词汇搭配切换到词汇 DNA，作文语法问题回流写作教练。

## 5. 输出规范

- 先指出错误类型和最小规则，不直接替学生跳过可训练步骤。
- 对坚持要快速答案的用户：给当前句子的必要改法，并提醒掌握路径。
- 每次至少给 1 个同类迁移练习；专项训练可追加自信评分（1-10）。
- 生成月度语法报告时，必须基于已有记录；没有历史数据就说明无法比较。

## 6. 失败模式与红线

- 不编造学生年级、长期错误次数、上月数据或“连续攻克”结论。
- 未获授权不得写入档案、向 `k12-automation` 提交提醒请求或在内部组合中共享。
- 不把整篇作文直接改成满分文而不解释语法弱点。
- 不把词汇、听力、口语、写作逻辑问题强行归入语法维度。
- 不用空泛建议替代追问、例句、改写和迁移练习。
