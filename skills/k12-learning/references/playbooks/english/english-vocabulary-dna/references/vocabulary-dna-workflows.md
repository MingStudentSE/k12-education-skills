# 📖 智能词汇 DNA 系统

> **一句话定位：** "今天背，明天忘"不是你的错——是你背单词的时间节点错了。  
> 正确时间复习，遗忘就会停下来。  
> 这个方法做的事：帮你找到正确的时间节点，然后在你授权后提醒你。

---

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于词汇积累、词汇复习或词汇使用画像更新；如果不是，先指出更合适的方法，或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：生词、语境句、错用记录和近期阅读/写作主题。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续章节推进，优先用追问、验证、例子和小步反馈帮助学生自己完成关键思考；不要把可训练的步骤直接替学生做完。
4. **产出结果**：给出词义辨析、词族网络、复习计划和可用例句，并明确“现在能做的下一步”。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不调用 `k12-automation` 创建提醒、不跨 module 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、历史记录或学习数据。
- **任务不匹配**：说明当前方法不适合的原因，并建议更合适的方法或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示“快速答案”和“真正掌握”是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 module 共享摘要。
- **跨 module 联动**：只传递当前任务需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加解释、变式或迁移；太困难时拆成子问题、补前置知识或降一级练习。

## ⚠️ 技术实现边界声明

> **关于“长期记忆、提醒与多模态识别”机制：**
> 1. 本模块对词汇项、复测表现和提醒状态的跨次记录，依托于 OpenClaw 的本地化持久状态，并非 LLM 自身记忆，也不等于已经形成认知上的长期记忆。
> 2. 定时提醒泛化支持任何已接入 OpenClaw 平台的 IM 软件（如微信、QQ等），并非针对单一软件定制，其定时唤醒能力依托于定制化平台（如 QClaw）的「定时任务机制」。
> 3. 拍照提取单词功能，强依赖于多模态大语言模型（Multimodal LLMs）的视觉能力，或宿主平台配置的本地 OCR 扩展。
> 4. 若本轮没有视觉/OCR 能力、图片不清或识别失败，必须请学生粘贴或手动输入词表；不得补猜图片内容。OCR 外传仍需逐批授权。

## 一、核心使命

**间隔复习起始模板（仅在用户同意提醒时执行）：**

```
无个体证据时可从 Day 1 → Day 3 → Day 7 → Day 14 → Day 30 开始。
每轮都先主动回忆、造句或辨析，再看答案：
  独立答对且能迁移 → 延长下一次间隔
  答对但靠提示     → 保持或缩短间隔并换题复测
  答错或无法提取   → 先修正，再安排较近的变式复测

完成固定轮次不等于已经进入长期记忆；必须用之后仍能独立提取和迁移的表现判断。
```

## 三、模块A：词汇DNA入库

### 三种入库方式

**方式①：拍照提取**

```
触发：学生拍照或截图发来单词表、课文词汇
前提：本轮宿主已返回可核验的图片识别结果；否则切换到方式③手动添加。
操作：
"我看到这里有[N]个词——我帮你把它们都存入DNA。
 你现在想先标记几个'重点词'吗？（这些会优先提醒）
 
 或者全部均等存入，都可以。"

存入格式（内部）：
批量入库，每个词标注：
- 入库日期
- 来源（哪节课/哪篇课文）
- 优先级（学生标记的重点）
```

**方式②：对话标记**

```
触发：口语/听力练习中遇到好词
触发词："把这个词存入DNA" / "记下这个" / "存这个"

存入时附带：
- 当前对话的语境（这个词在什么情境下出现的）
- 入库日期和场景标签

反馈：
"[词汇]已经存入你的词汇DNA！
 语境：[当前对话语境摘要]
 如果你同意提醒，第一轮复习会在24小时后发来一道闪卡测验。"
```

**方式③：手动添加**

```
触发：学生主动说出想记的词
格式示例：
"把 'meticulous' 加入我的词汇DNA，
 我想用它描述做事认真细致的人"

存入时记录：
- 词汇本身
- 学生提供的使用场景
- 标注：主动学习意愿强，优先级高

反馈：
"'meticulous' 已存入！这个词形容做事极其仔细、注重细节的人。
 例：She is meticulous about her work.
 
 如果你开启提醒，24小时后我会来考你——
 到时候你能用它造一个描述自己认识的人的句子吗？想想看。"
```

## 四、模块B：五轮`k12-automation`

### 五轮递进设计

每一轮的提醒形式不同，难度递进，从"被动识别"升级到"主动使用"：

**第1轮（24小时后）：闪卡测验**

```
IM推送（微信/QQ等）：
"📖 词汇提醒
 
 [词汇] 是什么意思？
 回复你的答案，不用查——直接说你记得的。"

学生回答后：
→ 答对：
  "✅ 对！[词汇] = [释义]。
   再巩固一下：你能用这个词造个短句吗？"

→ 答错或不记得：
  "没关系！[词汇] = [释义]
   例句：[例句]
   3天后我再问你一次，这次会记住了。"
```

**第2轮（3天后）：造句激活**

```
IM推送（微信/QQ等）：
"📖 词汇提醒（第2轮）
 
 用 [词汇] 造一个关于你自己生活的句子——
 不用复杂，用你真实的情况造就好。"

处理：
→ 学生造句后，评价是否正确使用
→ 如有更地道的表达，提供升级版本
→ 记录这个造句到词汇DNA（作为使用记录）
```

**第3轮（7天后）：对话植入**

```
IM推送（微信/QQ等）：
"📖 词汇提醒（第3轮）
 
 今天聊聊[和词义相关的话题]，试着用上 [词汇]——
 不用刻意，就在对话里自然用出来。"

操作：
→ 开启一段简短对话，话题与词汇语义相关
→ 对话结束后，检查学生是否自然使用了这个词
→ 如果用了：记录为"主动使用一次"，提升熟悉度评级
→ 如果没用：温和提示："这里其实可以用 [词汇] 来表达——试试？"
```

**第4轮（14天后）：语境扩展**

```
IM推送（微信/QQ等）：
"📖 词汇提醒（第4轮）
 
 [词汇] 的近义词/反义词/常见搭配有哪些？
 你知道它们有什么微妙的差别吗？"

回复内容：
→ 近义词对比（如 meticulous vs careful vs thorough）
→ 常见搭配（collocations）
→ 使用场景的细微差别
→ 出一道辨析题让学生练
```

**第5轮（30天后）：月度综合复习**

```
IM推送（微信/QQ等）：
"📖 月度词汇复习
 
 这个月你学了这些词：[列举本月入库词汇]
 来做一次综合测验——
 我出5道题，看看你还记得多少。"

测验形式：
→ 混合题型：选义、造句、辨析、填空
→ 测验后逐词记录“需要提示 / 独立答对 / 能迁移”
→ 需要提示或答错的词：先修正，再进入较近的变式复测
→ 能独立造句、辨析或迁移的词：延长间隔；不因一次综合测验直接标记“长期记忆”
```

## 五、模块C：新词汇雷达（课前7天预热）

### 触发方式

```
学生发送："下周我要学第[X]课，这是单词表[粘贴/拍照]，
          帮我启动7天预热计划。"

AI先经过提醒授权与真实调度能力检查。只有 `k12-automation` adapter 返回任务 ID、下一次触发时间和控制入口后，才确认：
"收到！我看到有[N]个新词。
 7天预热提醒已创建：任务[ID]，下次触发[时间]，可在[控制入口]暂停或取消。

 预热进度：
 Day 7 → 词形+发音初见
 Day 5 → 图像/场景联想
 Day 3 → 轻松开口使用
 上课前 → 自信提醒"

若没有调度能力或 adapter 返回不完整，明确回复“提醒未创建”，并把上述四阶段内容作为可复制计划交给学生，不得说“计划已启动”或“IM 消息会找到你”。
```

### 四阶段预热内容

**Day 7（第一次见面）：建立"见过"的印象**

```
IM推送（微信/QQ等）：
"📡 新词预热 · 第1天（距上课还有7天）

 下周你会遇到这些词，我们先认识一下：
 
 [词汇1] /[音标]/ 读作：[拼音辅助]
 [词汇2] /[音标]/ 读作：[拼音辅助]
 ...
 
 今天任务：把这些词的发音读三遍——
 不需要记意思，只是让它们变得不陌生。"
```

**Day 5（场景联想）：从符号变成有画面的概念**

```
IM推送（微信/QQ等）：
"📡 新词预热 · 第2天

 给这几个词配上画面——
 
 [词汇1]：[一张有画面感的场景描述或图示引导]
 [词汇2]：[场景描述]
 
 想象这个场景，把词和画面连在一起。
 下次见到这个词，画面会先出现，意思就跟着来了。"
```

**Day 3（轻松使用）：主动激活**

```
IM推送（微信/QQ等）：
"📡 新词预热 · 第3天

 用这3个词，和我聊3-5句话——
 随便聊，不用都用上，用到哪个算哪个：
 [词汇1] / [词汇2] / [词汇3]"
```

**上课前（自信提醒）**

```
IM推送（微信/QQ等）：
"📡 新词预热 · 最后提醒

 今天上课会遇到这些词——
 你已经见过它们[3]次了，不会陌生的。
 
 特别提示：[2-3个最重要的词] 可能是这节课的重点，
 注意听老师怎么用它们造句。"
```

## 六、模块D：提取表现与到期状态追踪

### 提取表现分类

根据学生在复测中的真实表现调整每个词的下一次间隔，不推断个人遗忘率：

```
最近复测需要提示或答错：
→ 缩短下一次间隔
→ 先做错误修正，再换语境复测

最近复测独立答对但尚不能迁移：
→ 保持默认窗口，下一轮改做造句或辨析

最近复测能独立迁移：
→ 延长间隔并减少不必要提醒
→ 后续用真实语境抽查，而不是宣告永久掌握
```

### 到期状态判断

```
现在复测：上次答错/依赖提示，且已完成修正
近期复测：上次独立答对，但还没有迁移证据
暂缓：上次能在新语境独立使用，当前没有更高优先级任务

状态由真实表现、内容重要性和用户可用时间共同决定；不计算个人“遗忘百分比”。
```

## 八、词汇DNA两个层次追踪

```
层次①：被动识别（看到认识）
  标准：看到这个词能理解意思
  
层次②：主动使用（能自己说/写出来）
  标准：在没有提示的情况下能用这个词表达想法

两个层次分开追踪，分开复习：
→ 层次①的词：闪卡测验为主
→ 层次②的词：造句/对话植入为主

目标：把词库中20%的核心词汇升级到层次②
     剩余80%维持层次①即可
```

## 九、同一结果的组合边界

```
主结果：词义/词形证据 → 主动使用任务 → 五轮复测建议 → 掌握判据
可选材料：当前口语、听力或写作中出现的词；同一结果可加入一句语法用法验证
Learning State：只有用户同意后才记录新词、使用层次或词汇积累摘要
真实提醒：切换到 `k12-automation`，由 Automation 展示五轮任务并自行取得调度授权
```

## 十、参考资源

- **证据说明**：历史遗忘实验不提供适用于所有学生和词汇的固定保留率。本方法只保留间隔复习、主动提取和基于真实表现调整间隔三个机制。
- Ebbinghaus, H. (1885/1913), [Memory: A Contribution to Experimental Psychology](https://psychclassics.yorku.ca/Ebbinghaus/index.htm)。
- Cepeda, Pashler, Vul, Wixted & Rohrer (2006), [Distributed practice in verbal recall tasks: A review and quantitative synthesis](https://doi.org/10.1037/0033-2909.132.3.354)。
- Roediger & Karpicke (2006), [Test-enhanced learning: Taking memory tests improves long-term retention](https://doi.org/10.1111/j.1467-9280.2006.01693.x)。
