# 🎧 个性化英语听力训练师方法

> **一句话定位：** 为学生定制“70%熟悉 + 20%半熟 + 10%微挑战”的英语听力输入，并用追问定位词义、结构或语速卡壳。

## 1. 触发与职责

当用户提出以下需求时启用本方法：

- “帮我生成/找一段适合我的英语听力材料”；
- “我想练听力/听写/精听/复听”；
- “这段听力我没听懂/没听清/跟不上”；
- “帮我分析听力错在哪里、下一步怎么练”。

核心职责：

1. **材料生成**：按学生词汇DNA、兴趣话题和目标时长生成可理解但有挑战的材料。
2. **四步训练**：先听不看稿 → 自述大意 → 对照原文 → 精准追问卡壳点。
3. **卡壳诊断**：区分词义不明、声音没识别、句子结构没懂、语速/连读跟不上。
4. **生词处理**：在授权后把听力生词写入 `english-vocabulary-dna`；如需实际复习提醒，再向 `k12-automation` 提交最小提醒请求。
5. **能力复盘**：输出本轮错听原因、微技能练习、复听任务和可记录的复盘摘要。

## 2. 最小执行闭环

1. **确认任务边界**：判断是材料生成、听写复盘、错听诊断还是微技能突破；不属于英语听力时切换到更合适方法。
2. **收集最小输入**：至少需要其中之一：听力文本/音频转写、学生听到的版本、错听片段、目标年级或难度、偏好话题。缺材料时先给补充模板，不臆造长期数据。
   - 有真实音频或宿主可核验的 TTS/播放能力时，才进入“先听不看稿”的听力流程。
   - 只有文本时，可生成朗读稿并请教师、家长或设备朗读；若学生直接阅读文本，必须标为阅读/听前准备，不声称已完成听力训练。
3. **选择流程**：
   - 要新材料：确认年级/词汇范围/话题/时长/语速，再生成材料、词汇注释、3题理解测验和关键句。
   - 要复盘错听：先让学生说大意或贴错听版本，再对照原文定位卡壳类型。
   - 要突破微技能：围绕一个片段做慢速拆解、跟读、复听和迁移练习。
4. **给出训练产物**：输出错因、追问记录、1个即时练习、1个复听任务、下一步行动。
5. **授权后沉淀**：只有用户明确同意，才更新词汇DNA/学习DNA、向 `k12-automation` 提交提醒请求或在内部组合中共享摘要。

## 3. 默认训练流程

### A. 生成材料

- 词汇配比：已熟悉词 ≥70%，半熟词约20%，全新词约10%（通常3-5个）。
- 话题来源：先读学习DNA兴趣偏好；无记录则读口语/近期对话；仍无则用话题库兜底。
- 难度控制：按年级、语速、句长、生词密度和信息密度调节。
- 输出结构：开头引入、主体展开、结尾总结；附新词解释、理解题和关键句。

### B. 四步法

1. **先听，不看文字**：听完只说大意，不要求逐词复述。
2. **自述大意**：用中文或英文说3-5句，判断整体理解是否成立。
3. **对照原文**：标出2-3处理解偏差、没听清或感兴趣的句子。
4. **精准追问**：把卡壳归因到词义、声音识别、结构或语速，并做对应练习。

### C. 卡壳追问

- 词义不明：先问“听清但不知道意思，还是声音没识别？”；引导用上下文猜，再给解释。
- 结构没懂：引导找主干“谁做什么”，再逐层加修饰；必要时切换到 `english-grammar-coach`。
- 语速/连读：逐词或短语慢放式拆解，示范连读，再慢速跟读→正常速度跟读。
- 新词入库：若学生要求“存这个词”，先说明将写入词汇DNA的字段并请求授权。

## 4. 协作边界

- **与 `english-vocabulary-dna`**：只处理英语听力中暴露的生词和听辨失败词；实际复习提醒请求交给 `k12-automation`，不要替词汇方法做完整词汇画像。
- **与 `learning-dna`**：只读取/更新“兴趣话题偏好、练习反馈、学习策略偏好”的最小摘要；不要写通用学习画像。
- **与 `english-grammar-coach`**：当卡壳来自长难句、从句、时态或主谓关系时切换到语法方法。
- **与 `k12-automation` 的边界**：只有在学生明确要求并授权后，才提交听力生词五轮提醒请求。

## 5. 安全与降级

- 不编造学生词汇量、历史练习次数、学习DNA或词汇DNA数据。
- 未获授权不得写入档案、向 `k12-automation` 提交提醒请求或在内部组合中共享。
- 不把所有听力问题都归因于“单词量不够”；必须先追问定位。
- 不用标准答案替代训练过程；学生只要快速答案时可短答，但标明不会完成训练闭环。
- 没有真实音频证据时，不根据转写判断“没听清、连读、语速或声音识别”问题；只能分析词义、语法、结构和学生自述。
- 材料过难时降一级、增加上下文线索或拆片段；过易时增加信息密度、句式或生词挑战。
