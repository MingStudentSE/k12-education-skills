# 生物实验设计指南

## 1. 探究问题格式

```text
探究 [自变量] 对 [因变量] 的影响。
比较 [处理组] 与 [对照组] 在 [指标] 上的差异。
验证 [某生命过程/结构功能] 是否成立。
```

## 2. 变量表

| 类型 | 定义 | 示例 |
|------|------|------|
| 自变量 | 主动改变的因素 | 光照强度、温度、激素浓度 |
| 因变量 | 观察或测量的结果 | 气泡数、萌发率、心率、叶面积 |
| 控制变量 | 需要保持一致的因素 | 水量、时间、材料大小、物种 |
| 无关变量 | 可能干扰但不是研究目标 | 环境波动、个体差异 |

## 3. 对照类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 空白对照 | 排除自然变化 | 不加激素的一组 |
| 条件对照 | 比较不同处理 | 强光组和弱光组 |
| 自身对照 | 同一对象前后比较 | 运动前后心率 |
| 阳性/阴性对照 | 检查实验系统是否有效 | 已知会/不会出现反应的组 |

## 4. 重复与样本

生物实验常有个体差异，所以需要重复和足够样本。只用一粒种子、一片叶或一个人，很难支持普遍结论。

## 5. 方案检查

1. 是否一次只改变一个自变量。
2. 因变量是否可观察、可测量。
3. 控制变量是否列全。
4. 是否有对照组。
5. 是否有重复或足够样本。
6. 是否符合伦理和安全边界。

## 6. 禁止/降级

不指导人体风险试验、动物伤害、不安全微生物培养或医疗处置。可降级为教材数据分析、虚拟实验、图表解读或方案评价题。
