# 生物概念图构建指南

## 1. 概念图四步

```text
列核心概念 → 标关系词 → 排层级/因果/并列/调节 → 回测
```

## 2. 关系词库

| 关系 | 常用词 | 示例 |
|------|--------|------|
| 层级 | 属于、组成、包括 | 细胞组成组织 |
| 因果 | 导致、促进、抑制、影响 | 光照影响光合速率 |
| 过程 | 先后、转化、运输、释放 | 有机物分解释放能量 |
| 调节 | 反馈、维持、协调 | 胰岛素调节血糖 |
| 对比 | 区别于、共同点、边界 | 光合作用区别于呼吸作用 |

## 3. 图谱类型

| 类型 | 适用 | 结构 |
|------|------|------|
| 层级图 | 生命层级、分类、系统组成 | 上位概念到下位概念 |
| 因果图 | 生态、调节、影响因素 | 条件到结果 |
| 过程图 | 光合、呼吸、消化、循环 | 起点到终点 |
| 对比图 | 易混概念 | 共同点 + 边界 |

## 4. 回测方法

完成概念图后至少做一个：

- 用自己的话沿箭头讲一遍。
- 遮住某个节点，说出相邻关系。
- 给一个题目，标出考到的节点和关系。
- 改一个条件，预测图中哪些节点会变化。

## 5. 常见问题

| 问题 | 表现 | 修复 |
|------|------|------|
| 节点太多 | 像目录不是概念图 | 合并低价值细节 |
| 没有关系词 | 只有箭头 | 每条箭头写动词 |
| 层级错 | 不同层级平铺 | 先定位生命层级 |
| 不回测 | 图画完就结束 | 加题目或现象检验 |

## 6. 输出模板

```text
中心概念：

关系词：

易混边界：
回测题：
```
