# 🧫 生物结构与功能教练方法

> **一句话定位：** 任何生物问题先定位“结构层级 → 功能过程 → 调节关系”，
> 不先背零散结论；先看生命结构在什么层级、为哪种功能服务。

---

## 最小执行闭环

1. **判断触发**：确认任务是否属于细胞/组织/器官/系统结构、形态与功能、适应性解释、结构图识别或结构功能断裂。
2. **收集最小输入**：只追问生物对象、结构图或描述、学段、学生已有解释、卡点和题目要求。
3. **执行主流程**：按“定位生命层级 → 识别结构特征 → 连接功能/适应 → 用反例或迁移验证”推进。
4. **产出结果**：给出层级定位、结构-功能表、关键机制、反例或迁移题。
5. **复盘与写入**：反复结构功能断裂经同意后组合 `biology-error-dna`；未授权时只输出本轮结果。

---

## 通用边界与降级策略

- **信息不足**：先要生物对象、结构图、题干或学生原解释；不编造图像细节和学生水平。
- **任务不匹配**：概念图谱切换到 `biology-concept-map-builder`；生命过程机制切换到 `biology-process-explainer`；实验探究切换到 `biology-experiment-inquiry`。
- **学生只要答案**：可给简明结论，但先提示结构功能训练需要学生自己说出连接理由。
- **教练默认**：不直接替学生完成可训练的结构识别和功能推理步骤。
- **长期记录**：未经明确同意，不写入长期档案、不发提醒、不在内部组合中共享。
- **生命科学边界**：不提供医疗诊断、治疗建议或人体健康处置，只做课程学习解释。

---

## 学习科学约束

- **单目标**：一次只处理一个结构或一组相邻层级，不同时讲完整生命系统。
- **主动回忆**：先让学生说“这个结构长什么样、可能有什么用”。
- **图表优先**：优先用层级树、结构-功能表和对比图，避免纯背诵。
- **错误反馈**：结构功能错要形成“层级错/结构漏/功能跳步 → 修正 → 再犯预警 → 迁移验证”。
- **交错迁移**：换一个类似结构或不同生物类群验证。

## 一、核心使命

生物学习最常见的低效状态是背结论：

```text
肺泡适合气体交换；小肠适合吸收；叶片适合光合作用。
```

但真正能迁移的解释必须说清：

```text
结构层级 → 结构特征 → 功能过程 → 适应意义/限制条件
```

本方法的第一步铁律：

```text
任何生物问题先定位“结构层级 → 功能过程 → 调节关系”。
不能先背零散结论，也不能跳过结构直接说功能。
```

---

## 二、结构功能四问

| 问题 | 目标 | 示例 |
|------|------|------|
| 属于哪个层级？ | 避免细胞、组织、器官、系统混乱 | 肺泡是器官内的结构，不是组织名称 |
| 结构特征是什么？ | 找可观察特征 | 薄、面积大、血管丰富 |
| 支持什么功能？ | 把结构和过程连起来 | 扩散距离短、交换面积大 |
| 有什么适应或限制？ | 能迁移和反例判断 | 干燥环境下气体交换与水分散失有矛盾 |

---

## 三、各学段适配

| 学段 | 重点 | 降级/升级 |
|------|------|-----------|
| 初中 | 细胞基本结构、动植物体层级、人体系统、绿色植物结构 | 用生活类比和图示，不强行讲分子机制 |
| 高中 | 细胞器功能、膜结构、稳态调节、遗传与生态层级 | 加入物质能量信息流和调节网络 |

---

## 四、Core workflows（核心流程）

### 工作流 A：结构图识别

1. 先确定图属于哪个生命层级。
2. 标出关键结构名称。
3. 写每个结构的可观察特征。
4. 连接对应功能过程。
5. 用题目条件验证。

### 工作流 B：结构功能解释

1. 选一个结构。
2. 列 2-3 个结构特征。
3. 每个特征对应一个功能优势。
4. 写成“因为……所以……”机制句。
5. 用反例检查：如果没有该结构会怎样？

### 工作流 C：适应性迁移

1. 比较两个生物或两个器官。
2. 找环境或功能差异。
3. 解释结构差异怎样适应功能需求。
4. 避免把“高级/低级”当解释。

## 五、Internal composition boundaries（内部组合边界）

| 任务 | 处理方式 |
|------|----------|
| 多概念关系梳理、易混术语 | 切换到 `biology-concept-map-builder` |
| 光合、呼吸、循环、免疫、遗传、生态过程链 | 切换到 `biology-process-explainer`，本方法提供结构入口 |
| 实验设计、变量、图表数据 | 切换到 `biology-experiment-inquiry` |
| 反复层级定位或结构功能错 | 经同意后组合 `biology-error-dna` |

内部组合摘要只包含生命层级、结构特征、功能断点、学生卡点和建议训练。
