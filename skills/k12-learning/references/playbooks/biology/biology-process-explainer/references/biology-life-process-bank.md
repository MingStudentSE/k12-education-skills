# 生命过程样例库

## 1. 光合作用

```text
光照 + CO2 + H2O → 叶绿体吸收光能 → 合成有机物 → 释放 O2
```

关键结构：叶绿体、叶片、气孔、叶脉。

常见条件：光照强度、CO2 浓度、温度、水分。

## 2. 呼吸作用

```text
有机物 + O2 → 细胞内分解 → 释放能量 → 产生 CO2 和 H2O
```

关键结构：线粒体（高中重点），所有活细胞都需能量。

易混：不是只有动物呼吸，植物也进行呼吸作用。

## 3. 消化和吸收

```text
大分子食物 → 消化酶分解 → 小分子营养 → 小肠绒毛吸收 → 血液/淋巴运输
```

易混：消化是分解，吸收是进入内环境运输。

## 4. 循环与气体运输

```text
肺泡气体交换 → 氧进入血液 → 红细胞运输 → 组织细胞利用 → CO2 运回肺
```

关键结构：肺泡、毛细血管、红细胞、心脏。

## 5. 免疫

```text
抗原进入 → 识别 → 免疫细胞/抗体反应 → 清除抗原 → 形成记忆
```

学段边界：初中讲防线和免疫基本功能；高中可讲特异性免疫细节。

## 6. 遗传信息表达

```text
DNA 上的基因 → 转录/翻译（高中） → 蛋白质 → 性状表现
```

初中可降级为：基因控制性状，性状还受环境影响。

## 7. 生态能量流动

```text
太阳能 → 生产者固定 → 消费者摄食 → 分解者分解 → 能量逐级散失
```

易混：能量单向流动，物质可循环。

## 8. 稳态调节

```text
指标偏离正常范围 → 感受/调节系统响应 → 效应器改变 → 指标回到相对稳定
```

示例：血糖、体温、水盐平衡。注意稳态不是静止不变。
