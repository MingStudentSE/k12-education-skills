# 🧬 数学错误DNA

> 普通错题本记录“哪道题错了”；本方法诊断“为什么总在同一类数学点上出错”，并把根因、趋势和突破计划沉淀为可授权的数学错因档案。

## 什么时候用我

- 用户要分析数学错因模式、概念混淆、长期错误画像、顽固弱项或数学弱项月报。
- 当前结果已有 `correction-notebook` 视图提取的基础四维、题目摘要、学生答案、正确答案和可用的历史引用。
- 学生说“为什么我总在这种题上错”“我数学太差了”“生成数学月报”等，需要用数据定位根因或缓解数学焦虑。
- 当前单题结果已经形成错因证据，用户同意把本次根因更新到 Learning State。

## 什么时候不用我

- **通用错题管理**、跨学科错题收纳、拍题三信息法和学期全景报告入口 → 用 `correction-notebook`；真实提醒请求 → 用 `k12-automation`。
- 单题即时讲解、从零带学生解一道题 → 用 `math-problem-solving-coach`，只在学生同意记录错因时切换到本方法。
- 概念本身没懂、需要重新讲概念 → 由 `k12-learning` 采用 `math-concept-explainer`；本方法只给错因诊断和内部组合理由。
- 只想要快速答案、不愿建立档案或授权持续跟踪 → 只输出本轮诊断，不写入、不提醒、不在内部组合中共享。
- 非数学科目错误或普通学习复盘 → 不触发本方法。

## 最小输入

1. 当前错题：题目摘要或图片文字、学生步骤/答案、正确答案或标准思路。
2. 初步标签：知识点、通用错题本基础四维标签，或学生自述的错因。
3. 历史证据：同类错误记录、出现次数、最近练习日期；没有就明确“暂无历史”。
4. 授权状态：是否允许把展示过的字段写入 Learning State。本方法不收集或保存调度授权；需要真实提醒时由 `k12-automation` 通过自己的 interface 另行确认。

信息不足时先发补充模板，不编造学生水平、历史记录或长期数据。

## 核心流程骨架

1. **判定边界**：确认是数学错因诊断而不是通用错题收纳；只需通用记录时，当前主流程仅采用 `correction-notebook` 视图。
2. **收集证据**：用最小输入模板收齐错题、步骤、自述和历史；没有历史就只做单次诊断。
3. **四维归类**：在计算失误、概念模糊、方法用错、读题失误中选一个主维度，细则见 `references/math-error-dimension-table.md`。
4. **子类型定位**：定位 C/B/M/R 子类型；表内可使用短码，任何跨科汇总、报告、导出或持久化字段必须写成 `math:C01`、`math:B03` 等带学科命名空间的规范码。
5. **纠偏与验证**：给出针对性练习、概念重建或读题习惯训练；概念混淆查 `references/concept-confusion-map.md`，读题问题查 `references/reading-habits.md`。
6. **档案更新**：仅在授权后，把数学专属字段附在同一条 Learning State 错题记录中，不建立第二条记录；写入 DNA 摘要时主码使用 `primarySubtypeId`，关联码使用 `relatedSubtypeIds`，值必须带 `math:` 命名空间。
7. **趋势产出**：当用户要求图谱、月报或焦虑处理时，使用 `references/math-error-dna-operations.md` 中的报告模板和“数据替代情绪”流程。

## 输出格式

- **本轮诊断**：主维度 + 带 `math:` 命名空间的子类型 ID + 证据句 + 深度根因。
- **纠偏策略**：今天能做的1个动作、3道以内验证题或1条自检清单。
- **档案动作**：写明“未授权，仅显示建议字段”或“已获授权，同一条 Learning State 记录补充字段如下”。
- **复测计划**：只生成次日/3 天后/下月的复测内容、建议时间和掌握判据；真实调度走 `k12-automation` seam。

## 飞轮闭环出口（本轮错因必须推进）

- ① 掌握验证：概念模糊类（C）在同一结果中加入 `feynman-learning` 视图（让学生自己复述概念+举一反例）；计算/方法/读题类（B/M/R）加入 1 道变式（采用 `math-problem-solving-coach` 视图，独立做到第一步）。给通过判定：学生能独立说清 __ 算掌握。
- ② 沉淀入口：同一条错题记录保留通用字段与数学深度字段；概念混淆可同时生成康奈尔线索栏建议。给字段摘要+授权状态（未授权只给建议字段，不实写）。
- ③ 复测安排：T+1→T+3→T+7→T+14 间隔序列，复测用变式题（非原题）；需要实际提醒时，切换到 `k12-automation` 并由其展示渠道、频率和下次触发时间后另行取得授权。
- ④ 复盘入口：本题+本周同类纳入 `weekly-review`，给触发信号（同类累计≥3 或 复测未过）。

## 失败模式与红线

- 不把“粗心”当终点；必须继续定位到符号、分数、概念、方法或读题等可训练根因。
- 不为凑趋势编造历史数据；没有档案时只输出当前样本诊断。
- 不为通用记录和数学深度诊断创建两份错题；同一结果只保留一个题目记录 ID。
- 不在未授权情况下建立长期档案、写入学习 DNA 或向周复盘展开完整记录；不在 Learning State 中保存调度授权。
- 不重复生成预警或练习：数学同类错误只有在多次独立证据或复测支持时才进入一组突破流程。
- 不用“你数学不行”这类标签；用具体数据把焦虑落到可解决任务。
- 不分析完就结束：错因诊断后必须产出飞轮闭环出口四要素；只给纠偏策略而无掌握验证/沉淀/复测/复盘推进，等同"分析完就结束"。
