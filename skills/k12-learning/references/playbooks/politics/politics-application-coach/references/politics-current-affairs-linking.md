# 政治时政素材链接方法

> 本文档为 `politics-application-coach` 的时政链接参考，训练学生把现实材料映射到政治理论模块。所有价值相关表达只训练论证构建，不评判学生个人立场。

---

## 一、时政链接四步法

```text
Step 1 抽取事实
  发生了什么？主体是谁？做了什么？产生什么结果？

Step 2 定位模块
  这件事主要涉及经济、政治、文化、哲学，还是初中生活主题？

Step 3 映射原理
  材料事实对应哪条教材原理？

Step 4 组织表达
  用"事实 + 原理 + 分析 + 结论"写成答案点。
```

### 四步表

| 步骤 | 问题 | 输出 |
|------|------|------|
| 抽取事实 | 谁做了什么 | 主体、行为、对象、结果 |
| 定位模块 | 讨论资源、权力、文化还是方法 | 模块和单元 |
| 映射原理 | 哪条原理能解释事实 | 2-4条原理 |
| 组织表达 | 怎样写成答案 | 分点骨架 |

## 二、时政素材模块映射表

| 素材类型 | 事实信号 | 优先模块 | 可用原理 |
|----------|----------|----------|----------|
| 科技创新、产业升级 | 企业研发、数字经济、绿色转型 | 经济生活 | 创新发展、企业经营、市场与调控 |
| 民生政策、公共服务 | 社保、教育、医疗、就业 | 经济/政治生活 | 共同富裕、政府履职、人民利益 |
| 政务公开、基层治理 | 信息公开、协商议事、群众监督 | 政治生活 | 依法行政、民主监督、基层民主 |
| 文化遗产保护 | 非遗、文物、传统节日 | 文化生活 | 文化传承、文化创新、文化自信 |
| 国际合作 | 外交、贸易、气候合作 | 政治/经济生活 | 国家利益、和平发展、互利共赢 |
| 调查研究、试点推广 | 先调研、再试点、后推广 | 生活与哲学 | 实践认识、从实际出发、矛盾特殊性 |

## 三、事实抽取模板

```text
时政材料：
  某地通过线上平台公开民生项目进度，居民可提交意见，政府按月公布整改结果。

事实抽取：
  主体：政府、居民
  行为：公开项目进度、提交意见、公布整改
  对象：民生项目
  结果：提升透明度、回应群众需求

模块定位：
  政治生活 → 政府依法行政/接受监督/服务人民

表达：
  政府公开项目进度并公布整改结果，有利于规范权力运行、接受群众监督，
  体现政府坚持为人民服务，提升治理效能。
```

## 四、常见素材链条

### 经济发展类

```text
事实链：
  技术研发 → 产品升级 → 市场竞争力提升 → 高质量发展

可用原理：
  企业经营成功因素、创新驱动、市场配置资源、宏观调控、绿色发展
```

### 法治政府类

```text
事实链：
  权力清单公开 → 程序透明 → 群众监督 → 依法行政

可用原理：
  政府依法行政、权力需要监督、建设服务型政府、人民利益
```

### 基层治理类

```text
事实链：
  居民议事 → 协商共治 → 问题解决 → 公共参与提升

可用原理：
  基层群众自治、公民有序参与、民主协商、公共利益
```

### 文化传承类

```text
事实链：
  传统资源 → 新技术传播 → 年轻群体参与 → 文化生命力增强

可用原理：
  文化传承、文化创新、文化交流、文化自信
```

### 哲学方法类

```text
事实链：
  调查实际 → 发现矛盾 → 分类施策 → 实践检验

可用原理：
  一切从实际出发、具体问题具体分析、实践是认识的基础、联系观点
```

## 五、避免机械套时政

| 机械套用 | 问题 | 修正 |
|----------|------|------|
| 看到政策就写政府职能 | 可能设问限定经济或哲学 | 先看设问模块 |
| 看到传统文化就只写文化自信 | 忽略传承、创新、传播 | 先抽取具体行为 |
| 看到国际合作就只写和平发展 | 可能还涉及国家利益和经济全球化 | 按材料主体和结果选原理 |
| 看到"人民"就写政治认同 | 口号化，缺少具体依据 | 写清人民利益如何体现 |
| 看到开放性题就判断立场 | 越过价值红线 | 只评价论证链和学科依据 |

## 六、时政材料迁移训练

### 训练流程

```text
1. 给一段100字以内时政材料
2. 学生先抽取主体、行为、结果
3. 学生定位模块和原理
4. AI 检查是否模块错、原理泛、映射断
5. 换一个设问重新作答
```

### 示例材料

```text
材料：某市建设"15分钟便民生活圈"，引入社区食堂、托育点和智慧养老服务，
并通过居民议事会收集意见，动态调整服务清单。

设问A：运用政治生活知识说明该市做法的意义。
模块：政治生活
原理：政府履职、基层民主、公共参与、人民利益

设问B：运用经济生活知识分析该做法如何促进民生消费。
模块：经济生活
原理：消费需求、公共服务供给、市场主体参与

设问C：运用哲学知识说明动态调整服务清单的方法论。
模块：生活与哲学
原理：从实际出发、实践与认识、具体问题具体分析
```

## 七、价值相关时政题红线

```text
可以做：
  抽取事实
  说明教材中的学科评价标准
  检查论证链是否完整
  引导学生把结论建立在事实和依据上

不能做：
  评判学生个人政治立场或价值取向对错
  用"立场错误"解释失分
  要求学生持有某个个人态度
```
