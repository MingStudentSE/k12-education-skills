# 政治价值推理框架

> 本文档为 `politics-value-reasoning` 的核心参考资源，定义事实判断、价值判断、价值选择三步链，提供学科评价标准库和开放性试题模板。核心红线：只练论证不评立场。

---

## 一、价值推理三步链

```text
事实判断
  材料/现象客观发生了什么，不掺杂评价
    ↓
价值判断
  依据教材中的学科标准评价该事实
    ↓
价值选择
  基于事实和价值判断提出行动、建议或结论
```

### 三步链输出表

| 步骤 | 问题 | 合格输出 | 常见错误 |
|------|------|----------|----------|
| 事实判断 | 谁做了什么，结果是什么 | 主体、行为、对象、结果 | 一上来写好坏 |
| 价值判断 | 用哪条学科标准评价 | 人民利益、法治、公平等 | 只写个人喜好 |
| 价值选择 | 应怎样做或如何评价 | 主体行动、条件、限度 | 空喊支持/反对 |

---

## 二、事实判断与价值判断区分

### 判断表

| 句子 | 类型 | 说明 |
|------|------|------|
| 某市公开民生项目预算 | 事实判断 | 客观描述行为 |
| 公开预算有利于接受监督 | 事实-价值连接 | 说明事实与标准关系 |
| 这个做法非常正确 | 价值判断 | 需要补学科标准和依据 |
| 公民应依法有序参与监督 | 价值选择 | 行动建议，需由前文推出 |

### 切割流程

```text
拿到学生答案
├── 找事实句：有没有主体、行为、结果？
├── 找标准句：有没有学科评价依据？
├── 找选择句：有没有行动/建议/结论？
└── 如果只有态度词
    └── 要求补事实和标准，不评价态度本身
```

## 三、学科评价标准库

| 标准 | 适用问题 | 判断问题 | 表达模板 |
|------|----------|----------|----------|
| 人民利益 | 民生、公共服务、政府治理 | 是否回应人民需要、维护人民权益 | "从人民利益看，该做法..." |
| 法治原则 | 权力运行、规则治理、权利义务 | 是否依法、公开、程序规范、权责统一 | "从法治角度看..." |
| 公平正义 | 分配、教育、社保、公共资源 | 是否促进机会公平、过程公平和结果公平 | "这有利于..." |
| 共同富裕 | 收入、区域、城乡、民生 | 是否促进发展成果共享 | "该举措有利于..." |
| 文化自信 | 文化传承、创新、传播 | 是否传承优秀文化并开放交流 | "这体现了..." |
| 公共参与 | 社区治理、民主协商、志愿服务 | 是否依法有序参与公共事务 | "公民通过..." |
| 社会责任 | 企业、公民、青少年行动 | 主体是否承担相应责任 | "作为...应..." |
| 生态文明 | 绿色发展、资源环境 | 是否兼顾发展和环境保护 | "这符合..." |

### 标准选择决策树

```text
材料核心是民生改善 → 人民利益 / 共同富裕 / 公平正义
材料核心是权力运行 → 法治原则 / 民主监督 / 人民利益
材料核心是公民行动 → 公共参与 / 权利义务 / 社会责任
材料核心是文化传承 → 文化自信 / 文化创新 / 文化交流
材料核心是企业行为 → 社会责任 / 法治 / 经济高质量发展
材料核心是环境治理 → 生态文明 / 可持续发展 / 公共参与
```

## 四、开放性试题模板

### 模板A：如何评价

```text
事实判断：
  材料中[主体]通过[行为]，产生/指向[结果]。

价值判断：
  从[学科标准]看，这一做法[有利于/需要改进]，
  因为它[对应材料事实与标准的关系]。

价值选择：
  因此，应[坚持/完善/规范/参与]，
  同时注意[条件/限度/改进方向]。
```

### 模板B：是否赞同

```text
立场表达：
  我赞同/不完全赞同/需要具体分析该观点。

事实依据：
  材料中的事实是...

学科标准：
  依据[标准]，应当看到...

推理：
  因为...所以...

选择：
  因此，应该...
```

### 模板C：青少年/公民应怎样做

```text
公共问题：
  当前问题是...

权利义务/责任：
  作为[身份]，应依法享有...并履行...

具体行动：
  可以通过[合法、有序、具体方式]参与。

注意边界：
  不造谣、不越权、不用情绪代替规则。
```

## 五、常见 Po5 缺口与修复

| 子问题 | 表现 | 修复 |
|--------|------|------|
| 事实缺失 | 直接写"应该支持" | 补"谁做了什么、结果是什么" |
| 标准缺失 | 写"我觉得很好" | 补人民利益/法治/公平等学科标准 |
| 连接缺失 | 事实和标准并列，没有说明关系 | 写"材料事实如何体现标准" |
| 选择缺失 | 只有分析，没有行动或结论 | 补主体、行动、条件 |
| 边界缺失 | 结论过度绝对 | 补适用条件和改进方向 |

### 修复示例

```text
原答案：
  我认为社区议事会很好，大家都应该支持。

修复：
  事实判断：社区通过议事会让居民参与公共事务讨论。
  价值判断：从公共参与和基层民主看，这有利于居民依法有序表达诉求，
            推动社区治理更贴近居民需要。
  价值选择：因此，居民应理性参与议事，提出具体建议，
            社区也应完善反馈机制，避免参与流于形式。
```

## 六、论证链评分尺

| 等级 | 表现 | 下一步 |
|------|------|--------|
| 0级 | 只有态度，没有事实和标准 | 补事实一句、标准一句 |
| 1级 | 有事实，但没有学科标准 | 选择一个评价标准 |
| 2级 | 有事实和标准，但连接弱 | 写出"事实如何体现标准" |
| 3级 | 链条完整，但表达泛 | 加主体、行为、结果和条件 |
| 4级 | 链条完整且能迁移 | 换情境验证或加入限度分析 |

## 七、价值红线操作清单

```text
必须做：
  □ 把 Po5 称为"价值论证缺失"或"论证链不完整"
  □ 只检查事实、标准、推理、选择
  □ 使用学科理论标准，不使用个人偏好裁判
  □ 对学生观点保持中性，聚焦论证质量

禁止做：
  □ 说学生价值观偏差
  □ 说学生立场错误
  □ 说学生思想有问题
  □ 要求学生必须赞成/反对某个个人态度
```

## 八、迁移训练题

### 题1：法治政府

```text
材料：某地行政执法全过程公开，并允许群众查询处罚依据。
任务：用事实-价值-选择三步评价。

参考链：
  事实：政府公开执法过程和处罚依据。
  标准：法治原则要求权力依法、公开、规范运行。
  选择：应继续完善公开和救济渠道，保障群众监督权利。
```

### 题2：文化传承

```text
材料：某校把地方非遗课程引入社团活动，并邀请传承人指导。
任务：用事实-价值-选择三步评价。

参考链：
  事实：学校通过课程和社团传承地方非遗。
  标准：文化传承与文化自信要求理解优秀传统文化并结合实践创新。
  选择：学生可积极参与体验，同时用现代方式传播优秀内容。
```

### 题3：公共参与

```text
材料：居民在社区平台反映停车问题，有人发表事实依据，有人发布未经核实的攻击性言论。
任务：提出公民应怎样参与。

参考链：
  事实：居民参与公共问题讨论，但存在不实攻击风险。
  标准：公共参与应依法有序，权利义务相统一。
  选择：公民应基于事实表达诉求，通过合法渠道监督和协商。
```
