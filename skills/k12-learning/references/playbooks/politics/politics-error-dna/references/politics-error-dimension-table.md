# 政治错因维度表

> 本文档为 `politics-error-dna` 的核心参考资源，定义政治学科包 Po1-Po5 五维错因体系、子类型分类、跨维度关联规则与追踪标准。

---

## 一、维度总览

```text
政治错因维度体系（Po1-Po5×多子类型）

Po1 理论模块定位错误 ── 政治独有的地基错误
  没有先判断经济、政治、文化、哲学或初中生活主题，导致理论入口选错

Po2 概念原理混淆 ── 理解层错误
  概念边界、原理适用条件和相邻原理混用

Po3 理论联系实际错误 ── 应用层错误
  材料和理论无法对应，机械套模板，迁移生硬

Po4 逻辑与表达错误 ── 输出层错误
  答题层次、术语、逻辑词和分点结构不规范

Po5 价值论证缺失 ── 论证能力错误
  事实、学科标准、价值选择链条不完整；只评价论证质量，不评价个人立场

每道错题必须归入且只归入一个主维度。
如存在跨维度因素，记录为"主维度+次要维度"。

优先处理顺序：Po1(模块定位) > Po2(概念原理) > Po3(理论映射) > Po4(表达) > Po5(价值论证)
→ 模块定位是政治分析起点，入口错会导致后续全错。
```

---

## 二、Po1：理论模块定位错误

**定义：** 没有先定位理论模块、单元和原理，导致答题入口错误。

**判断标准：** 学生拿到政治题后跳过设问限定和材料主体，指出模块定位问题后能修正后续分析，则 Po1 为主。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| Po11 | 设问限定漏看 | "运用经济生活"却答政府职能 | 材料题/选择题 | 设问限定圈画 |
| Po12 | 四大模块错判 | 经济、政治、文化、哲学互串 | 材料题 | 30秒模块定位 |
| Po13 | 单元层级错判 | 政治生活中把公民题答成政府题 | 材料题 | 主体-单元匹配 |
| Po14 | 哲学板块错判 | 唯物论、认识论、辩证法混用 | 哲学题 | 哲学关键词树 |
| Po15 | 初高中表达错配 | 初中题硬套高中术语，或高中题只写生活口号 | 开放题 | 学段适配训练 |

### 根治方法映射

```text
Po11 → 每题先圈设问限定：模块、主体、题型动词
Po12 → 四模块判别树：资源/权力/文化/方法
Po13 → 主体匹配表：公民、政府、党、人大、企业、文化机构
Po14 → 哲学板块关键词：实际/实践/联系/矛盾/群众
Po15 → 初中生活化三步，高中模块化四步
```

## 三、Po2：概念原理混淆

**定义：** 政治概念、原理或适用条件理解错误，导致判断和表达失准。

**判断标准：** 学生模块定位大体正确，但概念必要条件、相邻概念边界或原理适用条件说不清。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高频模块 | 关联训练 |
|---------|------|----------|----------|----------|
| Po21 | 经济概念混淆 | 商品/产品、价值/价格、市场/调控混 | 经济生活 | 概念必要条件 |
| Po22 | 政治主体概念混淆 | 权利/权力、政府/党、民主决策/监督混 | 政治生活 | 主体边界表 |
| Po23 | 法治与责任概念混淆 | 法律/道德/规则、权利/义务混 | 初中/政治生活 | 生活情境辨析 |
| Po24 | 文化概念混淆 | 继承/创新、文化自信/文化自大混 | 文化生活 | 文化概念双栏 |
| Po25 | 哲学概念混淆 | 实践/认识、主要矛盾/矛盾主要方面混 | 生活与哲学 | 哲学边界判断 |
| Po26 | 原理适用条件错 | 把"决定"写成"影响"，把方法论泛化 | 综合题 | 原理条件卡片 |

### 根治方法映射

```text
Po21 → 商品=劳动产品+用于交换，价值和价格分开
Po22 → 先问主体：公民享有权利，公共机关行使权力
Po23 → 法律强制性、道德自律性、规则生活化
Po24 → 继承保留优秀内容，创新形成新表达
Po25 → 多个矛盾中抓重点 vs 一个矛盾中看主流
Po26 → 写清原理关键词和适用条件
```

## 四、Po3：理论联系实际错误

**定义：** 不能把材料现象与理论原理建立对应关系，导致机械套模板、材料和理论两张皮。

**判断标准：** 学生能说出原理，但不能指出材料中哪一句支持该原理，或答案点与材料无对应。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| Po31 | 材料要素漏提取 | 不圈主体、行为、结果、价值目标 | 材料题 | 四类词标注 |
| Po32 | 理论材料两张皮 | 原理一段、材料一段，互不解释 | 材料题 | 映射表训练 |
| Po33 | 机械套模板 | 不看设问，把背过模板全写上 | 大题 | 设问动词拆解 |
| Po34 | 映射跳步 | 材料只能支持A，却直接推出C | 分析题 | 材料句→有限结论 |
| Po35 | 时政链接生硬 | 时政材料和教材原理硬连 | 时政题 | 事实抽取四步 |
| Po36 | 主体措施错配 | 政府题写公民措施，企业题写政府责任 | 措施题 | 主体-措施矩阵 |

### 根治方法映射

```text
Po31 → 主体词、行为词、结果词、价值词四色标注
Po32 → 每个答案点必须写"材料句→原理→分析句"
Po33 → 先拆设问动词：说明/分析/措施/评析
Po34 → 材料能证明什么就写到哪里，不扩大结论
Po35 → 时政事实→模块→原理→表达
Po36 → 政府/企业/公民/文化机构主体措施分开
```

## 五、Po4：逻辑与表达错误

**定义：** 答题结构、学科术语、逻辑连接和分点表达不规范，导致本来会的内容无法得分。

**判断标准：** 模块、原理和材料基本正确，但答案层次乱、口语化、没有逻辑词或观点依据脱节。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| Po41 | 分点结构混乱 | 一大段写到底，点与点重复 | 材料题 | 分点骨架 |
| Po42 | 学科术语缺失 | 用"管一管""好起来"替代依法行政等术语 | 大题 | 术语替换表 |
| Po43 | 逻辑连接缺失 | 没有因为、体现、有利于、要求等关系词 | 材料题 | 逻辑词训练 |
| Po44 | 观点依据脱节 | 观点写了，依据没有或不支撑 | 论述题 | 观点-依据-分析 |
| Po45 | 措施空泛 | "加强管理、提高意识"无主体无路径 | 措施题 | 主体+措施+效果 |
| Po46 | 答非所问 | 问原因写措施，问意义写做法 | 设问题 | 设问动词表 |

### 根治方法映射

```text
Po41 → 每点一条原理，编号表达
Po42 → 口语改术语：管一管→依法监管/履行职能
Po43 → 每条线补关系词：体现/有利于/要求/促进/制约
Po44 → 观点后必须跟事实依据和理论分析
Po45 → 主体、措施、对象、效果四件套
Po46 → 先翻译设问动词，再组织答案
```

## 六、Po5：价值论证缺失

**定义：** 价值评价论证链不完整，属于学科能力描述；不判断学生个人政治立场或价值取向。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| Po51 | 事实判断缺失 | 直接表态，不说明材料发生了什么 | 开放题 | 事实提取 |
| Po52 | 学科标准缺失 | 只写"我觉得好/不好" | 评价题 | 标准库匹配 |
| Po53 | 事实价值混淆 | 把事实描述和评价混在一起 | 开放题 | 事实/价值切割 |
| Po54 | 选择结论跳步 | 事实和标准有了，但行动建议突然出现 | 建议题 | 选择链补句 |
| Po55 | 口号化表达 | 空喊责任、担当、爱国，无具体依据 | 开放题 | 三行论证模板 |
| Po56 | 条件限度缺失 | 结论过度绝对，不说明条件 | 评析题 | 条件/限度补充 |

### Po5处理红线

```text
只训练：
  事实判断是否清楚
  学科标准是否明确
  事实和标准是否连接
  价值选择是否由前文推出

绝不训练：
  学生应该持什么个人立场
  用立场正确/错误给学生贴标签
  把 Po5 写成价值观偏差或思想问题
```

## 七、跨维度关联规则

```text
Po11(设问限定漏看) + Po32(理论材料两张皮)
  → 判断：重新圈设问限定后，材料映射能否修正？
    能 → Po1为主
    不能 → Po3为主

Po22(权利权力混淆) + Po36(主体措施错配)
  → 判断：主体边界讲清后，措施是否自然修正？
    能 → Po2为主
    不能 → Po3为主

Po14(哲学板块错判) + Po25(哲学概念混淆)
  → 判断：给出哲学关键词树后，概念能否区分？
    能 → Po1为主
    不能 → Po2为主

Po34(映射跳步) + Po44(观点依据脱节)
  → 判断：建立材料映射表后，表达是否改善？
    能 → Po3为主
    不能 → Po4为主

Po51(事实判断缺失) + Po43(逻辑连接缺失)
  → 判断：补事实-价值-选择三行后，表达是否完整？
    能 → Po5为主
    不能 → Po4为主

跨维度记录格式：
  主维度：[Po类+子类型ID]
  次要维度：[Po类+子类型ID]（如有）
  交叉判断依据：[纯净审题测试/概念对照/材料映射表/表达骨架/价值三步链结果]
```

## 八、顽固弱项追踪标准

```text
同一子类型（相同维度+子类型ID+相同知识点标签）出现次数追踪：

出现1次 → 标记"偶发"，低优先级
出现2次 → 标记"初步弱项"，进入观察期
出现≥3次 → 标记"顽固弱项"，启动专项突破流程

顽固弱项突破流程（政治版）：
  Step 1：纯净版审题测试
    给一道极简政治定位任务，只看设问限定、材料主体、模块和原理
    → 定位对了 → 问题在概念、映射、表达或价值论证
    → 定位错了 → Po1或Po2优先处理

  Step 2：专项训练
    Po1 → 模块定位四步法/设问限定训练
    Po2 → 概念混淆对照/原理适用条件
    Po3 → 理论联系实际四步法/材料映射
    Po4 → 规范表达模板/逻辑连接词
    Po5 → 事实-价值-选择链/只练论证不评立场

  Step 3：验证锁定（次日+3天后各验证一次）
    → 连续2次做对 → 标记"攻克（待巩固）"
    → 连续3次做对 → 标记"已攻克"

  Step 4：写入档案
    更新该条目状态；获授权后向 `k12-automation` 提交验证提醒请求
```

## 九、与通用错题本的协作边界

```text
通用错题本职责（表面层）：
  → 接收所有科目错题（统一入口）
  → 拍题三信息法收集信息
  → 基础四维分类（概念/计算/审题/策略）
  → 记录错题表面信息
  → 跨科目统一管理与学期报告汇总
  → `k12-automation` 提醒统一调度

政治错误DNA职责（深度层，本维度表）：
  → 政治专属 Po1-Po5 深度分类
  → 子类型精确定位（Po11/Po23/Po34等）
  → 跨维度关联分析
  → 顽固弱项专项突破（纯净版审题测试→规则重建→验证锁定→写入档案）
  → 政治焦虑处理
  → 政治弱项月报生成
```

### 通用四维到政治五维映射

| 通用错题本四维 | 可能映射 | 判断依据 |
|----------------|----------|----------|
| 概念模糊 | Po1/Po2 | 是模块入口不清，还是概念/原理边界不清？ |
| 计算失误 | Po4 | 政治极少计算，多为图表数据表达或比例读取失误 |
| 读题失误 | Po1/Po3/Po4 | 是漏设问限定、漏材料要素，还是答非所问？ |
| 方法用错 | Po3/Po5 | 是理论联系实际方法错，还是价值论证链缺失？ |

组合摘要时使用 `politicsBasicDimension` 字段，枚举值必须与 schema 一致。
