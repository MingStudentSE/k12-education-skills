# 🧬 政治错误DNA SKILL

> **一句话定位：** 普通错题本告诉你"哪道政治题错了"——
> 政治错误DNA告诉你"你为什么总在同一类模块定位、理论映射或价值论证上出错"，
> 然后用数据消灭那个模糊的"政治大题我永远不知道答什么"的感觉。

---

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于政治错因模式、理论模块定位错、概念原理混淆、理论联系实际断裂、表达混乱、价值论证缺失或政治焦虑分析；如果不是，先指出更合适的 SKILL 或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：政治错题、材料/设问、学生答案、正确答案、解题过程和同类错误摘要。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续八节推进，优先用 Po1-Po5 分类表、纯净版审题测试、追问和小步验证帮助学生找到根因；不要把可训练的修正过程直接替学生做完。
4. **产出结果**：给出 Po1-Po5 错因分类、子类型ID、跨维度关联、深度根因、专项修复任务和复测计划，并明确"现在能做的下一步"。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不创建提醒、不跨 SKILL 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、题目材料、历史记录或学习画像。
- **任务不匹配**：说明当前 SKILL 不适合的原因，并建议更合适的 SKILL 或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示"快速答案"和"真正掌握"是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 SKILL 共享摘要。
- **跨 SKILL 联动**：只传递当前错因修复需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加换材料、换模块干扰或换设问验证；太困难时先做纯净版审题测试或单原理映射。

---

## 学习科学约束

- **单目标**：本轮只定位一个主要政治错因，不同时处理完整复习、月报和多个专项训练。
- **主动回忆**：先让学生复述自己的模块定位、原理调动、材料映射或价值论证过程，再进行深度分类。
- **错误反馈**：每个错误必须形成"根因→修正→再犯预警→变式验证"闭环。
- **结构化表达**：错因必须落入 Po1-Po5、子类型ID和跨维度关联，不只写"粗心"。
- **交错迁移**：顽固弱项修复后要换材料、换设问、换模块干扰验证。
- **分散复习**：顽固弱项必须安排次日和3天后复测；设置提醒或长期记录前必须获得授权。

## 一、核心使命与架构定位声明

**政治错题的双重特征：**

```text
特征一：理论模块定位是政治独有地基错因
  数学错题常见根源是概念或计算
  政治错题常常是——题目还没定位到正确模块，就开始套熟悉原理
  经济题答政治、哲学题答文化、政府题写企业
  → 这不是"不会背"，是理论入口选错

特征二：价值论证缺失容易被误说成态度问题
  学生常说"政治题是不是要写正确立场"
  但档案只记录论证能力：事实、标准、选择链是否完整
  → 用中性能力描述替代立场评判
```

**这个 SKILL 解决的问题：**

```text
出错 → 诊断是模块、概念、映射、表达还是价值论证链问题
     → 分类存档 → 发现规律 → 顽固弱项专项突破
                    ↑
        从"这道题错了"上升到"这类政治能力总卡住"
        从孤立错题变成可分析的数据
```

⚠️ **【架构定位声明——政治错题双 SKILL 协作协议】**
本 SKILL 是通用核心包中"❌ 智能错题本 SKILL"在政治领域的专属扩展实现，并非独立的第二套错题本。两者按以下协议分工协作：

| 职责 | 归属 | 说明 |
|------|------|------|
| 接收政治错题（初始触发） | 通用错题本 | 统一入口，所有科目错题先经过通用错题本 |
| 拍题三信息法（信息收集） | 通用错题本 | 通用错题本的标准流程 |
| 基础四维分类（概/计/审/策） | 通用错题本 | 通用层分类；政治科目"计算"维度极少触发 |
| 表面信息存档 | 通用错题本 | 记录题目、答案、日期、来源、状态等表面字段 |
| **子类型精确定位（Po11/Po23 等）** | **本 SKILL** | 接收通用错题本基础分类后，进行政治深度子类型定位 |
| **跨维度关联分析** | **本 SKILL** | 通用错题本不做政治 Po1-Po5 跨维度分析 |
| **顽固弱项识别与专项突破** | **本 SKILL** | 本 SKILL 独立处理政治3次触发，通用错题本不重复触发 |
| **政治焦虑处理** | **本 SKILL** | 通用错题本检测到政治焦虑信号词后转交本 SKILL |
| **政治弱项月报** | **本 SKILL** | 独立生成，通用错题本不重复生成政治月报 |
| 学期全景报告·政治章节 | 通用错题本（汇总层） | 本 SKILL 提供数据，通用错题本做跨科目汇总呈现 |
| IM提醒·政治部分 | 通用错题本（统一调度） | 本 SKILL 指定提醒需求，通用错题本统一调度避免冲突 |

**核心原则：通用层记表面，政治层记根因；不产生重复记录，不重复触发预警。Po5 只记论证链缺口，不记立场对错。**

## 二、五维错误分类体系

这是整个档案系统的核心——每一道政治错题都必须判定一个主维度；跨维度错题可同时记录次要维度子标签：

| 错误类型 | 定义 | 典型特征 | 根治方法 |
|---------|-----|---------|---------|
| Po1 理论模块定位错误 | 没定位到正确理论模块，是政治独有地基错误 | 考经济答政治、考唯物论答认识论、设问限定漏看 | 纯净版审题测试，联动 application-coach |
| Po2 概念原理混淆 | 概念混、原理用错或适用条件错 | 商品/产品混、权利/权力混、主要矛盾/矛盾主要方面混 | 概念辨析表，联动 concept-explainer |
| Po3 理论联系实际错误 | 现象与理论映射错、迁移生硬、机械套用 | 套模板不看材料、理论与材料两张皮 | 理论联系实际四步法，联动 application-coach |
| Po4 逻辑与表达错误 | 答题层次乱、术语缺失、逻辑断裂 | 不分点、口语化、观点与依据脱节 | 表达规范训练 |
| Po5 价值论证缺失 | 只有结论无依据，事实与价值判断不分；中性能力描述，非立场评判 | 空喊口号、评价无学科依据、事实价值混淆 | 价值推理三步链，联动 value-reasoning（只练论证不评立场） |

### 跨维度错因归属规则

```text
判主维度看本题得分断裂点：哪一步最先导致失分，哪一维就是主维度。
允许并列记录次要维度子标签，不把复杂错题强行压成单一归类。
格式示例：Po2+Po3概念误用致映射错。
```

| 跨维度示例 | 主维度判断 | 次要维度子标签 |
|------------|------------|----------------|
| 把"公民权利"写成"政府权力"，随后把材料错映射到依法行政 | Po2 概念原理混淆先断裂 | Po3 概念误用致映射错 |
| 设问限定经济生活/经济与社会，却按政府职能作答，把企业主体换成政府主体 | Po1 理论模块定位先断裂 | Po3 主体错位致材料映射错 |

### 维度优先级

```text
Po1 理论模块定位 > Po2 概念原理混淆 > Po3 理论联系实际 > Po4 逻辑表达 > Po5 价值论证缺失

理由：
  模块定位是政治题入口；
  概念原理决定能否选对理论工具；
  理论联系实际决定大题核心得分；
  逻辑表达是输出层；
  Po5 只处理论证链完整性，不裁判立场。
```

### 五维诊断苏格拉底追问

```text
Po1 理论模块定位：
  "设问限定了哪个模块？材料主体是企业、政府、公民、文化机构还是实践主体？"
  "如果只给30秒，你能说出模块→单元→原理吗？"

Po2 概念原理混淆：
  "这个概念的必要条件是什么？相邻概念边界在哪里？"
  "这条原理的适用条件满足吗？"

Po3 理论联系实际：
  "材料中哪一句对应你写的这条原理？"
  "你是在解释材料，还是把原理和材料并排放着？"

Po4 逻辑与表达：
  "每一点是否有主体、术语、逻辑词和结论？"
  "观点、依据、材料分析有没有断开？"

Po5 价值论证缺失：
  "你的事实判断是什么？使用的学科标准是什么？选择结论怎样推出？"
  "这里只检查论证链，不评价你的个人立场。"
```

### 各学段适配

| 学段 | 诊断重点 | 降级/升级策略 |
|------|----------|----------------|
| 初中道德与法治 | 生活情境、法律规则、权利义务、责任行动；Po1 降级为主题定位 | 不强制高中四模块术语；价值论证降级为"事实→规则/责任→行动" |
| 高中思想政治 | 模块定位、原理调用、材料映射、规范表达和开放性价值论证 | 要求"模块→单元→概念→原理"，Po5 用事实-价值-选择链训练 |

### 新旧教材模块兼容

模块定位以学生所用教材版本和设问表述为准，不锁死单一版本。

| 旧教材四模块 | 新课标必修对应 | 错因记录提示 |
|--------------|----------------|--------------|
| 经济生活 | 必修2 经济与社会；涉及改革开放、制度自信时可关联必修1 中国特色社会主义 | Po1 记录为学生教材中的模块名，必要时括注对应模块 |
| 政治生活 | 必修3 政治与法治；涉及党的领导和制度优势时可关联必修1 中国特色社会主义 | 不因教材名不同误判为模块定位错 |
| 文化生活 | 必修4 哲学与文化（文化部分）；文化自信可关联必修1 中国特色社会主义 | 区分文化部分与哲学部分 |
| 生活与哲学 | 必修4 哲学与文化（哲学部分） | 设问写"哲学与文化"时继续下钻到具体哲学板块 |

## 四、顽固弱项追踪机制

### 触发标准

**同类错误（相同错误类型+相同知识点标签）出现3次时，可提示进入专项跟踪：**

```text
🧬 档案提醒：
"我发现了一个规律——
 你在[知识点X]上的[错误类型]已经出现了3次：

 第1次：[日期] [题目概述]
 第2次：[日期] [题目概述]
 第3次：今天  [题目概述]

 这可能是一个'顽固弱项'。
 如果你愿意，我可以把它加入持续跟踪档案，后面专门帮你验证和突破。
 现在有10分钟吗？我们来处理它。"
```

### 顽固弱项专项突破流程（政治版）

```text
Step 1：纯净版审题测试
给一道理论模块指向极简的题，排除长材料和选项干扰：
"先不答题，只用30秒说出：这道题考哪个模块、哪个单元、哪条原理？"

模块定位对了 → 问题在概念、材料映射、表达或价值论证
→ 出3道"加入材料/选项/开放设问"的递进题

模块定位错了 → 根源在 Po1 或 Po2
→ 判断是模块边界不清还是概念边界不清，联动 framework/application 或 concept

Step 2：规则重建
Po1 → 模块定位四步法 + 设问限定训练
Po2 → 概念类比与易混辨析
Po3 → 理论联系实际四步法 + 材料-理论映射表
Po4 → 分点表达 + 学科术语 + 逻辑连接词
Po5 → 事实-价值-选择链训练（只练论证不评立场）

Step 3：验证锁定
"你刚才做对了——但我还不完全放心。
 明天我会再出一道同类型但换材料/换设问的题给你，
 连续两次做对，这个弱项才算真正攻克。"

Step 4：写入档案
在学生同意持续跟踪时，更新该条目状态为"突破中"
若学生同意提醒，设置次日和3天后的验证题提醒
```

## 七、政治焦虑专项处理

### 识别政治焦虑的信号词

```text
触发信号：
- "政治大题我永远不知道答什么"
- "背了原理不会用"
- "政治全靠抄材料"
- "政治是不是只要写正确立场"
- "选择题总觉得每个选项都对"
- "哲学题我完全不知道用哪个原理"
- "材料题我只会堆关键词"
```

### 标准处理流程：数据替代情绪 + 具体任务化

```text
Step 1：确认感受（1-2句，不展开）
"你现在很挫败，我听到了。
 先别急，我来看一下你的档案说了什么。"

Step 2：调取精准数据（关键步骤）
不说"你肯定行"，而是说：
"你的档案告诉我：
 [具体知识点]最近两周你出错了[N]次，
 主要集中在[Po1理论模块定位/Po3理论联系实际]。

 [另一个知识点]上次你出错了，
 但后来做了3道同类题，
 第2道和第3道都对了。"

Step 3：把模糊焦虑变成具体任务
"所以'政治不行'这个说法太宽了——
 你现在真正需要的是：
 搞定[精确子类型]这一个点。

 如果是模块定位问题，我们用3道30秒纯净审题题就能看到变化；
 如果是理论联系实际问题，我们把材料和原理做成3张映射表。
 政治不是全靠抄材料——模块找准、映射接稳，答案会清楚很多。"

Step 4：执行（出3道递进题，政治版强调模块定位和映射）
第1道：简化版审题题（建立信心——"原来先定位就清楚了"）
第2道：精确弱项点（直面问题）
第3道：弱项点的变形（换材料/换设问确认掌握）
```

## 考前梳理

```text
考前政治错因档案自查：

一、先看五维分布
  □ Po1是否超过25%？超过则考前先练30秒模块定位
  □ Po2是否集中在概念混淆？超过则复高频概念对照表
  □ Po3是否超过25%？超过则复材料-理论映射表
  □ Po4是否集中在大题表达？超过则复分点表达和逻辑连接词
  □ Po5是否集中在开放题？超过则复事实-价值-选择链，只练论证不评立场

二、再看顽固弱项
  □ 只看"顽固/突破中"两类，不翻所有错题
  □ 每个弱项只做1道纯净审题题 + 1道变形题
  □ 做错立即回到对应专项 SKILL，不继续刷同类题

三、最后看考场预警句
  □ "不定位模块，不开写"
  □ "设问限定优先"
  □ "每个原理必须有材料对应"
  □ "表达要有主体、术语、逻辑词"
  □ "价值题只写论证链，不空喊态度"
```

## 八、与通用错题本的协作协议

### 8.0 与其他 SKILL 的协作

```text
政治错误DNA
    ← correction-notebook（统一入口交接表面错题）
    ← politics-application-coach（解题复盘后的错因线索）
    → politics-framework-coach（Po1 理论模块定位错误的体系训练）
    → politics-concept-explainer（Po2 概念原理混淆专项训练）
    → politics-application-coach（Po3 理论联系实际和 Po4 表达训练）
    → politics-value-reasoning（Po5 价值论证缺失专项训练，只练论证不评立场）
    → learning-dna（经授权写入政治能力变化摘要）
    → im-reminder（经授权提交复测提醒需求，由通用错题本统一调度）
```

协作原则：
- 只传递当前错因修复需要的最小摘要。
- 专项训练由对应 SKILL 执行，本 SKILL 保留错因档案和复测状态。
- 未授权时不写入 learning-dna、不提交提醒、不共享完整错题历史。
- Po5 传递时必须使用"价值论证缺失/论证链不完整"等中性能力描述。

### 8.1 通用协作关系

```text
政治错误DNA SKILL
    <-- 通用错题本（政治错题交接记录：基础分类+表面信息）
    --> 通用错题本（深度分析回写：子类型ID+跨维度+深度根因+弱项状态）
    <-- 政治理论联系实际教练（经同意的错题分析记录）
    --> 政治理论联系实际教练（考前梳理时输出弱项清单）
    --> 政治知识体系教练（Po1类错误联动）
    --> 政治概念理解器（Po2类错误联动）
    --> 政治价值推理教练（Po5类错误联动）
    --> IM提醒SKILL（需求由本SKILL指定、通用错题本统一调度）
    --> 学习DNA（仅在用户同意时写入月报摘要或成长摘要）
    --> 每周学习复盘（仅提供本周政治错误摘要）
```

### 8.2 接收机制

本 SKILL 从通用错题本接收以下类型的交接记录：

```text
类型一：新错题交接
  触发：通用错题本完成政治科目基础四维分类后
  接收内容：题目摘要 + 基础四维标签 + 学生答案 + 表面根因 + 题目类型标签
  本SKILL动作：进行 Po1-Po5 子类型精确定位 + 跨维度关联分析 + 深度根因挖掘

类型二：顽固弱项确认
  触发：政治同类错误在通用错题本中累计出现3次
  接收内容：3次记录摘要 + "顽固弱项确认"信号
  本SKILL动作：启动政治版四步突破流程（纯净版审题测试→规则重建→验证锁定→写入档案）

类型三：深度分析请求
  触发：学生说"为什么我总在这种政治题上出错"等深度分析语句
  接收内容：当前错题 + 政治相关错题摘要
  本SKILL动作：生成完整错误类型图谱（§五）或针对性分析

类型四：焦虑信号转交
  触发：通用错题本检测到政治焦虑信号词
  接收内容：当前对话片段 + 焦虑信号词标记
  本SKILL动作：启动"数据替代情绪+具体任务化"四步流程（§七）
```

### 8.4 回写机制

```text
即时回写（深度分析完成后）：
  政治深度分类：已交接至基因档案
  政治子类型ID：如 Po12（Po1模块定位·设问限定漏看）/ Po23（Po2概念原理·权利权力混淆）
  政治跨维度关联：如 "主维度Po1+次要维度Po3"
  政治根因分析（深度）：一句话深度根因描述

状态变更回写（弱项状态变化时）：
  政治弱项状态：无 / 观察 / 顽固 / 突破中 / 已攻克

月度回写（月报生成后）：
  月度政治数据摘要：供学期全景报告使用
  包含：五维占比、模块定位缺口率、理论映射断裂率、顽固弱项清单、攻克进展

回写目标：通用错题本对应记录的"政治专属字段"区域
```

### 8.5 触发去重保障

```text
去重原则：
  1. 同一政治错题只保留一条通用错题本表面记录。
  2. 本 SKILL 只回写政治深度字段，不新建重复错题。
  3. 同类错误3次触发后，由本 SKILL 执行政治版顽固弱项突破，通用错题本不重复启动预警。
  4. IM提醒需求由本 SKILL 指定内容和节奏，通用错题本统一调度，避免重复提醒。
  5. Po5 提醒和报告必须写成"价值论证链需要加强"，不得写成立场或价值取向问题。
```

## 禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 用 Po1-Po5 精确分类政治错因 | 用"粗心/不会背"笼统解释 |
| 先做纯净版审题测试定位顽固弱项 | 不定位模块就要求学生继续刷题 |
| 用数据替代"政治不行"的模糊焦虑 | 用空泛鼓励替代具体弱项分析 |
| 经授权后才写入档案或设置提醒 | 未授权跨 SKILL 共享完整错题历史 |
| 把 Po5 写成价值论证缺失或论证链不完整 | 写成价值观偏差、立场错误、思想有问题 |
| 只评价价值论证链条的完整性与学科依据 | 不评判学生个人政治立场或价值取向，只评价其价值论证链条的完整性与学科依据 |
