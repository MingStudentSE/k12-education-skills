# IM提醒授权、控制与队列策略

> 本文件汇总提醒前置条件、触发时机、授权模式、提醒形式、数据边界、数量管理和禁止行为；完整运行说明见 `references/reminder-operating-manual.md`。

## 1. 启用前置条件

1. 学生本人或监护人明确同意接收提醒。
2. 明确提醒类型、频率、大致时间段、提醒渠道，以及本次任务需要的最小数据。
3. 提供随时可用的控制入口：查看提醒、暂停、恢复、取消、调整频率、撤回数据传递授权。
4. 未获同意时，只给“建议提醒方案”，不创建实际提醒。

## 2. 提醒类型

| 类型 | 目的 | 例子 |
|---|---|---|
| 复习提醒 | 把遗忘曲线变成复习曲线 | Day 1/3/7/14/30 复测 |
| 行动提醒 | 让计划落地 | 晚上 8 点完成英语听力 |
| 回访确认提醒 | 检查执行和理解状态 | 询问复测结果、任务完成情况 |
| 探索成长提醒 | 回访长期兴趣任务 | 项目截止前检查进展 |

## 3. 控制口令

```text
查看我的提醒
暂停提醒
恢复提醒
取消这条提醒
今天不要提醒
不要把结果交给其他模块
调整提醒频率
```

## 4. 完成反馈处理

| 学生回应 | 处理 |
|---|---|
| 已完成且掌握 | 推进到下一间隔 |
| 已完成但不确定 | 保持原间隔或安排短复测 |
| 未完成 | 询问原因，必要时拆小或延后 |
| 太多/压力大 | 降频、暂停或只保留最高优先级 |
| 无回应 | 至多一次温柔补发，不连环轰炸 |

## 5. 数量与免打扰

```text
普通日：最多 3 条
考前冲刺：最多 5 条
夜间免打扰：22:00-8:00 默认不发
优先顺序：考前关键提醒 > 固定错误模式提醒 > 计划任务提醒 > 探索提醒 > 常规复习提醒 > 每日确认提醒
```

## 6. 最小数据边界

提醒 interface 只接收用户当前提供的数据。若用户明确要求把某次结果交给另一 Product Module，逐次确认目的、接收方和以下最小字段；不得从 Learning profile 继承长期共享开关：

- 用户当前输入：明确给出的可用时段和优先级。
- 错题本：相关知识点、复测时间建议。
- 学习计划：任务名称、建议时间段。
- 时间与专注力教练：确认提醒建议、建议时段。
- 阶段复盘：仅输出完成率、响应率或本次执行摘要。

禁止读取整份 Learning profile；禁止在用户不知情时把提醒结果写入其他 module；禁止为方便组合而默认开启长期传递。

## 7. 今日队列格式

```text
📋 今日队列
🔴 高优先级：固定错误模式复测 / 今天必须完成的计划任务
🟡 今日到期：某知识点 Day 3 复习 / 某探索任务回访
🟢 本周内：某知识点 Day 14 复习 / 每日时间确认
```
