# 间隔复习与提醒节奏

> 此文档为 IM 提醒提供可调整的起始节奏。真正决定下次间隔的是学生的主动提取表现，而不是一张固定“记忆保留率”表。

---

## 证据边界

艾宾浩斯的经典研究主要来自研究者本人对无意义音节的学习与再学习实验。它说明遗忘会随时间发生、间隔后的主动提取有价值，但不能推出所有学生、所有学科在固定时间点都具有相同的精确保留率。

因此本方法只采用三个机制：

1. **分散复习**：把复测分布到多个时间点，而不是一次刷完。
2. **主动提取**：先让学生回忆、解释或应用，再看答案。
3. **表现自适应**：根据“答得是否正确、是否需要提示、能否迁移”调整下次间隔。

---

## 提醒间隔动态调整规则

### 默认起始序列
```
Day 0 (学习当天)
Day 1 → Day 3 → Day 7 → Day 14 → Day 30
```

这只是没有个体证据时的计划模板，不代表精确遗忘节点。用户已有复测记录时，优先依据真实表现调整。

### 动态调整规则

**独立答对且能解释/迁移 → 延长间隔**
```
下一次比原计划更晚；具体日期由可用时间和任务重要性共同决定。
```

**答对但不确定、靠提示或只会原题 → 保持或小幅缩短**
```
保留原定复测窗口，并在下一次换一种表述或题型。
```

**答错或无法提取 → 缩短间隔并先修正**
```
先完成错误—修正—再试，再安排较近的变式复测；不要机械重置所有内容。
```

**未回应 → 一次温和确认，随后暂停自动加压**
```
不把沉默解释为遗忘或懒惰；询问保留、改期、降频还是取消。
```

## 证据来源

- Ebbinghaus, H. (1885/1913), [Memory: A Contribution to Experimental Psychology](https://psychclassics.yorku.ca/Ebbinghaus/index.htm)：原始研究使用研究者本人和无意义音节，不能直接外推成所有学习者的统一百分比。
- Cepeda, Pashler, Vul, Wixted & Rohrer (2006), [Distributed practice in verbal recall tasks: A review and quantitative synthesis](https://doi.org/10.1037/0033-2909.132.3.354)：支持分散练习，但最佳间隔随目标保持期和任务而变化。
- Roediger & Karpicke (2006), [Test-enhanced learning: Taking memory tests improves long-term retention](https://doi.org/10.1111/j.1467-9280.2006.01693.x)：支持用主动提取而非重复阅读检验学习。

## 不同类型内容的提醒策略

### 理解类内容（概念、公式推导、解题思路）
- 重点检验：能否用自己的话解释
- 提醒形式：开放性问答
- 间隔：标准序列

### 记忆类内容（单词、古诗、公式、年代）
- 重点检验：能否准确回忆
- 提醒形式：填空/默写题
- 间隔：标准序列 + 额外高频提醒（前3天每天1次）

### 应用类内容（解题方法、分析框架）
- 重点检验：能否在新题目中正确应用
- 提醒形式：出一道变形练习题
- 间隔：标准序列，但每次提醒必须附题目

### 错题类内容（来自当前错题证据）
- 重点检验：同类题是否不再犯同样错误
- 提醒形式：针对性练习题（难度略高于原错题）
- 间隔：强化序列（Day 1 → 2 → 5 → 10 → 21）

## 考前复习倒计时参数

| 剩余天数 | 复习重点 | 提醒频率 | 情绪基调 |
|---------|---------|---------|---------|
| 14天+ | 薄弱点专项突破 | 每天1-2条 | 从容，有计划感 |
| 7-14天 | 系统梳理+错题集 | 每天2-3条 | 专注，不焦虑 |
| 3-7天 | 重点知识点快速过 | 每天3-4条 | 紧张但有序 |
| 1-3天 | 轻度提醒+信心建立 | 每天1-2条 | 平静，相信积累 |
| 考试当天 | 速览关键词+加油 | 1条（早上） | 温暖，正向激励 |

## 提醒时间优化

根据用户本次明确给出的可用时段选择提醒时间；不得读取 Learning profile 推断调度时间：

| 学生类型 | 建议提醒时间 |
|---------|------------|
| 放学后学习型 | 16:30-17:30 / 19:00-20:00 |
| 夜间学习型 | 20:00-21:00 |
| 早起学习型 | 7:00-7:30 |
| 午休利用型 | 12:00-12:30 |

**原则：** 在学生精力充沛、即将可以学习的时间点提醒，  
而不是在学生正在吃饭/睡觉/上课时提醒。
