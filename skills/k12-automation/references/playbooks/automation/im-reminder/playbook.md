# ⏰ IM智能提醒 SKILL

> 一句话定位：在学生或监护人明确授权后，把复习、行动和回访按合适节奏提醒出来。

## 技术实现边界声明

- LLM 本身不具备自主计时或主动唤醒能力；实际调度依赖宿主平台的定时任务机制与自动化工作流引擎。
- 可由 QClaw 等定制化 OpenClaw 平台实现；消息推送应泛化到已接入的 IM 渠道，不绑定单一软件。
- 未获授权时，不创建定时提醒、不做闲置唤醒、不跨渠道推送。

## 触发边界

- 触发：用户明确要求设置复习提醒、间隔复测、任务执行提醒、探索任务回访，或明确同意接收某类提醒。
- 不触发：只是问题、要讲解、要计划但未同意提醒；此时只给建议方案或转交更合适的 SKILL。
- 最小输入：提醒内容、目标时间/频率、提醒渠道、是否授权；信息不足时先给补充模板。
- 任何长期记录、跨 SKILL 共享或回写，都必须先说明路径、字段和理由，并获得明确同意。

## 流程骨架

1. **判断授权**：确认学生或监护人是否同意开启提醒；未同意时只输出建议方案。
2. **明确提醒对象**：区分复习提醒、行动提醒、回访确认提醒或探索成长提醒。
3. **设定节奏**：复习类参考 Day 1/3/7/14/30 与错题强化序列；行动类按计划节点；考前按剩余天数降噪。
4. **确认渠道与控制口令**：告知查看、暂停、恢复、取消、调整频率、关闭共享的方法。
5. **执行与反馈**：根据完成、未完成、答错、无回应等结果调整下一次提醒；无回应只温柔补发一次。
6. **队列化呈现**：当用户问“今天有什么”时，用高优先级/今日到期/本周内输出统一队列。

## 授权与控制规则

- 启用前必须明确提醒类型、频率、大致时间段、渠道和共享范围。
- 用户可随时说“暂停提醒”“取消这条提醒”“今天不要提醒”“不要共享给其他SKILL”。
- 默认夜间免打扰：22:00-8:00 不发；如需例外必须单独授权。
- 普通日最多 3 条，考前冲刺最多 5 条；压力过高时降频或只保留最高优先级。
- 使用学习DNA活跃时段只能基于已授权摘要，不读取或传输整份档案。

## 提醒策略

- 理解类：用自己的话解释；按标准间隔复测。
- 记忆类：填空/默写；前 3 天可更密集，但必须受数量上限约束。
- 应用类：附一道变形练习；检查能否迁移。
- 错题类：针对同类错误复测；可用 Day 1/2/5/10/21 强化序列。
- 行动类：提醒具体可执行动作，而不是空泛目标。
- 回访类：记录完成率、响应率和必要调整建议；回写只传最小摘要。

## 失败红线

- 不在未授权时创建提醒、闲置唤醒或跨 IM 推送。
- 不把“几天没对话”当作默认唤醒理由；只有用户订阅的指定提醒才可发送。
- 不默认长期保留所有提醒；必须提供暂停、取消、调频入口。
- 不把提醒结果默认同步给所有 SKILL；仅按授权共享最小必要摘要。
- 不用提醒制造压力、羞辱或连环轰炸；允许跳过、延后、暂停。
- 不把 runtime 写死为某一平台或某一个 IM 软件。
