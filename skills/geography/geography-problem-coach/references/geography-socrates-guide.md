# 地理解题苏格拉底追问指南

> 本文档为 `geography-problem-coach` 的追问资源，定义读图层、原理层、评价层三层追问及学段适配。

---

## 一、追问总原则

```text
不先给答案，先让学生：
  1. 说图上证据
  2. 说要调用的原理
  3. 说证据和原理怎样连成结论
```

| 低效追问 | 有效追问 |
|----------|----------|
| "你会不会？" | "图例里哪个符号和设问有关？" |
| "还有什么原因？" | "这个因子怎样一步步导致结果？" |
| "答案是什么？" | "你能用证据+原理写出第一点吗？" |
| "这个措施对吗？" | "这个措施对应题中的哪个具体问题？" |

---

## 二、第一层：读图层

### 目标

确保学生先从图表和材料中提取证据，而不是凭记忆或熟词答题。

### 标准追问

```text
图名告诉你这张图研究什么？
图例中哪些符号、颜色或线型和设问有关？
比例尺/方向/经纬网说明这个区域是什么尺度和位置？
最大值、最小值、密集区、异常区在哪里？
统计图的横轴、纵轴、单位和时间范围是什么？
```

### 错误回退

| 学生回答 | 回退动作 |
|----------|----------|
| "我看不懂图" | 只读图名和图例，不讲原理 |
| "应该是某某气候" | 要求指出图上气温/降水证据 |
| "大概在南方" | 要求经纬、海陆或相对位置证据 |
| "趋势是增加" | 要求说起点、终点、转折和单位 |

---

## 三、第二层：原理层

### 目标

把图上证据连接到地理概念、过程机制、区域框架或计算公式。

### 标准追问

```text
这道题要调用哪个地理原理？
这个现象属于自然过程、人文过程还是区域综合？
这个原理的适用条件是什么，题目是否满足？
如果是自然题，主要因子和机制链是什么？
如果是人文题，区位条件和结构关系是什么？
如果是计算题，公式和单位是什么？
```

### 原理匹配表

| 图上/题干信号 | 追问方向 | 可能联动 |
|---------------|----------|----------|
| 箭头、环节、循环 | "这是哪个过程？每个箭头代表什么？" | process-explainer |
| 区域图、资源、产业、交通 | "位置和要素如何关联？" | region-analyzer |
| 等值线、统计图 | "数值和趋势如何支撑判断？" | map-coach |
| 时区、比例尺、太阳高度 | "公式、单位和条件是什么？" | natural-calculation |

---

## 四、第三层：评价层

### 目标

检查推理链完整性、措施对应性、迁移能力和价值维度表达边界。

### 标准追问

```text
你的结论是否每一点都有图上证据？
因果链中有没有跳过关键步骤？
措施是否对应题目中的具体问题？
如果换一个区域/季节/图型，这个结论是否还成立？
这里评价的是地理论证链，还是在评价个人立场？
```

### 措施题对应表

| 问题 | 不合格措施 | 合格措施 |
|------|------------|----------|
| 水资源短缺 | "加强管理" | "发展节水灌溉、调整高耗水作物、提高水资源循环利用率" |
| 水土流失 | "保护环境" | "退耕还林还草、坡面工程、沟道治理、控制过度开垦" |
| 城市内涝 | "改善城市建设" | "增加透水铺装、建设雨水花园、保留湿地和排水通道" |
| 资源型城市衰退 | "发展经济" | "延长产业链、发展替代产业、治理矿区生态、提高技术水平" |

## 五、题型追问脚本

### 选择题

```text
1. 设问让你选"正确"还是"不正确"？
2. 题干限定的区域、时间、图型是什么？
3. 每个选项能否在图上找到证据？
4. 哪个选项和区域条件或地理原理冲突？
5. 回代最佳选项，是否最符合题干限定？
```

### 描述题

```text
1. 描述对象是什么：位置、分布、变化还是特征？
2. 最大值/最小值/方向/范围在哪里？
3. 能不能用"由A向B递增/递减"表达？
4. 有没有异常点需要单独说明？
```

### 成因题

```text
1. 这是自然成因还是人文成因？
2. 每个因子怎样起作用？
3. 主因和辅因分别是什么？
4. 有没有区域条件限制？
```

### 评价题

```text
1. 评价对象是什么：区位、措施、开发方式还是影响？
2. 有利和不利条件分别有哪些证据？
3. 适用前提和限制是什么？
4. 最终结论是否有条件，而不是绝对判断？
```

## 六、各学段适配

| 学段 | 追问重点 | 降级/升级 |
|------|----------|------------|
| 初中 | 图上证据、基础概念、简单因果、规范句 | 一次只问一个问题，不要求完整多因子体系 |
| 高中 | 多图互证、机制链、区域综合、评价限制 | 增加反事实验证、主因辅因和学科术语 |

```text
初中示例：
  "图上哪里降水多？为什么迎风坡多雨？"

高中示例：
  "该地降水空间差异由哪些因子叠加形成？
   地形抬升和季风水汽输送分别如何作用？"
```
