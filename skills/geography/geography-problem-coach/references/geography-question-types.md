# 地理题型手册

> 本文档为 `geography-problem-coach` 的题型资源，定义选择题、综合题、区域题、过程题、评价措施题的判别和作答模板。

---

## 一、题型总览

| 题型 | 识别信号 | 核心动作 | 常见错因 |
|------|----------|----------|----------|
| 选择题 | 有选项，问正确/不正确/最符合 | 限定词+图证+排除 | 熟词诱导、绝对化、区域不符 |
| 描述题 | 描述分布/变化/特征 | 方向、数值、范围、异常 | 只写原因，不描述现象 |
| 成因题 | 分析原因/为什么/形成机制 | 因子+作用方式+结果 | 只列标签 |
| 区域题 | 区位条件/区域特征/比较 | 位置+要素+关联 | 清单式罗列 |
| 评价题 | 评价条件/影响/措施可行性 | 有利+不利+条件限制 | 只写好或坏 |
| 措施题 | 提出治理/发展建议 | 问题+措施+作用路径 | 措施空泛 |
| 计算题 | 时区、比例尺、太阳高度、密度 | 公式+单位+检验 | 单位和日期错 |

---

## 二、选择题

### 四步法

```text
1. 抓限定：正确/不正确/最符合/主要/直接/根本
2. 读图证：图名、图例、数值、位置
3. 排陷阱：图证不符、区域不符、因果不符、绝对化
4. 回代验：最佳选项能否解释题干全部信息
```

### 陷阱表

| 陷阱 | 表现 | 处理 |
|------|------|------|
| 熟词诱导 | 选项是熟悉知识点，但与题干无关 | 回到题干限定和图上证据 |
| 绝对化 | 一定、全部、唯一、彻底 | 地理规律通常有条件和区域差异 |
| 因果错位 | 把结果当原因或机制不成立 | 写出一条因果链检查 |
| 区域错配 | 把别的区域特征套来 | 先定位当前区域 |
| 数据误读 | 单位、比例、时间范围看错 | 重新读坐标轴和图例 |

## 三、描述题

### 描述对象

| 对象 | 答题要素 | 句式 |
|------|----------|------|
| 位置 | 经纬、海陆、相对位置 | "位于……，临近……，处于……" |
| 分布 | 疏密、方向、集聚、空白区 | "总体呈……，主要集中在……" |
| 变化 | 增减、波动、阶段、转折 | "先……后……，在……达到峰值" |
| 结构 | 主导项、占比、变化 | "以……为主，……占比上升" |
| 地形 | 高低、起伏、坡向、地势 | "地势由……向……倾斜" |

### 描述题禁忌

```text
题问"描述"时，先描述图上现象，不急着解释原因。
可在最后一句补"可能与……有关"，但不能用成因替代描述。
```

## 四、成因题

### 成因题标准结构

```text
自然成因：
  位置/纬度/海陆/地形/洋流/气候/水文 → 作用机制 → 现象

人文成因：
  资源/交通/市场/劳动力/技术/政策/历史基础 → 作用方式 → 结果

综合成因：
  自然基础 + 人文推动 + 区域限制 → 综合结果
```

### 成因题质量表

| 低质量 | 高质量 |
|--------|--------|
| "受地形影响" | "山地阻挡湿润气流，迎风坡抬升降水多，背风坡下沉少雨" |
| "交通便利" | "铁路和港口降低原料、产品运输成本，扩大市场联系" |
| "政策支持" | "政策提供土地、资金和产业引导，促进企业集聚" |
| "人口多" | "人口密集提供劳动力和消费市场，同时增加资源环境压力" |

## 五、区域题

### 区位条件题

| 类型 | 必答维度 | 表达方式 |
|------|----------|----------|
| 农业区位 | 气候、地形、土壤、水源、市场、交通、劳动力 | 分自然条件和社会经济条件 |
| 工业区位 | 原料、能源、交通、市场、劳动力、技术、政策、环境 | 结合工业类型判断主导因素 |
| 城市区位 | 地形、河流、交通、资源、政治、历史 | 说明形成和发展条件 |
| 交通区位 | 地形、城市、资源、经济联系、技术、生态 | 说明建设有利条件和限制 |

### 区域比较题

```text
比较流程：
  1. 明确比较对象和尺度
  2. 选定比较维度
  3. 分别写 A、B 表现
  4. 写差异原因
  5. 写对发展的影响
```

## 六、评价题

### 评价框架

```text
评价 = 有利条件 + 不利条件 + 适用前提 + 有条件结论
```

| 评价对象 | 有利角度 | 不利角度 | 结论要求 |
|----------|----------|----------|----------|
| 工程建设 | 资源、交通、防灾、经济收益 | 生态、移民、投资、地质风险 | 说明适宜条件和限制 |
| 产业发展 | 原料、市场、劳动力、技术 | 环境、资源约束、竞争 | 不写绝对好坏 |
| 区域开发 | 就业、基础设施、财政 | 生态破坏、资源枯竭 | 措施对应问题 |
| 人口迁移 | 劳动力、收入、城市活力 | 留守、拥堵、住房、公共服务 | 双向影响 |

### 价值维度红线

评价题只评价地理论证链条：证据是否充分、条件是否清楚、影响是否平衡。不得评判学生个人立场或价值取向。

## 七、措施题

### 措施对应表

| 问题 | 成因 | 对应措施 |
|------|------|----------|
| 水资源短缺 | 降水少、用水量大、污染、浪费 | 节水农业、循环利用、跨流域调水、治污 |
| 土地荒漠化 | 过度放牧、过度开垦、水资源不合理利用 | 退耕还草、控制载畜量、节水灌溉 |
| 水土流失 | 坡地开垦、植被破坏、暴雨集中 | 植树种草、梯田、坡面工程、沟道治理 |
| 城市内涝 | 地面硬化、排水不足、强降水 | 海绵城市、透水铺装、湿地保留 |
| 产业衰退 | 资源枯竭、产业单一、污染严重 | 产业转型、技术升级、环境治理 |

### 措施题公式

```text
针对[具体问题]，采取[具体措施]，
通过[作用机制]，达到[地理效果]。
```

## 八、错题复盘题

```text
复盘顺序：
  1. 这题图上证据读对了吗？若否 → G1
  2. 概念和原理选对了吗？若否 → G2
  3. 过程机制链完整吗？若否 → G3
  4. 区域要素关联完整吗？若否 → G4
  5. 计算、单位、术语、表达规范吗？若否 → G5
```

错题复盘不直接贴"粗心"标签，必须定位到可训练的步骤。
