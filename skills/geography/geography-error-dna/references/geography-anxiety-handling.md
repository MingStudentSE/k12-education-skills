# 地理焦虑处理手册

> 本文档为 `geography-error-dna` 的焦虑处理参考资源，定义地理焦虑信号词、数据替代情绪流程和递进任务模板。

---

## 一、触发信号词

```text
读图焦虑：
  "地理图我从来读不懂"
  "看到等值线我就慌"
  "经纬网我永远看反"
  "图表题完全没思路"

自然地理焦虑：
  "自然地理太难"
  "大气环流洋流我背不住"
  "热力环流方向总是反"
  "太阳高度我不会算"

综合题焦虑：
  "大题不知道答什么"
  "区域题我只会乱写"
  "措施题我只会写保护环境"
  "地理全靠背"

自我标签：
  "我没有空间想象力"
  "我地理就是不行"
  "我一看到地图脑子就空白"
```

## 二、处理原则

| 原则 | 应该做 | 不应该做 |
|------|--------|----------|
| 承认感受 | 用1-2句确认挫败感 | 长篇安慰或讲大道理 |
| 数据替代情绪 | 用错因分布、进步记录和具体子类型说话 | 说"你肯定行"但无证据 |
| 任务具体化 | 把"地理不行"缩小成一个训练点 | 同时布置很多任务 |
| 小步验证 | 用1道纯净图题建立可控感 | 直接上高难综合题 |
| 授权边界 | 写入档案和提醒前请求同意 | 未授权长期记录 |

## 三、标准四步流程

### Step 1：确认感受

```text
"你现在很挫败，我听到了。
 先别急，我们不用先评价你地理好不好，
 先看这次到底卡在哪一步。"
```

### Step 2：调取或构造当前数据

有长期档案时：

```text
"档案显示，最近两周你在地理上出错[N]次：
  G1读图定位[X]次，G3过程推理[Y]次。
  所以现在最该处理的不是'地理不行'，
  而是[具体子类型]。"
```

无长期档案时：

```text
"我们还没有长期数据，所以这次只看当前题。
  我会用一个30秒纯净读图测试判断：
  是图没读稳，还是原理/机制没接上。"
```

### Step 3：模糊焦虑具体任务化

| 焦虑句 | 转化任务 |
|--------|----------|
| "地图看不懂" | 30秒读图：图名、图例、位置、关键信息 |
| "自然地理太难" | 只写一条因子→机制→结果链 |
| "大题不知道答什么" | 先判断设问动词，再写证据+原理+结论 |
| "区域题乱写" | 只连一条自然→人文要素链 |
| "计算永远错" | 只检查公式、单位、日期三个点 |

### Step 4：三题递进执行

```text
第1题：纯净版
  只考一个点，排除复杂材料和选项干扰。

第2题：原题弱项版
  保留原题的核心错误点，让学生修正。

第3题：变式迁移版
  换图型、换区域或换设问，确认不是只会原题。
```

## 四、纯净版读图测试

### 测试格式

```text
给学生一张极简图或口述简图：

请在30秒内回答：
  1. 图名/主题是什么？
  2. 图例或符号代表什么？
  3. 这是哪里，位置线索是什么？
  4. 图上最关键的一条信息是什么？
```

### 判读结果

| 结果 | 判断 | 下一步 |
|------|------|--------|
| 四问基本正确 | 读图地基可用 | 查 G2/G3/G4/G5 |
| 图名图例漏读 | G11 倾向 | 三要素训练 |
| 位置判错 | G12/G15 倾向 | 经纬网/相对位置训练 |
| 等值线或趋势读反 | G13/G14 倾向 | 等值线/统计图专项 |
| 读图对但解释错 | 非 G1 主因 | 转概念、过程或区域分析 |

## 五、焦虑话术库

### 读图焦虑

```text
"我们先不处理整道大题。
 只做30秒读图：图名、图例、位置、一个关键信息。
 如果这四个能读出来，后面就不是'图看不懂'，而是原理怎么接的问题。"
```

### 自然地理焦虑

```text
"自然地理不是把一串成因全背下来。
 我们这次只写一条链：
 [因子]怎样导致[过程]，最后形成[结果]。
 一条链走通，再加第二条。"
```

### 综合题焦虑

```text
"大题不是一上来写满。
 先拆设问：它让你描述、分析、评价，还是提措施？
 每一点都按'证据+原理+结论'写，先写第一点。"
```

### 计算焦虑

```text
"计算题先不急着算。
 只做三件事：判断类型、写公式、统一单位。
 这三步对了，再代入。"
```

## 六、家长沟通摘要模板

仅在用户明确请求并同意分享时使用。

```text
本月地理学习不是简单的"会/不会"问题。
数据上看，孩子主要卡在[具体维度]：
  [G1/G3/G4等]出现[N]次，集中在[具体子类型]。

已经采取的训练：
  [读图四步法/过程机制链/区域要素关联/计算自检]

建议下阶段：
  每次只练一个小目标，
  例如每天1张极简图或1条机制链，
  避免一次性刷大量综合题造成挫败。
```

## 七、禁止话术

| 禁止话术 | 替代话术 |
|----------|----------|
| "你就是空间感差" | "这次是经纬网/图例/等值线哪一步断了" |
| "地理靠背，多背就行" | "先读图证据，再把原理接上" |
| "这个很简单" | "我们把它拆成一个可完成的小步骤" |
| "你不要紧张" | "先用数据看具体卡点" |
| "你态度不对" | "这里只评价地理论证链条和证据，不评价个人立场" |
