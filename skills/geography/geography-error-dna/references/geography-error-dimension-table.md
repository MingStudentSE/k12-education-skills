# 地理错因维度表

> 本文档为 `geography-error-dna` 的核心参考资源，定义地理学科包的五维错因维度体系、子类型分类、跨维度关联规则与追踪标准。

---

## 一、维度总览

```text
地理错因维度体系（G1-G5×多子类型）

G1 读图与空间定位错误 ── 地理独有的地基错误
  图名、图例、比例尺、经纬网、等值线、统计图和空间关系读错

G2 地理概念/原理错误 ── 理解层错误
  地理概念边界不清、原理适用条件错、相似概念混用

G3 地理过程推理错误 ── 机制层错误
  因子遗漏、机制方向反、多因子叠加和反事实迁移失败

G4 区域综合分析错误 ── 综合层错误
  要素提取不全、要素关联断裂、尺度错配和比较维度缺失

G5 地理计算与表达错误 ── 工具和输出层错误
  时区、比例尺、太阳高度、相对高度等计算错误，或术语和答题结构不规范

每道错题必须归入且只归入一个主维度。
如存在跨维度因素，记录为"主维度+次要维度"。

优先处理顺序：G1(图和位置) > G3(过程) > G4(区域) > G2(概念) > G5(计算表达)
→ 图和位置是一切地理分析的起点，读图错会导致后续全错。
```

---

## 二、G1：读图与空间定位错误

**定义：** 不会将题面、文字和图表信息转化为空间证据，导致区域位置、图表信息、分布趋势或等值线判断错误。

**判断标准：** 学生拿到地理题后跳过图名图例、经纬网、比例尺、等值距或统计图单位，指出读图问题后能修正后续分析，则 G1 为主。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| G11 | 地图三要素漏读 | 不看图名、图例、比例尺/方向 | 图表题/区域题 | 30秒三要素读图 |
| G12 | 经纬网定位错误 | 东西经、南北纬、半球或范围判错 | 区域定位/时区题 | 经纬网三问 |
| G13 | 等值线误读 | 等高线、等温线、等压线弯曲闭合读反 | 自然地理图题 | 等值线五原则 |
| G14 | 统计图趋势误读 | 轴名、单位、峰谷、转折读错 | 人口/产业/气候图 | 统计图四读 |
| G15 | 空间关系错乱 | 海陆、上下游、迎背风坡、相对位置混乱 | 区域综合题 | 相对位置定位 |
| G16 | 多图互证失败 | 多张图分别能读，但不能综合 | 高中综合题 | 多图证据表 |

### 根治方法映射

```text
G11 → 图名/图例/比例尺三要素口头化训练
G12 → 先纬后经、先半球后范围、东西半球分界专项
G13 → 同线等值、疏密、走向、弯曲、闭合五原则
G14 → 读轴、读点、读线、读义四步
G15 → 参照物明确化：相对谁、哪个方向、上下游/迎背风如何判
G16 → 每张图先独立读，再找共同结论和矛盾点
```

## 三、G2：地理概念/原理错误

**定义：** 地理概念、原理或适用条件理解错误，导致判断和表达失准。

**判断标准：** 学生图能读对，但对概念边界、原理条件或相邻概念的区别说不清。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| G21 | 天气/气候混淆 | 把短时天气当长期气候特征 | 气候题 | 概念时间尺度对照 |
| G22 | 水资源/水能资源混淆 | 有水不等于水能丰富 | 流域题 | 资源条件对照 |
| G23 | 人口流动/人口迁移混淆 | 通勤、旅游和迁居混用 | 人口题 | 时间和居住地变化判断 |
| G24 | 寒流/暖流影响混淆 | 寒暖性质、增温增湿/降温减湿搞反 | 洋流题 | 洋流性质-影响表 |
| G25 | 地形/地势/地貌混淆 | 把海拔高低、起伏方向和形态混用 | 地形图题 | 三概念边界表 |
| G26 | 城市化概念误用 | 把城市人口增长等同城市化水平 | 城市题 | 城市化指标对照 |
| G27 | 区位因素主导性误判 | 不区分资源型、市场型、技术型 | 区位题 | 主导因素判断 |

### 根治方法映射

```text
G21 → "时间尺度"追问：今天/本周是天气，多年平均是气候
G22 → 水量、水位落差、开发条件分开判断
G23 → 是否跨越行政边界并改变常住地
G24 → 洋流性质→沿岸气候→渔场/海雾影响链
G25 → 地形类型、地势方向、地貌成因三栏表
G26 → 城市化水平=城市人口占总人口比重，速度=变化快慢
G27 → 先判产业类型，再找主导区位因素
```

## 四、G3：地理过程推理错误

**定义：** 不能用因子和机制解释地理过程，包括自然过程和人文过程的因子遗漏、方向反、叠加关系错。

**判断标准：** 学生能说出结论或因子标签，但说不清作用方式；换区域、季节或条件后推理失败。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| G31 | 过程识别错误 | 水循环、热力环流、洋流、城市化过程混判 | 示意图题 | 过程类型判别树 |
| G32 | 因子遗漏 | 只写一个因素，漏地形、海陆、洋流或人类活动 | 成因题 | 因子分解表 |
| G33 | 机制方向反 | 热力环流、风向、洋流方向、河流补给关系反 | 自然图题 | 方向检查 |
| G34 | 多因子叠加错误 | 主因辅因不分，因子作用互相矛盾 | 高中综合题 | 主因+辅因链 |
| G35 | 反事实迁移失败 | 换半球、季节、坡向或区域后仍套原结论 | 迁移题 | 换条件验证 |
| G36 | 人文过程链断裂 | 城市化、人口迁移、产业转移只列原因不写过程 | 人文综合题 | 推拉阻力/产业链 |

### 根治方法映射

```text
G31 → 先看箭头和环节，判断过程类型
G32 → 驱动因子、限制因子、调节因子三栏拆分
G33 → 先判冷热/高低压/坡向/流向，再画箭头
G34 → 主因、辅因、局部因素排序
G35 → 换区域、换季节、换半球、换人类活动强度验证
G36 → 人文过程写成"条件→行为→空间变化→影响"
```

## 五、G4：区域综合分析错误

**定义：** 不能把区域自然要素和人文要素联系起来，或比较时尺度、维度、证据不一致。

**判断标准：** 学生能列出要素，但要素之间没有因果、制约或反馈关系；比较题没有统一维度。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| G41 | 要素提取不全 | 只写自然或只写人文 | 区域综合题 | 自然/人文要素表 |
| G42 | 要素关联遗漏 | 地形、气候、产业等清单式罗列 | 区域分析题 | 要素关联矩阵 |
| G43 | 区域特征概括偏差 | 抓局部当整体，或特征过泛 | 描述/概括题 | 总体-局部区分 |
| G44 | 比较维度缺失 | A说气候，B说交通，无法比较 | 比较题 | 比较矩阵 |
| G45 | 跨尺度硬比 | 国家、城市、流域、局部地貌混在一起比 | 综合题 | 尺度前置检查 |
| G46 | 人地协调论证空泛 | 只写保护环境，不写具体活动和过程 | 措施评价题 | 人地协调四问 |

### 根治方法映射

```text
G41 → 位置、地形、气候、水文、资源、人口、城市、产业、交通逐项检查
G42 → 每两个要素至少连一条"因为/导致/促进/限制"链
G43 → 先写总体规律，再写局部异常
G44 → 统一比较维度：位置/地形/气候/资源/产业/交通
G45 → 先标尺度，再决定能否比较
G46 → 人类活动→自然过程变化→问题→对应措施
```

## 六、G5：地理计算与表达错误

**定义：** 地理计算、单位、术语、答题结构或措施对应出现错误。

**判断标准：** 读图、原理或区域分析大体正确，但在计算执行或答案表达中失分。

### 子类型分类

| 子类型ID | 名称 | 典型表现 | 高发题型 | 关联训练 |
|---------|------|----------|----------|----------|
| G51 | 时区/地方时计算错 | 东加西减反，日期跨越漏算 | 时区题 | 时区公式 |
| G52 | 比例尺/距离换算错 | cm、m、km混用 | 地图计算题 | 单位统一 |
| G53 | 太阳高度计算错 | 直射纬度南北号取错 | 高中自然题 | 正午太阳高度公式 |
| G54 | 等高线相对高度错 | 等高距、闭合区、陡崖范围错 | 地形图题 | 等高线计算 |
| G55 | 统计/人口密度计算错 | 万人、面积、占比换算错 | 人文统计题 | 单位和比例 |
| G56 | 术语与答题结构不规范 | 口语化、分点乱、措施不对应问题 | 综合题 | 规范表达模板 |

### 根治方法映射

```text
G51 → 目标时间=已知时间+(目标时区-已知时区)，跨24点调日期
G52 → 图上和实地距离先统一到同一单位
G53 → H=90°-|当地纬度-太阳直射纬度|，北正南负
G54 → 等高距、相邻线、闭合区高低先判断
G55 → 人口/面积，单位统一为人/km²
G56 → "证据+原理+结论"分点表达，措施一一对应问题
```

## 七、跨维度关联规则

```text
G12(经纬网定位错误) + G51(时区计算错)
  → 判断：给出正确经纬/时区后能否计算？
    能 → G1为主
    不能 → G5为主

G13(等值线误读) + G33(机制方向反)
  → 判断：等值线高低读对后，机制方向是否能修正？
    能 → G1为主
    不能 → G3为主

G21(概念混淆) + G32(因子遗漏)
  → 判断：概念边界讲清后，因子是否能列全？
    能 → G2为主
    不能 → G3为主

G42(要素关联遗漏) + G56(答题结构不规范)
  → 判断：给出要素关联矩阵后，表达是否自然改善？
    能 → G4为主
    不能 → G5为主

G46(人地协调空泛) + G35(反事实迁移失败)
  → 判断：明确人类活动改变的自然过程后，能否换区域推理？
    能 → G4为主
    不能 → G3为主

跨维度记录格式：
  主维度：[G类+子类型ID]
  次要维度：[G类+子类型ID]（如有）
  交叉判断依据：[纯净读图测试/概念对照/机制链/区域关联/计算自检结果]
```

## 八、顽固弱项追踪标准

```text
同一子类型（相同维度+子类型ID+相同知识点标签）出现次数追踪：

出现1次 → 标记"偶发"，低优先级
出现2次 → 标记"初步弱项"，进入观察期
出现≥3次 → 标记"顽固弱项"，启动专项突破流程

顽固弱项突破流程（地理版）：
  Step 1：纯净版读图测试
    给一张极简图，只看图名、图例、位置、关键信息
    → 读图对了 → 问题在原理、区域或表达
    → 读图错了 → G1或G2优先处理

  Step 2：专项训练
    G1 → 读图四步法/经纬网/等值线/统计图
    G2 → 概念混淆对照/原理适用条件
    G3 → 过程推理四步法/反事实验证
    G4 → 区域五步框架/要素关联矩阵
    G5 → 计算手册/规范表达模板

  Step 3：验证锁定（次日+3天后各验证一次）
    → 连续2次做对 → 标记"攻克（待巩固）"
    → 连续3次做对 → 标记"已攻克"

  Step 4：写入档案
    更新该条目状态 + 设置验证提醒（需授权）
```

## 九、与通用错题本的协作边界

```text
通用错题本职责（表面层）：
  → 接收所有科目错题（统一入口）
  → 拍题三信息法收集信息
  → 基础四维分类（概念/计算/审题/策略）
  → 记录错题表面信息
  → 跨科目统一管理与学期报告汇总
  → IM提醒统一调度

地理错误DNA职责（深度层，本维度表）：
  → 地理专属G1-G5深度分类
  → 子类型精确定位（G11/G23/G34等）
  → 跨维度关联分析
  → 顽固弱项专项突破（纯净版读图测试→规则重建→验证锁定→写入档案）
  → 地理焦虑处理
  → 地理弱项月报生成
```

### 通用四维到地理五维映射

| 通用错题本四维 | 可能映射 | 判断依据 |
|----------------|----------|----------|
| 概念模糊 | G1/G2/G3/G4 | 是图没读懂、概念不清、机制不清，还是区域关联不清？ |
| 计算失误 | G1/G5 | 是等值线/经纬网读错，还是公式单位执行错？ |
| 读题失误 | G1/G4/G5 | 是漏图例/设问，还是比较维度/表达结构问题？ |
| 方法用错 | G3/G4/G5 | 是过程方法、区域方法，还是答题结构方法错？ |

交接时使用 `geographyBasicDimension` 字段，枚举值必须与 schema 一致。
