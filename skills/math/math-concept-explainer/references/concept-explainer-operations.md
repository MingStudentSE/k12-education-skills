# 数学概念解释器操作细则

> 承接原 `SKILL.md` 中的三模型流程、空间想象训练、理解验证和跨 Skill 协作规则。主文件只保留路由；执行时按本文件展开。

## 1. 核心使命与执行闭环

学生背公式失败，通常不是记忆力问题，而是只记住结论、没有理解“为什么”。本 Skill 的顺序固定为：先建立生活直觉，再引入数学语言，最后连接公式和练习。

最小闭环：
1. 判断是否为数学概念解释、公式原理追问、例题理解、几何想象或概念卡生成。
2. 收集概念名、年级、已懂部分、卡点例题；信息不足时只追问这些最小项。
3. 选择解释模型：生活类比、图解可视化、逐步拆分。
4. 输出直觉解释、例子、反例、概念边界、练习建议和下一步行动。
5. 若要写入长期档案、提醒或跨 Skill 共享摘要，先说明路径和用途，等用户明确同意。

## 2. 模型A：生活类比法

适用：运算规则、代数概念、统计概念、学生要求“用生活举例解释”。

操作顺序：
1. 找一个学生熟悉且不牵强的生活场景；必要时读取 `analogy-bank.md`。
2. 先只谈生活场景，暂不写公式。
3. 用追问确认学生已经建立直觉。
4. 把学生刚说出的生活关系翻译成数学定义、公式或符号。
5. 要求学生用同一理解解释另一个相近概念，验证迁移。

示例锚点：
- 负负得正：少花钱、倒放的倒放、减少的减少；追问“少花 3 天钱等于多了多少钱”。
- 一次函数 `y=kx+b`：出租车起步价是 `b`，每公里加价是 `k`；追问起步价或每公里价格改变时图像如何变。
- 绝对值：点到原点的距离永远非负；追问 `|x|` 是否可能等于 `-3`。
- 频率与概率：抛硬币 10 次的频率会波动，次数越多越接近理论概率。
- 等比数列：复利中每一年都乘同一个数。

## 3. 模型B：图解可视化法

适用：几何概念、函数图像、空间想象、折叠/展开/截面/旋转类问题。

触发信号：学生说“建不起图形”“立体几何想不出来”“折叠展开看懵”“旋转后不知道是什么”。

三步训练：
1. **实物锚定**：圆柱找水杯/罐头，正方体找骰子，棱锥找金字塔；先问手边能否找到相似物。
2. **动作模拟**：让学生在脑中切开、展开、旋转，而不是静态看答案。
3. **语言替代视觉**：看不到图时改问“侧面的宽对应哪里，高对应哪里”“平面经过几个面，截面就可能有几条边”。

常用追问：
- 圆柱/圆锥展开：侧面剪开是什么形状；宽和高分别来自原立体哪里；侧面积公式如何得到。
- 正方体展开：6 个面如何排列才能折回；哪个面会折不到正确位置。
- 截面：截面边数等于平面经过的面数；先猜三角形、六边形是否可能。
- 旋转体：直角三角形绕直角边旋转得到什么；如果绕斜边是否一样。

## 4. 模型C：逐步拆分法

适用：复杂定理、多条件判定、综合性公式、学生知道结论但不懂每个条件为什么必要。

操作顺序：
1. 从最极简情形开始，去掉附加条件，只保留核心一层。
2. 每加入一个条件就追问一次：结论变了吗，为什么。
3. 用反例挑战确认边界：满足前面条件但结论不成立的情况是否存在。
4. 要求学生用自己的话总结定理；能说出原因才算理解。

示例：相似三角形 AA 判定。先问一对角相等是否足够，再加第二对角；引导发现第三个角由三角形内角和确定；用“只有一个 60° 角”作反例；最后让学生复述“两个角相等就相似”。

## 5. 概念理解验证检查点

讲解后必须至少做一个验证，不能只问“明白了吗”。

1. 换例子：让学生举一个不是刚才那个的新例子。
2. 判反例：给一个不符合该概念的情形，请学生判断并说明原因。
3. 做迁移：给一道简单直接应用题。
4. 连旧知：问它和已学相关概念有什么关系。

## 6. 协作与降级

- 概念模糊导致错题时，可把“概念混淆摘要”交给 `math-error-dna`，但不默认写入长期档案。
- 解题过程中遇到公式原理、概念边界或几何想象卡点时，由 `math-problem-solving-coach` 转入本 Skill。
- 概念理解状态、复习提醒、跨 Skill 共享摘要，必须先征得用户授权。
- 学生只要快速答案时，先区分“快速答案”和“真正掌握”；若坚持，只回答当前问题，不强行完整训练。
