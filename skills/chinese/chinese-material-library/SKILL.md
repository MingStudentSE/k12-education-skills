# 📚 语文素材库2.0

## 触发条件

- 学生要“存入素材库/这句话先存着/记一下这条素材/以后写作文能用”。
- 学生要按主题、来源、情感色彩或文体检索素材。
- 学生进入写作前备料：要求围绕主题、文章基调、立意或论点找可用素材。
- 阅读理解、文言文、古诗词或自创好句场景中，学生同意把表达沉淀为素材。
- 学生要求查看使用记录、最常用主题、月度素材报告或积累建议。

## 不触发边界

- 只是要求解释词句、翻译文言、改作文、列提纲，且没有“收藏/检索/调用素材”的意图。
- 只需要通用素材推荐而不涉及个人素材库时，不得假装已经读取或写入长期数据。
- 未获授权时，不写入 learning-dna、提醒系统、周报或跨 skill 共享记录。
- 素材库为空、资料不足或来源不明时，先降级为补充信息模板或通用推荐，不能臆造历史积累。

## 最小输入

| 场景 | 至少需要 |
|---|---|
| 单条存入 | 素材原文；来源/作者如不确定需标注“待确认”；学生确认是否保存 |
| 批量存入 | 多条素材边界、来源状态、停止词“存完了” |
| 主题检索 | 主题/关键词；可选文体、立意、情感基调、年级难度 |
| 写作前调用 | 作文题目或主题、中心论点/基调、希望放在开头/论据/结尾的位置 |
| 使用追踪/月报 | 学生同意记录使用情况，并确认统计范围 |

## 核心流程

1. **识别任务类型**：在“存入、检索、写作前调用、阅读联动、使用追踪/月报”中选一类；混合请求先拆步。
2. **补齐最小输入与授权**：缺素材、主题、来源或写入授权时先问；对长期记录和跨 skill 协作显式征得同意。
3. **标签化建卡**：给出主题标签、类型标签、情感色彩、适用场景、来源可信度；来源不确定时不得补编。
4. **主动推送**：围绕当前作文主题筛出 3-5 条素材，逐条说明匹配理由、建议位置和自然引用示范。
5. **使用后追踪**：仅在授权后记录“用在哪篇文章、效果如何、下次怎么复用”，并可生成月度积累摘要。
6. **收束下一步**：询问保留/修改标签、是否继续存下一条、是否要把某条写进当前段落。

## 输出要求

- 存入结果必须包含“素材卡”：原文、来源、主题/类型/情感标签、适用场景、引用提醒。
- 检索和写作前调用必须给 3-5 条候选；若个人库不足，先说明不足，再给通用高质量素材并邀请保存。
- 引用示范要自然嵌入语境，避免堆砌名言；说明适合开头、论据、结尾或过渡的理由。
- 阅读联动只做轻提示：“这句是否要存？”不得打断主任务；学生说“存”后再建卡。
- 月度报告只基于已授权记录，输出主题分布、最常用素材、空白主题、下月积累建议。

## 失败模式与红线

- 禁止未经同意创建、读取、修改学生长期素材库或 learning-dna。
- 禁止把通用素材说成“你之前积累过”；禁止臆造或编造来源、作者、使用次数和历史偏好。
- 禁止只存原文不打标签；没有标签就无法在写作前主动推送。
- 禁止一次推送过多素材，导致学生无法选择；优先 3-5 条并解释使用位置。
- 禁止脱离作文中心硬塞素材；不匹配时要提示“这条不适合当前基调”。
- 禁止跨 skill 自动共享全文；只共享必要摘要、标签和授权状态。
