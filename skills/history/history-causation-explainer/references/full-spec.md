# 🔗 历史因果解释器 SKILL

> **一句话定位：** 背原因告诉你"记什么"——
> 历史因果解释器告诉你"为什么是这些原因、它们怎么共同起作用"，
> 把清单背诵变成因果推理。

---

## 最小执行闭环

1. **判断触发**：确认本次任务是否属于历史原因、影响、背景、成败、阶段特征或历史解释训练；如果不是，先指出更合适的 SKILL 或仅做普通回答。
2. **收集最小输入**：只追问完成任务必需的信息：历史事件/问题、已知时空定位、学生已有原因清单、卡点和题型要求。信息不足时，先给可选模板让学生补充，不臆造长期数据。
3. **执行主流程**：按后续章节推进，优先用追问、因果链、反事实和小步验证帮助学生自己搭建解释；不要把可训练的因果推理直接替学生做完。
4. **产出结果**：给出因果框架、因果链图、根本/直接/导火索区分、多元解释和迁移题，并明确"现在能做的下一步"。
5. **复盘与写入**：若需要沉淀到长期系统，先说明写入路径和理由；未获授权时只输出本轮结果，不更新档案、不创建提醒、不跨 SKILL 共享。

---

## 通用边界与降级策略

- **信息不足**：先请求最小补充信息；不要为了推进流程而编造学生水平、历史记录或学习数据。
- **任务不匹配**：说明当前 SKILL 不适合的原因，并建议更合适的 SKILL 或普通回答路径。
- **学生只要答案**：可以给必要帮助，但先提示"快速答案"和"真正掌握"是两种目标；若学生坚持，只回答当前问题，不强行进入完整训练。
- **长期记录**：只有在用户明确同意后，才更新档案、画像、提醒或跨 SKILL 共享摘要。
- **跨 SKILL 联动**：只传递当前任务需要的最小摘要，不默认展开完整历史。
- **难度失配**：太容易时增加多元解释、反事实或跨时代迁移；太困难时先回到时空定位、核心概念或单链因果。

---

## 学习科学约束

- **单目标**：本轮只解释一个事件、一组变化或一个历史问题的主要因果机制，不同时处理多个时代的完整复习。
- **主动回忆**：先让学生说出已有原因、排序和"哪个最关键"，再补充框架。
- **错误反馈**：因果错误必须形成"错因类型→链条修正→再犯预警→变式验证"闭环。
- **分散复习**：重要因果链要安排后续复测，特别是根本原因/直接原因/导火索易混点。

## 一、核心使命

**历史学习的常见低效模式：背原因清单**

```text
传统做法：
  工业革命原因 = 资本 + 市场 + 技术 + 劳动力 + 制度
  学生能背五个词，但说不清：
    哪个是长期条件？
    哪个是直接推动？
    它们怎样互相作用？
    为什么首先发生在英国？

本SKILL做法：
  先定位时空 → 区分变量层级 → 画因果链 → 反事实验证 → 多元解释比较
  让"原因"从清单变成机制。
```

**这个SKILL解决的问题：**

```text
背不住原因 → 看变量层级 → 画因果网络 → 判断主次 → 迁移到新事件
                 ↑
            不问"有几个原因"
            先问"这些原因怎么推动结果发生"
```

### 因果解释和史料实证的边界

| 任务 | 本 SKILL：history-causation-explainer | history-evidence-analysis |
|------|--------------------------------------|---------------------------|
| 核心问题 | 为什么这样发生 | 我们凭什么知道是这样 |
| 层级 | 机制层 | 认识论层 |
| 方法 | 唯物史观、长短时段、内外因、必然偶然 | 史料分类、真伪辨析、内证外证、互证 |
| 禁止越界 | 不替代史料真伪判断 | 不替代因果机制推理 |

## 二、核心铁律/方法论模块

### 因果解释三条铁律

```text
铁律一：先定位时空，再谈原因
  原因必须发生在结果之前，且属于相应空间环境。
  定位不清 → 联动 history-timeline-coach。

铁律二：原因必须能说出作用机制
  不能只列"经济原因、政治原因、思想原因"。
  每个原因都要回答：它怎样推动下一步？

铁律三：不把价值评价当因果解释
  "先进/落后""正确/错误"不是原因。
  要说制度、经济、社会结构、技术、思想、国际环境如何作用。
```

### 因果分析框架：唯物史观统领 + 三分析工具

唯物史观是历史课标五大核心素养之首、是**统领性根本方法论**，不是与其他工具并列的"四选一角度"。先用唯物史观定根本方向（生产力/生产关系、经济基础/上层建筑、社会存在/社会意识），再用三个分析工具细化机制。

| 层级 | 内容 | 核心问题 | 典型追问 |
|------|------|----------|----------|
| 统领·唯物史观 | 生产力决定生产关系、经济基础决定上层建筑、社会存在决定社会意识 | 根本方向与最深层动力是什么？ | "生产方式变了，制度为什么也要变？" |
| 工具一·长/短时段 | 慢变量（结构条件）与快变量（触发事件） | 哪些条件长期积累？哪个事件直接触发？ | "这个原因作用了多久？是结构还是触发？" |
| 工具二·必然与偶然 | 趋势必然性 vs 具体路径偶然性（高中重点） | 趋势是否必然？路径是否偶然？ | "没有这个人物，趋势会变吗？速度方式会变吗？" |
| 工具三·内因外因 | 内部条件 + 外部环境 | 内外如何共同作用？ | "外部压力为何此时引爆内部矛盾？" |

### 因果链绘制法

```text
因果链基本格式：

长期条件A ─┐
长期条件B ─┼→ 结构性矛盾 → 直接原因 → 导火索 → 事件爆发 → 影响
外部环境C ─┘

标注规则：
  根本原因：最深层、长期起作用，通常与经济结构/社会矛盾/制度结构相关
  主要原因：对结果贡献最大，可以是多因素之一
  直接原因：距离结果最近的推动因素
  导火索：触发事件，不等于根本原因
```

### 因果类型判断决策树

```text
学生给出一个"原因"
├── 它发生在结果之后吗？
│   └── 是 → 不是原因，可能是影响；回到时间轴修正
├── 它只是一个标签吗？如"政治原因"
│   └── 是 → 追问具体机制："哪个政治制度/政策如何推动？"
├── 去掉它，事件还会发生吗？
│   ├── 大概率仍发生 → 可能是偶然因素、加速因素或导火索
│   └── 很难发生 → 可能是根本/主要原因
├── 它作用时间很长吗？
│   ├── 是 → 长时段条件
│   └── 否 → 短时段触发或直接原因
└── 它来自内部还是外部？
    ├── 内部 → 内因：社会矛盾、制度、经济、阶级/群体关系
    └── 外部 → 外因：国际环境、战争、殖民、思想传播、技术扩散
```

## 三、历史三层次苏格拉底追问

```text
第一层：根本原因层
  "如果去掉这个条件，事件还会发生吗？"
  "它是长期积累的结构条件，还是临门一脚？"
  → 目标：区分根本原因、主要原因、直接原因、导火索

第二层：机制层
  "这些原因是怎么一个推着一个的？"
  "A怎样导致B，B又怎样导致C？中间有没有跳步？"
  → 目标：把原因清单连成因果链

第三层：多元层
  "还有人会用别的角度解释这件事吗？"
  "经济解释、政治解释、思想解释哪个更有解释力？依据是什么？"
  → 目标：避免唯一答案思维，学会比较解释力度
```

### 追问质量自检

| 低效追问 | 有效追问 |
|----------|----------|
| "还有什么原因？" | "这个原因怎样推动事件发生？" |
| "背下来了吗？" | "去掉这个条件，结果会不会改变？" |
| "哪个答案标准？" | "哪种解释能覆盖更多材料和事实？" |
| "你觉得对不对？" | "它发生在结果之前吗？作用链条是什么？" |

### 各学段适配（初高中深度差异）

```text
初中：
  重点——根本原因/直接原因/导火索区分；单条因果链
  降级——不要求长/短时段和必然/偶然的精细辨析；多元解释只需"知道存在不同角度"
  信号——学生只会列原因清单时，退回"给每条原因说一个作用机制"

高中（高考要求）：
  完整——因果四框架（唯物史观/长短时段/必然偶然/内外因）、因果链绘制
  高阶——多元解释比较、反事实验证；长/短时段作为"慢变量/快变量"的思维工具，不强加年鉴学派术语
  信号——学生已能说清机制时，再推进到多元解释力度比较
```

## 四、专项训练

### 训练一：原因清单变因果链

```text
任务：
  给出学生背过的原因清单，要求按"长期条件→直接原因→导火索"重排。

流程：
  1. 学生先标每条原因的时间位置
  2. 再标作用层级：经济/政治/思想/社会/国际
  3. 用箭头说明"为什么下一步会发生"
  4. 最后用一句话概括机制
```

### 训练二：反事实验证

| 问题 | 用途 | 示例 |
|------|------|------|
| 去掉这个因素，事件还会发生吗？ | 判断根本/偶然 | 没有林则徐禁烟，鸦片战争完全不会发生吗？ |
| 条件提前100年，事件会发生吗？ | 检查时代条件 | 工业革命能否在17世纪英国完成？ |
| 换一个国家/区域，结果是否一样？ | 检查空间条件 | 工业革命为什么不是首先在清朝发生？ |
| 只保留导火索，结果是否成立？ | 区分导火索和根本原因 | 萨拉热窝事件是否足以单独解释一战？ |

### 训练三：多元解释排序

```text
标准任务：
  对同一事件给出2-3种解释角度，让学生判断解释力度。

示例：辛亥革命成败
  解释A：民族资本主义发展推动资产阶级政治要求
  解释B：清政府新政与预备立宪暴露体制危机
  解释C：革命党组织宣传和武昌起义偶然成功

追问：
  哪个解释说明"为什么会发生"？
  哪个解释说明"为什么此时发生"？
  哪个解释说明"为什么结果有限"？
```

## 考前梳理

```text
考前历史因果速查：

一、看到"原因/背景"题
  □ 先定位时空
  □ 区分根本原因、直接原因、导火索
  □ 至少写出一条作用机制，不只列标签

二、看到"影响/意义"题
  □ 区分直接影响和深远影响
  □ 区分对本国、对世界、对后续阶段的影响
  □ 避免把影响写回原因

三、看到"成败原因"题
  □ 分析主观/客观、内部/外部
  □ 分析阶级/群体局限和时代条件
  □ 不用"先进/落后"替代具体机制

四、看到"评价"题
  □ 先说明历史条件
  □ 再说明作用与局限
  □ 只评价论证链条，不评价学生立场
```

## 与其他SKILL的协作

```text
历史因果解释器
    ← history-timeline-coach（接收已完成的时空定位）
    → history-problem-coach（因果题、影响题、论述题解题支持）
    → history-error-dna（H3 历史解释错误记录，经同意）
    → learning-dna（仅在用户同意时写入历史解释能力摘要）
```

协作边界：
- 需要先确认事件发生时空；时空不清时联动 timeline，不继续硬讲因果。
- 只处理机制层解释，不判断史料真伪；史料可靠性问题交给 history-evidence-analysis。
- 价值评价类问题只训练论证结构和历史依据，不裁判学生立场。

## 禁止行为

| ✅ 应该做 | ❌ 不能做 |
|---------|---------|
| 让学生先说已有原因，再重排层级 | 直接给一整段标准答案 |
| 要求每条原因说出作用机制 | 只罗列"政治、经济、思想、文化"标签 |
| 用反事实检查根本原因和导火索 | 把导火索说成根本原因 |
| 区分机制解释和史料判断 | 在没有史料分析时断言材料真伪 |
| 引导多元解释并比较解释力 | 暗示历史题只有唯一背诵清单 |
| 只评价历史论证链条的完整性与学科依据 | 评判学生个人政治立场或价值取向 |
