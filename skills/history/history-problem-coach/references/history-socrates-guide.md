# 历史三层次追问适配指南

> 本文档为 `history-problem-coach` 的配套追问库，定义历史解题中的史料层、解释层、评价层追问及学段适配。

---

## 一、三层次追问框架总览

| 层级 | 核心问题 | 目标 | 常见回退 |
|------|----------|------|----------|
| 史料层 | 题目/材料到底给了什么？ | 提取证据、定位时空、区分史实观点 | 回到材料标注 |
| 解释层 | 材料与所学如何连接？ | 建立因果、概念、阶段特征 | 回到知识框架 |
| 评价层 | 结论是否有依据、有条件、有结构？ | 形成规范答案和历史评价 | 回到论证链 |

---

## 二、史料层追问

### 通用追问

```text
1. 题干的时间、地点、人物、制度名在哪里？
2. 设问动词是什么：概括、指出、说明、分析、评价？
3. 材料中哪些词是事实？哪些词是作者评价？
4. 这句话能直接证明什么？不能证明什么？
5. 出处告诉我们什么：作者、时间、材料性质？
```

### 选择题史料层

| 题干特征 | 追问 |
|----------|------|
| 有时间限定 | "这个选项是否属于同一时期？" |
| 有空间限定 | "题干说中国/世界/某区域，选项是否跑题？" |
| 有程度限定 | "设问是主要原因还是直接原因？" |
| 有否定设问 | "题目问不正确，你有没有反向检查？" |

### 材料题史料层

```text
读材料顺序：
  1. 先看设问，知道要找什么
  2. 再看出处，判断时空和立场
  3. 最后读正文，圈关键词
```

### 论述题史料层

```text
如果材料给出观点：
  "这段材料的中心观点是什么？"
  "你是要赞同、反驳还是评析？"

如果材料给出图表：
  "横轴纵轴是什么？变化趋势是什么？异常点在哪里？"
```

## 三、解释层追问

### 通用追问

```text
1. 这个材料对应课本哪个阶段/专题？
2. 这里的关键词和哪个历史概念有关？
3. 如果要解释原因，哪些是根本原因、直接原因、导火索？
4. 如果要解释影响，哪些是直接影响、深远影响？
5. 这个结论是否符合当时的历史条件？
```

### 因果追问

| 错误表现 | 追问 |
|----------|------|
| 原因清单化 | "这些原因怎样一个推着一个？" |
| 导火索当根本 | "去掉这个导火索，深层矛盾还在吗？" |
| 影响写成原因 | "这个因素发生在事件之前还是之后？" |
| 单一角度解释 | "还有经济/政治/思想/国际环境角度吗？" |

### 概念追问

```text
概念不清时：
  "你这里说的'革命/改革/改良'分别指什么？"
  "这个概念在古代语境和现代语境一样吗？"
  "它是制度、思想、事件，还是阶段特征？"
```

---

## 四、评价层追问

### 通用追问

```text
1. 你的观点有没有史实支撑？
2. 每个史实后有没有解释它如何支持观点？
3. 评价是否放在当时历史条件中？
4. 是否既看到作用，也看到局限？
5. 是否只训练论证链条，而不是评判个人立场？
```

### 价值评价题追问

```text
注意：只评价论证，不评价立场。

追问模板：
  "你的评价标准是什么？"
  "这个标准有没有历史依据？"
  "你用了哪些史实支持这个评价？"
  "有没有说明当时的时代条件？"
```

### 论述题追问

| 结构问题 | 追问 |
|----------|------|
| 没观点 | "你要证明的判断是什么？能写成一句话吗？" |
| 观点过大 | "这个观点能用两三个史实证明吗？是否太宽？" |
| 史实不准 | "这个史实的时间和空间能定位吗？" |
| 史论脱节 | "这个史实如何支持你的观点？中间少了哪一步解释？" |

---

## 五、学段适配

| 学段 | 史料层 | 解释层 |评价层 |
|------|--------|--------|-------|
| 初中 | 圈关键词、找时间地点、概括材料 | 联系课本知识，区分原因和影响 | 分点答题，史实准确 |
| 高中 | 出处辨析、史实观点切割、多材料互证 | 因果分层、多元解释、阶段特征 | 观点-史实-论证，历史条件和限度 |

## 六、常见场景处理

### 学生说"我懂了"但无法回扣材料

```text
处理：
  "你说你懂了。那你指出材料中哪一句支持你的结论？"
  指不出 → 回到史料层
  指得出但推理跳步 → 回到解释层
```

### 学生回答"不知道"

```text
三步降级：
  1. 选择题：先问时间和设问词
  2. 材料题：让学生只圈3个关键词
  3. 论述题：先写一个最小观点句
```

### 学生只想背答案

```text
话术：
  "可以给你简答，但这只解决这一题。
   如果要下次也会做，我们至少走两步：
   先定位时空，再圈材料关键词。"
```

## 七、追问话术质量自检

| 合格追问 | 不合格追问 |
|----------|------------|
| 能让学生产生下一步动作 | 只问"你懂了吗" |
| 指向具体证据、时空或机制 | 只问"还有吗" |
| 一次只问一个问题 | 连续抛出多个抽象问题 |
| 不替学生完成可训练步骤 | 直接给答案让学生记 |
| 不评价个人立场 | 用立场词替代学科评价 |
