# 历史焦虑处理手册

> 本文档为 `history-error-dna` 的配套参考资源，用于把"历史背不下来"等模糊焦虑转化为可诊断、可训练、可复测的具体任务。

---

## 一、历史焦虑信号词库

| 信号词 | 可能真实根因 | 第一反应 |
|--------|--------------|----------|
| "历史背不下来" | H1时空轴缺失、H4概念术语混乱 | 不急着加背诵量，先测时空坐标 |
| "史料看不懂" | H2史实/观点切割弱、出处意识弱 | 先做短材料标注 |
| "大题不知道答什么" | H3解释链或H5论证链缺口 | 先拆观点、史实、解释 |
| "历史全靠蒙" | 选择题限定词和时空排除弱 | 先做选择题排除流程 |
| "我记性不好学不了历史" | 用记忆问题掩盖方法问题 | 用数据说明具体错因 |
| "材料题我只会抄材料" | H25内证外证缺失 | 训练材料+所学双证 |

## 二、数据替代情绪四步流程

### Step 1：确认感受

```text
目标：承认学生体验，但不放大情绪。

话术：
"你现在很挫败，我听到了。
 先别急，我们不用'历史行不行'这种大标签，
 我先看这几次错题到底集中在哪里。"
```

### Step 2：调取精准数据

```text
数据格式：
  最近[N]次历史错题中：
    H1时空定位：[N]次
    H2史料实证：[N]次
    H3历史解释：[N]次
    H4概念术语：[N]次
    H5价值评价：[N]次

话术：
"你不是所有历史都不行。
 数据显示，你主要卡在[H类+子类型]：
 [具体表现]出现了[N]次。"
```

### Step 3：变成具体任务

```text
把情绪句改写为任务句：
  "历史背不下来"
  → "先把中国近现代四节点轴补稳：1840、1919、1949、1978"

  "史料看不懂"
  → "先练3段短材料，只判断史实/观点/能证明什么"

  "大题不会答"
  → "先练观点-史实-解释三段式，不追求长答案"
```

### Step 4：执行3道递进题

```text
第1道：建立信心
  只考一个基础动作，如30秒画时间轴或标材料史实句。

第2道：直面弱项
  精准命中子类型，如H13序列倒置或H21史论不分。

第3道：变形验证
  换时代、换材料或换题型，确认不是只会原题。
```

## 三、焦虑类型与递进题模板

### 类型A：时空焦虑

```text
信号："我事件顺序老记混。"

递进题：
  1. 30秒写出洋务运动→戊戌变法→辛亥革命→新文化运动→五四运动顺序
  2. 给一个材料，判断它属于哪一阶段探索
  3. 换成世界史：文艺复兴→新航路→启蒙运动→工业革命
```

### 类型B：史料焦虑

```text
信号："材料题我不知道材料在说什么。"

递进题：
  1. 给两句话，只标史实/观点
  2. 给一段材料，标能证明什么、不能证明什么
  3. 给两条冲突材料，判断需要如何互证
```

### 类型C：大题焦虑

```text
信号："大题不知道答什么。"

递进题：
  1. 把一个观点句补完整
  2. 给观点配两个准确史实
  3. 每个史实后写一句"这说明"
```

### 类型D：选择题焦虑

```text
信号："选择题总是两个选项纠结。"

递进题：
  1. 只找题干时间和设问词
  2. 排除一个时空不符选项
  3. 在两个正确表述中选最符合题干主旨的一项
```

## 四、禁用话术与替代话术

| 禁用话术 | 问题 | 替代话术 |
|----------|------|----------|
| "你就是没背熟" | 模糊且打击 | "这次主要是H1时间轴缺口，我们先补坐标" |
| "历史就是背" | 否定方法训练 | "历史要背，但先要有时空和证据框架" |
| "别焦虑，你可以的" | 空泛安慰 | "数据看，H2错了3次，我们练3段短材料" |
| "你的观点不对" | 立场评判风险 | "你的论证链还缺史实依据和历史条件" |
| "大题多写就行" | 鼓励堆字 | "每点要有观点、材料/史实、解释" |

## 五、提醒与复测规则

```text
提醒前提：
  必须获得学生明确同意。

建议节奏：
  当天：完成3道递进题
  次日：1道同子类型短题
  第3天：1道变形题
  第7天：混入其他类型题进行交错复测

攻克判定：
  连续2次同子类型复测正确 → 攻克（待巩固）
  连续3次正确且能解释方法 → 已攻克
```
