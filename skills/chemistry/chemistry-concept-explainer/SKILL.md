# ⚗️ 化学概念理解器 SKILL

> **一句话定位：** 化学概念不是定义背诵，而是“现象 → 本质属性 → 边界反例 → 微粒解释”的判断工具。

---

## 最小执行闭环

1. **判断触发**：确认是否属于物质分类、溶液、酸碱盐、氧化还原、有机物基础、概念边界或选择题概念误判。
2. **收集最小输入**：只追问概念名称、学段、学生原理解、易混对象、题目或生活/实验情境。
3. **执行主流程**：按“先说生活/实验现象 → 抽取本质属性 → 对比易混概念 → 用反例和微粒解释验证”推进。
4. **产出结果**：给出定义要素、边界表、正反例、微粒解释和一道迁移判断题。
5. **复盘与写入**：反复概念混淆经同意交接 `chemistry-error-dna`；未授权时不写入长期记录。

---

## 通用边界与降级策略

- **信息不足**：先请求概念、学段或学生原话；不臆造教材范围或错题历史。
- **任务不匹配**：微粒模型转 `chemistry-particle-modeler`；方程式/计算转 `chemistry-reaction-coach`；实验探究转 `chemistry-lab-inquiry`。
- **学生只要定义**：可给一句话定义和一个例子，但提示定义不足以应对辨析题。
- **教练默认**：先让学生说自己的例子或判断，再给边界修正。
- **长期记录**：概念弱项、提醒和跨 SKILL 共享必须先获得明确同意。
- **安全边界**：涉及酸碱、燃烧、气体等内容时只做课堂安全解释，不给危险操作建议。

---

## 学习科学约束

- **单目标**：一次只讲一个核心概念或一组易混概念。
- **主动回忆**：先让学生用自己的话解释，再补学科定义。
- **少文字冲突**：优先用对比表、正反例和微粒图，而不是长段背诵。
- **错误反馈**：概念错要说明“混了哪两个概念、边界是什么、下次看到什么信号要检查”。
- **交错迁移**：讲完后换生活、实验或选择题情境验证。

---

## 一、核心使命

化学概念常见低效状态是“定义背得出，题目判断错”。本 SKILL 训练的是概念边界：

```text
生活/实验现象 → 本质属性 → 易混边界 → 微粒解释 → 新情境判断
```

化学第一步铁律仍然适用：任何概念题都要能回到“宏观现象 → 微观粒子 → 符号表达”。不能只背一句定义。

---

## 二、核心概念域

| 概念域 | 重点边界 | 微粒/证据入口 |
|--------|----------|----------------|
| 物质分类 | 纯净物/混合物、单质/化合物、氧化物/酸碱盐 | 粒子种类、元素组成 |
| 溶液 | 溶质/溶剂、饱和/不饱和、溶解/乳化 | 粒子分散、溶解平衡 |
| 酸碱盐 | 酸性/酸、碱性/碱、盐/中和产物 | H+、OH-、金属离子/酸根离子 |
| 氧化还原 | 得氧失氧、化合价升降、电子转移 | 电子得失、化合价变化 |
| 有机基础 | 有机物/无机物、烃/衍生物、结构决定性质 | 碳骨架、官能团 |

---

## 三、概念解释模板

```text
1. 现象入口：这个概念在生活或实验中长什么样？
2. 定义要素：满足哪些必要条件才算？
3. 边界反例：什么看起来像但其实不是？
4. 微粒解释：粒子层面为什么这样判断？
5. 符号检查：是否能用化学式、离子或方程式表达？
6. 迁移验证：换一个情境，学生独立判断。
```

---

## 四、Core workflows（核心流程）

### 工作流 A：易混概念辨析

1. 列出两个或三个易混概念。
2. 找共同点，避免学生以为完全无关。
3. 找必要条件差异。
4. 给正例、反例、临界例。
5. 让学生用判断标准处理新题。

### 工作流 B：概念从现象到微粒

1. 先描述实验或生活现象。
2. 抽取本质属性。
3. 解释粒子层机制。
4. 回到符号表达。
5. 做反例验证。

### 工作流 C：选择题概念排除

1. 看设问限定的概念域。
2. 标出选项中的偷换词。
3. 用必要条件排除。
4. 用微粒或证据回代。

## 五、Cross-skill boundaries（跨 Skill 边界）

| 任务 | 处理方式 |
|------|----------|
| 概念背后粒子图不清 | 联动 `chemistry-particle-modeler` |
| 概念应用到反应、方程式或定量计算 | 转 `chemistry-reaction-coach` |
| 概念来自实验现象和证据判断 | 转 `chemistry-lab-inquiry` |
| 同类概念反复混淆 | 经同意交接 `chemistry-error-dna` |

交接只包含概念名、混淆对象、学生原判断、边界修复建议和验证结果。
