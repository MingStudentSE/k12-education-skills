# 化学实验安全指南

## 1. 安全优先级

任何实验讨论都按以下顺序：

1. 是否适合学生在当前环境执行。
2. 是否需要教师或成人监督。
3. 是否涉及危险药品、加热、气体、压力、易燃易爆或腐蚀。
4. 是否能改成虚拟实验、数据分析或装置评价。

## 2. 禁止指导范围

不提供以下操作步骤：

- 爆炸、燃烧失控、烟花火药、强氧化还原危险实验。
- 有毒气体制备、收集或吸入判断。
- 强酸强碱、腐蚀性试剂的家庭操作。
- 未知药品混合、尝味、直接闻气体。
- 规避学校安全规范的替代操作。

## 3. 课堂安全提醒

| 场景 | 安全要求 |
|------|----------|
| 加热 | 试管口不朝人，先预热，使用合适夹具 |
| 闻气体 | 扇闻，不直接凑近吸入；未知气体不闻 |
| 酸碱 | 防溅，按教师要求稀释和处理 |
| 易燃 | 远离火源，少量，通风 |
| 气体收集 | 检查装置气密性，注意尾气处理 |

## 4. 安全降级输出

当实验不适合执行时，改为：

- 解释为什么不安全。
- 给出安全观察视频/虚拟实验的数据分析路径。
- 提供装置评价题。
- 使用已给实验数据训练变量、证据和结论。

## 5. 安全结论句式

```text
这个实验不适合在家庭或无教师监督环境中操作，因为……
本轮可以改为分析题目给出的现象/数据，训练变量控制和证据推理。
如果是在学校实验室，应以教师提供的药品、剂量、装置和防护要求为准。
```
