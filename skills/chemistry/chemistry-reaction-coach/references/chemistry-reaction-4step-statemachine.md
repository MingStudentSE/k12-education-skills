# 化学反应四步状态机

## 状态机总览

```text
S1 证据判断 → S2 物质确定 → S3 方程表达 → S4 守恒/计算验证
```

每一步都必须能回答“凭什么”，不能只背模板。

## S1 证据判断

| 问题 | 合格表现 | 常见错误 |
|------|----------|----------|
| 是否发生化学变化？ | 能说出新物质证据 | 把溶解、蒸发、混合都当反应 |
| 反应条件是什么？ | 写出加热、点燃、催化剂、溶液环境等 | 忽略条件导致产物判断错 |
| 现象是否充分？ | 能区分证据和猜测 | “有气泡”但不判断气体来源 |

## S2 物质确定

1. 列反应物。
2. 根据反应类型、物质性质或实验事实判断生成物。
3. 写正确化学式。
4. 必要时标气体、沉淀或水。

检查：不能为了配平改变化学式；化学式错，后面全错。

## S3 方程表达

| 类型 | 关键点 |
|------|--------|
| 化合反应 | 多变一，产物化学式必须符合化合价 |
| 分解反应 | 一变多，注意条件和常见产物 |
| 置换反应 | 活泼性/金属活动性或卤素活动性 |
| 复分解反应 | 沉淀、气体或水生成 |
| 离子反应 | 拆可溶强电解质，保留弱电解质、沉淀、气体、水 |
| 氧化还原 | 标化合价，检查电子得失 |

## S4 守恒/计算验证

必须至少完成一个验证：

- 原子种类和数目守恒。
- 离子方程式电荷守恒。
- 氧化还原电子得失守恒。
- 化学计算的单位和比例关系正确。
- 结论能解释原题宏观现象。

## 降级策略

学生卡在 S1：退回宏观现象和物理/化学变化区分。

学生卡在 S2：转到物质性质、概念边界或微粒模型。

学生卡在 S3：使用配平表格，不直接给完整答案。

学生卡在 S4：拆成守恒检查或单位检查单题。
