# 化学计算检查清单

## 1. 解题骨架

```text
题目信息 → 方程式 → 配平 → 已知/未知 → 单位统一 → 比例关系 → 计算 → 合理性检查
```

## 2. 已知未知表

| 项目 | 要写清 |
|------|--------|
| 已知量 | 质量、体积、浓度、物质的量、质量分数等 |
| 未知量 | 题目要求的物质或指标 |
| 关系式 | 方程式系数比、质量守恒、溶质质量分数、稀释关系 |
| 单位 | g、mol、L、mL、%、mol/L 等 |

## 3. 常见题型

| 题型 | 核心关系 | 易错点 |
|------|----------|--------|
| 质量守恒 | 反应前总质量 = 反应后总质量 | 忽略逸出气体或沉淀 |
| 方程式计算 | 系数比 = 物质的量比 | 未配平就计算 |
| 溶液计算 | 溶质质量分数 = 溶质质量 / 溶液质量 | 把溶剂质量当溶液质量 |
| 稀释计算 | 稀释前后溶质质量不变 | 体积和质量混用 |
| 过量判断 | 比较实际量与化学计量比 | 默认反应物都完全反应 |

## 4. 四项检查

1. **方程式检查**：产物和配平是否正确。
2. **单位检查**：质量、体积、浓度是否统一。
3. **比例检查**：用的是系数比、质量比还是浓度关系。
4. **合理性检查**：结果是否超出题目条件或化学常识。

## 5. 错因定位

| 表现 | 可能错因 | 修复 |
|------|----------|------|
| 算式会列但结果离谱 | 单位或比例错 | 重写单位栏，做数量级估计 |
| 已知量用不上 | 题型识别错 | 回到题目问的量和反应关系 |
| 每次漏配平 | 流程顺序错 | 先方程式后计算，强制检查 |
| 溶液题混乱 | 溶质/溶剂/溶液不分 | 画三者关系图 |

## 6. 教练提示阶梯

先问“题目要什么”，再问“哪个方程式或关系式连接已知和未知”，最后才代入计算。学生没列已知未知前，不直接给完整计算过程。
