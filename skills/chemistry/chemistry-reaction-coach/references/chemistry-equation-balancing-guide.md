# 化学方程式配平指南

## 1. 配平原则

1. 只能改系数，不能改化学式下标。
2. 反应前后元素种类不变。
3. 每种原子数量相等。
4. 离子方程式还要电荷守恒。
5. 氧化还原还要电子得失守恒。

## 2. 基本流程

```text
写对化学式 → 找复杂物质 → 先配非 H/O 元素 → 再配 H/O → 化简系数 → 守恒检查
```

## 3. 常用方法

| 方法 | 适用 | 提醒 |
|------|------|------|
| 观察法 | 简单反应 | 先配出现次数少的元素 |
| 最小公倍数法 | 某元素两边下标明显 | 不要改下标 |
| 原子团整体法 | 原子团反应前后未拆开 | 如 SO4、NO3、OH 可整体看 |
| 化合价升降法 | 氧化还原反应 | 先标化合价，再配电子转移 |

## 4. 检查表

| 检查项 | 通过标准 |
|--------|----------|
| 化学式 | 每个物质化学式正确 |
| 系数 | 最简整数比 |
| 原子守恒 | 每种元素两边数量相等 |
| 电荷守恒 | 离子方程式两边电荷总数相等 |
| 状态/条件 | 需要时标明气体、沉淀、加热、催化剂等 |

## 5. 常见错误

| 错误 | 示例 | 修复 |
|------|------|------|
| 改下标 | 把 H2O 改成 H2O2 | 重新写正确物质，再改系数 |
| 漏配氧氢 | 只配金属元素 | 最后专门检查 H/O |
| 原子团拆错 | 把 SO4 拆开乱配 | 未变化时整体配 |
| 系数未化简 | 4H2 + 2O2 = 4H2O | 化简为 2H2 + O2 = 2H2O |

## 6. 教练追问

```text
你先不要算结果，先说：哪个元素最适合先配？
你改的是系数还是下标？
配完后，左右两边每种原子分别有几个？
如果这是离子方程式，左右总电荷是多少？
```
