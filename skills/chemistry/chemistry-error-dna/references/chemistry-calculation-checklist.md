# 化学计算与用语错因检查清单

## 1. 计算前置检查

| 检查 | 问题 |
|------|------|
| 方程式 | 写对并配平了吗？ |
| 已知未知 | 题目给什么，求什么？ |
| 单位 | 是否统一到同一体系？ |
| 关系 | 用方程式系数比、质量分数、稀释关系还是守恒？ |
| 过量 | 是否需要判断哪种反应物过量？ |

## 2. 溶液题三量关系

```text
溶液质量 = 溶质质量 + 溶剂质量
溶质质量分数 = 溶质质量 / 溶液质量 × 100%
稀释前后：溶质质量不变
```

常见错因：把加入水后的溶液质量仍当原溶液质量；把溶剂质量当溶液质量。

## 3. 方程式计算顺序

1. 写反应方程式。
2. 配平。
3. 在对应物质下方写已知量和未知量。
4. 必要时换算物质的量或质量。
5. 按系数比列比例。
6. 检查结果单位和合理性。

## 4. 化学用语检查

| 用语 | 常见错误 | 修复 |
|------|----------|------|
| 化学式 | 下标、电荷、括号漏写 | 拆元素和离子团 |
| 方程式 | 漏条件、漏气体/沉淀、未配平 | 方程式五项检查 |
| 实验结论 | 口语化、证据不足 | 用“证据支持……”句式 |
| 计算答案 | 无单位、有效信息不明 | 最后写单位和限定条件 |

## 5. 复测建议

Ch5 错因不要只重做原题。至少做一题同方程式不同数据、一题同数据不同设问、一题溶液/单位变式，确认学生不靠记答案通过。
