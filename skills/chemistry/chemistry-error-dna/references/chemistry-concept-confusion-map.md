# 化学易混概念地图

## 1. 快速定位

| 概念域 | 常见混淆 | 判断标准 |
|--------|----------|----------|
| 物质分类 | 纯净物/混合物、单质/化合物、氧化物/含氧化合物 | 物质种类、元素种类、组成条件 |
| 溶液 | 溶解/反应、饱和/浓、溶质/溶剂/溶液 | 粒子分散、是否生成新物质、比例关系 |
| 酸碱盐 | 酸/酸性、碱/碱性、盐/食盐、中和/生成盐 | H+、OH-、离子组成和反应本质 |
| 氧化还原 | 氧化剂/还原剂、氧化/还原、剧烈反应/氧化还原 | 化合价和电子转移 |
| 有机基础 | 有机物/含碳物、烃/有机物、官能团/离子 | 碳骨架和官能团 |

## 2. 错因判定用法

1. 先看学生最早使用了哪个概念。
2. 判断这个概念是否满足必要条件。
3. 如果概念错导致方程式、实验或计算后续错，主错因仍归 Ch2。
4. 修复时使用“正例、反例、临界例”三件套。

## 3. 典型再犯信号

- 看见“含氧”就判氧化物。
- 看见“生成盐”就判中和反应。
- 看见“含碳”就判有机物。
- 把“溶液很浓”当作“饱和”。
- 把“氧化剂”理解成“自己被氧化的物质”。
