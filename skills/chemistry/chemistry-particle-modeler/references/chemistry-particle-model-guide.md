# 化学微粒观建模指南

## 1. 宏微符三层模型

| 层级 | 核心问题 | 证据来源 | 输出形式 |
|------|----------|----------|----------|
| 宏观 | 能观察到什么现象？ | 题干、实验、生活现象 | 颜色、气体、沉淀、温度、导电性 |
| 微观 | 哪些粒子在运动、结合、分离或重新组合？ | 物质组成、溶液环境、反应类型 | 原子、分子、离子、电子转移 |
| 符号 | 用什么化学语言表达？ | 化学式、离子符号、方程式 | 化学式、结构示意、方程式、离子方程式 |

使用规则：必须能从宏观现象追到微观粒子，再回到符号表达；任何一层说不清，都不能判定学生真正理解。

## 2. 粒子类型快速判断

| 情境 | 优先粒子视角 | 追问 |
|------|--------------|------|
| 金属单质 | 原子/金属阳离子与自由电子模型 | 为什么能导电、导热、延展？ |
| 非金属气体 | 分子或原子 | 分子间距离、运动和碰撞怎样变化？ |
| 盐类晶体 | 阳离子和阴离子 | 溶于水后哪些离子分开？ |
| 酸碱盐溶液 | 离子 + 水分子 | 哪些离子真正参与反应？ |
| 化学反应 | 原子重新组合 | 反应前后原子种类和数目是否守恒？ |

## 3. 微粒图绘制规范

1. 不同元素用不同形状或颜色标记。
2. 同种粒子大小和标记保持一致。
3. 反应前后原子数量必须一一对应。
4. 溶液中离子要分散表示，沉淀要聚集表示。
5. 不把系数画成下标；不把电荷画成原子数量。

## 4. 追问模板

```text
你先只说宏观：看到了什么？
再说微观：这些现象背后有哪些粒子？
哪些粒子只是旁观，哪些粒子真正发生变化？
如果用符号表达，下标、系数、电荷分别对应微观图的哪里？
换一个同类现象，你能重新画一遍吗？
```

## 5. 常见断裂与修复

| 断裂 | 表现 | 修复动作 |
|------|------|----------|
| 宏观到微观断裂 | 只说“反应了”“变色了” | 让学生列粒子清单，区分反应前后 |
| 微观到符号断裂 | 会画粒子但不会写式子 | 把粒子个数比转成化学式或系数 |
| 符号到宏观断裂 | 会配平但解释不了现象 | 让学生用符号反推可观察证据 |
| 原子守恒断裂 | 画图前后原子数量变了 | 用颜色标记逐个配对 |

## 6. 学段边界

初中重点是分子、原子、离子、化学式意义和质量守恒；高中可加入离子反应、电子转移、物质的量和结构性质关系。不要为了完整性把高中微观理论塞给初中学生。
