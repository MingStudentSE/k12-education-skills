# 化学符号表达速查

## 1. 化学式意义

| 符号 | 宏观意义 | 微观意义 | 易错点 |
|------|----------|----------|--------|
| H2O | 水这种物质 | 一个水分子含 2 个 H 原子和 1 个 O 原子 | 下标只管前面的元素 |
| O2 | 氧气 | 一个氧分子含 2 个氧原子 | 不能写成 2O 表示氧气 |
| NaCl | 氯化钠 | Na+ 与 Cl- 的个数比为 1:1 | 离子晶体不说“一个 NaCl 分子” |
| Ca(OH)2 | 氢氧化钙 | Ca2+ 与 OH- 个数比为 1:2 | 括号外下标作用于整个离子团 |

## 2. 系数、下标、电荷

```text
2H2O
│└─ 下标2：每个水分子里有2个氢原子
└── 系数2：有2个水分子

SO4^2-
└── 电荷2-：整个硫酸根离子带两个单位负电荷
```

检查口诀：系数管“几个粒子”，下标管“粒子内部几个原子”，电荷管“得失电子后的带电状态”。

## 3. 方程式基本检查

1. 反应物、生成物是否符合事实。
2. 元素种类是否一致。
3. 每种原子数是否守恒。
4. 离子方程式中电荷是否守恒。
5. 条件、气体、沉淀符号是否需要标注。

## 4. 常见符号错误

| 错误 | 为什么错 | 修复 |
|------|----------|------|
| 把 2O 写成氧气 | 2O 表示两个氧原子，不表示氧分子 | 氧气写 O2 |
| 配平时改下标 | 改下标会改变物质 | 只能改系数 |
| 忘记离子电荷 | 离子符号不完整 | 先判断得失电子或离子团电荷 |
| 把沉淀符号当反应条件 | ↑/↓ 是生成物状态提示 | 条件写在等号上方或旁边 |

## 5. 回到微观验证

每一个符号表达都要能回答：

- 它代表哪种粒子？
- 粒子内部原子个数是多少？
- 粒子之间数量比是多少？
- 反应前后哪些粒子改变、哪些粒子旁观？
- 这个符号能解释题目中的宏观现象吗？
