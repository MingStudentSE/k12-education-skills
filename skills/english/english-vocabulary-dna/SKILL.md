# 📖 智能词汇DNA系统 SKILL

> 一句话定位：“今天背，明天忘”不是你的错；本 Skill 帮你把英语词汇放在正确时间复习，并只在授权后提醒或写入。

## 什么时候用我

- 学生要积累、复习、辨析或主动使用英语单词、短语、搭配、词族。
- 学生上传/粘贴单词表、课文生词、听力/口语/写作中遇到的好词，要求“存入词汇DNA”。
- 学生说下周要学新单元、启动课前预热、查看词汇DNA、生成词汇健康报告。
- 其它英语 Skill 在用户同意后，把生词或推荐词汇交给本 Skill 维护。

## 什么时候不用我

- 全学科长期学习画像、偏好、成长图谱、跨学科概念图谱：交给 `general/learning-dna`。
- 纯语法结构诊断：交给 `english-grammar-coach`；纯听力材料训练交给 `english-listening-trainer`；完整作文批改交给 `english-writing-coach`；口语流利度/发音训练交给 `english-speaking-coach`。
- 学生只问一个词的即时释义且不要求长期复习时，可直接回答，不默认建档或提醒。
- 未获授权时，不创建提醒、不写长期档案、不跨 Skill 共享词汇摘要。

## 与 `general/learning-dna` 的边界

- 本 Skill 管“英语词汇项”：词形、词义、语境句、来源、优先级、被动识别/主动使用状态、复习轮次、遗忘速度与危险指数。
- `learning-dna` 管“全局学习画像”：学习偏好、跨学科成长证据、长期目标、情绪/动力支持策略。
- 只有在用户同意长期记录时，本 Skill 才向 `learning-dna` 写入最小摘要，例如“本月新增30词、抽象名词遗忘快、meticulous已能主动使用”。禁止转发完整词库。
- `learning-dna` 不替代本 Skill 的词汇复习调度；本 Skill 不把一次词汇表现写成全局能力标签。

## 最小执行闭环

1. **判定任务**：确认是词汇入库、复习提醒、课前预热、遗忘追踪或健康报告；不匹配则路由到对应 Skill。
2. **收集输入**：只追问必需信息：词汇/短语、语境句、来源、错用记录、年级或当前阅读/写作主题。
3. **授权检查**：说明是否需要写入词汇DNA、创建提醒或同步学习DNA；未获同意只输出本轮结果。
4. **执行模块**：按下方流程选择模块；长话术、模板和公式见 `references/vocabulary-dna-workflows.md`。
5. **给出下一步**：输出词义辨析、词族网络、可用例句、复习计划或预热任务，并明确下一次学生要做什么。

## 核心流程骨架

### A. 词汇DNA入库

- 三种入口：拍照/截图提取、口语/听力/写作对话标记、学生手动添加。
- 每个词至少记录：词汇、来源、语境、入库日期、优先级；主动添加的词标记较高意愿。
- 细则与反馈话术见 `references/vocabulary-dna-workflows.md`。

### B. 五轮复习提醒

- 默认节奏：24h 闪卡测验 → 3d 造句激活 → 7d 对话植入 → 14d 近反义/搭配辨析 → 30d 月度综合复习。
- 只有学生同意提醒后才调用提醒能力；提醒内容要从“看到认识”递进到“主动会用”。
- 留存率 <60% 的词重启五轮；>80% 的词进入长期/季度复习。

### C. 新词汇雷达

- 用于“下周要学新课/新单元”的课前7天预热：Day 7 词形发音初见、Day 5 场景联想、Day 3 轻松使用、上课前自信提醒。
- 话题分组、教材/考试/兴趣模板、每次8-12词分组规则见 `references/vocabulary-radar-topics.md`。

### D. 遗忘速度与危险指数

- 根据五轮表现标记快速/正常/慢速遗忘型；快速型提前提醒，慢速型减少不必要提醒。
- 危险指数 = 距上次复习天数 / 预计遗忘天数 × 100%；>80% 今日必须复习，50-80% 本周建议复习。

### E. 词汇DNA健康报告

- 学生说“看看词汇情况”或月度复盘时生成：词库总览、遗忘速度、主动使用情况、下月重点。
- 分开追踪被动识别（看到认识）与主动使用（能说/写出来）；核心目标是把约20%核心词升级到主动使用。

## 失败模式与红线

- 不臆造学生长期词库、教材版本、遗忘速度、留存率或提醒记录。
- 不把 IM/定时任务写死为某一平台；说明需要平台提醒能力支持。
- 不把拍照识词写死为内置能力；需要多模态模型或本地 OCR 扩展。
- 不未经同意就写入词汇DNA、同步 `learning-dna`、创建提醒或读取其它 Skill 记录。
- 不把词汇训练变成只背中文释义；每轮都要推动语境、搭配和真实使用。
- 不把全部词都推到主动使用；普通识别词维持被动识别即可，核心词才升级。
