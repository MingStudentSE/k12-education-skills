# 实验设计与报告复盘指南

> 本指南服务于「物理实验思维教练」：把主文件中的实验设计、误差分析、数据处理与报告复盘长细则外移，便于在真实题目中按证据链诊断。

## 一、实验设计闭环

### 1. 目的句改写

把题目或学生口头描述改写成可检验目的：

| 模糊说法 | 合格目的句 |
|---|---|
| 看看摩擦力 | 探究滑动摩擦力大小与接触面粗糙程度/压力大小的关系 |
| 做电阻实验 | 探究导体电流与电压的关系，并由 I-U 图像求电阻 |
| 测密度 | 用天平和量筒测物体密度，比较测量误差来源 |

### 2. 变量表

| 类型 | 要写清 | 常见失误 |
|---|---|---|
| 自变量 | 本轮主动改变的量、改变范围、改变方式 | 一次改变两个条件 |
| 因变量 | 观察或测量的结果量、仪器、单位 | 只写现象不写测量量 |
| 控制变量 | 必须保持相同的条件、控制方法 | 只喊“控制变量”不说怎样控制 |
| 观测量 | 转换法中实际看到的现象 | 把观测量误当成被研究量本身 |

### 3. 步骤检查

1. 器材能否完成变量改变与测量，量程/分度值是否合适。
2. 是否先调零、校准、检查电路连接或水平状态。
3. 每次实验只改变自变量，其余条件保持一致。
4. 数据组数足够支持趋势，关键范围不能只取一组。
5. 记录表格包含物理量、单位、条件和必要备注。

## 二、误差分析框架

误差不是“写一句读数不准”。按下面顺序判断：

| 类别 | 判断标准 | 表述模板 |
|---|---|---|
| 偶然误差 | 同一条件多次测量有小幅波动 | 多次测量取平均值可减小偶然误差 |
| 系统误差 | 仪器零点、方法假设或装置结构导致同向偏差 | 由于……，测得值会偏大/偏小 |
| 操作失误 | 未调零、读错量程、接线错误、没保持变量一致 | 这不是可接受误差，应重做或剔除并说明 |
| 模型近似 | 忽略摩擦、热损失、空气阻力等 | 结论只在……近似成立时适用 |

写误差时必须包含三件事：来源、影响方向、改进办法。例：弹簧测力计未沿水平方向匀速拉动会使读数偏大，应保持木块匀速直线运动并多次测量。

## 三、数据处理细则

1. **表格先验算**：单位是否统一，读数有效位数是否一致，异常数据是否标注。
2. **图像三步**：选轴与比例尺；描点并按趋势连线；用斜率、截距或曲线形状解释物理意义。
3. **关系判断**：
   - 正比：图像过原点且比值恒定；
   - 线性：图像接近直线但不一定过原点；
   - 反比：乘积近似恒定；
   - 只说“越大越大”只能算定性趋势。
4. **异常点处理**：先查仪器、读数、连接和条件控制；不能为了好看直接删除。
5. **结论回证据**：每个结论后都能指出来自哪一列数据或哪段图像。

## 四、实验报告复盘清单

| 报告部分 | 必检问题 | 修改方向 |
|---|---|---|
| 实验目的 | 是否可检验、变量是否明确 | 改成“探究 X 对 Y 的影响” |
| 器材 | 是否覆盖测量、调节、安全需求 | 补量程、分度值、连接注意 |
| 步骤 | 是否按变量控制组织 | 用编号步骤写清“只改变/保持不变” |
| 数据表 | 是否有表头、单位、足够组数 | 补单位、补平均值或图像列 |
| 图像 | 坐标轴、比例尺、点线是否规范 | 重画并标注物理意义 |
| 结论 | 是否带条件、证据和定量关系 | 用“在……一定时……”句式 |
| 误差 | 是否说明来源、方向、改进 | 删除空话，补影响方向 |

## 五、苏格拉底追问库

- 你这次真正想研究的是哪两个量之间的关系？
- 如果只改变这个量，另外哪些条件必须保持不变？你用什么办法保持？
- 你的表格中哪一列能支持结论？单位写全了吗？
- 图像如果不过原点，还能直接说“正比”吗？为什么？
- 这个误差会让结果偏大还是偏小？怎样改进才对应这个来源？
- 如果让你重做一次，最应该补测哪一组数据？

## 六、报告句式模板

### 方法与变量

“本实验采用____法，目的是探究____对____的影响。实验中改变____，观察/测量____，并保持____、____不变。”

### 数据结论

“由表格/图像可知，在____一定时，____随____的增大而____；当数据满足____时，可进一步判断二者____。”

### 误差与改进

“本实验的主要误差来自____，会使测量值偏____。改进方法是____；若要减小偶然误差，可在相同条件下____。”
