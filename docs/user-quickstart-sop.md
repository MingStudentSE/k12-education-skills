# 四模块用户快速上手 SOP

> 适用版本：**V3.0**。目标：第一次使用者在 10 分钟内完成安装、验证和第一次真实学习任务。

## A. 安装

把下面整段发给 AI：

```text
请帮我安装以下两个模块：
k12-learning：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/k12-learning
llm-wiki：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/llm-wiki
```

安装路径和具体操作由 AI 自行处理。

想先浏览全部能力与可复制话术，查看 [K12 学习系统用户指南](../skills/k12-learning/references/system-user-guide.md)。日常不需要记住内部能力名称。

## B. 第一次学习任务

从手头任选一份近期课本、作业、试卷、错题或作文材料，复制这句话并一起发出：

```text
我是第一次使用，这是我最近的学习材料和自己的过程。请先基于材料做一次 3–5 分钟快速测评，不做全面测评、不让我填长问卷；形成一份有证据的初版学习 DNA，然后马上带我完成一个真实学习动作。跨会话保存前再单独问我。
```

验收：系统不要求从内部名称中选择，也不做全科问卷；只补最小信息，用材料完成 1–3 个短测评动作，输出会话内初版学习 DNA，并立即处理同一材料中的一个真实问题。未确认时不跨会话保存。

以下通用能力也直接自然表达：

- “用费曼方法追问我这个概念。”
- “我总犯同类错误，帮我找错误 DNA；没有足够证据就别下长期结论。”
- “用理科四步法带我做，但先不公布答案。”
- “给我设计一周跨学科侦探任务。”
- “三周后考试，先制定计划；我已有计划但总拖延，重点解决执行。”

验收：这些都是 `k12-learning` 内部能力，不需要额外安装。

## C. 建立或接入 Wiki（可选）

你不需要先理解目录结构。第一次只需选“新建”或“接入已有 Obsidian/Markdown 知识库”：

```text
我想新建一个学习 Wiki。请先用通俗语言说明结构和计划，等我确认后再创建。
```

```text
我有一个正在使用的 Obsidian/Markdown 知识库。请先盘点现有结构和本地规则，给增量适配计划；不要批量改名、搬空或覆盖已有笔记。
```

如果已选定一个目录或 vault，也可以这样说：

```text
使用 llm-wiki 适配这个目录：/绝对路径。先判断现状并列出计划，不覆盖或搬空已有文件；首次写入前等我确认。
```

空库确认后将采用：

```text
100-Raw/
200-Wiki/
300-Output/
999-Assets/
```

验收：已有库先读取本地规则并输出增量映射；新库在确认后创建四层和控制文件。批量迁移与删除仍要再次确认；只有任务确实需要 Obsidian 原生能力时，缺失的官方 `kepano/obsidian-skills` 会自动尝试安装，网络失败则继续普通 Markdown 流程。

把资料和学习结果沉淀进去时说：

```text
把这份资料入我的 Wiki。保留原始材料，提炼可复习的知识点；先展示会新增或更新哪些页面，再执行。
```

```text
把刚才已经确认的错因和方法写入我的 Wiki。只传这次任务所需的最小内容，写入前展示文件清单。
```

需要找回或检查已有知识时说：

```text
在我的 Wiki 里找与“函数单调性”相关的笔记和错因；只返回本次复习所需的摘要。
```

```text
检查我的 Wiki 的断链、孤儿页、来源和过期结论；先按严重程度列问题和修复计划，不要直接批量修改。
```

## D. 安装自动化（仅在需要时）

需要时告诉 AI：

请帮我安装 k12-automation：https://github.com/MingStudentSE/k12-education-skills/tree/main/skills/k12-automation。

需要真正启用夜跑时再说：

```text
请帮我启用夜间错题分析。
```

## E. 日常操作口令

- 完整学习话术：[学习系统用户指南](../skills/k12-learning/references/system-user-guide.md)。
- 查看/更正/删除长期状态：“查看我的学习档案”“更正……”“删除我的档案”。
- 会话不留存：“这次只在当前会话使用，不要保存。”
- 提醒控制：“查看提醒”“暂停提醒”“恢复提醒”“取消提醒”。
- Wiki 写入控制：“先预览变更”“这次不要写入”“撤销本次新增文件”。
- 路由解释：“刚才用了哪些内部方法，为什么？”

## F. 故障排查

| 现象 | 检查与处理 |
|---|---|
| 宿主仍显示几十个 Skill | 移走旧平级 Skill 目录，只保留四模块；刷新宿主 |
| 只复制了 `SKILL.md` 后能力缺失 | 重新复制整个模块目录，保留 references/schemas/scripts/assets |
| 学习请求被要求选 Skill | 明确使用 `k12-learning`；检查是否装的是旧 router 版本 |
| Wiki 要覆盖旧目录 | 停止写入，要求先读本地规则并输出增量映射 |
| 提醒说成功但没有任务 ID | 视为未创建；检查宿主是否有真实调度 adapter |
| 夜跑找不到教学契约 | 设置 `K12_LEARNING_ADAPTER` 为已安装 `k12-learning/references/adapters/night-analysis-v1.md` 的绝对路径 |
| 夜跑无授权仍继续 | 立即停止，保留证据并运行仓库 `bash pipeline/review.sh all` |

## G. 完成标准

满足以下条件即可投入日常使用：

- 宿主只暴露需要的 Product Module，不暴露内部 playbook。
- 首次使用可用一份材料在 3–5 分钟内形成会话内初版学习 DNA，并立即进入真实任务。
- 未确认时不跨会话保存画像、不写 Wiki、不提醒、不外传。
- 可选自动化先通过 mock，且真实运行有独立授权和可撤回入口。

维护者再安装 `k12-skill-studio`，并以 `bash pipeline/review.sh all` 作为发布前最低质量门。
