# K12 夜间错题分析 — 使用教学文档

> 适用对象：试点学生与家长（A 部分）、产线运营者（B 部分）
> 产线位置：当前仓库根目录；运行入口为 `engine/night-run.mjs`
> 版本：2026-06-15 仓库整合版

---

## A 部分：学生 / 家长使用指南

### 这是什么

一个"睡前交错题、早起拿方案"的服务。你晚上把当天的错题发过来，系统在夜里完成分析，第二天早上你会收到四份东西：

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| **晨报** | 一页总览：昨晚处理了几道题、建议使用顺序 | 早上第一眼看它 |
| **错因诊断** | 这道题为什么错（不是"粗心"，是具体机制）、是不是老毛病第几次犯 | 学生和家长一起读，5 分钟 |
| **变式训练题** | 3-5 道针对你的错因定制的题，从直击根因到迁移逐级加深 | **学生独立做，做完之前不许看答案** |
| **答案与讲解** | 变式题完整解答，讲解会点名"你的老毛病会在哪一步复发" | 做完后对照，重点看自己又卡住的那步 |

### 怎么交错题（睡前 5 分钟）

1. **拍照或打字**都行，发到约定的微信通道。一道题一条消息。
2. 必须包含三样东西，缺一样分析质量就会打折：
   - **题目原文**（拍照拍全，别裁掉条件）
   - **学生的卷面步骤**（错的过程比错的答案值钱十倍——**千万别擦掉重写**）
   - **一句话背景**（学生自己说"我当时怎么想的"，或家长补充老师批了什么）
3. **当晚 24:00 前**发的，第二天早上取货；过了点就排到下一晚。

### 正确的使用节奏（这部分是教学法，请认真执行）

1. **先读诊断，再做题**。诊断里会有"最想问你的 2 个追问"——学生先试着自己回答，再往下读。
2. **变式题必须先于答案**。直接看答案 = 这次分析白做。系统出题是按你的错因排的雷，你要自己踩一遍才知道排没排干净。
3. **触发"顽固弱项专项"时**（同一类错误犯满 3 次会自动触发），诊断里会给一张**专属自检清单**——之后做同类型题，无论多简单，都先把清单那几行写了。这是改习惯，不是做题。
4. **复测会自动安排**：专项触发后，次日和 3 天后的错题里混入复测题。别刻意准备，平常心做。

### 给家长的三句话

1. 报告里**不会出现"粗心、不认真、笨"**这类词——不是客气，是这些词在教学上没有信息量。报告说的是机制（比如"把去分母理解成了消去分母项"），请你也用机制跟孩子讨论。
2. 晨报适合早饭时间花 2 分钟过一遍；**别把诊断报告当成绩单追问**，它是修理手册不是审判书。
3. 孩子的错题档案归你们家所有（标准 Markdown 文件，随时可以打包带走或要求删除）。

### 数据授权说明

- 建档前需要监护人一次性书面同意（微信文字确认即可）。
- 系统记录的内容：错题原文、卷面步骤、错因分类、练习记录。**不记录**：成绩排名、与他人对比、任何课堂外的个人信息。
- 档案只用于给这个学生生成分析和练习，不共享给任何第三方。

## B 部分：运营者操作手册

### 新学生建档（2 分钟）

```bash
cd /path/to/k12-education-skills/students
mkdir -p stu-00X/{inbox,archive,outbox}
cat > stu-00X/profile.md <<'EOF'
---
id: stu-00X
name: XX同学
grade: 初二
subjects: [math]
authorized: true
authorized_by: 监护人（YYYY-MM-DD 微信书面同意建档）
---

# 学习画像（种子版）

- （已知倾向，没有就写"待积累"）
EOF
```

### 投料（收到学生错题后）

把错题转成 Markdown 丢进该学生 inbox，frontmatter 带 `subject`，决定调用哪个学科技能包。当前支持：

`math`、`physics`、`chinese`、`english`、`history`、`geography`、`politics`、`chemistry`、`biology`、`general`

```bash
cat > students/stu-00X/inbox/题目简称-序号.md <<'EOF'
---
subject: math
date: YYYY-MM-DD
source: 家长拍照转录
---

# 错题
（题目原文）

# 学生卷面步骤（原样转录）
（不要改写、不要纠正，错的就让它错着）

# 家长/学生补充
（原话）
EOF
```

照片暂时人工转录（OCR 接入是下一棒）。**转录铁律：卷面步骤逐字照搬，包括错误**——引擎要的是病灶证据。

### 晨检（每天早上 1 分钟）

```bash
tail -20 logs/night-$(date +%Y%m%d).log
ls students/*/outbox/$(date +%F)/
```

- 日志见 `✓ ... 完成` 且 outbox 有四件套 → 取货发给家长
- 见 `✗ ... 失败` → 该件留在 inbox，手动重跑：`node night-run.mjs --student stu-00X`
- 常见故障：CPA 号池抖动（ConnectionError，重跑即愈）、输出缺节（LLM 偶发，重跑即愈）

### 手动即时跑（不等夜里）

```bash
node engine/night-run.mjs --student stu-00X
```

### 红线（运营者也要守）

1. 产物先过你的眼再发家长——引擎偶发的称呼错误、LaTeX 渲染问题，人工兜底。
2. 不许手改 archive/ 里的档案内容（recurrence_count 是机器数的，改了顽固弱项判定就失真）。
3. 学生要求删档 → 整个 stu-00X 目录打包发还后删除，不留副本。
4. 引擎与技能包的任何改动走 GA 进化回路三闸口，**不许在生产目录直接改 night-run.mjs**。

## 已知边界（v1 诚实声明）

- 数学公式显示为 LaTeX 源码（`\[...\]`），微信里可读性一般——打磨中
- 暂只支持文字转录投料，拍照直传是下一版
- 一晚一个学生多道题没问题，但同一道题不要重复提交（会重复计入错因次数）
