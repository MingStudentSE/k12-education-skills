# K12 学习 Wiki 工作规则

> 将本文件复制为目标 Wiki 根目录的 `AGENTS.md`，并按实际情况修改方括号内容。已有 `AGENTS.md` 时只增量合并，不覆盖本地规则。

## 目标与边界

本 Wiki 用于沉淀经过确认的 K12 学习资料、概念、错因、方法和输出。日常教学由 `k12-learning` 完成；知识库结构与写入由 `llm-wiki` 完成；提醒和夜间运行由 `k12-automation` 完成。

未获明确确认时：

- 不建立或读取长期学习档案；
- 不把会话内容写入 Wiki；
- 不向外部模型、提醒渠道或其他系统传输；
- 不把一次错误或情绪固化为长期标签。

## 四层目录

```text
100-Raw/     来源快照，不改写正文
200-Wiki/    编译知识、SCHEMA、index、log
300-Output/  可复用或可分享的综合输出
999-Assets/  PDF、图片、音频等附件
```

`200-Wiki/SCHEMA.md` 是领域、命名、frontmatter、标签和页面阈值的单一来源。本文件只声明工作约束，不复制第二套 taxonomy。

## 写入流程

1. 明确任务、目标目录和允许变更范围。
2. 先读取本文件、`200-Wiki/SCHEMA.md`、`200-Wiki/index.md` 和日志最近 20–30 条。
3. 新来源先进入 `100-Raw/`；正文不可改写，来源变化时建立新 dated snapshot。
4. 只为有持续价值的概念、方法、人物或错因建立 `200-Wiki/` 页面。
5. 普通问答留在会话；昂贵且可复用的综合才进入 `300-Output/`。
6. 每次 material write 同步 index，并向 append-only log 追加记录。
7. 创建、移动、重命名、归档或删除后重扫 wikilink/embed；不创建空占位页掩盖断链。

批量迁移、删除、归档、安装依赖，或单次更新超过 10 个既有页面前，先展示文件清单并等待确认。

## 学习数据规则

- 只保存本次任务所需的最小字段；真实姓名、联系方式、证件、住址、医疗、财务和家庭纠纷不写入。
- “学习 DNA”必须基于多次证据或用户确认；允许查看、更正、删除和本次不记忆。
- 错因使用可训练机制描述，如“条件转译遗漏”，不用“粗心、不认真、能力差”。
- 政史地只训练证据和论证，不评价学生个人政治立场或价值取向。
- 家长或教师查看、导出学生内容前，确认授权主体和范围。

## 命名与来源

- 文件名使用 lowercase kebab-case；不确定规则时先查 `200-Wiki/SCHEMA.md`。
- 每个可验证结论保留来源、日期和置信度；冲突观点并列记录，不静默覆盖。
- 引用 `100-Raw` 时链接到具体快照；不要把 URL 当作唯一来源副本。
- 附件放 `999-Assets/`，知识页使用相对链接或合法 embed。

## 完成报告

只报告真实完成的读取、创建、修改、跳过和未解决项。报告应包含：

- 变更文件清单；
- 新增/更新的 index 与 log；
- 断链、冲突、缺失来源或待确认事项；
- 是否涉及长期状态或外部传输。
