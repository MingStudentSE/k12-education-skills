# 学习科学原则接入规范

本文档把 `references/大脑记忆与表达12个认知原理.md` 中的 12 个认知原理转化为本仓库教育 SKILL 的维护标准。完整理论索引见 `references/理论资料索引.md` 与 `references/K12教育SKILL理论基础总表.md`。

## 使用边界

- 根目录 `references/` 记录理论来源和项目级研究材料。
- 单个 SKILL 的运行参考仍必须放在该 SKILL 自己的 `references/` 或 `schemas/` 下。
- 因此，SKILL 正文可以吸收这些原则，但不要在 frontmatter `references:` 中引用 `../../references/...`。
- 学习区、85% 熟悉内容和 15% 意外挑战的定义记录在 `references/学习区.md`、`references/85-15意外挑战.md`。

## 每个教育 SKILL 的最低要求

新增或大改 SKILL 时，至少检查以下 8 项：

1. **单目标**：一轮输出只推进一个主要学习目标，避免多任务切换。
2. **先激活**：讲新内容前，先用问题、误区、例子或旧知识激活正确框架。
3. **少文字冲突**：不要同时要求学生读长文、听长解释、做复杂操作。
4. **结构化表达**：能用图、表、步骤、固定版式时，不只堆段落。
5. **主动回忆**：必须让学生先讲、先写、先答、先预测，再给总结。
6. **错误反馈**：错误要形成根因、修正、再犯预警和变式验证。
7. **交错与迁移**：掌握同类题后，加入相似易混、跨章节或换场景任务。
8. **分散复习**：重要知识点要安排后续复测，不把复习留到最后一次。

## 推荐 frontmatter 标签

当某个 SKILL 明确强化这些原则时，可在 `tags` 中加入：

```yaml
tags: [主动回忆, 错误反馈, 分散练习, 交错练习, 学习区]
```

不要为了凑标签而全部加入；只标注该 SKILL 真正承担的部分。

## 推荐正文段落

核心 SKILL 可在“通用边界与降级策略”后加入一个短段：

```markdown
## 学习科学约束

- **单目标**：本轮只推进一个学习目标，不同时要求学生阅读长材料、听长解释和完成复杂操作。
- **主动回忆**：先让学生输出自己的理解，再给提示、答案或总结。
- **错误反馈**：错误必须变成下一步练习，而不是只被解释。
- **分散复习**：重要结论要进入后续复测或提醒。
```

不同 SKILL 应根据职责改写，而不是机械复制。

## 重点 SKILL 接入分工

| SKILL | 主要承担的原则 |
|-------|----------------|
| `educational-skill-creator` | 新 SKILL 创建时的 12 原理检查清单 |
| `correction-notebook` | 错误促进学习、变式验证、再犯预警 |
| `feynman-learning` | 主动回忆、故事化表达、迁移与批判性验证 |
| `cornell-notes` | 固定版式、线索回忆、分散复习 |
| `learning-plan` | 分散练习、交错练习、学习区和适度压力 |
| `time-focus-coach` | 反多任务、单时间块单目标、情境记录 |
| `weekly-review` | 检查主动回忆、错误反馈、交错、分散复习是否发生 |

## 周期性维护检查

每次新增、恢复、重命名或大改 SKILL 后，维护者应确认：

- 新 SKILL 是否声明了它承担哪些学习科学原则。
- 输出模板是否让学生发生主动回忆，而不是只读 AI 总结。
- 计划和提醒是否包含分散复习。
- 错误处理是否包含变式验证和再犯预警。
- 是否避免了“解释很多、任务很多、学生只负责看”的低效模式。
