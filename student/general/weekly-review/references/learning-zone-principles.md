# 学习区原则

> 本文件随 `weekly-review` 单个 skill 安装，用于周复盘时检查学生是否真的待在学习区。

## 三个区域

```text
熟悉区：几乎全会，但新增学习量低
学习区：大部分能处理，少量内容带来意外和挑战
挫败区：大量不会，持续卡住，容易只等答案
```

周复盘不只看完成率，还要看任务是否处在学习区。

## 周复盘判断信号

```text
正确率：是否大约能做对 80%-90%
解释率：做对后能否说出理由
意外点：本周是否出现少量“原来还能这样”的新信息
情绪状态：是否有挑战感，但没有明显崩溃或逃避
迁移证据：是否能做变式、换场景或讲给别人听
```

## 85%规则

有效训练中，大约 85% 是学生熟悉或基本能处理的内容，大约 15% 是带来意外、迁移或新理解的挑战。

复盘时不要把它算成精确分数，而是用来判断：

- 本周是不是太熟了
- 本周是不是太难了
- 本周有没有足够但不过量的意外挑战

## 复盘追问

```text
这周哪些任务太熟，只是在重复？
哪些任务刚好有挑战，但你能撑住？
哪些任务明显太难，需要拆小或补前置？
本周最大的一个意外发现是什么？
这个新发现和旧知识有什么连接？
下周要保留、加难还是降难？
```
