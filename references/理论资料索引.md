## 与单个 SKILL references 的关系

根目录 `references/` 是项目级理论库。
单个 SKILL 目录下的 `references/` 是运行时随包资料。

规则：

- 项目级理论先记录在根目录 `references/`。
- 如果某个 SKILL 运行时需要使用该理论，则在该 SKILL 自己的 `references/` 放精简版。
- `SKILL.md` 的 frontmatter `references:` 不引用根目录文件，避免单个 SKILL 独立安装后缺失依赖。

## 后续维护清单

- 新增理论前，先查本索引是否已有同类理论。
- 一个理论写一个 Markdown 文件；不要把多个理论合并成一个笔记。
- 如果是某个学科内部资料，只放在对应 SKILL 的 `references/`；如果会影响多个 SKILL，也补充到根目录理论库。
- 每次把聊天中的理论判断转成系统规则时，都要确认是否需要新增或更新根目录理论文件。
