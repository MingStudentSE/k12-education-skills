# 项目式学习

## 核心定义

学生围绕真实问题持续探索、产出作品和复盘过程，比孤立刷知识点更容易形成意义感和迁移能力。

## 项目式任务要素

1. 一个真实问题。
2. 多学科知识连接。
3. 可观察产出。
4. 阶段性反馈。
5. 最终展示或复盘。

## 落地 SKILL

- `cross-subject-detective`：侦探周流程。
- 学科专项：把知识点接入真实表达、实验、写作、建模。

## 实践案例与效果

- PBLWorks、High Tech High、New Tech Network 是常见项目式学习实践案例。
- 严谨 PBL 可以提升参与度、真实问题解决和部分学科学业成果；实施成本高，需要明确评价量规、内容知识支架和阶段反馈。
