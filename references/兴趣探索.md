# 兴趣探索

## 核心定义

兴趣不是靠想象确定，而是在多次低成本真实体验中验证出来的。

## 判断维度

- 内容偏好：学生被什么主题吸引。
- 挑战反应：遇到困难后还愿不愿意继续。
- 时间感：是否出现投入后忘记时间。
- 外部反馈：作品、表达或行动是否得到真实反馈。

## 落地 SKILL

- `interest-explorer`：52 杯咖啡、兴趣 DNA、批判性验证。
- `cross-subject-detective`：项目式跨科探索。
- `learning-dna`：兴趣摘要和跨学科连接。
- `english-listening-trainer`：用兴趣话题生成个性化材料。
