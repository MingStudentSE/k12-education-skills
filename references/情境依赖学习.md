# 情境依赖学习

## 核心定义

学习表现会受环境、设备、声音、情绪、身体状态影响。学习时的情境可能成为记忆和表现的一部分。

## 为什么要记录情境

情境记录能避免误判：

- 不是不会，而是太困。
- 不是不自律，而是任务设计过难。
- 不是粗心，而是考试焦虑或时间压力。
- 不是能力差，而是多任务切换太多。

## 推荐字段

```text
地点：
设备：
噪音：
身体状态：
情绪状态：
时间压力：
是否模拟考试环境：
```

## 落地 SKILL

- `time-focus-coach`：记录学习情境。
- `correction-notebook`：记录做错时状态。
- `learning-plan`：考试训练尽量模拟考试环境。
