# 错误驱动学习

## 核心定义

错误不是学习失败的证据，而是心理模型和现实反馈之间的差距。

真正有价值的错题处理，不是订正答案，而是定位差距、修正模型、预防再犯。

## 错误闭环

```text
错误出现
  → 记录情境
  → 分类错因
  → 找根因
  → 修正理解或策略
  → 形成再犯预警
  → 同类题验证
  → 易混/变式/跨场景验证
  → 间隔复测
  → 写入趋势
```

## 落地 SKILL

- `correction-notebook`：通用错题记录、四维错因、弱项预警。
- 各学科 `*-error-dna`：深度错因和顽固弱项追踪。
- `weekly-review`：错题趋势、错误反馈是否发生。

## 实践案例与效果

- ASSISTments 在学生作答后提供即时反馈、提示和教师报告；MATHia 用知识组件追踪错误模式。
- 错误驱动学习不是让学生反复失败，而是让错误后马上发生解释、比较、修正和再测。
