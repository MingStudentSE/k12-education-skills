# 间隔重复

## 核心定义

一次集中复习不如多次分散复习。复习间隔应随着掌握程度动态调整。

## 基础节奏

```text
当天 → 1天后 → 3天后 → 7天后 → 14天后 → 30天后
```

## 内容类型

- 概念类：用自己的话解释。
- 记忆类：默写、填空、闪卡。
- 应用类：变式题或新场景题。
- 错题类：同类题 + 易混题 + 再犯预警。

## 落地 SKILL

- `im-reminder`：五轮提醒、动态调整复习间隔。
- `english-vocabulary-dna`：词汇 24h/3d/7d/14d/30d 复习。
- `learning-plan`：计划中加入复测节点。
- `cornell-notes`：笔记条目记录建议复测时间。
