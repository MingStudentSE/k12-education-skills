# 间隔重复

## 核心定义

一次集中复习不如多次分散复习。复习间隔应随着掌握程度动态调整。

## 基础节奏

```text
当天 → 1天后 → 3天后 → 7天后 → 14天后 → 30天后
```

## 内容类型

- 概念类：用自己的话解释。
- 记忆类：默写、填空、闪卡。
- 应用类：变式题或新场景题。
- 错题类：同类题 + 易混题 + 再犯预警。

## 当前落地

- `k12-automation`：经授权执行提醒；复习间隔和内容仍由学习任务决定。
- `english-vocabulary-dna`：词汇 24h/3d/7d/14d/30d 复习。
- `learning-plan`：计划中加入复测节点。
- `cornell-notes`：笔记条目记录建议复测时间。

## 参考文献

- Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006). Distributed Practice in Verbal Recall Tasks: A Review and Quantitative Synthesis. Psychological Bulletin. https://www.yorku.ca/ncepeda/publications/CPVWR2006.html
- Settles, B., & Meeder, B. (2016). A Trainable Spaced Repetition Model for Language Learning. ACL. https://research.duolingo.com/papers/settles.acl16.pdf

## 实践案例与效果

- Anki、Quizlet、Duolingo 都把复习间隔产品化，用遗忘风险安排再次提取。
- Duolingo 的 half-life regression 模型用大规模学习日志预测词项记忆半衰期，用于个性化复习安排；具体学习效果仍取决于卡片质量、复习遵守率和是否加入应用任务。
