# 学习区

## 核心定义

学习任务大致分为三个区：

```text
熟悉区：几乎全会，练习顺畅，但新增学习量很低。
学习区：大部分能处理，少部分会意外，最适合成长。
挫败区：大量不会，持续卡住，容易放弃或只等答案。
```

本体系默认优先把任务放在学习区，而不是追求题量最大或难度最高。

## 判断信号

- 熟悉区：完成很快，连续正确，但没有新发现，也说不出迁移点。
- 学习区：大部分能做，少数点会卡；学生还能解释错误并愿意继续尝试。
- 挫败区：连续不会、沉默、明显焦虑、只等答案或想放弃。

## 调参动作

| 区域 | 调参 |
|------|------|
| 熟悉区 | 加变式、迁移、易混题、费曼解释或换场景测验 |
| 学习区 | 保持节奏，安排间隔复测，逐步减少提示 |
| 挫败区 | 拆小任务、补前置、改成选择/判断/样例模仿，先恢复掌控感 |

## 落地 SKILL

- `learning-plan`：每个任务标注学习区。
- `skill-coordinator`：发现系统过易或过难时建议调参。
- `weekly-review`：回看本周学习区命中情况。
- `science-solving-four-steps`：用单题变式、口头解释和复测验证掌握。

## 实践案例与效果

- Khan Academy、MATHia 等自适应学习产品都把任务放在“略高于当前掌握”的区域，通过练习表现调节后续题目。
- 实践重点不是一味变难，而是持续观察正确率、求助次数、情绪和迁移表现，及时在舒适区、学习区和挫败区之间调节。
