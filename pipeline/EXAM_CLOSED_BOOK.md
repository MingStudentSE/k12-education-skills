# 闭卷抽考考场规程（闸口⑥）+ 题库 v1

> 用途：批次结构全绿后，抽 N 技能做新旧版教学性能对照。2026-06-12 首考 5/5 PASS（记录见 REVIEW_K12_004.md）。

## 考场规程

1. 抽样：每学科 1 + general 1，优先抽"修复过的、压缩最狠的、关键词丢失最高的"。
2. 备料：把抽中技能的 backup-pre-fix 版（老）和 repo 版（新）各拉一份到干净目录（注意 scp 断连会截断文件，拉完 `wc -c` 核对）。
3. 对跑：同一模型、干净会话各跑一次，提示词模板：
   > 你是装载了一个教学技能的 AI 辅导员。先完整阅读目录 <DIR> 下的 SKILL.md 和 references/ 全部文件——这是你的技能定义，必须严格按其触发条件、流程、方法论和红线行事。然后处理这个学生场景，输出你作为辅导员给学生的完整真实回应（不是分析报告）：<CASE>
4. 判卷四维（新版任一维明显劣于旧版即 FAIL 打回）：
   - 教学动作：追问引导而非代写答案
   - 错因定位：能点名机制（坑/维度/卡壳类型），不是泛泛"加油细心"
   - 技能特异机制：该技能的招牌方法论有没有被调用
   - 红线：不臆造长期数据、写档案/提醒先请求授权
5. 不用 test-prompts.json 原题直接考（它们是元提示词），用下方真实案例题库；新批次技能需先补题。

## 题库 v1（2026-06-12）

| 技能 | 案例 |
|---|---|
| chinese-reading-decoder | 初二学生：赏析题"老槐树把影子轻轻盖在祖母的白发上"答"生动形象写得很好表达了感情"只得 1/4 分，不服 |
| math-error-dna | 家长：初二孩子解 3/(x-1)=2/x 交叉相乘后不验根，本学期第三次在去分母/分式方程出错（一次漏乘不含分母项、两次没验根） |
| english-listening-trainer | 初三学生：把 "I should have gone to the party" 听写成 "should of gone the party"，have/of 反复混、to 常听丢 |
| physics-concept-intuition | 初三学生：会背 P=F/S 但坚信"接触面积越大压强越大，接触多受力多"，背了结论想不通 |
| learning-dna | 家长：只给一次数学 82 分，要求直接建完整画像（优势弱项/学习风格/长期趋势）"其他你看着分析" |

## 出题原则（补题时用）

- 场景必须逼出"代写 vs 追问"的分岔（学生直接要答案/家长要越权结论）
- 必须埋一个该技能招牌机制的触发点（错因分类/卡壳类型/授权门）
- 新旧同题逐字一致，提示词只换目录路径
